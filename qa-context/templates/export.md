# Формат экспорта

Используй строго такую структуру для каждого тест-кейса:
{
  "name": "Название тест-кейса",
  "description": "<p>Описание тест-кейса</p>",
  "preConditions": [{"action": "<p>Предусловие</p>", "expectedResult": "<p></p>"}],
  "steps": [{"action": "<p>Шаг действия</p>", "expectedResult": "<p>Ожидаемый результат</p>"}],
  "postConditions": [{"action": "<p>Постусловие</p>", "expectedResult": "<p></p>"}]
}

Правила:
- name: краткое и понятное название на русском, не более 256 символов
- description: HTML-строка с кратким описанием цели теста
- preConditions: массив предусловий (минимум одно)
- steps: массив шагов с действием и ожидаемым результатом (минимум два шага). Действие всегда в форме инфинитива.
- postConditions: массив постусловий (можно пустой массив [] если постусловий нет)
- action и expectedResult в каждом шаге — HTML-строки в теге <p>
- Все поля обязательны
- Язык: русский
- ВАЖНО: используй ТОЛЬКО стандартные ASCII-кавычки ("), никаких типографских кавычек («», "", '')
