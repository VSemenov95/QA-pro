# Правила для агента

Строго следуй этим правилам:
- Если нужно выставить переменной какое-то значение, то укажи это в том числе.
- Если нужно создать что-то в предусловиях, чтобы пройти основной тест, то напиши об этом. По возможности подробно и через API.
- Не указывай в названии теста название топиков кафка, лучше в шагах
- Если предусловий несколько, не нужно все писать в одном блоке, разделяй на несколько
- Если нужно отправить/подготовить сообщение в кафку, тело запроса/ответа или запрос в БД в предусловиях или же в шаге, то пиши в формате:  </p>\n<p></p>\n<pre data-id=\"eb6498da-822e-4387-9bce-3ca8bc36ab2a\" style=\"height: 47.986114501953125px\">
{"Ключ1":"Значение1","Ключ2":"Значение2»} </pre>\n<p></p>. Не нужно оборачивать это в json``` ```, sql ``` ```
- В предусловиях не нужно писать "action" и "expectedResult".
- Если postcondition никакого нет, то оставляй блок полностью пустым
- В шагах не нужно ставить лейбл по типу [БД], [Web] и так далее
- В каждом API тесте должен в шагах, где нужно вызвать API должен быть указан метод, пример запроса и пример ответа
- Выставляй в тестах automationStatus = A3_READY_TO_AUTOMATE
- Выставляй в тестах: statusId=0ce83c7e-5080-11f1-96c8-005056053b2e
- Приоритет = P3_MAJOR не бывает
