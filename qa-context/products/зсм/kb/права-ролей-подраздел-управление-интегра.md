# Права ролей: подраздел «Управление интеграцией»

> Подраздел «Управление интеграцией» вкладки «Администрирование» ЗСМ: каталоги и карточки точек подключения и точек интеграции с правами на просмотр, добавление, редактирование, отключение и удаление, а также API получения списка точек интеграции.

### Описание
- Вкладка «Администрирование» содержит подраздел «Управление интеграцией» с правом «Просмотр» (read). (200-Описание ролевой модели ЗСМ)
- GET /admin/integration-point — «Получение списка точек интеграции». (portalbackend)

### Экраны и навигация
- Вкладка «Администрирование» → подраздел «Управление интеграцией». (200-Описание ролевой модели ЗСМ)
- Каталог точек подключения → Карточка точки подключения. (200-Описание ролевой модели ЗСМ)
- Каталог точек интеграций → Карточка точки интеграции. (200-Описание ролевой модели ЗСМ)

### Поля и элементы
- Пункт 89: Вкладка «Администрирование» с подразделом «Управление интеграцией»: Просмотр (read). (200-Описание ролевой модели ЗСМ)
- Пункт 90: Каталог точек подключения: Просмотр (read). (200-Описание ролевой модели ЗСМ)
- Пункт 91: Карточка точки подключения: Просмотр (read); Добавление (create); Удаление (delete); Окончательное удаление (delete-full, задача PPMON-1144); Отключение (switching_off). (200-Описание ролевой модели ЗСМ)
- Пункт 92: Каталог точек интеграций: Просмотр (read). (200-Описание ролевой модели ЗСМ)
- Пункт 93: Карточка точки интеграции: Просмотр (read); Добавление (create); Редактирование (update); Отключение (switching_off). (200-Описание ролевой модели ЗСМ)

### API и интеграции
- GET /admin/integration-point — «Получение списка точек интеграции». Параметры: filterDto (в запросе, object, обязательный). (portalbackend)
- Ответ 200 — OK: itemsCount (integer, int64) — Общее число элементов; items (массив) — Элементы на странице. (portalbackend)
- Элемент items: id (integer, int64) — Идентификатор; name (string) — Наименование; description (string) — Описание; sourceId (string) — Идентификатор источника; expirationDays (integer, int32) — Количество дней с даты последнего значения метрики, после которых метрика считается неактуальной; filterRules (string) — Правило фильтрации; metricRules (string) — Правило резолвинга метрик; namingRules (string) — Правило определения имени метрики; groupingRules (string) — Правило резолвинга коллекций; ciRules (string) — Правило резолвинга КЕ; status (string: CREATED | PROCESSING | CONNECTED | ERROR) — Статус; connectedCollectionsCount (integer, int64) — Количество подключенных коллекций. (portalbackend)

### Роли и права
- Ссылка на задачу PPMON-1144 (окончательное удаление). (200-Описание ролевой модели ЗСМ)
- Знаки по ролям в документе разорваны, соответствие прав конкретным ролям восстановить невозможно. (200-Описание ролевой модели ЗСМ)

### Открытые вопросы
- Какие роли имеют какие права в подразделе — в источнике не восстанавливается. (200-Описание ролевой модели ЗСМ)
