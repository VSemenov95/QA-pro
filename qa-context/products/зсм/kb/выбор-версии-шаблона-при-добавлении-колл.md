# Выбор версии шаблона при добавлении коллекции и отображение версии в коллекциях

> При добавлении коллекции метрик пользователь выбирает фиксированную версию выбранного шаблона, а название шаблона и версия отображаются в списке коллекций, в карточке коллекции и в черновике заявки.

### Описание
- Доработка управления экземплярами коллекций в рамках стори PPPM-5796 US-Q3-3 «Версионирование шаблонов коллекций». Сценарий 1.0 «Доработка добавления коллекции — выбор версии при добавлении коллекции» (Коллекция метрик /create). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Раздел «Доработка отображения коллекций метрик»: 2.0 «Просмотр отображения плашки шаблона и версии в карточке коллекции (в списке и в самой карточке)» (Карточка объекта мониторинга /read, Коллекция метрик /read); 2.1 «Отображение плашки версии коллекции в черновике заявки» (Коллекция метрик /update). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Экраны и навигация
- Скриншоты дизайна: просмотр карточки коллекции в ОМ (номер версии в списке коллекций и в карточке коллекции); выбор версии шаблона при добавлении коллекции (выбор шаблона, затем выбор версии после выбора шаблона). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- В 4.2.2 также есть скриншот «выбор версии при массовых изменениях». (59-230. Версионирование шаблонов коллекций)
- 2.0, список ОМ: при открытии ОМ у каждой коллекции отображаются название шаблона + версия в формате "%Название шаблона% } Версия %номер версии%". (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 2.0, карточка коллекции: под заголовком версии отображаются название шаблона и версии в том же формате. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 2.1, карточка черновика коллекции, созданного для добавления или изменения коллекции: отображаются название и версия шаблона; требования к виду и формату те же, что в 2.0. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Поля и элементы
- Элемент выбора версии расположен рядом с выбором шаблона; тип — выпадающий список; по умолчанию выбрана самая последняя версия (с самым высоким номером). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Доступны только фиксированные версии, т.е. сохранённые при редактировании шаблона как отдельные версии (см. п. 4.1, сценарий 1.4). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- При выборе значения версии форма добавления коллекции целиком перестраивается данными из шаблона (как при выборе нового шаблона). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Элемент обязательный; выделяется красным при попытке создать черновик без его заполнения. (57-230. Версионирование шаблонов коллекций)
- При выборе значения версии появляется кнопка добавления в черновик; при снятии выбора версии кнопка пропадает и текущее заполнение формы сбрасывается. (59-230. Версионирование шаблонов коллекций)

### Бизнес-правила и ограничения
- Черновик шаблона для выбора недоступен (только фиксированные версии). (57-230. Версионирование шаблонов коллекций)
- Название версии отображается всегда целиком; название шаблона отображается так, чтобы вместилось название версии (если название больше выделенной области — часть скрывается за "..."). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Отображается название шаблона на момент добавления коллекции из шаблона. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Если у коллекции нет шаблона (внешняя коллекция или связь с шаблоном не определена) — название шаблона и версия не отображаются. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Версия в карточке черновика: при добавлении коллекции — версия, выбранная при добавлении; при ручном или массовом изменении — текущая версия шаблона, на основании которого сделана коллекция; при обновлении коллекции — версия, на которую обновляется черновик (завязано на 1826, пока не делаем). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Роли и права
- Роли: Ответственный ИС (в пределах своих ИС), Инженер ЗОНТ. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 2.0: права Карточка объекта мониторинга/read, Коллекция метрик/read. 2.1: право Коллекция метрик/update. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Сценарии
- Сценарий 1.0: 1) пользователь вызывает форму добавления коллекции согласно RI1 «Возможность Пользователя добавить коллекцию метрик для объекта мониторинга в карточке мониторинга» и видит форму выбора шаблона; 2) выбирает шаблон аналогично текущей логике; 3) видит элементы выбранного шаблона самой последней фиксированной версии (с самым высоким номером); 4) видит рядом с выбором шаблона новый элемент выбора версии; 5) после успешного создания черновика заявки на добавление в нём отображается версия, после успешного добавления коллекции для неё отображаются название шаблона + версия (подробнее — сценарий 2.0 и далее; текст фрагмента обрезан). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Расхождения между документами
- Название кнопки: в 59-230 в одном месте «сохранить в черновик», в другом «СОХРАНИТЬ ЧЕРНОВИК»; в 57-230 кнопка не упомянута.
