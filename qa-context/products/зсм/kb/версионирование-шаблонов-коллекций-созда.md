# Версионирование шаблонов коллекций: создание шаблона и просмотр версии в карточке

> Создание шаблона коллекции с автоматическим созданием первой версии и просмотр карточки первой версии шаблона (только чтение, плашка версии, кнопка «Создать черновик»).

### Описание
- Сценарий 1.0 «Создание шаблона с автоматическим созданием первой версии»: пользователь добавляет шаблон по ранее реализованной логике (RI1 «Возможность пользователя добавить шаблон коллекций в Каталоге шаблонов коллекций»). Создаются сам шаблон коллекции, доступный для просмотра в списке коллекций, и первая версия шаблона, заполненная значениями по умолчанию согласно преднастройкам типа коллекции (логика связи шаблонов и версий — в интеграционных требованиях). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Первая версия шаблона доступна для: добавления коллекции (см. 4.2, сценарий 1.0); использования в массовом редактировании (см. 4.2, сценарий 1.1); обновления коллекции на эту версию (см. 1826. Реализация точечного обновления коллекции из шаблона). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Сценарий 1.1 «Просмотр карточки первой версии шаблона коллекции»: предусловия — выполнен сценарий 1.0, пользователь открывает карточку шаблона; система отображает карточку согласно [US] «Просмотр карточки шаблона» с учётом изменений, описанных в разделе. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Экраны и навигация
- Шаблон, открытый на просмотр, показывает актуальную версию, недоступную для редактирования, и кнопку создания черновика. Кнопки «Удалить шаблон» (доступна всегда) и «Добавить метки» (недоступна) отображаются в виде иконок (скриншот 2 в 59-230). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Карточка шаблона коллекции: объект ролевой модели /create (сценарий 1.0) и /view (сценарий 1.1). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Переход к другим версиям через плашку версии описан в сценариях 3.0–3.3. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Поля и элементы
- Все элементы на вкладках «Общие сведения», «Атрибуты», «Метрики» недоступны для редактирования, все кнопки на вкладках неактивны. Можно открыть карточку метрики/атрибута для просмотра, но нельзя ничего изменить. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Кнопка «Добавить метку» недоступна для нажатия (изменение дизайна — теперь иконка). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Кнопка «Удалить шаблон» доступна для нажатия всегда, при нажатии срабатывают новые ограничения (см. сценарий 4.0). Изменение дизайна — теперь иконка. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Новый элемент — кнопка «Создать черновик». Отображается только если черновик не создан. Доступна для нажатия только пользователю с правами на создание шаблона (Инженер ЗОНТ). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Новый элемент под названием шаблона — плашка версии с номером текущей версии (для первой версии написано «Версия 1»). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Роли и права
- Сценарий 1.0 (создание шаблона с автоматическим созданием первой версии): Инженер ЗОНТ. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Сценарий 1.1 (просмотр карточки первой версии): Инженер ЗОНТ, Ответственный ИС, Аудитор ИБ, Аудитор ДВА. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Кнопка «Создать черновик» — только Инженер ЗОНТ. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Сценарии
- Сценарий 1.0: создание шаблона с автоматическим созданием первой версии. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Сценарий 1.1: пользователь открывает карточку шаблона, система отображает её согласно [US] «Просмотр карточки шаблона» с учётом изменений раздела. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
