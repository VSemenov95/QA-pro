# Массовое редактирование коллекций: таблица правил фильтрации

> Таблица правил фильтрации (раздел 2.1.1) массового поиска и изменения коллекций в разрезе ИС/шаблона: для каждого типа условия и параметра задаёт доступные операции сравнения и элемент ввода.

### Описание
- Таблица (раздел 2.1.1) задаёт для каждого типа условия и параметра, какие операции доступны и какой элемент ввода используется. Колонки: Тип условия фильтрации; Тип фильтра (параметр); Равно/Не равно; Содержит/Не содержит; Начинается с/Не начинается с; Заканчивается на/не заканчивается на; Заполнено/Не заполнено; >,<,>=,<=; Элемент для поиска; Принцип заполнения (для всех типов фильтра, кроме Заполнено/Не заполнено). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Обозначения: Р = Равно/Не равно; С = Содержит/Не содержит; Н = Начинается с/Не начинается с; З = Заканчивается на/не заканчивается на; Зап = Заполнено/Не заполнено; Cмп = >,<,>=,<=. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Поля и элементы
**Параметр коллекции**
- Название коллекции: Р, С, Н, З доступны; Зап, Cмп недоступны; поле для ввода (текст в одну строку). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Метки коллекции: Р, С доступны; Н, З недоступны; Зап доступно; Cмп недоступно; выпадающий список с выбором 1 значения. Метки соответствующих типов согласно ролевой модели (Описание ролевой модели ЗСМ, п. 2.1.1 «Работа с метками на уровне экземпляра коллекций метрик/отдельных метрик»). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Признак бизнес-сервиса: Р, С, Н, З недоступны; Зап доступно; Cмп недоступно; нет элемента для заполнения. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Комментарий (в документе строка записана как «Пока не получается Комментарий»): Р, С, Н, З доступны; Зап доступно; Cмп недоступно; область для ввода (текст в несколько строк, по введённой маске). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

**Атрибут шаблона** (название вида «%Название переменной%»). Ограничения при заполнении аналогичны «Правилам обработки атрибутов разных типов в экземпляре коллекции». Везде ниже Зап «доступно, если атрибут необязательный», кроме Сетевая зона и Булево (там Зап доступно). Cмп недоступно везде, кроме Число и Дробь.
- Сетевая зона: Р; С, Н, З недоступны; Зап доступно; выпадающий список с 1 значением (выбор сетевой зоны). 
- Строка: Р, С, Н, З; поле для ввода (текст в одну строку, по маске).
- Текст: Р, С, Н, З; область для ввода (текст в несколько строк, по маске).
- Число: Р; С, Н, З недоступны; Cмп доступно; поле для ввода (число без разделителя).
- Дробь: Р; С, Н, З недоступны; Cмп доступно; поле для ввода (число с разделителем).
- Булево: Р, С, Н, З недоступны; Зап доступно; нет элемента для заполнения.
- ТУЗ: Р; С, Н, З недоступны; выпадающий список с выбором 1 значения. Отображаются только ТУЗ, доступные для ХОТЯ БЫ ОДНОЙ выбранной ОМ, отобранной для фильтрации на первом шаге. Если ни одна ОМ не выбрана, отображаются все ТУЗ, которые можно выбрать хотя бы в одном ОМ ИС, для которой выполняется поиск и замена.
- Перечень/Базы данных: Р; С, Н, З недоступны; выпадающий список с выбором 1 значения (БД из фиксированного списка).
- Перечень/расписание: Р; С, Н, З недоступны; выпадающий список с выбором 1 значения. Инженер ТУЗ может выбрать все расписания. Ответственный ИС может выбрать: 1. Все системные без ИС; 2. Все системные расписания, в ИС которых присутствует текущая ИС; 3. Все пользовательские расписания, в ИС которых присутствует текущая ИС.
- Список: Р, С, Н, З; поле для ввода (значение, по которому идёт поиск среди всех строк списка). Пример: для «равно» будут отобраны все коллекции, у которых есть атрибут типа «Список» с хотя бы одной строкой с указанным значением.
- Точка подключения: Р; С, Н, З недоступны; выпадающий список с выбором 1 значения (все точки подключения в статусе «Добавлено»/«Подключено»). Должны быть доступны ТП, для которых выбраны ТУЗ, по которым можно фильтроваться (см. ТУЗ).
- Массив (ключ): Р, С, Н, З; поле для ввода (поиск среди всех ключей массива). Массив script_args доступен, если в шаблоне выбран скрипт.
- Массив (значение): Р, С, Н, З; поле для ввода (поиск среди всех значений массива). Массив script_args доступен, если в шаблоне выбран скрипт.
- Подстановка из ТУЗ: Р; С, Н, З недоступны; выпадающий список с выбором 1 значения; для каждого списка отображаются название подстановки и тип ТУЗ; выбор из списка ТУЗ, ограничения как для ТУЗ.
(50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

**Параметр метрики**
- Название метрики: Р, С, Н, З доступны; остальные колонки записаны так: «Доступно если в шаблоне выбран скрипт», «недоступно», «Недоступно», «Поле для ввода».
- Тип метрики: Р; С, Н, З, Зап, Cмп недоступны; выпадающий список с выбором 1 значения (регулярная, метрика-контейнер, метрика скрипта).
- Активность: Р, С, Н, З недоступны; Зап доступно; Cмп недоступно; нет элемента для заполнения.
- %Уровень порога%/Группа рассылки: Р; С, Н, З недоступны; Зап доступно; Cмп недоступно; выпадающий список с выбором 1 значения (все группы рассылок ЕСМ).
- %Уровень порога%/Правило реагирования: Р; С, Н, З недоступны; Зап доступно; Cмп недоступно; выпадающий список с выбором 1 значения (все локальные правила реагирования, доступные для этой ИС).
- %Уровень порога%/Описание порога: Р, С, Н, З; Зап доступно; Cмп недоступно; область для ввода (текст в несколько строк, по маске).
- Метки метрики: Р, С; Н, З недоступны; Зап доступно; Cмп недоступно; выпадающий список с выбором 1 значения (метки соответствующих типов согласно ролевой модели, п. 2.1.1 «Работа с метками на уровне экземпляра коллекций метрик/отдельных метрик»).
- Категории: Р, С; Н, З недоступны; Зап доступно; Cмп недоступно; выпадающий список с выбором 1 значения (метка типа «Категория» согласно ролевой модели).
(50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

**Параметр контейнера**
- Кросс-закрытие: Р, С, Н, З недоступны; Зап доступно; Cмп недоступно; нет элемента для заполнения.
- Шаблон имени ряда: Р, С, Н, З; Зап, Cмп недоступны; поле для ввода (маска для поиска по внутреннему содержанию параметра метрики-контейнера «Шаблон имени ряда»).
- Параметр фильтрации (ключ): в таблице три значения «Доступно» для операций; Зап доступно; Cмп недоступно; поле для ввода (маска по внутреннему содержанию ключа параметра метрики-контейнера «Параметр фильтрации»).
- Параметр фильтрации (значение): Р, С, Н, З; Зап доступно; Cмп недоступно; поле для ввода (маска по внутреннему содержанию значения параметра «Параметр фильтрации»).
- Тип агрегации: Р; С, Н, З, Зап, Cмп недоступны; выпадающий список с выбором 1 значения (описание значений в документе не приведено).
(50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Открытые вопросы
- Для «Название метрики» не ясно, как «Доступно если в шаблоне выбран скрипт» распределено по колонкам. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Для «Параметр фильтрации (ключ)» указаны только три значения операций вместо четырёх. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
