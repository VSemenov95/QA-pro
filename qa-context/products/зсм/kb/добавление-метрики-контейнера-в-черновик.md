# Добавление метрики-контейнера в черновик экземпляра коллекции

> Добавление метрики-контейнера (с правилами отбора динамических рядов) в черновик экземпляра коллекции через шторку из списка метрик с валидацией и созданием записи в metrics.

### Описание
- Пользовательская история: «Я КАК Авторизованный пользователь ХОЧУ Добавить метрику-контейнер ДЛЯ ТОГО, ЧТОБЫ Поставить на мониторинг метрику-контейнер с заданными мной правилами отбора динамических рядов». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Метрика-контейнер добавляется в черновик коллекции (на изменение/добавление) из списка метрик экземпляра коллекции. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### Экраны и навигация
- Сценарий 1.0: пользователь создал черновик коллекции на изменение/добавление, перешел в него, открыл список метрик (#[RI1] «Возможность пользователя просматривать/редактировать список метрик экземпляра коллекции метрик»), видит кнопку «Добавить метрику-контейнер». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Сценарий 2.0: при нажатии кнопки открывается шторка с формой добавления метрики-контейнера. Переключатель вкладок: «Параметры» (по умолчанию) и «Подключение к ИАС». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- «Подключение к ИАС»: тип «Несколько рядов» — форма настройки правил отбора ([US] Управление правилами отбора рядов для метрики-контейнера); тип «Один ряд» — обычная форма подключения ([US] Управление подключением метрик из ИС в ИАС). (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- В документе есть скриншоты: «Выбран вариант с одним рядом (агрегация в один ряд)» и «Выбран вариант с одним рядом (первый отобранный ряд)». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### Поля и элементы
- Шторка: редактируемое название; переключатель активности ВКЛ/ВЫКЛ (по умолчанию ВКЛ); переключатель вкладок. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Вкладка параметров: блок общих настроек (тип выходного значения и единицы измерения, как у обычных метрик, #[RI1] «Возможность Пользователя просматривать/редактировать карточку конкретной метрики экземпляра коллекции»); блок настроек контейнера; блок управления категориями метрик (реализация в PPMON-715. Передача ключевых метрик для дашбордов СЦ); блок управления метками («Экземпляр коллекции - управление метками»); блок управления порогами, как у обычных метрик; кнопки «Добавить» / «Отменить». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Переключатель типа контейнера: «несколько рядов» (по умолчанию) / «один ряд». Набор элементов зависит от типа. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- «Несколько рядов»: переключатель «Кросс-закрытие» — ВЫКЛ (по умолчанию): события по рядам контейнера закрывают друг друга в разрезе породившего событие ряда; ВКЛ: в разрезе всего контейнера. «Шаблон имени ряда» — обязательный, по умолчанию не заполнен, текст в свободной форме, ожидаются выражения вида {{{имя лейбла1}}}:{{{имя лейбла2}}}:...; в название отобранных рядов подставляются значения лейблов через «:». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- «Один ряд» (подробнее: [US] Добавление метрики-контейнера с агрегацией): радиобаттон — «агрегация в один ряд» (по умолчанию): данные по отобранным рядам собираются в один ряд по типу агрегации, отображается обязательный выпадающий список «Тип агрегации» (минимум, максимум, среднее); «один ряд»: отбирается только один первый случайный ряд по текущей фильтрации. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Блок фильтрации: по умолчанию кнопка «Добавить условие»; по нажатию появляется строка условия, напротив неё кнопка «Удалить». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Строка условия, «Параметр фильтрации»: Строка; полное название лейбла/имени метрики (часть до фигурных скобок); ряды статусов не отбираются; обязательное; ошибка: «Значения фильтрации не заполнены». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Строка условия, «Значение фильтрации»: Строка; поддерживает регулярные выражения и отрицание в них; если не заполнено — фильтрация по всем значениям параметра; обязательное; ошибка: «Значения фильтрации не заполнены». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### Бизнес-правила и ограничения
- Доступ по статусной модели (PM. Статусная модель заявки на мониторинг) и ролевой модели (/объекта мониторинга v2, «Описание ролевой модели продукта для подключения к ДиР»). (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Доступно только для коллекций с динамическими метриками (актуально на 17.04.2024): SQL, URL, CUSTOM_PYTHON, CUSTOM_WMI, PROMQL, JMX, KAFKA, ASTROM_KEY, SQL_JDBC, DYNAMIC_DISK_SPACE_WINDOWS, DYNAMIC_DISK_SPACE_UNIX. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Все правила фильтрации работают по «И» в первой версии. Ряды статусов не отбираются. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Тип контейнера и «Кросс-закрытие» в черновике можно менять только для контейнеров, ни разу не установленных на мониторинг (не активных при постановке коллекции на мониторинг). (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### API и интеграции
- При успешном добавлении (5.0) в таблице metrics создается запись о метрике-контейнере (см. «Атрибуты в метриках в разрезе типов метрик»). (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Несколько рядов + кросс-закрытие: сохраняются thresholdReduction (ФТ «Кросс-закрытие событий») и crossClosing = true. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- UPD PPMON-550, PPMON-551 («Костыль»), опция «Один ряд»: metricKey по маппингу (тип коллекции — metric_key), сохраняется в metric.metric_key Портала: SQL — sql_dynamic_request; URL — url_dynamic_content_match_value; PYTHON — не заполняется (определяется скриптом); PROMQL — promql_dynamic_request; JMX — jmx_dynamic_request; KAFKA — не заполняется (N значений); ASTROM_KEY — astrom_key_metric. promql_expression = {metricInstanceId="Id"}metric_key; metric_source_type = dynamic_container; dynamic_сontainer_rule — JSON правила наименования, отбора и обработки: {"name": "string","crossClosing": true,"severityReductionInteval": 120 (только для crossClosing = true),"rules": {"additionalProp1": "string","additionalProp2": "string","additionalProp3": "string"}}; при агрегации и выбранном типе заполняется agregationMethod (см. «Атрибуты в метриках в разрезе типов метрик»). (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### Сообщения и ошибки
- Под незаполненными обязательными полями фильтрации: «Значения фильтрации не заполнены». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Успех: всплывающее сообщение, метрика «Добавлена». (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- Ошибки валидации (4.0): незаполненные поля красным, под ними текст ошибки. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### Роли и права
- Пользователь: «Авторизованный пользователь»; доступ по статусной модели заявки на мониторинг и ролевой модели объекта мониторинга v2. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

### Сценарии
- 1.0: создан черновик, открыт список метрик, видна кнопка «Добавить метрику-контейнер». 2.0: нажатие кнопки — шторка с формой. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)

(22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- 4.0 (после 2.0): обязательные не указаны или заполнены неверно — поля красным с текстом ошибки, метрика не добавляется, окно не закрывается. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
- 5.0 (после 2.0): все параметры заданы, нажато «Добавить» — сообщение «Добавлена», метрика типа «Метрика-контейнер» добавлена в коллекцию, создана запись в metrics; при нескольких рядах с кросс-закрытием сохраняются thresholdReduction и crossClosing = true. (22-[US] Добавление метрики-контейнера в черновик экземпляра коллекции)
