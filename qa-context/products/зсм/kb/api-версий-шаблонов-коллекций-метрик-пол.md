# API версий шаблонов коллекций метрик (получение версии, связанные синтетические и дефолтные шаблоны метрик, типы данных)

> Набор GET-эндпойнтов админского API Portal backend для получения версий шаблонов коллекций метрик, связанных синтетических и дефолтных шаблонов метрик и справочника типов данных выходных значений метрик.

### Описание
- Раздел описывает административные GET-методы: типы данных метрик, последняя опубликованная версия шаблона, версия шаблона по ID, связанные шаблоны синтетических метрик, дефолтные шаблоны метрик версии шаблона коллекции (portalbackend).

### API и интеграции
- **GET /admin/metric-data-type** — получить типы данных выходных значений метрик. 200 — OK, элементы массива: id (integer, int64) — Идентификатор; name (string) — Имя типа данных; displayName (string) — Отображаемое имя типа данных (portalbackend).
- **GET /admin/metric-collection-template/{baseId}** — Получение последней опубликованной версии шаблона. Параметры: baseId (в пути, integer, обязательный). 200 — OK, структура ответа общая с GET /admin/metric-collection-template/version/{versionId} (portalbackend).
- **GET /admin/metric-collection-template/version/{versionId}** — Получение версии шаблона. Параметры: versionId (в пути, integer, обязательный). 200 — OK (portalbackend):
  - id (integer, int64) — Идентификатор версии шаблона; baseId (integer, int64) — Базовый идентификатор для всех версий одного шаблона; version (integer, int64) — Номер версии шаблона.
  - allVersions (массив из object) — Список всех версий шаблона: id — Идентификатор версии шаблона; version — Номер версии шаблона; status (string) — Статус версии шаблона.
  - status (string) — Статус версии шаблона (DRAFT/PUBLISHED); name (string) — Название версии шаблона коллекции метрик; description (string) — Описание версии шаблона коллекции метрик.
  - metricCollectionType (object): id (int64) — Идентификатор типа коллекции метрик; code — Код типа коллекции метрик; description — Описание типа коллекции метрик; authTypes (массив string: LP | SSH | MTLS | TOKEN | AUTHORIZATION_HEADER | OAUTH2) — Типы поддерживаемых аутентификации.
  - autoMonitoringPossible (boolean) — Возможность автоматической постановки коллекции на мониторинг.
  - script (object): id (integer, int64, пример: 1) — Идентификатор; name (string, обязательное, пример: "Script") — Наименование; description (string, пример: "Description") — Описание; extendedScriptCategory (object): id (int32) — Идентификатор категории скрипта, code — Код категории скрипта, description — Описание категории скрипта.
  - isAvailableAddDynamicContainerMetric (boolean) — Признак доступности создания метрики контейнера.
  - Все поля, кроме script.name, необязательные.
- **GET /admin/metric-collection-template/version/{templateVersionId}/metric-template/{metricTemplateId}/linked-synth-metric-templates** — Получить связанные шаблоны синтетических метрик по ID шаблона регулярной метрики. Параметры: templateVersionId (в пути, integer, обязательный); metricTemplateId (в пути, integer, обязательный). 200 — OK, элементы массива (portalbackend):
  - id (integer, int64) — Идентификатор; name (string) — Имя; unit (string) — Единица измерения; defaultMetricTemplateId (integer, int64) — Идентификатор дефолтного шаблона метрики; isUsed (boolean) — Признак использования метрики.
  - dataType (object): id (int64) — Идентификатор; name — Имя типа данных; displayName — Отображаемое имя типа данных.
  - metricConstructor (object): expressionAttributes (object): булевы признаки array, empty, null, missingNode, object, valueNode, pojo, number, integralNumber, floatingPointNumber, short, int, long, float, double, bigDecimal, bigInteger, textual, boolean, binary, container, string, embeddedValue; nodeType (string: ARRAY | BINARY | BOOLEAN | MISSING | NULL | NUMBER | OBJECT | POJO | STRING); parameters (массив из object): name (string), metricId (integer, int64), metricName (string); defaultValue (string); promqlExpression (string); isManual (boolean); promqlQueryStep (string).
  - metricSourceType (string: DEFAULT | SCRIPT | DYNAMIC | SYNTHETIC | COMPLEX | EXTERNAL | DYNAMIC_CONTAINER | COLLECTION_STATUS | COMPOSITE) — Тип метрики.
  - dynamicContainerRule (object): name (string), crossClosing (boolean), rules (object), aggregationMethod (string: MAX | MIN | AVG).
  - expectSingleMetric (boolean) — Количество рядов для отбора для динамического контейнера, true - Один ряд.
  - statusCalcMethod (string: MOST_CRITICAL | MOST_NORMAL) — Метод расчета статуса коллекции; manualThreshold (boolean) — Ручное управление порогами; expertMode (boolean) — Признак настройки порогов в экспертном режиме.
  - selectionRules (массив из object) — Правила отбора рядов метрики контейнера: id (string, uuid); name (string); selectionType (string: FILTER | MANUAL); filterSelection (массив: key, value); manualSelection (массив: name, promql); noDataWarningMs (integer, int64); noDataCriticalMs (integer, int64); availableForBs (boolean); connectToAiops (boolean); aiopsConnect (object): toggleSetParametersInIas (boolean); notificationsMetricTemplate (object: id (string), name (string)); groupReactions (массив: aiopsGroupId — айди группы реакций из шаблона метрик ИАС; aiopsGroupLabel — лейбл группы реакций из шаблона метрик ИАС; ecosGroupId (uuid) — айди группы ЭКОС; ecosGroupName — название группы ЭКОС); hyperparametersMetricTemplate (object: id (string), name (string)).
- **GET /admin/metric-collection-template/version/{templateVersionId}/default-metric-template** — Получить дефолтные шаблоны метрик по id шаблона коллекции метрик. Параметры: templateVersionId (в пути, integer, обязательный); filter (в запросе, object, обязательный). 200 — OK: itemsCount (integer, int64) — Общее число элементов; items (массив из object) — Элементы на странице: id (int64) — Идентификатор; name — Имя; dataType (string) — Тип данных; unit — Единица измерения (portalbackend).
