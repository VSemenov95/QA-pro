# Массовое редактирование коллекций: отбор коллекций, просмотр изменений и создание заявки

> Этап мастера массового редактирования коллекций, на котором пользователь видит найденные по правилам фильтрации и замены коллекции, просматривает изменения БЫЛО/СТАЛО и создаёт заявку на массовое изменение.

### Описание
- После завершения этапа формирования правил замены на бэке выполняется поиск подходящих под изменение коллекций и метрик, затем пользователь видит этап отбора коллекций для изменений. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Экраны и навигация
- Заголовок экрана: «Массовое редактирование коллекций». Таблица найденных коллекций, подлежащих изменению; строка — коллекция, отобранная по алгоритму. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Над таблицей текст: «Найдено X из Y коллекций, созданных по шаблону в выбранных объектах мониторинга», где X — количество найденных коллекций, подходящих для изменения, Y — всего коллекций, дочерних для выбранного шаблона, в выбранных на первом шаге объектах мониторинга. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Кнопки: «Обновить» — повторный отбор коллекций; «Назад» — возврат к предыдущему этапу со сбросом настроек текущего (альтернатива: переход по иконкам предыдущего этапа); «Создать заявку» — создание заявки массового изменения, доступно, если выбраны коллекции; «Отменить» — отказ от выполнения массового поиска и замены, с пользовательским предупреждением. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Для каждой коллекции можно открыть перечень изменений согласно правилам замены (сценарий 9). История организована аналогично истории изменений в заявке: блок «Атрибуты» — слева значения до изменения, справа после; блок «Параметры коллекции» — слева до, справа после. Отображается изменение по ВСЕМ изменённым атрибутам, параметрам метрик, коллекций и т.д. (по метрикам, по признаку бизнес-сервиса и т.д.). Для каждой метрики свой блок с названием метрики; изменения параметров метрики — таблицей было/стало; состояния порогов было/стало — таблицами. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Поля и элементы
- Столбцы таблицы: чекбокс выбора коллекции с массовым выбором (реализация в PPPM-2634 (Улучшайзинг) (Поиск и замена): добавить возможность массового выбора коллекций для изменения, Закрыто); название коллекции; объект мониторинга — родительский объект найденной коллекции; статус коллекции; статус заявки по коллекции — статус последней заявки по коллекции (аналогично плашке статуса заявки в самой коллекции). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- При массовом выборе отбираются ВСЕ коллекции без учёта пагинации и постраничной навигации. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Бизнес-правила и ограничения
- Алгоритм отбора, шаг 1 (по правилам фильтрации): (1) отбираются коллекции, порождённые выбранным шаблоном (дамми-шаблон / коллекции по типу коллекций пока недоступно); (2) из (1) — принадлежащие выбранным на шаге фильтрации ОМ (если ОМ не выбраны, условие не учитывается); (3) из (2) — в статусе НА МОНИТОРИНГЕ / ОСТАНОВКА СБОРА ДАННЫХ / ИДЕТ ОСТАНОВКА СБОРА ДАННЫХ / ИДЕТ ВОЗОБНОВЛЕНИЕ СБОРА ДАННЫХ; (4) из (3) — попадающие под условия фильтрации с первого шага: коллекция подходит, если она или её дочерние метрики типа РЕГУЛЯРНАЯ, КОНТЕЙНЕР, СКРИПТ (с учётом пользовательского фильтра по типу) удовлетворяют условиям; (5) для каждой коллекции из (4) формируется список метрик: тип РЕГУЛЯРНАЯ, КОНТЕЙНЕР, СКРИПТ (если пользователь не указал конкретное условие на тип) и попадающих под условия фильтрации по метрикам (если условий нет, попадают все метрики доступных типов). Итог: набор коллекций под правила фильтрации и набор дочерних метрик для каждой. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Шаг 2: для каждой отобранной коллекции и её метрик последовательно применяются заданные пользователем правила изменения (реализация в PPPM-2613 [2025.03][BE](ТехДолг, portalbackend): добавить проверку правил замены при формировании списка доступных коллекций + массовый выбор коллекций на 4-м этапе массового поиска и замены, Создано). Проверки по типу правила: замена атрибутов — «Правила обработки атрибутов разных типов в экземпляре коллекции» (при сохранении только у разрешённых для массового поиска и замены объектов); замена метрик и метрик-контейнеров — «Правила обработки метрик в экземпляре коллекции» (только у разрешённых объектов); замена параметров коллекции — проверка по меткам как для меток метрик; по признаку БС: ВЫКЛ→ВКЛ — изменение сохраняется в любом случае; ВКЛ→ВЫКЛ и хотя бы одна метрика коллекции подключена к БС — не сохраняется. Успешная проверка — применена, переход к следующей; с ошибкой — не применена, переход к следующей. После всех проверок отображаются коллекции, у которых отобранная коллекция или её дочерняя метрика были изменены. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- При каждом раскрытии истории изменений с бэка запрашивается актуальный набор изменений (шаг 2). Если коллекция перестала соответствовать хотя бы одному изменению, список обновляется и коллекция пропадает из списка. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Создание заявки (сценарий 10): 1) пользователь выбирает коллекции вручную (при обновлении списка выбранные остаются); 2) подтверждает нажатием «СОЗДАТЬ ЗАЯВКУ»; 3) если коллекции выбраны, создаётся заявка на массовое изменение и дочерние заявки на изменение каждой отобранной коллекции (см. «Заявка на массовое изменение коллекций»). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Сценарии
- 8) Увидеть список коллекций, подходящих под условия фильтрации и преобразования. 9) Увидеть список изменений БЫЛО/СТАЛО для коллекции. 10) Запустить заявку на массовое изменение коллекций. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Открытые вопросы
- Выбор дамми-шаблона и коллекций по типу коллекций пока недоступен. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Описание заявки «Заявка на массовое изменение коллекций» и раздел 2.2 «Управление заявками поиска и замены» в данный фрагмент не вошли. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
