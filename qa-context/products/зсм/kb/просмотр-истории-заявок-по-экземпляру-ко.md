# Просмотр истории заявок по экземпляру коллекции (вкладка «История заявок»)

> Вкладка «История заявок» в карточке экземпляра коллекции показывает список заявок по этой коллекции с возможностью перейти к карточке заявки.

### Описание
- Критерий 7.0 «Возможность пользователя просматривать историю заявок по коллекции». Добавлен в версии 12.0 (22.02.2024, PPPM-3488 «[2024.02] [SA/BA] Доработка реестра заявок с учетом изменения ТУЗов»). (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)

### Экраны и навигация
- Пользователь просматривает карточку экземпляра коллекции и переходит на вкладку «История заявок». (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)
- Система отображает список заявок согласно #6 Визуальный дизайн. (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)
- У пользователя есть возможность перейти к карточке заявки. (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)

### Поля и элементы
- Атрибуты списка заявок: ID Заявки; Дата создания; ИС; Название объекта; Тип заявки; Исполнитель; Статус заявки (статусная модель согласно «PM.Статусная модель заявки на мониторинг/объекта мониторинга v2»). (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)

### Роли и права
- Ответственный ИС/Инженер ЗОНТ/Аудитор ИБ. (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)
