# Права ролей: реестр заявок

> Права на вкладку, каталог, карточку заявки и комментарии в реестре заявок; у «Ответственного ИС» — только заявки по его ИС.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
Значения «Ответственный ИС»:
- Вкладка «Мониторинг» с подразделом «Реестр Заявок»: Просмотр (read) +.
- Каталог заявок: Просмотр (read) + — отображаются только те заявки, по ИС которым пользователь является Ответственным ИС.
- Карточка заявки: Просмотр (read) + (только те заявки, по ИС которым пользователь является Ответственным ИС); Назначить на себя (assign) −; Автопостановка (automonitoring) −; Перейти к объекту (readobject) +; Перевести в работу / Отклонить или Выполнить (changestatus): не может отклонить из карточки заявки, может отозвать из истории заявок согласно «Статусная модель + Действия доступные для коллекций в зависимости от статусов заявок».
- Комментарии в карточке заявки: Просмотр (read) + (только заявки по ИС, где пользователь Ответственный ИС); Добавление (create) + (то же ограничение); Редактирование, отложено (update) −; Удаление, отложено (delete) −.
- В колонках других ролей встречаются пометки: «PPPM-120 (только свои БС и ТМ БС)», «PPPM-5985 — все заявки по ИС, связанными со своими БС», «Только те, к которым имеет доступ», ссылки PPPM-7178; у действия «Перейти к объекту» — «Изменено на + (Мысев А. Э.)».

### Открытые вопросы
- Явное значение +/− для changestatus у «Ответственного ИС» в тексте не читается.
