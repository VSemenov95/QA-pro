# Интеграционные требования: хранение данных версионирования, миграция и СС Аудита

> Интеграционные требования (TO BE) к версионированию шаблонов коллекций: доработка структур хранения данных шаблонов и коллекций, миграция существующих данных и доработка СС Аудита.

### Описание
- Раздел 5) «Интеграционные требования (TO BE)» включает: 5.1) доработка структуры хранения данных для реализации версионирования шаблонов; 5.2) доработка структуры хранения данных коллекций; 5.3) выполнение миграции данных; 5.4) доработка СС Аудита. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Поля и элементы
- Новая таблица metric_collection_template_base — информация о самом шаблоне (вся общая информация для всех версий шаблона). Состав: id — ид родительского шаблона, общего для всех версий (учесть при миграции); name — общее название для всех шаблонов; type — тип шаблона (аналогично текущей реализации для шаблонов). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Существующая таблица metric_collection_template хранит сами версии шаблона. Добавляются новые колонки: (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
  - id — остаётся как и было, но теперь это не ID шаблона, а ID конкретной версии (не путать с номером, это первичный ключ версии);
  - metric_collection_template_base_id — ссылка на базовый шаблон, общий для всех версий; базовые шаблоны хранятся в новой таблице metric_collection_template_base;
  - version — порядковый номер версии;
  - status (DRAFT/PUBLISHED) — является/не является версия черновиком.
- В таблице metric_collection добавляется параметр для хранения связи с версией шаблона, на основании которой создана коллекция. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Бизнес-правила и ограничения
- В истории изменений ИС, в отчёте ИС и БС не добавляются версии шаблонов, т.к. шаблон в отчёте не выводится. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Только одна версия для одного metric_collection_template_base_id может быть черновиком в один момент времени. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Черновиком может быть только последняя версия базового шаблона. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### API и интеграции
- Миграция данных: подготовить инструменты для миграции: (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
  1) для каждого текущего шаблона: в metric_collection_template_base заводится запись о родительском шаблоне, присваивается ID аналогичный текущему номеру шаблона; в metric_collection_template текущая запись становится первой версией шаблона;
  2) для каждой текущей коллекции, для которой определён существующий шаблон — коллекция становится привязанной к шаблону первой версии;
  3) зачистить привязку к шаблону у коллекции, если шаблона больше нет.
- СС Аудита: обновить текущие эндпоинты; добавить новые эндпоинты. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Открытые вопросы
- Новая логика хранения шаблонов и версий: «Дополнить после реализации». (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- СС Аудита: «Дополнить после реализации» (подробности по эндпоинтам — после реализации). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
