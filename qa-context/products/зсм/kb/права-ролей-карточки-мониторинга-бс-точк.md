# Права ролей: карточки мониторинга БС, точки мониторинга

> Права на каталог и карточки мониторинга БС, историю, точки мониторинга и их метрики; у роли «Ответственный ИС» доступ отсутствует.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
Значения «Ответственный ИС» (все «−»):
- Вкладка «Мониторинг» с подразделом «Карточки мониторинга БС»: Просмотр (read) −.
- Каталог карточек мониторинга БС (Активные/Сняты с мониторинга): Просмотр (read) −; Выгрузка сокращенного отчета по всем БС (PPMON-338) (create) −.
- Карточка мониторинга БС: Просмотр (read) −; Выгрузка полного отчета по выбранной БС (PPMON-338) (create) −; Добавление (постановка БС на мониторинг) (create) −; Удаление (снятие БС с мониторинга) (delete) −; Окончательное удаление карточки БС (PPMON-1144) (delete-full) — значение не читается; Возвращение БС на мониторинг (PPMON-19) (recover) −.
- Карточка мониторинга БС (вкладка «Комментарии»): Просмотр (read) −; Добавление (create) −.
- История изменений БС: Просмотр (read) −.
- Каталог точек мониторинга БС: Просмотр (read) −.
- Точка мониторинга: Просмотр (read) −; Добавление (create) −; Управление метриками в точке мониторинга (metric_update, PPPM-1613) — значение не читается; Редактирование (update) −; Удаление (delete) −; Доступ к кнопке «Перейти к метрике» (PPPM-7241) (read) −; Доступ к кнопке «Перейти к ИАС» (PPPM-7241) (read) −.
- История ТМ БС: Просмотр (read) — значение не читается.
- В колонках других ролей встречаются пометки: «Вижу только свои объекты», «по своим БС», «Только те, к которым имеет доступ», «С учетом ограничений по доступам к БС», «По ИС, связанным со своими БС», «В отчете отображаются все БС», «В отчете отображаются только доступные БС», ссылки PPMON-692, PPPM-7299, PPMON-19.
