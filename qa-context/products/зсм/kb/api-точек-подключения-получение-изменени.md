# API точек подключения (получение, изменение, удаление, правка в статусе «Ошибка создания»)

> Административный REST API точек подключения ЗСМ: получение списка и точки по ID, изменение имени и описания, удаление, а также полное редактирование точки в статусе «Ошибка создания», плюс справочники и список подключённых коллекций.

### Описание
- GET /admin/connection-point/{id} — «Получение точки подключения по ID». (portalbackend)
- GET /admin/connection-point — «Получение списка точек подключения». (portalbackend)
- PUT /admin/connection-point/{id} — Изменение точки подключения. (portalbackend)
- DELETE /admin/connection-point/{id} — Удаление точки подключения. (portalbackend)
- PUT /admin/connection-point/{id}/update-from-error-status — Изменение точки подключения в статусе Ошибка создания. (portalbackend)

### Бизнес-правила и ограничения
- В статусе «Ошибка создания» можно редактировать любые поля точки подключения (через метод update-from-error-status); обычный PUT изменяет только name и description. (portalbackend)

### API и интеграции
**GET /admin/connection-point/{id}**
- Параметры: id (в пути, integer, обязательный). Ответ 200 — OK, все поля необязательные:
  - id (integer, int64) — Идентификатор точки подключения; name (string) — Имя точки подключения; description (string) — Описание точки подключения; cmdbId (string) — CMDB ID точки подключения; url (string) — Адрес подключения точки подключения; connectedCollectionsCount (integer, int64) — Количество подключенных к точке подключения коллекций
  - type (object): id (integer, int32) — Идентификатор; name (string) — Значение
  - networkZone (object): cmdbId (string, пример: "00000001-5717-4562-b3fc-2c963f66afa6") — CMDB ID сетевой зоны; name (string, пример: "DEV-SRV-APP") — Имя сетевой зоны
  - status (object): id (integer, int32) — Идентификатор статуса сетевой зоны; name (string) — Название статуса сетевой зоны
  - serviceAccount (object): id (string) — Идентификатор; name (string) — Название; description (string) — Описание; login (string) — Логин; username (string) — Имя пользователя; tokenUrl (string) — URL токена; clientId (string) — Идентификатор клиента, зарегистрированного у IdP; scope (string) — Список прав/разрешений для токена; resource (string) — URI API, на который выдается токен
    - configurationUnits (массив object) — Конфигурационные единицы: cmdbId (string) — Идентификатор; name (string) — Значение; typeId (string) — Идентификатор типа; ciTypeReadable (string) — Тип КЕ для вывода пользователю; smId (string, пример: "CI1203767") — Идентификатор конфигурационной единицы (КЕ); editable (boolean) — Признак возможности изменения связи
    - relatedTypes (массив object) — Типы КЕ для системного ТУЗа: name (string) — Название типа КЕ; editable (boolean) — Признак возможности изменения связи
    - globalType (string: USER | SYSTEM) — Тип ТУЗа; authType (string: LP | SSH | MTLS | TOKEN | AUTHORIZATION_HEADER | OAUTH2) — Подтип ТУЗа
    - countMetricCollection (integer, int64) — Количество связанных коллекций метрик; countIntegrationPoint (integer, int64) — Количество связанных точек интеграций
    - allowMetricManage (boolean) — Разрешение на создание метрик (true-разрешено, false-запрещено)
    - requestStatus (object): id (integer,null, int32); name (string,null); editable (boolean,null)
    - createdTime (integer, int64) — Дата создания; lastModifiedTime (integer, int64) — Дата изменения

**GET /admin/connection-point**
- Параметры: filter (в запросе, object, обязательный). Ответ 200 — OK: itemsCount (integer, int64) — Общее число элементов; items (массив) — Элементы на странице; элемент items содержит те же поля, что ответ GET /admin/connection-point/{id}. (portalbackend)

**PUT /admin/connection-point/{id}**
- Параметры: id (в пути, integer, обязательный). Тело (application/json), необязательные: name (string) — Имя точки интеграции; description (string) — Описание. Ответ: 200 — OK. (portalbackend)

**DELETE /admin/connection-point/{id}**
- Параметры: id (в пути, integer, обязательный). Ответ: 200 — OK. (portalbackend)

**PUT /admin/connection-point/{id}/update-from-error-status**
- Параметры: id (в пути, integer, обязательный). Тело (application/json), необязательные: name (string) — Имя точки интеграции; description (string) — Описание; typeId (integer, int32, пример: 1) — ID типа точки интеграции; url (string) — Адрес подключения; networkZoneCmdbId (string, пример: "47ce625ca7f5cc959f3487d843563b70") — CMDB ID сетевой зоны точки интеграции; serviceAccountCmdbId (string, пример: "47ce625ca7f5cc959f3487d843563b70") — CMDB ID ТУЗа для точки интеграции. Ответ: 200 — OK. (portalbackend)

**Связанные методы (справочники)**
- GET /admin/connection-point/{id}/connected-collections — список подключенных коллекций. Параметры: id (в пути, integer, обязательный). Ответ 200 — массив: metricCollectionId (integer, int64) — Идентификатор коллекции; metricCollectionName (string) — Имя коллекции; cardId (integer, int64) — Идентификатор карточки мониторинга; infoSystemCmdbId (string) — CMDB ID инфосистемы; infoSystemName (string) — Имя инфосистемы; infoSystemRisId (string) — RIS ID ИС; monitoringObjectId (integer, int64) — Идентификатор объекта мониторинга; monitoringObjectCmdbId (string) — CMDB ID объекта мониторинга; monitoringObjectName (string) — Имя КЕ объекта мониторинга; metricCollectionStatus (object): id (integer, int32) — Идентификатор; name (string) — Наименование. (portalbackend)
- GET /admin/connection-point/types — типы точек подключения. Ответ 200: массив id (integer, int32) — Идентификатор; name (string) — Значение. (portalbackend)
- GET /admin/connection-point/statuses — статусы точек подключения. Ответ 200: массив id (integer, int32) — Идентификатор статуса сетевой зоны; name (string) — Название статуса сетевой зоны. (portalbackend)
- GET /admin/connection-point/service-accounts — ТУЗы для точек подключения. Параметры: filter (в запросе, object, обязательный). Ответ 200: itemsCount (integer, int64); items (массив) — элементы с теми же полями, что serviceAccount выше. (portalbackend)
- GET /admin/connection-point/network-zones — сетевые зоны. Параметры: filter (в запросе, object, обязательный). Ответ 200: itemsCount (integer, int64); items: cmdbId (string, пример: "00000001-5717-4562-b3fc-2c963f66afa6") — CMDB ID сетевой зоны; name (string, пример: "DEV-SRV-APP") — Имя сетевой зоны. (portalbackend)
