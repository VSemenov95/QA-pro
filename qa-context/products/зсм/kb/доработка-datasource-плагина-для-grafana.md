# Доработка DataSource плагина для Grafana

> Доработка datasource плагина Grafana: вывод признака «На базовом мониторинге» (TRUE/FALSE) для сущностей «БС», «Точка мониторинга», «Метрика БС» по аналогии со «Статусом карточки БС», в настоящий момент отложена.

### Описание
- Статус: ОТЛОЖЕНО. (12-PPMON-1879. Базовый мониторинг)
- В datasource плагин надо выводить признак «На базовом мониторинге» для сущностей «БС», «Точка мониторинга», «Метрика БС» аналогично «Статусу карточки БС» с вариантами TRUE/FALSE. (12-PPMON-1879. Базовый мониторинг)
- Отображать и использовать так же, как статус карточки БС. (12-PPMON-1879. Базовый мониторинг)

### Бизнес-правила и ограничения
- В рамках фичи PPMON-1879 «Типовой дашборд БС» и доработки datasource плагина к нему не реализуются и не входят в оценку. (12-PPMON-1879. Базовый мониторинг)
