# Общая информация и объём фичи PPMON-1826: точечное обновление коллекции из шаблона

> Фича PPMON-1826 реализует только сам алгоритм точечного обновления коллекции из текущей версии шаблона (с учётом или без учёта пользовательских изменений) и фиксацию связей метрик с метриками шаблона; кнопки, экраны и полноценное API вынесены в бэклог или в другие задачи.

### Описание
- Фича ЗСМ PPMON-1826 «Доработка текущего функционала коллекций (обновление из шаблона, сбор данных)». Собранные требования описаны в статье «Скоуп - обновление коллекций». Дизайн: ссылка на PIXSO. (59-1826. Реализация точечного обновления коллекции из шаблона)
- AS IS: алгоритм обновления коллекций из последней версии фиксированного шаблона отсутствует. Для реализации обновления первично должно быть сделано версионирование (см. 230. Версионирование шаблонов коллекций). (59-1826. Реализация точечного обновления коллекции из шаблона)
- TO BE: реализация всего функционала должна быть выполнена в PPPM-5797 US-Q3-4 «Механизм точечного обновления коллекции из текущей версии шаблона (с учетом изменений/без учета изменений)». (59-1826. Реализация точечного обновления коллекции из шаблона)
- В рамках текущей фичи реализуется только сам алгоритм обновления. Реализация вызова обновления по кнопкам вынесена в бэклог. (59-1826. Реализация точечного обновления коллекции из шаблона)

### Экраны и навигация
- Раздел 4 содержит скриншоты дизайна по сценариям: «Просмотр наличия кнопки обновления коллекции» — НЕ РЕАЛИЗУЕМ, ПЕРЕНЕСЕНО В БЭКЛОГ; «Вызов обновления коллекции» — НЕ РЕАЛИЗУЕМ, ПЕРЕНЕСЕНО В БЭКЛОГ (варианты «если черновика нет» и «если черновик есть»); «Результат успешного обновления коллекции» — НЕ РЕАЛИЗУЕМ, ПЕРЕНЕСЕНО В БЭКЛОГ. (59-1826. Реализация точечного обновления коллекции из шаблона)

### Бизнес-правила и ограничения
- Критерий А) НЕ ВКЛЮЧЕНО, ПЕРЕНЕСЕНО В БЭКЛОГ PPMON-XXX2: в коллекции на UI подсвечивать атрибуты/метрики, если зафиксированы их изменения. Атрибут помечается как измененный, если пользователь при редактировании коллекции изменил его так, что он отличается от версии атрибута шаблона, из которой создана коллекция. Метрика помечается как измененная, если пользователь изменил любой параметр метрики так, что она отличается от версии метрики шаблона, из которой создана коллекция. Изменение названия коллекции, меток, категорий и признака доступности коллекции для БС не является фиксируемым изменением коллекции. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Критерий Б) ВКЛЮЧЕНО: при добавлении коллекций фиксировать связи метрик, созданных по шаблону, с метриками в шаблоне. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Критерий В) НЕ ВКЛЮЧЕНО, ПЕРЕНЕСЕНО В БЭКЛОГ PPMON-XXX1: механизм обновления коллекции — в карточке коллекции появляется кнопка, при нажатии на которую коллекция должна быть обновлена текущими настройками из актуальной версии шаблона коллекции с учетом/без учета изменений, внесенных пользователем. В результате нажатия создается черновик заявки, в который прокидываются настройки атрибутов/метрик из актуальной версии шаблона коллекции. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Алгоритм обновления целиком: ВКЛЮЧЕНО ЦЕЛИКОМ. (59-1826. Реализация точечного обновления коллекции из шаблона)
- ВКЛЮЧЕНО1: если изменений никаких не было — заявка все равно создается. (59-1826. Реализация точечного обновления коллекции из шаблона)
- ВКЛЮЧЕНО1: в коллекцию и черновик добавить версию шаблона (в UI). (59-1826. Реализация точечного обновления коллекции из шаблона)
- НЕ ВКЛЮЧЕНО, УЧЕСТЬ ДЛЯ PPMOM-XXX1: обновление коллекций по кнопке разрешено, если для версии шаблона коллекции установлено разрешение создавать/редактировать коллекцию. (59-1826. Реализация точечного обновления коллекции из шаблона)
- НЕ ВКЛЮЧЕНО, УЧЕСТЬ ДЛЯ PPMOM-XXX1: при обновлении по кнопке всегда перезаписывать текущий черновик коллекции (если черновик существует — предупреждать пользователя, что черновик будет потерян при обновлении коллекции). (59-1826. Реализация точечного обновления коллекции из шаблона)
- Алгоритм, учёт пользовательских изменений отключен: 1.1) атрибуты: из коллекции удаляются системные и пользовательские атрибуты, которых больше нет в новой версии шаблона; актуальные атрибуты (технические названия есть и в коллекции, и в шаблоне) обновляются значениями из новой версии шаблона; 1.2) метрики: удаляются унаследованные от предыдущей версии метрики, которых НЕТ в новой версии; все оставшиеся унаследованные обновляются значениями из новой версии; все новые метрики из новой версии прокидываются в коллекцию как новые; все созданные пользователем метрики сохраняются без изменений (!); 1.3) метки: удаляются метки, отсутствующие в новой версии шаблона (исключение — метки типа «пользовательские», остаются без изменения); добавляются метки из новой версии шаблона. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Учёт пользовательских изменений включен: 2.1) атрибуты — аналогично 1.1, но при перезаписи оставшихся сохраняются изменения пользователя; 2.2) метрики — аналогично 1.2, но при перезаписи оставшихся сохраняются изменения пользователя. (59-1826. Реализация точечного обновления коллекции из шаблона)
- После создания черновик отправляется в автообработку согласно признаку автообработки из шаблона. Исключение: если в результате обновления в заявке не заполнены все обязательные элементы, заявка переходит в статус неполных данных и автоматически в дальнейшую обработку не передается (см. блок X4 по параметризации). Блок Х4 — задача PPMON-1824 «Доработка управления коллекциями. Добавить возможность сохранения черновика без валидации (без заполнения обязательных полей)». (59-1826. Реализация точечного обновления коллекции из шаблона)

### API и интеграции
- Полноценное API будет реализовано в рамках PPMON-1810 (1810. PUT API: миграция коллекций при повторном применении стандарта с одной версии на другую). (59-1826. Реализация точечного обновления коллекции из шаблона)
- Версионирование — зависимость от задачи 230. Зависимости на другие задачи: PPMON-1823 (Настройка «Политики разрешений» в шаблоне коллекций), PPMON-1824, PPMON-1864. (59-1826. Реализация точечного обновления коллекции из шаблона)

### Роли и права
- Пользовательские сценарии должны быть реализованы согласно требованиям ролевки: «Описание ролевой модели ЗСМ» (https://sfera-t1.ru/knowledge/pages?id=108926). (59-1826. Реализация точечного обновления коллекции из шаблона)

### Открытые вопросы
