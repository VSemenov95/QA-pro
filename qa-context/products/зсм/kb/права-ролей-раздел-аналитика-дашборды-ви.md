# Права ролей: раздел «Аналитика» (дашборды, виджеты, ключевые метрики, отчёты)

> Права на глобальный раздел «Аналитика»: дашборды, виджеты, ключевые метрики и отчёт о полноте мониторинга.

## 200-Описание ролевой модели ЗСМ.pdf

### Описание
Глобальный раздел «Аналитика» со всеми подразделами (поз. 61): Просмотр read — «Доступ к отдельным подразделам».

### Поля и элементы
- 3.1 «Дашборды»:
  - 62 Вкладка «Аналитика» с подразделами/иконками «Дашборды»: Просмотр read +.
  - 63 Каталог дашбордов: Просмотр read +.
  - 64 Карточка дашборда: Просмотр read + (видит только свои, которые создал сам); Добавление create; Редактирование update; Удаление delete; Дублирование duplication; Настройка доступа access_setting.
  - 65 Каталог виджетов: Просмотр read.
  - 66 Карточка виджета: Просмотр read; Добавление create; Удаление delete; Редактирование update.
- 3.2 «Ключевые метрики»: 67 Список ключевых метрик — Просмотр (включает поиск и возможность перехода к карточке метрик), update_key_metrics.
- 3.3 «Отчеты»: 68 Отчет о полноте мониторинга — Выгрузка отчета create + (только по своим ИС).

### Роли и права
- В одной из колонок для дашбордов указано: «Только те, к которым имеет доступ».
- Ссылка на задачу: PPPM-8102.
- Знаки «+/-» по ролям разорваны, точное соответствие ролям не восстановимо.
