# Комплексная метрика: контекстные меню элементов конструктора

> Контекстные меню элементов конструктора комплексной метрики на портале позволяют менять тип агрегации переменных, арифметические операторы, операторы MIN/MAX/AVG, скобки и дочерние выражения, а также очищать и удалять эти элементы.

### Описание
- Портал, добавление комплексной метрики: изменение добавленных в конструктор элементов через контекстное меню. Во фрагменте последней страницы 6.5 и раздел «Формирование PROMQL-выражения» обрезаны. (13-[US] Добавление комплексной метрики)

### Экраны и навигация
- Иллюстрации к 6.0: «Контекстное меню переменная», «Выбран вариант SUM», «Контекстное меню арифметическое выражение», «Контекстное меню скобка», «Контекстное меню оператор», «Контекстное меню выражение оператора», «Выбран вариант PREV». (13-[US] Добавление комплексной метрики)

### Бизнес-правила и ограничения
- Всплывающее меню (6.0, 6.1, 6.2, 6.4, 6.5) появляется при нажатии на особую область элемента в конструкторе (решается при фронт-разработке); для скобок (6.3) — при наведении мышки на сами скобки (опционально — на незаполненные элементы области выражения). (13-[US] Добавление комплексной метрики)
- Формат формирования временного периода реализован согласно требованиям https://prometheus.io/docs/prometheus/latest/querying/basics/ (п. Time Durations). (13-[US] Добавление комплексной метрики)
- Для выбора типа агрегации кроме «текущее»: к параметру добавляется приставка с названием типа агрегации + поле для ввода периода (формат ввода Xh ym, ввод обязательный). (13-[US] Добавление комплексной метрики)

### Сценарии
- 6.0 Меню переменной (выполнено 4.0). Кнопки: «Выбрать тип агрегации - текущее значение» — переменная отображается без допэлементов (значение по умолчанию); «Выбрать тип агрегации - сумма за период» — префикс SUM + элемент для ввода времени в формате времени; «Выбрать тип агрегации - минимальное за период» — префикс MIN + элемент ввода времени; «Выбрать тип агрегации - максимальное за период» — префикс MAX + элемент ввода времени; «Выбрать тип агрегации - среднее за период» — префикс AVG + элемент ввода времени; «Удалить» — удаление текущей переменной. Проверка: (4) при выборе типа агрегации кроме текущего пользователь видит добавленную приставку и поле периода; (5) при повторном вызове и выборе «текущее» у параметра убирается приставка; (6) при «Удалить» элемент удален успешно. (13-[US] Добавление комплексной метрики)
- 6.1 Меню арифметического оператора (выполнено 4.1): «+», «-», «*», «/» — заменяет на указанный знак; «Удалить» — удаление соответствующего элемента. Проверка: (4) при выборе другой операции смена арифметической операции прошла успешно; (5) при «Удалить» элемент удален успешно. (13-[US] Добавление комплексной метрики)
- 6.2 Меню константы (выполнено 4.2): «Удалить» — удаление выражения вместе с оператором. Проверка: (4) пользователь нажимает «Удалить» — элемент удален успешно. (13-[US] Добавление комплексной метрики)
- 6.3 Меню оператора «скобки» (выполнено 4.3): «Очистить выражение» — выражение внутри скобок очищается, скобки остаются; «Удалить скобки» — скобки удаляются вместе со всем выражением. Проверка: (4) пользователь заполняет выражение внутри скобок (предварительно сделав пространство внутри скобок активным как в 5.0), затем применяет «Очистить выражение» — скобки остаются, внутреннее выражение удаляется; (5) «Удалить скобки» — элемент удален успешно. (13-[US] Добавление комплексной метрики)
- 6.4 Меню оператора «Min», «Max», «Avg» (выполнено 4.4): «MIN» — замена текущего оператора на МIN; «MAX» — замена на МАX; «AVG» — замена на AVG; «Добавить выражение» — добавление нового незаполненного выражения справа; «Удалить оператор» — удаление оператора вместе со всеми скобками. Проверка: (4) при выборе MIN, MAX, AVG фиксируется изменение оператора; (5) при «Добавить выражение» добавляется новое выражение (текст обрезан). (13-[US] Добавление комплексной метрики)
- 6.5 Меню дочернего выражения оператора «Min», «Max», «Avg» (выполнено 4.4): «Очистить выражение» — удаление выражения вместе с содержанием (доступно); «Удалить выражение» — удаление выражения вместе с содержанием (условие недоступности связано с оператором, текст обрезан). Проверка: (4) пользователь выбирает дочернее выражение согласно 5.0 и применяет «Очистить выражение» — выражение осталось, содержимое удалено; (5) «Удалить выражение»: если у оператора > 2 выражений, выражение удаляется; если <=2 выражений, не удаляется. (13-[US] Добавление комплексной метрики)

### Открытые вопросы
- Формат отображения префиксов и иллюстрация «Выбран вариант PREV» не раскрыты в тексте фрагмента (в иллюстрациях упомянут вариант PREV, в таблице меню его нет). (13-[US] Добавление комплексной метрики)
- Условие недоступности «Удалить выражение» в 6.5 обрезано в тексте фрагмента. (13-[US] Добавление комплексной метрики)
