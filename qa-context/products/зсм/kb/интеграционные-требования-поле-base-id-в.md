# Интеграционные требования: поле base_id в метриках шаблона

> Новое поле base_id (uuid) в метриках шаблона, которое генерируется, копируется в черновик и передаётся между беком и фронтом, чтобы метрики можно было сопоставлять при точечном обновлении коллекции из шаблона.

### Описание
- В метриках шаблона добавляется новое поле uuid base_id. (59-1826. Реализация точечного обновления коллекции из шаблона)

### Бизнес-правила и ограничения
- Для всех текущих метрик шаблонов генерируется random uuid. (59-1826. Реализация точечного обновления коллекции из шаблона)
- При создании черновика шаблона для копий метрики шаблона черновика base_id копируется. (59-1826. Реализация точечного обновления коллекции из шаблона)
- При создании нового шаблона base_id для метрик шаблона генерируется random uuid. (59-1826. Реализация точечного обновления коллекции из шаблона)

### API и интеграции
- Бек отсылает на фронт base_id при любых чтениях фронта. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Фронт при редактировании шаблона отправляет на бек либо полученный при чтении base_id, либо пустое поле, если метрика новая. (59-1826. Реализация точечного обновления коллекции из шаблона)
