# Права ролей: метки на уровне экземпляра коллекции метрик и отдельных метрик

> Матрица действий с системными, пользовательскими, служебными метками, меткой «Для СЦ» и категориями на уровне экземпляра коллекции и метрик.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
Значения «Ответственный ИС» (действие / код):
- **Системная метка**: Создать (create) −; Применить (attach) +; Снять применение (detach) +; Просмотр (read) +; Удалить (delete) −.
- **Пользовательская метка**: Создать (create) +; Применить (attach) +; Снять применение (detach) +; Просмотр (read) +; Удалить (delete) −.
- **Служебная метка**: Создать (create) −; Применить (attach) −; Снять применение (detach) −; Просмотр (read) +; Удалить (delete) −.
- **Для СЦ**: Создать (create) −; Применить (attach) −; Снять применение (detach) −; Просмотр (read) +; Удалить (delete) −.
- **Категория**: Создать, Применить, Снять применение, Просмотр, Удалить (create, attach, detach, read, delete) — значения для роли не читаются.
- Для действия «Удалить» в ряде строк стоит ссылка PPMON-1144.
