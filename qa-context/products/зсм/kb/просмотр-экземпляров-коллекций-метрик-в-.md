# Просмотр экземпляров коллекций метрик в карточке объекта мониторинга и переключение между ними

> Просмотр экземпляров коллекций метрик (управляемых и внешних) в карточке объекта мониторинга: список плашек со статусами и действиями, переключение между экземплярами, переключатель «Управляемые»/«Внешние» и поиск.

### Описание
- Пользовательская история: «Я как Авторизованный Пользователь хочу иметь возможность просматривать экземпляры коллекций метрик в карточке объекта мониторинга, для того чтобы выбирать конкретные экземпляры для просмотра и редактирования атрибутов и метрик, переходить к добавлению новых экземпляров, дублировать существующие экземпляры, удалять устаревшие экземпляры, формировать заявки постановки на мониторинг и заявки на снятие с мониторинга». (69-🟩[RI1]Возможность Пользователя открыть коллекцию для просмотра _переключаться между коллекциями)
- Критерии приёмки: «Возможность Пользователя видеть информацию об экземплярах коллекций метрик объекта мониторинга» (1.0, 1.1), «Возможность пользователя видеть действия над экземпляром коллекции при наведении мыши на экземпляр в списке экземпляров коллекции» (2.0), «Возможность Пользователя открыть новый экземпляр коллекции через список экземпляров коллекции» (3.0), «Возможность Пользователя найти необходимый экземпляр коллекции» (4.0, 4.1). (там же)
- Документ — статья с историей версий 1.0–13.0: в 13.0 в критерий 1 добавлено описание отображения с учётом внешних метрик, добавлен прототип 1.2, описаны ограничения для коллекций типа EXTERNAL; в 12.0 добавлен критерий 7.0 (вкладка «История заявок»); в 11.0 добавлен критерий 6.0 (изменение названия коллекции); в 10.0 добавлена функциональность подсказки. (там же)

### Экраны и навигация
- Критерий 1.0: пользователь нажал на определённый КЕ в карточке мониторинга ИС. Условие: в системе заведена карточка мониторинга И (добавлена хотя бы одна коллекция управляемых метрик в результате выполнения [текст обрезан] И/ИЛИ добавлена хотя бы одна коллекция внешних метрик в результате выполнения «Автоматическое создание внешних метрик»). Результат: страница объекта мониторинга в соответствии с #1.1-1.2 Визуальный дизайн. (там же)
- Состав страницы: заголовок выбранного объекта мониторинга; справа — список экземпляров коллекций текущего объекта мониторинга, для каждого отображается статус согласно «Статусная модель» + действия, доступные для коллекций в зависимости от статусов заявок. (там же)
- По умолчанию выбран первый экземпляр в списке; вкладки карточки экземпляра: метрики/атрибуты/история заявок/комментарии, по умолчанию «Атрибуты». (там же)
- Вкладка «Атрибуты»: перечень атрибутов, сформированных при добавлении/редактировании экземпляра; доступность редактирования определяется статусной моделью. (там же)
- Критерий 1.1: пользователь нажал на определённый объект мониторинга/метрики ИС в карточке мониторинга ИС И ни одной коллекции не добавлено. Результат: страница объекта мониторинга и сообщение «Нет ни одной коллекции» (#1.3 Визуальный дизайн). Можно добавить коллекцию (см. [RI1] Возможность Пользователя добавить коллекцию метрик для объекта мониторинга в карточке мониторинга) и удалить объект мониторинга (см. [RI1] Возможность Пользователя управлять карточкой мониторинга ИС). (там же)
- Критерий 3.0 (условие: выполнен 2.0): нажатие на плашку открывает выбранный экземпляр коллекции, отображение элементов аналогично 1.0. (там же)

### Поля и элементы
- Логика списка: только управляемые (вручную) — видны коллекции типов кроме EXTERNAL, автоматически выбирается самая свежая не-EXTERNAL (#1.1 Визуальный дизайн); только внешние — видны только EXTERNAL, выбирается самая свежая EXTERNAL; и внешние, и управляемые — переключатель «Управляемые»/«Внешние» (по умолчанию «Управляемые», выбрана самая свежая управляемая коллекция); при переключении отображаются все не-External или все External. (там же)
- Действия над плашкой: удалить экземпляр — см. [RI1] Возможность пользователя удалять экземпляры коллекций метрик (по статусной модели), недоступно для External; дублировать — см. [RI1] Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС, недоступно для External; массовый отбор коллекций для остановки и возобновления сбора данных — см. [US] Массовая остановка/возобновление сбора данных для коллекций объекта мониторинга. (там же)
- Действия в боковом списке: переключиться между External и не-External (если коллекции двух типов); поисковая строка/сброс результатов (критерий 4.0); наведение на другую плашку (критерий 2.0); выбор коллекции (критерий 3.0); добавить коллекцию — [RI1] Возможность Пользователя добавить коллекцию метрик для объекта мониторинга в карточке мониторинга; массовый выбор коллекций для остановки и возобновления сбора данных, см. [US] Массовая остановка/возобновление сбора данных для коллекций связанных с ТУЗ. (там же)
- Действия над карточкой: редактировать заголовок — название экземпляра без ограничений (Критерии приёмки, п. 6.0); переключаться между вкладками; остановка сбора данных — [US] Остановка сбора данных для коллекции; возобновление — [US] Возобновление сбора данных для коллекции. (там же)
- Действие над всем объектом — удалить объект мониторинга: кнопка только для типа «Информационная система»; обработка аналогична удалению из списка, см. [RI1] Возможность Пользователя управлять карточкой мониторинга ИС. (там же)
- Критерий 2.0 (условие: выполнен 1.0 И в объект добавлено больше 1-й коллекции; действие: навести мышь на плашку, отличную от текущей): страница по #2.0 Визуальный дизайн; плашка выделяется, на ней отображаются действия (только для не-External): удалить экземпляр (по статусной модели), дублировать экземпляр, управлять списком меток. (там же)

### Бизнес-правила и ограничения
- «Удалить» и «дублировать» недоступны для External; действия на плашке при наведении — только для не-External. (там же)
- Переключатель «Управляемые»/«Внешние» — только при коллекциях двух типов. (там же)
- Критерий 4.0 (условие: выполнен 1.0): значение введено в поиск И совпадение найдено после ввода не менее 3-х символов (текущее состояние переключателя «Управляемые»/«Внешние» не учитывается). Результат: отображены подходящие экземпляры, можно выбрать экземпляр (#2.1 Визуальный дизайн). (там же)
- Критерий 4.1: совпадение НЕ найдено после ввода не менее 3-х символов — сообщение «Ничего не найдено» (#2.2 Визуальный дизайн). (там же)

### Сообщения и ошибки
- «Нет ни одной коллекции» (1.1); «Ничего не найдено» (4.1). (там же)

### Роли и права
- Критерии 1.0–4.1: Авторизованный Пользователь. Критерий 7.0 (вкладка «История заявок»): Ответственный ИС/Инженер ЗОНТ/Аудитор ИБ. (там же)
