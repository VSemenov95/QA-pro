# Добавление синтетической метрики: кнопка, шторка и форма добавления

> Добавление синтетической метрики в экземпляр коллекции метрик: кнопка «Добавить синтетическую метрику», шторка с конструктором арифметического выражения, переменными, порогами и метками, проверки при сохранении и запись метаданных.

### Описание
- User story: «Я как Авторизованный пользователь. Хочу задать арифметическое выражение из метрик коллекции с помощью конструктора для формирования синтетической метрики. Для того, чтобы поставить на мониторинг синтетическую метрику для сбора данных с экспортера по заданному арифметическому правилу». (25-[US] Добавление синтетических метрик)
- Работы в разрезе спецификации: 1) переход к добавлению синтетической метрики в списке метрик (критерий 1.0); 2) добавить/изменить/удалить переменную (2.0-2.4); 3) добавить/изменить/удалить элементы в конструкторе (3.0-3.4); 4) переключение уровней вложенности (4.0-4.2); 5) подтвердить добавление (5.0-5.3); 6) подтвердить изменение карточки при нажатии вне формы (6.0). (25-[US] Добавление синтетических метрик)
- История изменений: 1.0 (06 фев. 2023 / 26.11.2023, Шашков Алексей, «Конструктор для формирования арифметических выражений на основании метрик», закрыто) — первая версия на PROMQL запросах. 2.0 (15.12.2023, Шашков Алексей, PPPM-2971 [RI2][BA] Проработка требований к сохранению временного ряда для синтетики, закрыто) — вторая версия с конструктором. 3/0 [так в документе] (30.01.2024, Шашков Алексей, PPPM-3373) — формат изменен: из сценарного описания в описание по геркину. (25-[US] Добавление синтетических метрик)

### Экраны и навигация
- Критерий 1.0: пользователь нажал «Добавить синтетическую метрику» → видит шторку редактирования коллекции метрик по #1.0 Визуальный дизайн: редактируемое название синтетической метрики, нередактируемый подзаголовок «Синтетическая». (25-[US] Добавление синтетических метрик)
- Условия 1.0: пользователь добавил коллекцию метрик на основании шаблона с признаком автопостановки (#[RI1] Возможность Пользователя добавить коллекцию метрик для объекта мониторинга в карточке мониторинга) И открыл список метрик (#[RI1] Возможность пользователя просматривать/редактировать список метрик экземпляра коллекции метрик); список доступен для редактирования согласно #PM. Статусная модель заявки на мониторинг/объекта мониторинга. (25-[US] Добавление синтетических метрик)
- Прототипы: 1 Figma — карточка добавления, параметры не заполнены; 2 управление переменными (2.1 одна незаполненная строка, 2.2 строка заполнена корректно); 3 переменная добавлена в конструктор (без контекстного меню / с контекстным меню); 4 арифметическая операция; 5 константа; 6 Figma (на основании конструктора для комплексных метрик) — скобка; 7 оператор. (25-[US] Добавление синтетических метрик)
- Связанные документы: 1 — фича первой версии: https://sfera.inno.local/knowledge/pages?id=966729; 2 — основная статья о конструкторе: https://sfera.inno.local/knowledge/pages?id=1108194. (25-[US] Добавление синтетических метрик)

### Поля и элементы
- Шторка содержит: блок основных параметров коллекции — единица измерения, тип данных, активность (логика как у прочих метрик, см. #[RI1] Возможность Пользователя просматривать/редактировать карточку конкретной метрики). (25-[US] Добавление синтетических метрик)
- Блок конструирования: незаполненный блок управления переменными и кнопка «Добавить переменную»; незаполненный блок конструктора с кнопками +, -, *, /, (), min, max, avg, const; блок результирующего выражения с подсказкой «Сформируйте выражение с помощью конструктора». (25-[US] Добавление синтетических метрик)
- Обязательный параметр типа «дробь» «Укажите значение, которое будет формироваться в случае ошибки», по умолчанию 0.0. Подставляется как результат, если в любую переменную передан результат деления на ноль ИЛИ при вычислениях совершено деление на ноль. (25-[US] Добавление синтетических метрик)
- Блок управления метками (аналогичный описанному в «Метки»); блок управления порогами (аналогичный #[RI1] Возможность Пользователя просматривать/редактировать карточку конкретной метрики); кнопки «Добавить» и «Отменить»/X. (25-[US] Добавление синтетических метрик)
- Модальное окно «Сохранить изменения» (6.0): 'Х'/'Назад к заполнению', 'Не сохранить', 'Сохранить'. (25-[US] Добавление синтетических метрик)

### Бизнес-правила и ограничения
- Добавление синтетической метрики считается редактированием формы экземпляров коллекций; доступ по ролевой модели (https://sfera.inno.local/knowledge/pages?id=981853). Все критерии выполняются для одного типа объекта: METRIC_COLLECTION/update. (25-[US] Добавление синтетических метрик)
- Добавление возможно в форме добавления коллекции только если коллекция доступна для редактирования по #PM.Статусная модель заявки на мониторинг/объекта мониторинга. (25-[US] Добавление синтетических метрик)
- Любое изменение экземпляра коллекции (в т.ч. добавление метрики, изменение порогов) переводит его в состояние «Отредактировано»; пользователь должен повторно отправить заявку на мониторинг. (25-[US] Добавление синтетических метрик)
- 5.0: нажал «Отмена»/X (выполнено 1.0) → форма закрывается, метрика не добавляется. (25-[US] Добавление синтетических метрик)
- 5.1: если хотя бы одно обязательное поле в таблице порогов/шапке/управлении метрик не заполнено или некорректно, ИЛИ не заполнен параметр «Укажите значение, которое будет формироваться в случае ошибки», ИЛИ не заполнены поля добавленных переменных, И нажато «Добавить» → метрика не добавлена; форма открыта; подсвечиваются все незаполненные/некорректные поля; текстовая ошибка: незаполненные значения — TBD; незаполненные переменные — TBD; некорректное выражение — по описанию из «Конструктор для формирования арифметических выражений на основании метрик». (25-[US] Добавление синтетических метрик)
- 5.2: выражение некорректно по https://sfera.inno.local/knowledge/pages?id=1108194 И нажато «Добавить» → метрика не добавлена; форма открыта; область конструктора подсвечена красным; сообщение об ошибке с перечнем замечаний по таблице из «Конструктор для формирования арифметических выражений на основании существующих метрик», п. «Проверки выражения при сохранении для выражения конструктора». (25-[US] Добавление синтетических метрик)
- 5.3: корректно заданы шапка/пороги/метки/выражение и значение «Укажите значение, которое будет формироваться в случае ошибки» И нажато «Добавить» → форма закрывается; сообщение об успешном добавлении; новая метрика с типом коллекции «Синтетическая» добавляется в список коллекций метрик; статус коллекции «Отредактировано»; метаданные сохраняются по #1.0 Комментарий для разработки/тестирования. (25-[US] Добавление синтетических метрик)
- 6.0: изменены пороги/настройки конструктора и переменных/шапка И нажата область вне формы → модальное окно 'Сохранить изменения'. 'Х'/'Назад к заполнению': окно закрыто, пользователь на форме, изменения отображены. 'Не сохранять' [так в документе]: окно и форма закрыты, изменения не сохранены. 'Сохранить': окно закрыто И выполнены проверки 5.0-5.3. (25-[US] Добавление синтетических метрик)

### API и интеграции
- В таблице metrcis [так в документе] сохраняются: metric_source_type, STRING — synthetic; metric_key, STRING — маска %название типа коллекции метрик%_synthetic_metric; promql_expression, STRING — маска %metric_key%{metricInstanceId="%id%"}, где metric_key и id — параметры коллекции в таблице metrics. (25-[US] Добавление синтетических метрик)
- В разрезе метрики сохраняются: expression — арифметическое выражение из конструктора (логика перевода — п. «Конструктор для формирования арифметических выражений на основании существующих метрик»); default_value — значение по умолчанию, если в expression получен NaN (деление на ноль) ИЛИ при расчёте произошло деление на ноль после подстановки значений. (25-[US] Добавление синтетических метрик)
- Вместе с метрикой сохраняется JSON фронта (выражение и выбранные переменные); используется при открытии коллекции на редактирование — пользователь видит то же выражение и переменные. (25-[US] Добавление синтетических метрик)
- В SYNTH_METRIC_LINK сохраняются все метрики, выбранные как переменные, независимо от использования в выражении. (25-[US] Добавление синтетических метрик)
