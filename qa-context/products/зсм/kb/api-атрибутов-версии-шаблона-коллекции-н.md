# API атрибутов версии шаблона коллекции (настройка, получение, редактирование, удаление)

> Административный REST API атрибутов версии шаблона коллекции метрик: настройка параметров отображения, получение списка и одного атрибута, редактирование и удаление по идентификатору.

### Описание
- Методы администрирования атрибутов версии шаблона коллекции метрик: настройка параметров отображения атрибутов в коллекции метрик, получение списка, получение, редактирование и удаление атрибута по идентификатору. (portalbackend)

### Поля и элементы
**Настройка отображения (элемент массива тела PUT .../attributes/configure):**
- id (integer, int64) — Идентификатор
- technicalName (string) — Техническое наименование
- orderWeight (integer, int32) — Параметр, определяющий позицию атрибута в списке
- hidden (boolean) — Параметр для настройки видимости атрибута в коллекции метрик
- editable (boolean) — Параметр для настройки возможности редактирования атрибута в коллекции метрик (portalbackend)

**Атрибут (GET-ответ, элемент items списка и тело PUT по id):**
- name (string, обязательное) — Наименование
- technicalName (string, обязательное) — Техническое наименование
- value (object, необязательное): id (integer, int64) — Идентификатор; value (string) — Значение по умолчанию; valueTypeId (integer, int32) — Идентификатор значения по умолчанию для атрибута типа Список; key (string) — Ключ значения по умолчанию; dataType (string: STRING | LONG | FLOAT | TEXT | PRE_KNOWN_LIST | SERVICE_ACCOUNT | BOOLEAN | MAP | LIST | INTEGRATION_POINT | NETWORK_ZONE | SCRIPT) — Тип данных значения; additionalData (object) — Дополнительная ячейка данных; displayName (string) — Пользовательское название
- values (массив object) — Значения атрибута; элементы имеют ту же структуру, что и value (id, value, valueTypeId, key, dataType, additionalData, displayName)
- required (boolean, обязательное) — Обязательность атрибута
- hidden (boolean) — Параметр для настройки видимости атрибута в коллекции метрик
- editable (boolean) — Параметр для настройки возможности редактирования атрибута в коллекции метрик (portalbackend)
- Только в GET-ответе и элементах списка: id (integer, int64) — Идентификатор; attributeType (object: id (integer, int32) — Идентификатор; name (string) — Значение); type (string: USER | SYSTEM) — Тип источника атрибута; tooltip (string) — Подсказка (portalbackend)
- Только в теле PUT по id: attributeTypeId (integer, int32, обязательное) — Тип атрибута (portalbackend)

### API и интеграции
- **PUT /admin/metric-collection-template/version/{templateVersionId}/attributes/configure** — Настройка параметров отображения атрибутов в коллекции метрик. Параметры: templateVersionId (в пути, integer, обязательный). Тело (application/json): массив элементов (id, technicalName, orderWeight, hidden, editable). Ответ: 200 — OK. (portalbackend)
- **GET /admin/metric-collection-template/version/{templateVersionId}/attribute** — Получение списка. Параметры: templateVersionId (в пути, integer, обязательный); filter (в запросе, object, обязательный). Ответ 200 — OK: itemsCount (integer, int64) — Общее число элементов; items (массив) — Элементы на странице (поля атрибута выше). (portalbackend)
- **GET /admin/metric-collection-template/version/{templateVersionId}/attribute/{id}** — Получение по идентификатору. Параметры: templateVersionId (в пути, integer, обязательный); id (в пути, integer, обязательный). Ответ: 200 — OK (поля атрибута выше). (portalbackend)
- **PUT /admin/metric-collection-template/version/{templateVersionId}/attribute/{id}** — Редактирование по идентификатору. Параметры: templateVersionId, id (в пути, integer, обязательные). Тело (application/json): name, technicalName, value, values, required, hidden, editable, attributeTypeId. Ответ: 200 — OK. (portalbackend)
- **DELETE /admin/metric-collection-template/version/{templateVersionId}/attribute/{id}** — Удаление по идентификатору. Параметры: templateVersionId, id (в пути, integer, обязательные). Ответ: 200 — OK. (portalbackend)
