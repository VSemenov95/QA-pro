# Аудит и История изменений БС

> Раздел описывает доработку Аудита и Истории изменений БС для фиксации операций постановки БС на Базовый мониторинг и снятия БС с него, а также просмотр этих операций пользователями.

### Описание
- Доработан перечень событий для Аудита согласно новым функциям. (12-PPMON-1879. Базовый мониторинг)
- Доработана История изменений БС: поддержка новых функций «Постановка БС на Базовый мониторинг» и «Снятие БС с базового мониторинга». (12-PPMON-1879. Базовый мониторинг)
- Обе операции фиксируются в Аудите и Истории изменений БС. (12-PPMON-1879. Базовый мониторинг)

### API и интеграции
- СС Аудит: оформляется типовая запись о снятии конкретной БС с базового мониторинга (в разделе 7 упоминается только снятие). (12-PPMON-1879. Базовый мониторинг)

### Роли и права
- 3.1 Просмотр операций установки/снятия БС: объект «История изменений БС/read»; роли: «Просмотр сервисов (в разрезе своих БС)», «Пользователь (в разрезе своих БС)», «Технолог БС (в разрезе своих БС)», «Инженер ЗОНТ». (12-PPMON-1879. Базовый мониторинг)

### Сценарии
- 3.1 Просмотр операций установки/снятия БС с базового мониторинга в списке БС: при открытии истории изменений БС ([US] Просмотр истории изменений в карточке) пользователь бизнес-сервиса видит заявки, созданные при установке/снятии БС с мониторинга при выполнении п. 1.1 и 1.2. (12-PPMON-1879. Базовый мониторинг)

### Открытые вопросы
- В разделе 7 описана запись в Аудит только о снятии БС; о записи при постановке явно не сказано (в разделе 2 сказано, что обе операции фиксируются в Аудите). (12-PPMON-1879. Базовый мониторинг)
