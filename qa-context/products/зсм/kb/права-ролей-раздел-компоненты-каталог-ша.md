# Права ролей: раздел «Компоненты» — каталог шаблонов коллекций, комментарии и входные атрибуты

## 200-Описание ролевой модели ЗСМ.pdf

### Описание
- Матрица прав для раздела «Компоненты» / подраздела «Каталог шаблонов коллекций». Ниже указаны значения колонки «Ответственный ИС» (+ разрешено, − запрещено).

### Роли и права
- Глобальный раздел «Компоненты» со всеми подразделами: Просмотр (read) +.
- Вкладка «Компоненты» с подразделами/иконами «Каталог шаблонов коллекций»: Просмотр (read) +.
- Каталог шаблонов коллекций: Просмотр (read) +.
- Шаблон коллекций: Просмотр (read) +; Создание (create) −; Удаление (delete) −; Редактирование, в т.ч. редактирование карточек метрик (update) −.
- Шаблон коллекции (Комментарии): Просмотр (read) +; Добавление (create) −; Редактирование (update) −; Удаление (delete) −.
- Шаблон коллекции (Входные атрибуты — Системные) (PPPM-7241): Просмотр (read) +; Редактирование (update) −.
- Шаблон коллекции (Входные атрибуты — Пользовательские) (PPPM-7241): Просмотр (read) +; Добавление (create) −; Редактирование (update) −; Удаление (delete) −.
- Шаблон коллекции (Входные атрибуты — Метрики) (PPPM-7241): Просмотр (read) +; Добавление (Синтетические и метрики-контейнеры) (create) −; Редактирование (update) −; Удаление (Синтетические и метрики-контейнеры) (delete) −.
