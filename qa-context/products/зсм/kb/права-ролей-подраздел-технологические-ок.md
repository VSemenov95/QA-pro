# Права ролей: подраздел «Технологические окна» и звуковые уведомления

> Права на вкладку, каталог и карточку технологических окон (ТО) с ограничениями по доступным ИС/КЕ/БС, а также доступ к звуковым уведомлениям панели событий.

## 200-Описание ролевой модели ЗСМ.pdf

### Поля и элементы
- 5.5 «Технологические окна»:
  - 97 Вкладка «Администрирование» с подразделом «Технологические окна»: Просмотр read +.
  - 98 Каталог ТО: Просмотр read + — все ТО, в которых есть хотя бы одна ИС или КЕ, доступные пользователю. Для роли БС: все ТО, в которых есть хотя бы одна БС, доступная пользователю (PPPM-998); для другой роли: все ТО, в которых есть хотя бы одна ИС, КЕ или БС, доступные пользователю.
  - 99 Карточка ТО: Просмотр read + — все ТО, в которых есть хотя бы одна ИС или КЕ, доступные пользователю (аналогично для БС и для ИС/КЕ/БС).
  - Добавление create + — может добавлять только свои ИС/КЕ (для БС — только свои ТО, PPPM-998).
  - Редактирование update + — ко всем ИС/КЕ в ТО у пользователя есть доступ (для БС — ко всем БС в ТО, PPPM-998).
  - Удаление delete + — ко всем ИС/КЕ в ТО у пользователя есть доступ; только в статусе «Отключено» (для БС — ко всем БС в ТО у пользователя есть доступ, только в статусе отключено, PPPM-998).
  - Включение/Отключение switch_on/switch_off + — ко всем ИС/КЕ в ТО у пользователя есть доступ (для БС — ко всем БС, PPPM-998).
- 5.6 «Пользовательские настройки» (Звуковые уведомления):
  - 100 Звуковые уведомления (для «Панели событий»): Просмотр раздела (идентично настройкам доступа к просмотру «Панели событий») read +.

### Открытые вопросы
- Знаки по ролям разорваны, соответствие ролям не восстановимо.
