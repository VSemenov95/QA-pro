# Карточка метрики экземпляра коллекции: просмотр и редактирование (поля, пороги)

> Просмотр и редактирование карточки метрики экземпляра коллекции метрик: параметры шапки, пороговые значения, сохранение, отключение виджетов и подтверждение изменений.

### Описание
- История: «Я как Авторизованный Пользователь хочу иметь возможность редактировать параметры экземпляра метрики, для того чтобы внести изменения в параметры экземпляра метрики коллекции метрик». Контекст: редактирование параметров шаблона/экземпляра метрики и их пороговых значений, работа которых отслеживается при эксплуатации ИС. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Критерии: редактирование метрики (1.0-1.3); добавить порог (2.0-2.1); изменить порог (3.0); удалить порог (4.0); сохранить карточку (5.0-5.3); отключить виджеты при отключении метрики (6.0-6.3); подтвердить изменение при нажатии вне формы (7.0-7.3); добавление нескольких порогов одного уровня (8.0-8.2). Реакция на порог — PPPM-117 [RI1](Реакции), вне спецификации. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Связанные задачи: PPPM-1417, PPPM-2564, PPMON-208, PPPM-87, PPPM-88, PPPM-89, PPPM-842, PPPM-117, PPPM-90. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- История версий: 1.0 08.06.22 (PPPM-89) … 14 05.04.2024 (PPPM-4816, автоматическое создание порога NORMAL); 15 28.06.24 (PPPM-6556, невозможно установить пороговое значение меньше 0.01); 16 17.07.24 (PPPM-5804, запрос метрики в VM); 17 28.01.26 Мысев А.Э. (поддержка порога типа «NO DATA» (Нет данных)). Ограничение: нельзя создавать два порога разного уровня с идентичными операторами и значениями. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)

### Экраны и навигация
- Форма открывается кликом по записи на вкладке «Метрики» карточки экземпляра коллекции. Вкладки: «Параметры» (по умолчанию); «Связанные метрики» (рядом количество; только для типов коллекций, допускающих переменные в синтетических/комплексных метриках); «Связанные точки мониторинга БС» (рядом количество метрик-копий; только для типов коллекций, доступных для добавления в ТМ БС); «Внешний ряд» (только EXTERNAL); «Временные ряды (0)» (только метрика-контейнер; в скобках ряды, активные за последние 24 часа). (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- На форме: поля шапки; для синтетической/комплексной — блок формирования выражения и сформированное выражение; для метрики-контейнера — правила фильтрации и именования рядов (радиобаттон один ряд/все ряды заблокирован). Кнопки «Сохранить», «Отменить»/«X»; таблица порогов. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Окно «Сохранить изменения»: «Х»/«Назад к заполнению», «Не сохранить», «Сохранить». Окно отключения виджетов: «Отключить виджеты», «Отмена». (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)

### Поля и элементы
- Шапка: Название (строка, обяз., редактируется для всех типов кроме Внешних); Тип метрики (не ред.: регулярная, динамическая, синтетическая, комплексная, внешняя, метрика-контейнер); Тип данных (список: строка, число, дробь, текст, список, булевая переменная; обяз., ред.); Единицы измерения (строка, обяз., ред.); Связь с временным рядом (список, не обяз., только для динамических, будет удалено после миграции на метрики-контейнеры); Доступность метрик (переключатель Вкл/Выкл, обяз., ред.; при добавлении вместе со скриптом при редактировании — ВКЛ; проверки при сохранении); PromQL-запрос (promql_expression, обяз., не ред., кнопка копирования); Метод расчета (список, обяз., ред.; для статуса коллекции: «По максимальному уровню» по умолчанию, «По минимальному уровню»). (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Порог: Уровень (список: 'Предупреждение', 'Критический', 'Нормальный' при «Ручное формирование порогов «Нормальный»» = true; обяз., ред.); Оператор (обяз., ред.: Больше (>) по умолчанию, Меньше (<), Больше либо равно (>=), Меньше либо равно (<=), Равно (==), Не равно (!=), Нет данных — «NO DATA»); Значение (дробь, обяз., ред.); Описание (текст, не обяз., ред.). (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Новая строка порога: кнопка удаления строки; доступны только «Оператор» и «Значение»; Сохранить/Отменить. У «Нормального» порога доступны только «Описание», «Правило реагирования», «Группа рассылки ЭКОС». (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)

### Бизнес-правила и ограничения
- Авторизация с одной ролью Суперпользователь до имплементации Ролевой модели (разграничение прав не предусмотрено). (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Карточка редактируема, только если экземпляр коллекции редактируем по статусной модели (#PM. Статусная модель заявки на мониторинг/объекта мониторинга); для внешней метрики — если не включён внешний тоггл, запрещающий редактирование. Любое изменение экземпляра (в т.ч. добавление динамической метрики, изменение порогов) переводит его в «Отредактировано», нужна повторная отправка заявки на мониторинг. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- Можно задать ИЛИ один порог «критический», ИЛИ один «предупреждение», ИЛИ оба. Запрещён ввод порогов с одинаковыми операторами и одинаковым значением. Событие по порогу формируется в панели событий при нарушении значения согласно знаку оператора. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- При добавлении первого порога автоматически добавляется «Нормальный»; при «Ручное формирование порогов "Нормальный"» = false его «Оператор» и «Значение» рассчитаны автоматически и заблокированы (прочерки), доступны «Описание», «Правило реагирования», «Группа рассылки ЭКОС»; кнопка удаления Normal доступна только при = true; Normal удаляется, если остался единственным порогом (при = false). (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- При «Сохранить» с незаполненными обязательными полями они подсвечиваются красным. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
- «Булева переменная»: операторы только Равно (==), Не равно (!=); значения только «1» и «0». Метод расчета статуса коллекции — только для метрик типа статус коллекции. (68-🟩[RI1] Возможность Пользователя просматривать_редактировать карточку конкретной метрики экземпляра коллекции)
