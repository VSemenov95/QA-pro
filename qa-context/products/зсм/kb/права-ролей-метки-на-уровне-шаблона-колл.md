# Права ролей: метки на уровне шаблона коллекции

> Матрица действий с метками (пользовательская, системная, служебная, «Для СЦ», категории) на уровне шаблона коллекции.

## 200-Описание ролевой модели ЗСМ.pdf

### Описание
- Типы меток в матрице (поз. 9): Пользовательская метка, Системная метка, Служебная метка, Для СЦ, Категории.

### Роли и права
- Значения для «Ответственный ИС»: Создать метку (create) −; Применить метку (attach) −; Снять метку (detach) −; Просмотреть метку (read) +; Удалить метку (delete) −.
- В последующих фрагментах таблицы встречаются пометки «+ (Пользовательскую/Системную/Служебную метки)» для действий «применить/снять» и ссылка PPMON-1144 у действия «Удалить»; к конкретной роли они в тексте не привязаны.

### Открытые вопросы
- Раскладка значений по типам меток и остальным ролям в извлечённом тексте читается неоднозначно.
