# Массовое редактирование коллекций: настройка правил замены

> Мастер массового поиска и изменения коллекций в разрезе ИС и шаблона: этап настройки правил замены (по атрибутам шаблона, параметрам коллекции, метрики и контейнера) с операторами изменения, ограничениями и настройкой списка запрещённых атрибутов в CSM.

### Описание
- После выбора шаблона на первом этапе и настройки фильтров пользователь видит форму настроек преобразования. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Типы правил замены: атрибут шаблона (2.1.2.1), параметр коллекции (2.1.2.2), параметр метрики (2.1.2.3), параметр контейнера (2.1.2.4). Состав правил замены изменяется в зависимости от выбранного типа. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Набор правил по метрикам и параметрам коллекций универсальный и не зависит от шаблона; набор правил по атрибутам зависит от выбранного шаблона. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Для типа «атрибут шаблона» параметром замены может быть любой атрибут шаблона, системный или пользовательский; по типу атрибута в шаблоне меняются набор операторов и набор значений для оператора «установить новое значение». (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Экраны и навигация
- Заголовок формы: «Настройка правил изменения коллекции». Есть блок управления правилами замены через И: добавление, редактирование и изменение правил. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Кнопки: «Назад» — возврат к предыдущему этапу со сбросом настроек текущего (альтернатива: переход по иконкам предыдущего этапа); «Далее» — переход к следующему этапу; «Отменить» — отказ от массового поиска и замены, с пользовательским предупреждением. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Поля и элементы
- Для каждого правила: тип параметра, который будет изменён; параметр (с поиском по значению); операция изменения; значение операции (если задано согласно типу). (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- 2.1.2.1 Атрибут шаблона. Везде оператор «установить новое значение» = Да; условие доступности: «Доступно если такой атрибут задан в шаблоне». «Установить пустое значение» — «Да, если атрибут шаблона необязательный» (кроме Булево — Нет). Применение — «Полная замена на новое значение», если не указано иное:
  - (Строка): Поле для ввода; (Текст): Область для ввода; (Число), (Дробь): Поле для ввода; ввод нового значения.
  - (Булево): выпадающий список с 1 значением, выбор true или False.
  - (ТУЗ): выпадающий список с 1 значением; выбор с учётом ограничений как при фильтрации ТУЗ.
  - (Перечень/Базы данных), (Перечень/Расписание), (Точка подключения), (сетевая зона) %название сетевой зоны%: выпадающий список с 1 значением; выбор как при фильтрации.
  - (Список): строки с добавлением/удалением, структура наследуется из шаблона; ввод в каждую строку; полная перезапись атрибута у найденных коллекций на указанные значения.
  - (Массив): фиксированный набор строк ключ/значение; для Script_args наследуется из шаблона, а в шаблоне — из скрипта; полная перезапись; дополнительно «Массив script_args доступен если такой массив задан для скрипта в шаблоне».
  - (Подстановка из ТУЗ): фиксированный набор правил подстановки с выбором ТУЗ для каждой; наследуется из шаблона, а в шаблоне — из скрипта; выбор как при фильтрации; полная перезапись; доступно, если для шаблона выбран скрипт с соответствующей подстановкой. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- 2.1.2.2 Параметр коллекции (доступны всегда; колонки операторов: новое / пустое / Добавить / Удалить; элемент не отображается для «установить пустое значение»):
  - Метка: Нет / Да / Да / Да; выпадающий список с мультиселектом, ограничения на выбор меток как при фильтрации. Пустое — все метки удаляются; Добавить — новые метки добавляются в коллекции и их дочерние метрики; Удалить — метки, доступные для снятия пользователем, удаляются у коллекции, если ранее были добавлены.
  - Признак бизнес-сервиса: Да / Нет / Да / Да; выпадающий список с 1 значением, true или False; применение «Как у булевого оператора»; значение False; полная замена. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- 2.1.2.3 Параметр метрики (доступны всегда; порядок операторов: новое / пустое / Добавить / Удалить):
  - Название метрики: Да / Нет / Нет / Нет; поле для ввода; полная замена.
  - Активность: Да / Нет / Нет / Нет; выпадающий список с 1 значением, true или False; полная замена.
  - Метки метрики; Категории: Нет / Да / Да / Да; выпадающий список с мультиселектом, ограничения как при фильтрации; применение аналогично меткам коллекции.
  - %Уровень порога%/группа рассылки ЕСМ: Да / Да / Нет / Нет; выпадающий список с 1 значением, любая группа рассылки ЕСМ; полная замена.
  - %Уровень порога%/Условие: Да / Да / Нет / Нет; форма создания порогов как в карточке; формирование логического выражения по порогам; полная замена.
  - %Уровень порога%/правило реагирования: Да / Да / Нет / Нет; выпадающий список с 1 значением, оператор из фиксированного списка; полная замена. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- 2.1.2.4 Параметр контейнера (доступны всегда; колонки: новое / пустое):
  - Шаблон имени ряда: Да / Нет; поле для ввода; полная замена.
  - Параметр фильтрации: Да / Да; элемент — Массив; формирование нового массива как при добавлении метрики; полная замена.
  - Тип агрегации: Да / Нет; выбор из выпадающего списка из типов агрегации, разрешённых для агрегирующего контейнера; полная замена. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Бизнес-правила и ограничения
- Корректным считается заполненное правило. Правила добавляются через И и применяются последовательно, как указано в списке. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Верхнее правило удалить нельзя. Нельзя добавить новое правило, пока не заполнено предыдущее. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- При смене выбранного параметра изменения выбранный тип операции сбрасывается. При смене типа операции внесённые изменения сохраняются, если не изменился элемент для замены. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Исключения: недоступен выбор атрибутов, скрытых или нередактируемых на уровне шаблона (PPPM-2587 (Карточки ИС), смотреть «hidden» и «editable» при выводе атрибутов на этапе замены, Закрыто); недоступен выбор запрещённых атрибутов согласно файлу в CSM. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- «Далее»: если правила не заполнены — подсветка красным, переход не происходит; если заполнены корректно — переход к этапу выбора коллекций. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Сценарий 11: добавить настройку в CSM для запрета изменения конкретных атрибутов коллекций через массовое изменение по техническому названию. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### API и интеграции
- Настройка в CSM: список запрещённых к массовому изменению атрибутов коллекций (по техническому названию) и файл запрещённых атрибутов в CSM. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)

### Роли и права
- Настройку списка исключений выполняет Инженер ЗОНТ. (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
- Инженер ЗОНТ просматривает и управляет новыми заявками поиска замены и подзаявками без ограничений. Ответсвенный ИС просматривает новые заявки поиска замены и подзаявки только по своим ИС. Ограничения на работу с заявками прежние: сценарии Карточка заявки.read/assign/automonitoring/readis/changestatus согласно «Описание ролевой модели ЗСМ». (50-[US] Массовый поиск и изменение коллекций в разрезе ИС _ Шаблона)
