# Список шаблонов коллекций и просмотр версий шаблона

> Раздел описывает просмотр списка шаблонов коллекций (новые столбцы «версия» и «наличие черновика»), карточки шаблона с учётом черновика, выпадающего списка версий, выбор версии для просмотра и выбор черновика через меню версий.

### Описание
- Раздел охватывает просмотр списка шаблонов коллекций, просмотр карточки шаблона с учётом черновика, просмотр списка версий шаблона, выбор версии для просмотра и выбор черновика через меню версий. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- GET /admin/metric-collection-template: «Список шаблонов, отбирается последняя версия или черновик каждого шаблона». (portalbackend)

### Экраны и навигация
- 2.0 Просмотр списка шаблонов коллекций (Каталог шаблонов коллекции /read). Список открывается согласно RI1 «Возможность Пользователя просматривать список шаблонов и удалять шаблоны в Каталоге шаблонов коллекций». (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 2.1 Просмотр карточки шаблона с учётом черновика (Карточка шаблона /read; в 59-230 экран назван «Карточка шаблона коллекции»). Предусловие: выполнено 2.0. При открытии строки шаблона всегда открывается последняя актуальная версия, аналогично 1.1. Номер в плашке — номер текущей актуальной версии. Кнопка создания черновика доступна, если черновик для версии не создан. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 3.0 Просмотр списка версий шаблона (в 59-230: «Просмотр списка версий для выбора версии») (/read). Пользователь открыл шаблон (1.1 или 2.1) и видит в карточке выпадающий список для выбора версии; если параллельно существует черновик — отображается ещё и плашка «Черновик». (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 3.1 Выбор версии для просмотра (/read). Предусловие: выполнено 3.0. Пользователь выбирает версию и нажимает кнопку (в тексте документов кнопка не названа). Если выбрана актуальная версия — то же, что в 1.1/2.1 в зависимости от номера версии. Если выбрана предыдущая версия — форма просмотра шаблона без возможности внесения изменений, создания черновика, добавления меток + кнопка возвращения назад. Если внесены несохранённые изменения — предупреждение как в 1.5. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- 3.2 Выбор черновика через меню версий (/update). Предусловие: выполнено 3.0 и создан черновик (1.2). Пользователь выбирает в выпадающем списке «Черновик» и возвращается на экран редактирования черновика для актуальной версии (см. 1.2). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Скриншот 1: просмотр списка шаблонов, два новых столбца — версия и наличие черновика. (59-230. Версионирование шаблонов коллекций)
- Скриншот 5 (дополнительный сценарий — переход к неактуальному шаблону): просмотр списка версий, доступных для выбора; выбрана неактуальная версия для просмотра. (59-230. Версионирование шаблонов коллекций)

### Поля и элементы
- Новый столбец «версия»: номер последней фиксированной версии шаблона (если есть черновик — номер версии, из которой сделан черновик). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Новый столбец «наличие черновика»: «Да»/«Нет» в зависимости от того, создан ли черновик. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Столбец «название» берётся из последней актуальной версии; название перезаписывается целиком для всех версий при сохранении черновика (см. 1.6). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Столбцы «Описание», «Тип коллекции», «Автопостановка» заполняются данными из последней версии шаблона. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Выпадающий список версий и плашка «Черновик» в карточке шаблона. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### API и интеграции
- GET /admin/metric-collection-template. Параметры: filter (в запросе, object, обязательный). Ответ 200 — OK: itemsCount (integer, int64) — общее число элементов; items (массив) — элементы на странице. (portalbackend)
- Элемент items: baseId (integer, int64) — базовый идентификатор шаблона, объединяющий все версии; version (integer, int64) — актуальный номер версии (последняя зафиксированная версия); hasDraft (boolean) — есть ли черновик; name (string) — название шаблона коллекции метрик; description (string) — описание; metricCollectionType (object): id (integer, int64), code (string), description (string), authTypes (массив string: LP | SSH | MTLS | TOKEN | AUTHORIZATION_HEADER | OAUTH2) — типы поддерживаемых аутентификации; autoMonitoringPossible (boolean) — возможность автоматической постановки коллекции на мониторинг. (portalbackend)

### Роли и права
- Просмотр списка, карточки и версий (2.0, 2.1, 3.0, 3.1): Инженер ЗОНТ, Ответственный ИС, Аудитор ИБ, Аудитор ДВА. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Выбор черновика (3.2): Инженер ЗОНТ. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

- Кнопка возврата в 3.1 при просмотре предыдущей версии: 57-230 — возвращает назад к актуальной версии; 59-230 — «при нажатии на которое происходит возврат к выбранной версии».
