# Права ролей: каталог и карточка шаблонов оповещений

> Права роли «Ответственный ИС» на вкладку, каталог и карточки шаблонов оповещений с ограничениями по доступным ИС и БС.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
- Вкладка «Каталог шаблонов оповещений»: Просмотр (read) + (PPPM-3715).
- Каталог шаблонов оповещений: Просмотр (read) +. Видит только шаблоны, карточки которых доступны для просмотра (PPPM-3715). В колонке другой роли указано «Видит все шаблоны».
- Карточка шаблонов оповещений:
  - Просмотр (read): видит шаблоны, которые: системные/пользовательские шаблоны типа ИС, содержащие ИС из его набора объектов; системные/пользовательские шаблоны типа БС, содержащие БС, связанные с ИС из его набора на уровне; системные/пользовательские шаблоны типа ИС и БС, для которых не выбраны ИС или БС (PPPM-3715).
  - Добавление (create) +: только пользовательские; только доступные пользователю ИС для шаблонов типа ИС или БС, связанные со своими ИС, для шаблонов типа БС (PPPM-3715).
  - Редактирование (update) +: может редактировать только пользовательские шаблоны: ИЛИ шаблоны типа ИС, которые содержат ТОЛЬКО ИС из его набора, ИЛИ шаблоны типа БС, которые содержат ТОЛЬКО БС, связанные с ЕГО ИС из его набора на уровне (PPPM-3715).
  - Удаление (delete) +: удалять может те же, что и редактировать (PPPM-3715).
