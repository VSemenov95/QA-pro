# API справочников типов коллекций метрик, типов атрибутов и значений атрибутов

> Административные GET-методы Portal backend, возвращающие справочники: типы коллекций метрик, типы атрибутов, типы значений атрибутов и сами значения атрибутов.

### Описание
- Раздел описывает справочные GET-методы администрирования: типы коллекций метрик, типы значений атрибутов, значения по идентификатору типа, типы атрибутов. (portalbackend)

### API и интеграции
- **GET /admin/metric-collection-template/type** — Получение типов коллекции метрик. Ответ 200 — OK, массив элементов: id (integer, int64) — Идентификатор типа коллекции метрик; code (string) — Код типа коллекции метрик; description (string) — Описание типа коллекции метрик; authTypes (массив string: LP | SSH | MTLS | TOKEN | AUTHORIZATION_HEADER | OAUTH2) — Типы поддерживаемых аутентификации. (portalbackend)
- **GET /admin/metric-collection-template/metric-collection-types** — Получение типов метрик. Ответ 200 — OK, элементы с теми же полями (id, code, description, authTypes) и теми же описаниями, что у метода /type. (portalbackend)
- **GET /admin/attribute-values-type** — Получение списка типов значений атрибутов. Ответ 200: массив элементов id (integer, int32) — Идентификатор; name (string) — Наименование. (portalbackend)
- **GET /admin/attribute-values-type/{id}** — Получение значений по идентификатору. (portalbackend)
  - Параметры: id (в пути, integer, обязательный); filter (в запросе, object, обязательный); infoSystemCmdbId (в запросе, string, обязательный). (portalbackend)
  - Ответ 200 — OK: itemsCount (integer, int64) — Общее число элементов; items (массив object) — Элементы на странице: id — Идентификатор; name (string) — Наименование; value — Значение; constant (boolean) — Признак константы. (portalbackend)
- **GET /admin/attribute-type** — Получение списка типов атрибутов. (portalbackend)
  - Параметры (необязательные, в запросе): attributeSourceTypeId (integer) — ID типа источника атрибута, см. /api/attributeSourceType; если не задан, то типы атрибутов не фильтруются по типу источника атрибута. collectionTypeName (string) — Имя типа коллекции - PING/PROMQL и т.п., см. /admin/metricCollectionTemplate/metricCollectionTypes; если не задано, то типы атрибутов не фильтруются по типу коллекции. (portalbackend)
  - Ответ 200 — OK: массив элементов id (integer, int32) — Идентификатор; name (string) — Значение. (portalbackend)
