# API метрик и атрибутов коллекции по умолчанию

> Административный REST API портала (portalbackend) для чтения и управления метриками и атрибутами по умолчанию для заданного типа коллекции (collectionTypeCode).

### Описание
- Раздел покрывает эндпоинты /admin/default-metric-collection/{collectionTypeCode}/…: список и CRUD метрик по умолчанию, список и POST/PUT/DELETE атрибутов по умолчанию. (portalbackend)
- GET /admin/default-metric-collection/{collectionTypeCode}/metric/{metricKey} — «Получить метрику по умолчанию». (portalbackend)
- GET /admin/default-metric-collection/{collectionTypeCode}/metric — «Получить метрики по умолчанию». (portalbackend)
- GET /admin/default-metric-collection/{collectionTypeCode}/attribute — «получение атрибутов по умолчанию» (описание в документе не указано). (portalbackend)

### API и интеграции
#### Метрики по умолчанию
- GET …/metric. Параметр: collectionTypeCode (в пути, string, обязательный). Ответ 200 — OK, массив элементов с теми же полями, что в GET …/metric/{metricKey} (см. ниже). (portalbackend)
- Для /metric/{metricKey} параметры пути у всех методов: collectionTypeCode (string, обязательный), metricKey (string, обязательный). (portalbackend)
- GET …/metric/{metricKey}. Ответ 200 — OK, все поля необязательные: (portalbackend)
  - id (integer, int64) — Идентификатор
  - name (string) — Имя
  - metricKey (string) — Ключ метрики
  - dataType (object): id (integer, int64) — Идентификатор; name (string) — Имя типа данных; displayName (string) — Отображаемое имя типа данных
  - unit (string) — Единица измерения
  - metricSourceType (string: DEFAULT | SCRIPT | DYNAMIC | SYNTHETIC | COMPLEX | EXTERNAL | DYNAMIC_CONTAINER | COLLECTION_STATUS | COMPOSITE) — Тип метрики (DEFAULT/COLLECTION_STATUS/COMPOSITE)
  - statusCalcMethod (string: MOST_CRITICAL | MOST_NORMAL) — Метод расчета для статуса коллекции (MOST_CRITICAL/MOST_NORMAL)
- POST …/metric/{metricKey} — Создать метрику по умолчанию. Тело (application/json), все поля необязательные: name (Имя), dataTypeId (integer, int64; Идентификатор типа данных), unit (Единица измерения), metricSourceType (те же значения, что выше), statusCalcMethod (MOST_CRITICAL | MOST_NORMAL). Ответ 200 — OK: id (integer, int64) — Идентификатор. (portalbackend)
- PUT …/metric/{metricKey} — Обновление метрики по умолчанию. Тело (application/json), необязательные: name (Имя), unit (Единица измерения), statusCalcMethod (MOST_CRITICAL | MOST_NORMAL). Ответ: 200 — OK. (portalbackend)
- DELETE …/metric/{metricKey} — Удаление метрики по умолчанию. Ответ: 200 — OK. (portalbackend)

#### Атрибуты по умолчанию
- GET …/attribute. Параметр: collectionTypeCode (в пути, string, обязательный). Ответ 200 — OK, массив элементов: (portalbackend)
  - name (string, обязательное) — Наименование
  - technicalName (string, обязательное) — Техническое наименование
  - value (object, необязательное): id (integer, int64) — Идентификатор; value (string) — Значение по умолчанию; valueTypeId (integer, int32) — Идентификатор значения по умолчанию для атрибута типа Список; key (string) — Ключ значения по умолчанию; dataType (string: STRING | LONG | FLOAT | TEXT | PRE_KNOWN_LIST | SERVICE_ACCOUNT | BOOLEAN | MAP | LIST | INTEGRATION_POINT | NETWORK_ZONE | SCRIPT) — Тип данных значения; additionalData (object) — Дополнительная ячейка данных; displayName (string) — Пользовательское название
  - values (массив object, необязательное) — Значения атрибута; элементы с теми же полями, что и в value (id, value, valueTypeId, key, dataType, additionalData, displayName)
  - required (boolean, обязательное) — Обязательность атрибута
  - hidden (boolean, необязательное) — Параметр для настройки видимости атрибута в коллекции метрик
  - editable (boolean, необязательное) — Параметр для настройки возможности редактирования атрибута в коллекции метрик
  - id (integer, необязательное, int64) — Идентификатор
  - attributeType (object, необязательное): id (integer, int32) — Идентификатор; name (string) — Значение
  - type (string: USER | SYSTEM, необязательное) — Тип источника атрибута
  - tooltip (string, необязательное) — Подсказка
- Для /attribute/{technicalName} параметры пути у всех методов: collectionTypeCode (string, обязательный), technicalName (string, обязательный). (portalbackend)
- POST …/attribute/{technicalName}, тело (application/json): (portalbackend)
  - name (string, обязательное) — Наименование
  - value (object, необязательное) — поля как в GET (id, value, valueTypeId, key, dataType, additionalData, displayName)
  - values (массив object, необязательное) — Значения атрибута; элементы с теми же полями, что и value
  - required (boolean, обязательное) — Обязательность атрибута
  - attributeType (string, обязательное: STRING | LONG | FLOAT | TEXT | PRE_KNOWN_LIST | SERVICE_ACCOUNT | BOOLEAN | MAP | LIST | INTEGRATION_POINT | NETWORK_ZONE | SCRIPT) — Тип атрибута
  - tooltip (string, необязательное) — Подсказка
  - Ответ: 200 — OK.
- PUT …/attribute/{technicalName}, тело (application/json): name (string, необязательное) — Название атрибута; value (object) и values (массив object) — с теми же полями, что в POST; required (boolean, обязательное) — Обязательность атрибута; tooltip (string, необязательное) — Подсказка. Поля attributeType в PUT нет. Ответ: 200 — OK. (portalbackend)
- DELETE …/attribute/{technicalName} — Ответ: 200 — OK. (portalbackend)

### Открытые вопросы
- Описание поля metricSourceType указывает «DEFAULT/COLLECTION_STATUS/COMPOSITE», тогда как перечень значений содержит 9 вариантов. (portalbackend)
- Для GET …/attribute описание в документе не указано. (portalbackend)
