# Переход на «Типовой дашборд БС» в Grafana из реестра и карточки мониторинга БС

> Переход из Реестра Карточек мониторинга БС и из Карточки мониторинга БС по настраиваемой ссылке на «Типовой дашборд БС» в Grafana с подстановкой ciId выбранной БС.

### Описание
- Фича PPMON-1880: Переход на "Типовой дашборд БС" из карточки мониторинга БС ЗСМ в Grafana. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Из Реестра Карточек мониторинга БС и из Карточки мониторинга БС можно перейти по ссылке на «Типовой дашборд БС» в Grafana. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Дашборд открывается в новом окне с данными конкретной БС: идентификатор ciId подставляется в переменную дашборда Grafana через плейсхолдер в ссылке. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Шаблон ссылки хранится в ЗСМ, администратор меняет его через конфигурационные файлы или БД, без GUI. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Дизайн: PIXSO. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Критерии: реализована возможность перехода из Карточки мониторинга БС на "Типовой дашборд БС" в Grafana по ссылке; переход должен быть доступен из двух элементов интерфейса: из Реестра Карточек мониторинга БС и из Карточки мониторинга БС. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)

### Экраны и навигация
- Реестр бизнес-сервисов: для бизнес-сервисов на мониторинге в списке дополнительных действий добавляется новая кнопка «Типовой дашбор БС» (написание как в документе). (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Карточка бизнес-сервиса: появляется иконка «Типовой дашборд БС». (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- При нажатии на кнопку осуществляется переход в Grafana по полученной ссылке в новом окне браузера по текущей ролевой модели. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)

### Поля и элементы
- Кнопка «Типовой дашбор БС» в списке дополнительных действий реестра бизнес-сервисов (для БС на мониторинге). (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Иконка «Типовой дашборд БС» в карточке бизнес-сервиса. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Параметр ciId — идентификатор конкретной БС, автоматически передаётся в URL при переходе из Карточки или Реестра по ссылке в Grafana. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Плейсхолдер {ciId} в шаблоне ссылки. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)

### Бизнес-правила и ограничения
- При нажатии на кнопку используется шаблон ссылки на типовой дашборд: ЗСМ заменяет все вхождения {ciId} на идентификатор БС в URL-кодировке. Остальная часть шаблона передаётся без изменений. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Ссылка на "Типовой дашборд БС" в Grafana хранится в ЗСМ и может редактироваться администратором через конфигурационные файлы/БД (без привлечения разработки и без использования GUI). (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Ссылка должна являться корректной ссылкой на настроенный "Типовой дашборд БС". (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Редактирование ссылки: инженер меняет шаблон через конфигурационные файлы БД или API. Привлекать разработку для этого не нужно, GUI для редактирования не предусмотрен. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Корректность ссылки — на ответственности администратора. ЗСМ не проверяет формат, доступность ссылки и наличие в ней плейсхолдера {ciId}. Если плейсхолдера нет, ссылка открывается как есть, без данных конкретной БС. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Применение изменений через обновление кэша: новый шаблон ссылки начинает использоваться после обновления кэша в сервисе ЗСМ, который хранит ссылку. Этот механизм в сервисе уже есть, доработка не требуется. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)

### API и интеграции
- Для настройки доступа к Grafana по БС необходимо: провести настройку dataSource для формирования дашборда по ciId БС — OOS; подготовить типовой дашборд, который может открываться по ciId БС — OOS; создать новую настройку в common-settings-manager, содержащую шаблон ссылки, используемый при открытии дашборда для конкретной БС. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Состав настройки в common-settings-manager: Properties = link-template-config; Key = business-service; Value — текстовая строка ссылки на дашборд, содержит фиксированную часть ссылки, обязательно содержащую ссылку на саму Grafana и на UID дашборда по всем текущим правилам, и подстановку {ciId}, которая может быть указана в любом месте ссылки. Учитывать ограничения. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)

### Сообщения и ошибки
- Если ссылка отсутствует, пользователь видит ошибку «Отсутствует ссылка на Типовой дашборд БС». Переход не выполняется, новое окно не открывается. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)

### Роли и права
- Кнопка в реестре и иконка в карточке доступны для всех, кто имеет права просмотра карточки БС. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
- Переход в Grafana осуществляется по текущей ролевой модели. (PPMON-1880. Ссылка на типовой дашборд  в карточке бизнес-сервиса-10)
