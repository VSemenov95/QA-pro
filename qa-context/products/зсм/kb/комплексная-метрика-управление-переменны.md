# Комплексная метрика: управление переменными

> Управление переменными в форме добавления комплексной (синтетической) метрики: добавление, редактирование и удаление строк переменных (название и метрика) и их добавление в конструктор выражения.

### Описание
- Портал, добавление комплексной метрики: управление переменными. (13-[US] Добавление комплексной метрики)

### Поля и элементы
- Таблица переменных: все элементы доступны для редактирования и обязательны для заполнения. (25-[US] Добавление синтетических метрик)
- После нажатия кнопки «Добавить переменную» система добавляет строку параметров; в строке доступны кнопки «Удалить» и «+». (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- «Название переменной» — тип «Строка»; ввод названия переменной для использования в конструкторе. Используются обычные ограничения для строки, см. PМ. Общие ограничения по типам и ошибки заполнения полей. (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- «Метрика» — выпадающий список с возможностью ввода для поиска от 3х символов; выбор метрики для формирования переменной. (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- Отображение метрик в списке «Метрика» — вложенный список: 1й уровень — КЕ, которой принадлежат доступные метрики; 2й уровень — экземпляр, которому принадлежат доступные метрики; 3й уровень — сам перечень доступных метрик с возможностью выбора. (13-[US] Добавление комплексной метрики)
- Пользователь может по маске от 3х символов отобрать подходящие КЕ, экземпляры и метрики, попадающие под запрос. Если КЕ/экземпляры попали под запрос, выводятся все ее дочерние элементы, вне зависимости от того, попали ли они под запрос. (13-[US] Добавление комплексной метрики)
- «Удалить» — кнопка; при нажатии удаляется строка переменной, метрика становится доступной для выбора для других переменных. Недоступна для нажатия, если переменная/переменная с выбранной агрегацией добавлена в конструкторе. (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- «+» — кнопка; при нажатии в форму конструктора в выбранное выражение добавляется переменная без агрегации. Доступна для нажатия, если корректно заполнены поля «Название переменной» и «Метрика». (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)

### Бизнес-правила и ограничения
- Для выбора доступны метрики, для которых выполняется: метрика активна на текущий момент; тип метрики соответствует ограничениям для метрик в разрезе типов (см. «Ограничения для метрик в разрезе типов»). (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- Ограничения для метрик: метрика принадлежит коллекции в статусе «на мониторинге»; метрика относится к коллекции, принадлежащей КЕ, относящейся к той же ИС, для которой создана коллекция комплексных метрик. (13-[US] Добавление комплексной метрики)
- Метрика принадлежит текущей коллекции. (25-[US] Добавление синтетических метрик)
- Метрика, выбранная в переменной, становится недоступной для выбора для других переменных. (13-[US] Добавление комплексной метрики)
- Удаление (3.1, 2.4): переменная, не используемая в конструкторе, после нажатия «Удалить» удаляется из списка переменных, метрика освобождается; если переменная используется в конструкторе — кнопка удаления недоступна (п. 4.0). (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- Редактирование названия (3.2): если пользователь целиком удалил название в поле и нажал Enter/нажал за пределы поля — поле подсвечивается красным, изменения переменных в конструкторе не происходит; если целиком изменил название и нажал Enter/нажал за пределы поля — название переменной в конструкторе изменяется. (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- Редактирование метрики (3.2): при замене метрики на новую визуальных изменений в конструкторе не происходит, переменная считается привязанной к другой метрике. (13-[US] Добавление комплексной метрики)
- Критерий 2.2: при заполнении строки система сохраняет введенное значение названия параметра и выбранную метрику. (25-[US] Добавление синтетических метрик)
- Критерий 3.0 (связь): при добавлении переменной в конструктор пользователь может изменить переменную в списке переменных, изменения наследуются для переменной в конструкторе. (25-[US] Добавление синтетических метрик)

### Сценарии
- 3.0 Добавление переменной: (1) выполнено 2.0; (2) пользователь нажал «Добавить переменную»; (3) система добавила строку параметров для заполнения (состояние «Добавлена метрика и не заполнена»); (4) повторное нажатие «Добавить переменную» без заполнения — незаполненные поля выделяются красным; (5) пользователь заполнил поля и нажал «Добавить переменную» — добавилась новая строка («Добавлена одна метрика и открыта еще одна строка для заполнения»). (13-[US] Добавление комплексной метрики; 25-[US] Добавление синтетических метрик)
- 3.1 Удаление ранее добавленной переменной. 3.2 Редактирование ранее добавленной переменной. (13-[US] Добавление комплексной метрики)
- Критерий 2.3: нажатие «Добавить переменную» добавляет новую строку; если переменная добавлена в конструктор — изменяется название переменной в конструкторе. (25-[US] Добавление синтетических метрик)

### Расхождения между документами
- Новая строка при повторном нажатии «Добавить переменную» с незаполненными полями: 13 — поля подсвечиваются красным (о добавлении строки не сказано); 25 (критерий 2.1) — подсвечиваются красным, новая строка не добавляется.
- Кнопка «Удалить» для переменной в конструкторе: 13 — недоступна для нажатия; 25 (критерий 3.0) — скрывается (в описании поля — недоступна).
- Ограничение по коллекции для метрик: 13 — коллекция в статусе «на мониторинге» и КЕ той же ИС, что коллекция комплексных метрик; 25 — метрика принадлежит текущей коллекции.
