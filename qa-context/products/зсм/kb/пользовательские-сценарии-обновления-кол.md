# Пользовательские сценарии обновления коллекции из шаблона и таблица доступности обновления

> Точечное обновление коллекции метрик из актуальной версии шаблона: сценарии кнопки, окна подтверждения и алгоритма обновления с созданием черновика заявки, а также таблица сочетаний статусов, определяющая доступность обновления.

### Описание
- Сценарии: объект ролевой модели — «Коллекция метрик /update»; роли — «Ответственный ИС (только свои ИС)», «Инженер ЗОНТ». (59-1826. Реализация точечного обновления коллекции из шаблона)
- Сценарии 1.0 и 2.0 — НЕ РЕАЛИЗУЕМ, ПЕРЕНЕСЕНО В БЭКЛОГ. Сценарии 3.0 и 4.0 — РЕАЛИЗУЕМ ТОЛЬКО САМ АЛГОРИТМ, БЕЗ ВЫЗОВА ОБНОВЛЕНИЯ ПО КНОПКЕ! (59-1826. Реализация точечного обновления коллекции из шаблона)

### Сценарии
- 1.0 Отображение кнопки обновления коллекции (НЕ РЕАЛИЗУЕМ, ПЕРЕНЕСЕНО В БЭКЛОГ): 1) Пользователь открывает ОМ и выбирает коллекцию согласно «Возможность Пользователя открыть коллекцию для просмотра/переключаться между коллекциями». 2) В списке действий для коллекции пользователь видит новую кнопку «Обновить из шаблона». Кнопка отображается, если: для актуальной версии шаблона коллекции установлено разрешение создавать/редактировать коллекцию (согласно PPMON-1823 Настройка «Политики разрешений» в шаблоне коллекций); для коллекции установлен статус согласно таблице разрешенных статусов. (59-1826. Реализация точечного обновления коллекции из шаблона)
- 2.0 Вызов формы подтверждения обновления коллекции (НЕ РЕАЛИЗУЕМ, ПЕРЕНЕСЕНО В БЭКЛОГ): 1) Выполнено 1.0 + выполнены условия для отображения кнопки. 2) Пользователь нажимает кнопку обновления коллекции из шаблона; формируется окно. (59-1826. Реализация точечного обновления коллекции из шаблона)
- 3.0 Вызов формы подтверждения обновления коллекции (РЕАЛИЗУЕМ ТОЛЬКО САМ АЛГОРИТМ, БЕЗ ВЫЗОВА ОБНОВЛЕНИЯ ПО КНОПКЕ!): 1) Выполнено 2.0. 2) Пользователь нажимает кнопку «Обновить». 2.1) Если для коллекции/дочерних объектов коллекции есть незавершенные заявки по подключению к ИАС/установке метки/снятию метки/по управлению правилами отбора — формировать ошибку типа «Завершите текущие аткивные заявки по коллекции» и не запускать процесс обновления. 2.2) Если условие 2.1 не выполнено — переход к алгоритму обновления. (59-1826. Реализация точечного обновления коллекции из шаблона)
- 4.0 Обновление коллекции в результате выполнения алгоритма обновления (РЕАЛИЗУЕМ ТОЛЬКО САМ АЛГОРИТМ, БЕЗ ВЫЗОВА ОБНОВЛЕНИЯ ПО КНОПКЕ!): 1) Выполнено 3.0. 2) Алгоритм обновления выполнен успешно и в результате создан черновик заявки: если черновик заявки не удалось создать — сообщение «Обновление завершилось ошибкой»; если создан — сообщение «Заявка создана», далее: если черновик незаполнен — остается в новом статусе невалидированной заявки (реализация в рамках PPMON-1824); если создан и заполнен и не включен признак автопостановки — заявка переходит в статус СОЗДАНО и требует дальнейшей ручной обработки; если создан и в актуальной версии шаблона включен признак автопостановки — заявка передается в автообработку. 3) Если заявка успешно обработана — версия коллекции изменяется на версию шаблона, из которой выполнено обновление. В успешно созданном черновике заявки отображается номер версии шаблона, из которой он сделан (target-версии!). (59-1826. Реализация точечного обновления коллекции из шаблона)

### Поля и элементы
- Кнопка «Обновить из шаблона» в списке действий коллекции. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Окно подтверждения (сценарий 2.0): заголовок «Обновление коллекции»; текст «Вы уверены что хотите обновить коллекцию из текущей версии шаблона?»; предупреждение (если есть активный черновик) «При обновлении коллекции текущий черновик будет потерян!»; чекбокс «Учитывать пользовательские изменения» (по умолчанию ВКЛ); кнопки «Отменить» — закрывает окно без изменений, «Обновить» — переход к обновлению (п. 3.0). (59-1826. Реализация точечного обновления коллекции из шаблона)

### Бизнес-правила и ограничения
- Таблица сочетаний (статус коллекции / статус заявки / тип заявки → доступность):
  - Добавлено / Черновик / Создание коллекции → Доступно для обновления с заменой черновика.
  - Добавлено / Создано, Заблокировано, Автообработка, Ошибка, В работе, В ожидании / Создание коллекции → Недоступно для обновления.
  - Добавлено / Отклонено / Создание коллекции → Доступно с созданием нового черновика.
  - На мониторинге/Сбор данных остановлен / Черновик / Изменение коллекции → Доступно для обновления с заменой черновика.
  - На мониторинге/Сбор данных остановлен / Создано, Заблокировано, Автообработка, Ошибка, В работе, В ожидании / Изменение коллекции → Недоступно для обновления.
  - На мониторинге / Выполнено / Изменение коллекции → Доступно с созданием нового черновика.
  - На мониторинге/Сбор данных остановлен / Отклонено / Изменение коллекции → Доступно с созданием нового черновика.
  - К удалению / Любой статус / Удаление коллекции → Обновление недоступно.
  - Идет остановка сбора данных / Любой статус / Любой тип заявки → Обновление недоступно.
  - Идет возобновление сбора данных / Любой статус / Любой тип заявки → Обновление недоступно. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Примечание: фактически обновление доступно тогда же, когда доступно создание черновика заявки согласно разрешениям из статьи «Статусная модель + Действия доступные для коллекций в зависимости от статусов заявок» + при наличии неотправленного черновика, т.е. в сочетании статусов: Добавлено/черновик; На мониторинге/черновик. (59-1826. Реализация точечного обновления коллекции из шаблона)

### Сообщения и ошибки
- «Завершите текущие аткивные заявки по коллекции» (формулировка дана как «ошибку типа»). (59-1826. Реализация точечного обновления коллекции из шаблона)
- «Обновление завершилось ошибкой». (59-1826. Реализация точечного обновления коллекции из шаблона)
- «Заявка создана». (59-1826. Реализация точечного обновления коллекции из шаблона)
- «При обновлении коллекции текущий черновик будет потерян!» (59-1826. Реализация точечного обновления коллекции из шаблона)

- Объект ролевой модели: «Коллекция метрик /update»; роли: «Ответственный ИС (только свои ИС)», «Инженер ЗОНТ». (59-1826. Реализация точечного обновления коллекции из шаблона)
