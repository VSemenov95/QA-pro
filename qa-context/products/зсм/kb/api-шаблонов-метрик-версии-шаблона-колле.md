# API шаблонов метрик версии шаблона коллекции (создание, получение, обновление, удаление)

> Группа административных REST-методов для создания, получения (списком и по id), обновления и удаления шаблонов метрик внутри версии шаблона коллекции метрик.

### Описание
- Группа методов администрирования шаблонов метрик внутри версии шаблона коллекции метрик (`/admin/metric-collection-template/version/{templateVersionId}/metric-template`). (portalbackend)
- Все параметры тела запросов помечены как необязательные. (portalbackend)

### Поля и элементы
- Общие поля метрики: name (string) — Наименование метрики (в GET — «Имя»); metricUnit (string) — Единица измерения метрики (в GET поле называется unit — «Единица измерения»); timeSeries (string) — Временной ряд (только в POST); metricDataTypeId (integer, int64) — Идентификатор типа данных метрики (в PUT по id — «Идентификатор типа данных выходного значения метрики»); enable (boolean) — признак включена метрика или нет (POST, PUT по id). (portalbackend)
- metricSourceType (string: DEFAULT | SCRIPT | DYNAMIC | SYNTHETIC | COMPLEX | EXTERNAL | DYNAMIC_CONTAINER | COLLECTION_STATUS | COMPOSITE) — Тип метрики (POST, ответ GET). (portalbackend)
- expectSingleMetric (boolean) — Количество рядов для отбора для динамического контейнера, true - Один ряд; manualThreshold (boolean) — Ручное управление порогами. (portalbackend)
- expertMode (boolean) — Признак экспертного режима (POST); в GET — «Признак настройки порогов в экспертном режиме»; в PUT по id — «Признак использования экспертного режима настройки порогов». (portalbackend)
- statusCalcMethod (string: MOST_CRITICAL | MOST_NORMAL) — Метод расчета статуса коллекции (ответ GET и PUT по id). (portalbackend)
- Только в ответе GET: id (integer, int64) — Идентификатор; dataType (object): id (int64) — Идентификатор, name — Имя типа данных, displayName — Отображаемое имя типа данных; defaultMetricTemplateId (int64) — Идентификатор дефолтного шаблона метрики; isUsed (boolean) — Признак использования метрики. (portalbackend)
- metricConstructor (object): expressionAttributes (object) с булевыми полями array, empty, null, missingNode, object, valueNode, pojo, number, integralNumber, floatingPointNumber, short, int, long, float, double, bigDecimal, bigInteger, textual, boolean, binary, container, string, embeddedValue и nodeType (string: ARRAY | BINARY | BOOLEAN | MISSING | NULL | NUMBER | OBJECT | POJO | STRING); parameters (массив object): name (string), metricId (integer, int64), metricName (string); defaultValue (string); promqlExpression (string); isManual (boolean); promqlQueryStep (string). (portalbackend)
- dynamicContainerRule (object): name (string), crossClosing (boolean), rules (object), aggregationMethod (string: MAX | MIN | AVG). (portalbackend)
- thresholds — Пороги (массив object; в POST и PUT по id; в списочном GET — thresholdTemplates, «Порог шаблона метрики»): value (string) — Пороговое значение; description (string) — Описание; expression (string) — Выражение для поиска; isExpertMode (boolean) — Экспертный режим; id (integer, int32) — Идентификатор порога (только в PUT по id; в списочном GET — int64); type (object): id (int32) — Идентификатор, name — Значение; operator (object): id (int32) — Идентификатор, symbol — Значение, description — Описание; reactionRule (object): id (uuid) — Идентификатор правила реагирования, name — Название правила реагирования; ecosNotificationGroup (object): id (uuid) — Идентификатор группы рассылки ЭКОС, name — Название группы рассылки ЭКОС; rootId (string) — Идентификатор группировки; firstCondition (boolean); isFirstCondition (boolean) — Первое условие. (portalbackend)
- В списочном GET у порога thresholdTemplates дополнительно: error (string) — Ошибка валидации выражения. (portalbackend)
- aiopsConnect (object; в POST на уровне метрики): toggleSetParametersInIas (boolean); notificationsMetricTemplate (object): id (string), name (string); groupReactions (массив object): aiopsGroupId (string) — айди группы реакций из шаблона метрик ИАС, aiopsGroupLabel (string) — лейбл группы реакций из шаблона метрик ИАС, ecosGroupId (string, uuid) — айди группы ЭКОС, ecosGroupName (string) — название группы ЭКОС; hyperparametersMetricTemplate (object): id (string), name (string). В списочном ответе groupReactions описан как массив object без описания элементов. (portalbackend)
- selectionRules — Правила отбора рядов метрики контейнера (массив object): id (string, uuid); name (string); selectionType (string: FILTER | MANUAL); filterSelection (массив: key, value — string); manualSelection (массив: name, promql — string); noDataWarningMs (integer, int64); noDataCriticalMs (integer, int64); availableForBs (boolean); connectToAiops (boolean); aiopsConnect (object, та же структура). (portalbackend)

### Бизнес-правила и ограничения
- POST предназначен для метрик типов SYNTHETIC и DYNAMIC_CONTAINER (описание метода: «Создание метрики (SYNTHETIC, DYNAMIC_CONTAINER)»). (portalbackend)
- Пороги задаются при ручном управлении порогами (поле manualThreshold) и могут настраиваться в экспертном режиме. (portalbackend)

### API и интеграции
- GET /admin/metric-collection-template/version/{templateVersionId}/metric-template — получить сохраненные шаблоны метрик по id шаблона коллекции метрик. Параметры: templateVersionId (в пути, integer, обязательный); filter (в запросе, object, обязательный). Ответ 200 — OK: itemsCount (integer, int64) — Общее число элементов; items (массив object) — Элементы на странице, поля как в ответе по одному шаблону метрики плюс thresholdTemplates. (portalbackend)
- POST /admin/metric-collection-template/version/{templateVersionId}/metric-template — Создание метрики (SYNTHETIC, DYNAMIC_CONTAINER). Параметры: templateVersionId (в пути, integer, обязательный). Тело (application/json): name, metricUnit, timeSeries, metricDataTypeId, enable, metricSourceType, metricConstructor, dynamicContainerRule, expectSingleMetric, manualThreshold, thresholds, aiopsConnect, selectionRules, expertMode. Ответ: 200 — OK. (portalbackend)
- PUT /admin/metric-collection-template/version/{templateVersionId}/metric-template — Обновить шаблоны метрик коллекции. Параметры: templateVersionId (в пути, integer, обязательный). Тело (application/json) — массив элементов: metricTemplateId (integer, int64) — Идентификатор; isUsed (boolean) — Признак включения метрики в шаблоне. Ответ: 200 — OK. (portalbackend)
- GET /admin/metric-collection-template/version/{templateVersionId}/metric-template/{metricTemplateId} — Получить сохраненный шаблон метрики по id шаблона метрики. Параметры: templateVersionId, metricTemplateId (в пути, integer, обязательные). Ответ 200 — OK, поля: id, name, dataType, unit, defaultMetricTemplateId, isUsed, metricConstructor, metricSourceType, dynamicContainerRule, expectSingleMetric, statusCalcMethod, manualThreshold, selectionRules, expertMode (все необязательные). (portalbackend)
- PUT /admin/metric-collection-template/version/{templateVersionId}/metric-template/{metricTemplateId} — Обновить шаблон метрики коллекции по идентификатору шаблона. Параметры: templateVersionId, metricTemplateId (в пути, integer, обязательные). Тело (application/json): metricDataTypeId, metricUnit, manualThreshold, thresholds, name, metricConstructor, enable, dynamicContainerRule, expectSingleMetric, statusCalcMethod, selectionRules, expertMode. Ответ: 200 — OK. (portalbackend)
- DELETE /admin/metric-collection-template/version/{templateVersionId}/metric-template/{metricTemplateId} — Удалить сохраненный шаблон метрики по id шаблона метрики. Параметры: templateVersionId, metricTemplateId (в пути, integer, обязательные). Ответ: 200 — OK. (portalbackend)
