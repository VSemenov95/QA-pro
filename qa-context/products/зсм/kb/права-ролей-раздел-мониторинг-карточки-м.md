# Права ролей: раздел «Мониторинг» — карточки мониторинга ИС

> Права на каталог и карточку мониторинга ИС: просмотр, отчёты, постановка, настройка, снятие, возврат и переход к дашборду.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
Значения «Ответственный ИС»:
- Глобальный раздел «Мониторинг» со всеми подразделами: Просмотр (read) — «Доступ к отдельным подразделам».
- Вкладка «Мониторинг» с подразделом «Карточки мониторинга ИС»: read +.
- Каталог карточек мониторинга ИС (Активные/Сняты с мониторинга): Просмотр (read) + — «Вижу только свои ИС»; Выгрузка сокращенного отчета по всем ИС (PPMON-339) (create) + — в отчете отображаются только доступные ИС.
- Карточка мониторинга ИС: Просмотр (read) +; Выгрузка полного отчета по выбранной ИС (PPMON-339) (create) +; Просмотр Истории карточки ИС (read) +; Добавление (постановка ИС на мониторинг) (create) + — только свои доступные; Редактирование (настройка) (update) + — только свои доступные; Снятие ИС с мониторинга (PPMON-19) (delete) + — если включен тоггл и ИС относится к доступным для пользователя; Окончательное удаление ИС (ppmon-1144) (delete-full) — значение для роли не читается; Возвращение ИС на мониторинг (PPMON-19) (recover) + — если включен тоггл и ИС относится к доступным для пользователя; Переход к дашборду (grafana_viewer) +.
- Другие роли (без привязки к колонке): «Вижу все»; «Видит только ИС, связанные с доступными ему БС»; «Только те, к которым имеет доступ»; PPMON-692.
