# Права ролей: хранилище скриптов, хранилище MIB-файлов и реестр переменных

> Права роли «Ответственный ИС» на каталог и скрипты хранилища, а также статус разделов MIB-файлов и реестра переменных.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
**Хранилище скриптов** (значения «Ответственный ИС»):
- Вкладка «Компоненты» с подразделом/иконой «Хранилище скриптов»: Просмотр (read) +.
- Каталог скриптов: Просмотр (read) + — все системные и только свои.
- Скрипт: Просмотр (read) + — все системные и только свои; Редактирование (update) + — только свои (пользовательские); Добавление (create) + (пользовательские); Удаление (delete) + — только свои (пользовательские).
- Доступ к кнопке «Перейти в экземпляр коллекции» (PPPM-7241): read +.
- В колонке другой роли (без указания, какой) для каталога и скрипта: 1) Системные, 2) Пользовательские, к которым имеет доступ (запрещен просмотр текста скрипта, управления аргументами, управления подстановками).

**Хранилище MIB-файлов (не реализован)**: вкладка «Компоненты» с подразделом «Хранилище MIB-файлов» — Просмотр (read); Каталог MIB-файлов — Просмотр (read); MIB-файл — Просмотр (read), Добавление (create), Удаление (delete). Значения не указаны.

**Реестр переменных (реализация PPPM-5415 Анализ)**: вкладка реестра переменных — Просмотр (read) + (PPPM-5415); карточка реестра переменных — Просмотр (read) + (PPPM-5415), Добавление (create), Редактирование (update), Удаление (delete). Значения для create/update/delete однозначно не читаются, при них стоит ссылка PPPM-5415.

### Открытые вопросы
- Раздел «Хранилище MIB-файлов» помечен как не реализованный.
