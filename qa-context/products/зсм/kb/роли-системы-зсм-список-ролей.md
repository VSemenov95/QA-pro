# Роли системы ЗСМ: список ролей

> Перечень ролей Портала мониторинга (ЗСМ) с описанием полномочий каждой роли.

## 200-Описание ролевой модели ЗСМ.pdf

### Описание
- Раздел «1. Список ролей системы ЗСМ» содержит таблицу с колонками «Название роли» и «Описание».
- Документ далее (раздел 2) связывает роли с действиями над типами объектов. Колонки матрицы: «№», «Название типа объекта», «Название действия», «Код действия», «Роль».

### Роли и права
- **Ответственный ИС**: сотрудник, наделённый правами Ответственного ИС во внутреннем функционале Портала мониторинга. Создаёт/редактирует/управляет карточкой мониторинга ИС. Порталу мониторинга необходимо получать информацию из РИС о Владельце ИС и Заместителе Владельца ИС.
- **Инженер ЗОНТ**: инженер внедрения. Исполняет заявки на постановку метрики на мониторинг. Актуализирует данные в Каталоге метрик. Обеспечивает работоспособность и внесение изменений в настройки системы Портал мониторинга. Управляет скриптами в хранилище скриптов.
- **Инженер СЦ**: инженер ситуационного центра. Создаёт/редактирует/управляет дашборды, отслеживает работу ИС. Осуществляет мониторинг функционирования ИС, устраняет сбои в работе ИС и изменение её настроек в рамках делегированных им прав. Управляет панелью событий. Формирует метки «Для СЦ» на метриках, для которых должны формироваться события, подлежащие ручной обработке. Управляет представлениями фильтров панели событий для использования Дежурным смены.
- **Дежурный смены**: как инженер СЦ, выполняет: создаёт/редактирует/управляет дашборды, отслеживает работу ИС; осуществляет мониторинг функционирования ИС, устраняет сбои в работе ИС и изменение её настроек в рамках делегированных им прав; управляет панелью событий.
- **Аудитор ИБ**: сотрудник подразделения информационной безопасности, осуществляющий контроль и мониторинг действий пользователей в системе Портал мониторинга.
- **Администратор Портала**: пользователь, обладающий правами управления ролями Пользователей системы Портала мониторинга.
- **Технолог БС**: пользователь, который может управлять настройкой бизнес-сервисов: просматривать/создавать/снимать с мониторинга карточки мониторинга БС; просматривать/создавать/редактировать/удалять точки мониторинга карточек мониторинга БС. Также может: просматривать список карточек мониторинга ИС, связанных с БС напрямую или через ИТ сервис; просматривать карточку ИС, связанных с БС напрямую или через ИТ сервис; просматривать карточку ОМ, дочернюю для ИС, связанных с БС напрямую или через ИТ сервис; просматривать карточку экземпляра коллекции, созданных для ОМ, дочерних для ИС, связанных с БС напрямую или через ИТ сервис.
- **Просмотр сервисов**: пользователь, обладающий правами на просмотр всех бизнес-сервисов и точек мониторинга, заведённых в системе.
- **Пользователь**: пользователь, обладающий правами на просмотр назначенных ему карточек мониторинга ИС/БС, связанных с ними метрик, дашбордов. Ссылка: PPPM-3159 [2025] ПП. Зонтичный мониторинг. Новая роль «Пользователь» с настройками доступа к определенным сущностям ЗСМ для дашбордов Мобильного приложения (статус «Закрыто»).
- **Аудитор ДВА (департамент внутреннего аудита)**: сотрудник Департамента внутреннего аудита с правами на чтение всех возможных данных без возможности редактирования (фактически копия Аудитора ИБ). Реализован согласно требованиям Приложения №3 к Положению о ПроПро №405, Раздел 8.5 «Техническая реализация ролевой модели». По сути скопировать роль Аудитор ИБ и назвать Аудитор ДВА (задача ZONT-4785).
- В заголовках матрицы также присутствуют колонки: «Интеграция с ИАС», «Интеграция с Мощностями», «Служебная. Доступ к GraphQL». Описания этих ролей в данном фрагменте нет. Рядом с колонкой «Аудитор ДВА» указана ссылка PPMON-1258.

### Открытые вопросы
- Значения матрицы для ролей, кроме «Ответственный ИС», разнесены по страницам и в тексте PDF читаются фрагментарно. Их однозначное сопоставление с колонками по этому фрагменту невозможно.
