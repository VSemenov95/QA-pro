# Права ролей: раздел «Панель событий»

> Права на панель событий: просмотр, фильтры, поиск, настройка столбцов, массовые действия, отчёт, представления, карточка события и отчёт дежурной смены.

## 200-Описание ролевой модели ЗСМ.pdf

### Поля и элементы
- 69 Вкладка «Аналитика» с подразделами/иконками «Панель событий»: Просмотр read +.
- 70 Панель событий: Просмотр, включает: просмотр панели событий, использование активных фильтров, использование фильтров уровня, использование поиска, настройки столбцов — read +. Массовые действия над событиями («Добавлено в PPPM-7851») — complete -, PPPM-7851.
- 71 Формирование отчета по панели событий: Создание отчета create -.
- 72 Фильтры панели событий: Просмотр read +.
- 73 Представления: Управление представлением create/update +; read +; use +; delete + (только своя роль).
- 74 Карточка события: Просмотр read +; Обработка (new!) — повторная отправка оповещений, обработка события, комментирование событий, создание инцидентов и аварий, ручной запуск скриптов — complete -; Редактирование (new!, редактирование полей карточки событий) — update -.
- 75 Отчет дежурной смены: Выгрузка отчета create -.

### Роли и права
- Ссылки на задачи: PPPM-7851, PPPM-8102.
- Знаки по ролям разорваны, точное соответствие ролям не восстановимо.
