# API точек интеграции (получение, изменение, удаление)

> REST API административного раздела для получения, изменения и удаления точки интеграции по её ID (/admin/integration-point/{id}).

### API и интеграции
- GET /admin/integration-point/{id} — получение точки интеграции по ID. Параметры: id (в пути, integer, обязательный). Ответ 200 — OK (все поля необязательные): id (integer, int64) — Идентификатор; name (string) — Наименование; description (string) — Описание; sourceId (string) — Идентификатор источника; expirationDays (integer, int32) — Количество дней с даты последнего значения метрики, после которых метрика считается неактуальной; filterRules (string) — Правило фильтрации; metricRules (string) — Правило резолвинга метрик; namingRules (string) — Правило определения имени метрики; groupingRules (string) — Правило резолвинга коллекций; ciRules (string) — Правило резолвинга КЕ; status (string: CREATED | PROCESSING | CONNECTED | ERROR) — Статус; connectedCollectionsCount (integer, int64) — Количество подключенных коллекций. (portalbackend)
- PUT /admin/integration-point/{id} — изменение точки интеграции. Параметры: id (в пути, integer, обязательный). Тело запроса (application/json), все поля необязательные: name (Наименование), description (Описание), expirationDays (integer, int32; Количество дней с даты последнего значения метрики, после которых метрика считается неактуальной), filterRules (Правило фильтрации), metricRules (Правило резолвинга метрик), namingRules (Правило определения имени метрики), groupingRules (Правило резолвинга коллекций), ciRules (Правило резолвинга КЕ); все, кроме expirationDays, — string. (portalbackend)
- PUT, ответ 200 — OK: возвращается объект точки интеграции с теми же полями, что и в GET (id, name, description, sourceId, expirationDays, filterRules, metricRules, namingRules, groupingRules, ciRules, status, connectedCollectionsCount). (portalbackend)
- DELETE /admin/integration-point/{id} — удаление точки интеграции. Параметры: id (в пути, integer, обязательный). Ответ: 200 — OK. (portalbackend)

### Бизнес-правила и ограничения
- В теле PUT не передаются sourceId, status и connectedCollectionsCount: они присутствуют только в ответе. (portalbackend)
