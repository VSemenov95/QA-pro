# Сохранение черновика заявки на коллекцию без валидации (невалидированный черновик)

> Возможность сохранять черновик заявки на добавление/изменение коллекции метрик с незаполненными обязательными атрибутами (невалидированный черновик) с отображением признака невалидированности и запретом отправки и тестового подключения до успешной валидации.

### Описание
- Фича PPMON-1824 «Доработка управления коллекциями. Добавить возможность сохранения черновика без валидации (без заполнения обязательных полей)», критерии: ВКЛЮЧЕНО ЦЕЛИКОМ. Черновик заявки изменения/добавления коллекции можно сохранить с незаполненными обязательными атрибутами; отправить на согласование его нельзя, пока он не сохранен с правильными атрибутами. Добавляется статус полноты (заполнено, не заполнено). Валидация при сохранении черновика не убирается. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- Невалидированный черновик хранится в БД с признаком «Не заполнено» и не может быть отправлен, пока признак не будет убран при успешной валидации. Признак «Не заполнен» не статус заявки и не меняет логику ЖЦ заявки. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- Зачем: корректная раскатка коллекций через API стандартизации (1809. POST API: массовое создание коллекций для стандарта выбранной версии; 1810. PUT API: миграция коллекций при повторном применении стандарта с одной версии на другую); без фичи через стандарты раскатываются только шаблоны с полностью заполненными обязательными параметрами. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- PPMON-1825 «Добавление дополнительной валидации заявки в момент отправки» — критерии НЕ ВКЛЮЧЕНО: заказчик отказался от актуализации и валидации заявки при отправке (вычисление значений атрибутов/метрик, валидация, перевод в ошибку с новым исключением); делаем только 1824. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)

- Термины: Невалидированный черновик — хотя бы один параметр не прошел валидацию при сохранении; редактируется и отзывается как обычный, отправка недоступна. Невалидированная метрика — параметр не прошел валидацию при сохранении метрики в редактировании черновика; черновик с ней невалидирован. Невалидированное правило отбора — правило метрики-контейнера с несколькими рядами; метрика и родительский черновик тоже невалидированы. Признак невалидированности — визуальный маркер. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- AS IS: валидация происходит при сохранении черновика добавления/изменения коллекции; правила: «Правила обработки атрибутов разных типов в экземпляре коллекции», «Правила обработки параметров метрик в экземпляре коллекции», доп. валидация при сохранении композитных метрик. Разделы 4.1, 4.2 (алгоритмы валидации) и «4.2) Пользовательские сценарии AS IS» без текста. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)

- Места признака черновика: список коллекций и карточка выбранной коллекции в карточке ОМ (знак предупреждения, подсказка «Черновик заявки не прошел валидацию»); реестр заявок и история заявок конкретной ИС (знак без подсказки); карточка черновика — плашка «Не валидировано». Признаки метрики и правила дублируются в форме добавления коллекции, где заявка еще не сохранена. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)

### Бизнес-правила и ограничения
- Проверка всего черновика: при сохранении из формы добавления коллекции («Сохранить черновик») и при сохранении изменений созданного черновика («Сохранить черновик»). Также проверки при: сохранении метрики; сохранении правила отбора, дочернего к метрике-контейнеру; изменении состояния вкл-выкл в списке метрик. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- При повторном открытии черновика/метрики/правила, не прошедших валидацию, подсвечивать незаполненные обязательные поля. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- Если условия невалидированности исчезли, статус автоматически не меняется; пользователь повторно валидирует сохранением. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- Невалидированный черновик нельзя отправлять и нельзя выполнять тестовое подключение; при попытке из карточки заявки/черновика формируется системная ошибка. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- Копирование правила отбора копирует текущий статус валидации (4.3). Если удалено последнее невалидированное правило (2.4), метрика остается невалидированной (нужно ручное подтверждение сохранения метрики). (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
- При невалидированной метрике (сценарии 2.2, 3.2, 4.2) черновик помечается невалидированным только при редактировании черновика, при добавлении коллекции не помечается. (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)
