# Права ролей: правила корреляции

> Права на каталоги и правила корреляции по времени, на потоке и по топологии (просмотр, добавление, редактирование, удаление).

## 200-Описание ролевой модели ЗСМ.pdf

### Описание
Подраздел 2.6 «правила корреляции» ролевой модели ЗСМ.

### Поля и элементы
- 55 Каталог правил корреляции по времени: Просмотр read.
- 56 Правило корреляции по времени: Добавление create; Просмотр read; Редактирование update; Удаление delete.
- 57 Каталог правил корреляции на потоке: Просмотр read.
- 58 Правило корреляции на потоке: Добавление create; Просмотр read; Редактирование update; Удаление delete.
- 59 Каталог правил корреляции по топологии: Просмотр read.
- 60 Правило корреляции по топологии: Добавление create; Просмотр read; Редактирование update; Удаление delete.

### Роли и права
- В матрице встречаются ссылки на задачи: PPPM-3873 (правила корреляции по времени) и PPPM-4395 (правила корреляции на потоке/по топологии).
- Знаки «+/-» по ролям при извлечении разорваны, конкретное соответствие ролям не восстановимо.
