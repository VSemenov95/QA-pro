# Права ролей: объекты мониторинга и коллекции метрик в карточке ИС

> Права на каталог объектов мониторинга, объекты, коллекции метрик, их комментарии и историю заявок.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
Значения «Ответственный ИС»:
- Каталог объектов мониторинга карточки ИС: Просмотр (read) +.
- Объект мониторинга: Просмотр (read) +; Добавление (create) +; Удаление (delete) +.
- Каталог коллекций метрик: Просмотр (read) +.
- Коллекция метрик: Просмотр (read) +; Добавление (create) +; Удаление (delete) +; Редактирование, включает остановку и редактирование через заявки (update) +; Дублирование (duplication) +; Управление автопостановкой (auto_request_toggle) −; Остановка/Возобновление сбора данных (stop_monitoring) + — только для коллекций доступных ИС (PPPM-1354); Управление ключевыми метриками — значение «??».
- Коллекция метрик (тоггл «Используется для бизнес-сервисов») (PPPM-7241): Редактирование (update) +.
- Коллекция метрик (Комментарии): Просмотр (read) +; Добавление (create) +; Редактирование, отложено (update) + (предусмотреть, что только свои); Удаление, отложено (delete) + (предусмотреть, что только свои).
- Вкладка «История заявок» (PPPM-7241): Просмотр (read) +; Доступ к кнопке «Перейти к заявке» (read) +.
- Доступ к кнопке «Перейти к изменениям» (PPPM-7241): read +.
- В колонках других ролей встречаются ссылки PPPM-8023 и PPPM-1354.
