# Снятие БС с базового мониторинга

> Функция снятия бизнес-сервиса (БС) с базового мониторинга из Карточки мониторинга БС с подтверждением в модальном окне, отправкой сообщения в Каталог Сервисов через Kafka и фиксацией в Аудите и Истории изменений.

### Описание
- Снятие БС с базового мониторинга выполняется в Карточке мониторинга БС (признак) и включает отправку сообщения в Каталог Сервисов о том, что БС снята с БМ (через Kafka). (12-PPMON-1879. Базовый мониторинг)
- Функция вызывается из меню «…» карточки с подтверждением в модальном окне. (12-PPMON-1879. Базовый мониторинг)
- Операция фиксируется в Аудите и Истории изменений БС. (12-PPMON-1879. Базовый мониторинг)

### Экраны и навигация
- Скриншот 4: вызов операции снятия бизнес-сервиса с базового мониторинга, новая кнопка в дополнительных действиях. (12-PPMON-1879. Базовый мониторинг)
- Скриншот 5: экран подтверждения. (12-PPMON-1879. Базовый мониторинг)
- Скриншот 6: успех снятия сервиса с базового мониторинга. (12-PPMON-1879. Базовый мониторинг)
- Экран подтверждения (сценарий 2.1): заголовок «Снять сервис с мониторинга»; текст «Вы уверены что хотите снять бизнес-сервис с базового мониторинга?»; кнопки «Отменить» / «Снять». (12-PPMON-1879. Базовый мониторинг)

### Поля и элементы
- Кнопка в списке дополнительных действий: «Снять сервис с базового мониторинга». (12-PPMON-1879. Базовый мониторинг)
- Кнопки модального окна: «Отменить» / «Снять». (12-PPMON-1879. Базовый мониторинг)
- Плашка статуса в карточке БС (сценарий 2.0): «Установлено на базовый мониторинг». (12-PPMON-1879. Базовый мониторинг)

### Бизнес-правила и ограничения
- Операция снятия считается успешной без проверок. (12-PPMON-1879. Базовый мониторинг)
- Сценарий 2.3: при снятии бизнес-сервиса с мониторинга после удаления всех ТМ из БС (см. [US] Снятие бизнес-сервиса с мониторинга, третий этап) БС также должна сниматься с базового мониторинга, и в каталог сервисов формируется сообщение о снятии БС с базового мониторинга (см. описание пакетов). (12-PPMON-1879. Базовый мониторинг)

### API и интеграции
- При снятии формируется пакет в топик Kafka для передачи информации в каталог сервисов (см. раздел «Интеграция с Сфера.Каталог сервисов через Kafka»). (12-PPMON-1879. Базовый мониторинг)

### Сообщения и ошибки
- Успех: зелёный тостер с текстом «Сервис снят с мониторинга » (с пробелом перед закрывающей кавычкой, как в документе). (12-PPMON-1879. Базовый мониторинг)

### Роли и права
- Доступно ролям «Технолог БС» (в разрезе своих БС) и «Инженер ЗОНТ». (12-PPMON-1879. Базовый мониторинг)
- Объект ролевой модели: «Карточка мониторинга/update» (сценарии 2.0–2.2), «Карточка мониторинга/delete» (сценарий 2.3). (12-PPMON-1879. Базовый мониторинг)

### Сценарии
- 2.0 Отображение кнопки снятия: 1) выполнено 1.2; 2) пользователь открывает карточку бизнес-сервиса, установленного на базовый мониторинг; 3) видит плашку «Установлено на базовый мониторинг»; 4) открывает список дополнительных действий; 5) видит кнопку «Снять сервис с базового мониторинга». (12-PPMON-1879. Базовый мониторинг)
- 2.1 Вызов подтверждения: 1) выполнено 2.0; 2) при нажатии на кнопку возникает экран подтверждения. (12-PPMON-1879. Базовый мониторинг)
- 2.2 Подтверждение операции снятия: 1) выполнено 2.1; 2) пользователь нажимает «Снять»; 3) операция успешна без проверок. Действия системы: формируется пакет в топик Kafka для каталога сервисов; создаётся заявка типа «Установка на базовый мониторинг» для текущего БС, доступная в списке Истории изменений по БС и сразу выполненная; формируется зелёный тостер «Сервис снят с мониторинга »; статус БС меняется на «Не установлен на базовый мониторинг». (12-PPMON-1879. Базовый мониторинг)
- 2.3 Снятие БС с базового мониторинга при выполнении алгоритма снятия с мониторинга БС (см. «Бизнес-правила и ограничения»). (12-PPMON-1879. Базовый мониторинг)

### Открытые вопросы
- Тип заявки при снятии указан как «Установка на базовый мониторинг» (как в документе). (12-PPMON-1879. Базовый мониторинг)
- Статус после снятия указан как «Не установлен на базовый мониторинг», в других местах «Не на базовом мониторинге». (12-PPMON-1879. Базовый мониторинг)
- Подпись скриншота 5 и название сценария 2.1 в документе говорят об «установке» сервиса на мониторинг, хотя речь о снятии; текст на экране подтверждения продублирован с префиксом «Снять сервис с мониторинга». (12-PPMON-1879. Базовый мониторинг)
