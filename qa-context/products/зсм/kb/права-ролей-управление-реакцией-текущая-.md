# Права ролей: управление реакцией (текущая реализация)

> Права на каталоги и объекты списков адресатов, правил обогащения и правил реагирования с ограничением по ИС, где пользователь — Ответственный ИС.

## 200-Описание ролевой модели ЗСМ.pdf

### Роли и права
Значения «Ответственный ИС» (все «+» с ограничениями):
- Каталог списка адресатов: Просмотр (read) + — отображаются только те списки адресатов, по ИС которым пользователь является Ответственным ИС.
- Каталог правил обогащения: Просмотр (read) + — отображаются только те правила обогащения, по ИС которым пользователь является Ответственным ИС.
- Каталог правил реагирования: Просмотр (read) + — отображаются только те списки адресатов, по ИС которым пользователь является Ответственным ИС (формулировка из документа).
- Список адресатов: Просмотр (read), Добавление (create), Удаление (delete), Редактирование (update) — все +, только локальные по ИС, по которым пользователь является Ответственным ИС.
- Правило обогащения: Просмотр (read), Добавление (create), Удаление (delete), Редактирование (update) — все +, по ИС, по которым пользователь является Ответственным ИС.
- Правило реагирования: Просмотр (read), Добавление (create), Удаление (delete), Редактирование (update) — все +, ТОЛЬКО ЛОКАЛЬНЫЕ по ИС, по которым пользователь является Ответственным ИС.
- В колонке другой роли: «отображаются только те списки адресатов / правила обогащения, по ИС к которым получен доступ», «Только локальные по ИС к которым получен доступ».

### Открытые вопросы
- Фрагмент заканчивается заголовком «2.5 Подраздел «Управление реакцией — новая версия PPMON-154-155»»; его содержимое в этой части отсутствует.

## 200-Описание ролевой модели ЗСМ.pdf

### Бизнес-правила и ограничения
- Дочерние объекты реакций для комплектации правил обработки (правила обогащения, инструкции, списки адресатов): Просмотр read — «+» по ИС, которым пользователь является Ответственным ИС.
- Для одной из позиций: «(РЕАЛИЗАЦИЯ ОТЛОЖЕНА PPMON-154, 155)»; Добавление create «+»; Удаление delete «+» по ИС, которым пользователь является Ответственным ИС; Редактирование update «+» по ИС, которым пользователь является Ответственным ИС.
- Правило обработки новое (РЕАЛИЗАЦИЯ ОТЛОЖЕНА PPMON-154, 155): Просмотр read «+» ТОЛЬКО ЛОКАЛЬНЫЕ по ИС, которым пользователь является Ответственным ИС.
- Добавление create «+» ТОЛЬКО ЛОКАЛЬНЫЕ по ИС, которым пользователь является Ответственным ИС (примечание: «Добавил Мысев А. 27.09.2024, уточнить номер бага»).
- Удаление delete «+» ТОЛЬКО ЛОКАЛЬНЫЕ по ИС, которым пользователь является Ответственным ИС.
- Редактирование update «+» ТОЛЬКО ЛОКАЛЬНЫЕ по ИС, которым пользователь является Ответственным ИС.
- В одной из колонок (вероятно, другая роль) указано «Только локальные по ИС к которым получен доступ».

### Открытые вопросы
- Матрицы «+/-» по ролям при извлечении из PDF разорваны, соответствие знаков конкретным ролям в этом фрагменте восстановить нельзя.
- Номер бага к добавлению от 27.09.2024 требует уточнения.
