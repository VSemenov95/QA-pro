# Дублирование экземпляра коллекции метрик в рамках карточки мониторинга ИС

> Функциональность позволяет авторизованному пользователю дублировать экземпляр коллекции метрик в выбранные ИС и объекты мониторинга в рамках карточки мониторинга ИС с сохранением версии шаблона исходной коллекции.

### Описание
- User story: «Я как Авторизованный Пользователь хочу создать дубликат экземпляра коллекции метрики и разместить его в "Метриках ИС" или "Объектах мониторинга" текущей карточки мониторинга, для того, чтобы ускорить создание идентичных экземпляров метрики в рамках одной карточки мониторинга ИС». (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Работы: 1) информирование о возможности дублирования для объекта «Метрики ИС» (критерии 1.0-1.1; PPPM-1087 — Закрыто; PPPM-2143); 2) дублирование экземпляра в КЕ текущей ИС (2.0-2.5); 3) подтверждение дублирования в выбранные КЕ (3.0-3.3). (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- При дублировании новая коллекция создаётся на ту же фиксированную версию шаблона, что и исходная (п. 1.2; объект/операция: Коллекция метрик/duplication). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- История версий: 1.0 (05.06.2023, PPPM-1087) описание дублирования между объектами ИС; 2.0 (27.10.2023, PPPM-2143) убрано требование о неизменности шаблона, расширены проверки по типам атрибутов, изменён дизайн; 2.1 (15.12.2024) актуализация перед демо по сокупу PPPM-2099 «Дублирование экземпляров коллекций»; 3.0 (02.04.2024) копирование названия шаблона; 4.0 (10.06.2024) сценарий выхода итогового названия за пределы типа данных; 5.0 (15.10.2024, PPPM-8201) метки типа «для СЦ» не сохраняются в копиях. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)

### Экраны и навигация
- 1.0: пользователь авторизован, открыта карточка мониторинга, нажал на экземпляр коллекции метрик → видит карточку экземпляра; кнопка «Дублировать» доступна в карточке и в списке экземпляров коллекций. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- 1.1: при наведении мыши на плашку коллекции, отличной от текущей, появляется кнопка «Дублировать коллекцию». (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- 2.0: после нажатия «Дублировать коллекцию» открывается окно с выпадающим списком целевых КЕ (поиск от двух символов) и кнопками «Отменить»/«Дублировать». 2.1: нажатие на поле выбора формирует список целевых объектов. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- 2.2: подходящих КЕ нет → в списке недоступные ИС/КЕ с текстом «Нет доступных объектов». 2.3: подходящие КЕ показываются как доступные для выбора. 2.4: при выборе ИС и ОМ у каждого объекта кнопка удаления. 2.5: удаление через крестик или снятием галочки убирает объект из поля. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Прототипы Figma: 1.0 (макеты 1.0, 1.1), 2.0 окно выбора объекта назначения, 2.1 развёрнутый список ИС и ОМ, 2.2 после выбора ОМ доступна «Дублировать», перечень выбранных ИС и ОМ в поле списка, 3.0 подтверждение успешного дублирования. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)

### Поля и элементы
- Кнопки: «Дублировать» (карточка экземпляра и список), «Дублировать коллекцию» (плашка при наведении), «Отменить» и «Дублировать» (окно). (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Выпадающий список выбора целевых КЕ: поиск от двух символов (в маске 3 символа — см. комментарии для разработки). (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Кнопка удаления (крестик) у каждого выбранного объекта; также снятие галочки в списке. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)

### Бизнес-правила и ограничения
- Дублирование доступно только в пределах объектов карточки мониторинга ИС («Метрики ИС» и «Объекты мониторинга ИС»), которой принадлежит экземпляр. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Дублирование доступно независимо от статуса экземпляра и состояния заявки на постановку на мониторинг; дубликат всегда создаётся в статусе «Добавлен». Автоматической отправки заявок нет: пользователи отправляют их сами по логике Автопостановки ВЫКЛ/ВКЛ. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Отбор КЕ: 1) все КЕ данной ИС (в т.ч. сама ИС); 2) КЕ подходит, если для каждого обязательного атрибута текущей коллекции нет ограничений; 3) в списке автоматически отображаются подходящие КЕ с учётом введённого в маске 3 символа; 4) валидация по маппингу типов коллекций и КЕ (portal.mapping_ci_to_collection_type). Пример: для коллекции SQL — КЕ типов INFRASTRUCTURE_SERVICE, IT_SERVICE, DATABASE, ORACLE, SQL_SERVER, SPO_CLUSTER. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Наименование дубликата: «%Название исходного экземпляра коллекции% - Дубль от %ДД:ММ:ГГГГ, ЧЧ.ММ.СС». Наименование шаблона в дубликате формируется аналогично исходному (2.04.24). (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- В каждой копии создаются: внутренние атрибуты с теми же значениями параметров (ограничений нет); метки коллекции как в оригинале, кроме меток типа для СЦ; метрики, подходящие под «Ограничения для метрик в разрезе типов», с настройками (пороги, параметры метки), кроме меток типа для СЦ. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Типы атрибутов: Строка, Число, Дробь, Текст, Сетевая зона, Массивы, Строки — без ограничений; ТУЗ — нельзя копировать в КЕ, для которых ТУЗ недоступен по настройкам управления ТУЗ; ТИ — нельзя копировать в КЕ с привязанным ТУЗ, для которого действуют те же ограничения. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Новая коллекция создаётся на ту же фиксированную версию шаблона коллекции, что и исходная (PPMON-230). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Сообщения и ошибки
- «Нет доступных объектов» — в выпадающем списке, когда подходящих КЕ нет (критерий 2.2). (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- «Для дублирования выберите целевые объекты» — всплывающая ошибка при «Дублировать» без выбранных объектов. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- «Ошибка дублирования коллекции/Имя коллекции не должно превышать 255 символов» — если название с добавленным текстом превышает ограничение типа данных. (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
- Сообщение об успешном дублировании — по макету 3.0 «Визуальный дизайн». (27-🟩[RI1]Возможность Пользователя дублировать экземпляр коллекции метрик в рамках карточки мониторинга ИС)
