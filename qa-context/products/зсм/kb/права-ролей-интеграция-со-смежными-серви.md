# Права ролей: интеграция со смежными сервисами (служебные функции API ЗСМ)

> Права на служебные функции использования API ЗСМ: генерация и изменение событий, запросы к Victoria Metrics и метаданным метрик, доступ к core-api-graphql.

## 200-Описание ролевой модели ЗСМ.pdf

### Поля и элементы
- 101 Генерация событий на основе анализа метрик и запись в core-event-listener: Добавление create -.
- 102 Генерация новых событий на основе событий ЗСМ и запись в core-event-listener: Добавление create -.
- 103 Изменение события после обработки и запись в core-event-saver: Добавление create -.
- 104 Запрос временных рядов из Victiria Metris: Просмотр read -.
- 105 Запрос мета-данных по метрикам из ЗСМ: Просмотр read -.
- 106 Доступ к core-api-graphql: Просмотр read.

### API и интеграции
- core-event-listener, core-event-saver, Victiria Metris (так в документе), core-api-graphql.
- Для интеграционных колонок «Интеграция с ИАС» и «Интеграция с Мощностями» указано «Служебная. Доступ к GraphQl».

### Роли и права
- Ссылка на задачу PPPM-7390.
- В заголовках колонок: Ответственный ИС, Инженер ЗОНТ, Инженер СЦ, Дежурный смены, Аудитор ИБ, Аудитор ДВА, Администратор Портала, Технолог БС, Просмотр сервисов, Пользователь, Интеграция с ИАС, Интеграция с Мощностями.
