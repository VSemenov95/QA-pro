# Редактирование списка коллекций для расчета композитного монитора

> Функциональность позволяет при добавлении коллекции типа «Композитный монитор» настраивать, редактировать и удалять список коллекций для мониторинга (в форме добавления, в черновике и в заявке) для расчета композитного монитора.

### Описание
- Функционал редактирования списка коллекций используется для расчета композитного монитора, см. [IS] Расчет композитного монитора по статусам коллекций. (US-6)
- Пользователь добавляет шаблон коллекции типа «Композитный монитор» (написание типа в источнике частично обрезано: COMPOSITE_MO… / ITE_MONITORE), затем при добавлении коллекции этого типа настраивает список коллекций для мониторинга. (US-6)

### Экраны и навигация
- Каталог шаблонов коллекций: добавление шаблона по ранее реализованной логике #[RI1] «Возможность пользователя добавить шаблон коллекции в Каталоге шаблонов коллекций». В добавленном шаблоне отображаются список атрибутов и список метрик. (US-6)
- Форма добавления коллекции метрик (объект «20. Коллекция метрик», /create): в карточке мониторинга по логике #[RI1] «Возможность Пользователя добавить коллекцию метрик для объекта мониторинга в карточке мониторинга». При выбранном шаблоне композитного монитора отображается блок «Коллекции для мониторинга»; пользователь открывает вкладку и видит кнопку «Добавить коллекцию». (US-6)
- Карточка заявки/черновика заявки (объект «20. Коллекция метрик», /Update): пользователь видит перечень ранее добавленных коллекций. (US-6)

### Поля и элементы
- Кнопка «Добавить коллекцию»: появляется табличная строка с заголовками, все элементы по умолчанию не заполнены. (US-6)
- Повторное нажатие: если все ранее добавленные строки заполнены, возникает новая строка; если хотя бы в одной не указана коллекция, область невыбранной коллекции подсвечивается красным, новая строка не добавляется. (US-6)
- Кнопка удаления строки видна при наведении указателя на добавленную строку. (US-6)
- Таблица строки (заголовок · тип · описание): (US-6)
  - «Название коллекции» · выпадающий список, поиск по названиям от 3х букв · выбор коллекции, для которой считается композитный монитор; при выборе заполняются остальные поля. Элементы сгруппированы по названиям объектов мониторинга. Каждую коллекцию можно выбрать только 1 раз в рамках текущей коллекции.
  - «КЕ» · текст · название ОМ выбранной коллекции.
  - «Статус коллекции» · текст · текущий статус выбранной коллекции.
  - «Тип коллекции» · текст · тип выбранной коллекции.
  - «Метод расчета» · текст · метод расчета, выбранный при постановке на мониторинг коллекции с включенным «Статус коллекции»; определяется из таблицы CollectionStatusCalcRules (название частично обрезано в источнике).

### Бизнес-правила и ограничения
- На вкладке метрик в шаблон композитного монитора нельзя добавлять новые метрики (контейнеры, синтетические и т.д.; перечень частично обрезан). (US-6)
- Для выбора доступны только коллекции со статусом «На мониторинге», с состоянием метрики «Статус коллекции»=Вкл и не композитные (формулировка частично обрезана). (US-6)
- Каждую коллекцию можно выбрать только 1 раз в рамках текущей коллекции. (US-6)
- Новая строка добавляется только если все ранее добавленные строки заполнены. (US-6)
- При подтверждении создания проверяется заполнение обязательных параметров во всех строках; если все заполнены, добавление экземпляра коллекции успешно. (US-6)
- При редактировании заявки/черновика пользователь обязательно должен подтвердить изменения. (US-6)

### Сообщения и ошибки
- «Выберите коллекцию для расчета композитного монитора» — если хотя бы в одной строке не выбрана коллекция; область невыбранной коллекции подсвечивается красным, добавление не происходит. (US-6)

### Роли и права
- Сценарий 1.0: «4. Шаблон коллекции», Create. (US-6)
- Сценарии 1.1–1.4: «20. Коллекция метрик», /create. (US-6)
- Сценарий 1.5: «20. Коллекция метрик», /Update. (US-6)

### Сценарии
- 1.0 Добавить шаблон типа «Композитный монитор»: 1) создание шаблона по ранее реализованной логике; 2) в шаблоне отображаются список атрибутов и метрик, новые метрики на вкладке метрик добавлять нельзя. (US-6)
- 1.1 Открыть вкладку настройки списка коллекций: 1) выполнено 1.0; 2) открыта форма добавления коллекции; 3) выбран шаблон из 1.0; 4) виден блок «Коллекции для мониторинга»; 5) вкладка открыта, видна кнопка «Добавить коллекцию». (US-6)
- 1.2 Добавить коллекции в список: 1) выполнено 1.1; 2) нажатие «Добавить коллекцию»; 3) появляется пустая табличная строка; 4) выбор коллекции; 5) повторное нажатие кнопки (поведение см. «Поля и элементы»). (US-6)
- 1.3 Удалить коллекцию из списка: 1) выполнено 1.2, добавлена хотя бы одна строка; 2) наведение на строку, видна кнопка удаления; 3) нажатие удаляет строку. (US-6)
- 1.4 Подтвердить добавление коллекции типа «Композитный монитор»: 1) выполнено 1.2; 2) заполнены все элементы формы по требованиям #[RI1]; 3) подтверждение создания коллекции с черновиком заявки/отправка заявки по текущей логике. Если во всех строках заполнены обязательные параметры, добавление успешно; если в строке не выбрана коллекция, красная подсветка, добавления нет, ошибка «Выберите коллекцию для расчета композитного монитора». (US-6)
- 1.5 Управление набором при редактировании черновика/заявки: 1) выполнено 1.4; 2) заявка или черновик сформированы по логике «Возможность пользователя создавать и редактировать заявки на изменение/добавление коллекций с использованием BPMN-движка»; 3) в карточке виден перечень ранее добавленных коллекций, управление аналогично 1.2–1.4 (в источнике «2.2–2.4»); 4) изменения обязательно подтверждаются. (US-6)

### Открытые вопросы
- В источнике ссылки на сценарии указаны как «2.0» и «2.2-2.4», тогда как сценарии пронумерованы 1.0–1.5. (US-6)
- Часть текста (тип шаблона, условия выбора коллекции, название таблицы расчета) в источнике обрезана. (US-6)
