# Общие сведения

> Версионирование шаблонов коллекций мониторинга в ЗСМ (PPMON-230): нумерованные версии шаблонов, черновик с фиксированием новой версии, выбор версии при работе с коллекциями и запрет удаления шаблонов с привязанными коллекциями.

### Описание
- Фича ЗСМ PPMON-230 «Версионирование шаблонов коллекций»; все доработки выполняются в рамках PPPM-5796 US-Q3-3 «Версионирование шаблонов коллекций». (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Версия — нумерованный слепок набора атрибутов, метрик, меток, настроек разрешений. Название шаблона сквозное для всех версий. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Собранные требования описаны в статье «Скоуп - версионирование шаблонов коллекций». Дизайн: ссылка на PIXSO. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Обновление коллекций на актуальную версию реализуется отдельно: «1826. Реализация точечного обновления коллекции из шаблона». (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- AS IS: версионирование шаблонов не реализовано, в рамках фичи создаётся новый функционал. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Пользовательские сценарии реализуются согласно требованиям ролевой модели ЗСМ (https://sfera-t1.ru/knowledge/pages?id=108926). Новых объектов ролевой модели и ролей в задаче не добавляется. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Оглавление документа включает раздел 5 «Интеграционные требования (TO BE)»: 5.1 Доработка структуры хранения данных для реализации версионирования шаблонов; 5.2 Доработка структуры хранения данных коллекций; 5.3 Выполнение миграции данных; 5.4 Доработка СС Аудита. Содержимого этих подразделов в имеющейся части документа нет. (57-230. Версионирование шаблонов коллекций)

### Поля и элементы
Новая терминология:
- Шаблон коллекции — набор различных версий преднастроек экземпляра коллекции. Преднастройки — полный набор атрибутов/метрик/меток/разрешений со значениями по умолчанию. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Версия шаблона коллекции — фиксированный набор преднастроек экземпляра коллекции. Последняя версия шаблона называется АКТУАЛЬНОЙ. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Черновик шаблона коллекции — набор изменений актуальной версии шаблона для создания новой версии на основании актуальной. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Фиксирование версии — переход черновика шаблона в актуальную версию с подтверждения пользователя. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Инфопанель с версией в интерфейсе коллекций мониторинга. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Бизнес-правила и ограничения
Включено в критерии фичи:
- Обновить интерфейс управления шаблонами коллекций мониторинга в части версионирования. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Интерфейс позволяет создавать и изменять шаблоны мониторинга в разрезе версий. Договорились: изменять старые версии нельзя. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Текущие коллекции, тиражированные до появления версионирования, адаптируются к шаблонам с версионированием без дополнительных трудозатрат КВ (с 1-й версией шаблона). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Интерфейс имеет возможность использования черновика, чтобы накопительным эффектом сохранять новую версию. Логика черновика заимствуется из коллекций: черновик существует 1 в 1 момент времени, общий для всех инженеров ЗОНТ, его можно удалить. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Интерфейс позволяет просматривать любую версию шаблона мониторинга. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Запрещено удалять шаблоны, если для любой версии шаблона существует хотя бы одна привязанная коллекция. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- При выполнении массовых изменений выбирать версию шаблона, по которой будут внесены изменения. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- При добавлении коллекции выбирать версию шаблона, по которой будут внесены изменения. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- При дублировании коллекция-копия создаётся для той же версии шаблона коллекции, что и оригинал. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

Не включено:
- Отображение в интерфейсе, на какие версии шаблонов какие версии коллекций тиражированы (по аналогии со списком связанных коллекций для ТУЗ). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Кнопка «обновить шаблон на версию х» в интерфейсе коллекций мониторинга (требование убрано, дублируется в отдельной фиче, достаточно обновления на актуальную). (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
- Вкладка просмотра истории изменения шаблона мониторинга. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)

### Роли и права
- Управление интерфейсом: Инженер ЗОНТ; просмотр: другие роли (аналогично другим ролям с возможностью просмотра). Новых ролей и объектов ролевой модели не добавляется. (57-230. Версионирование шаблонов коллекций; 59-230. Версионирование шаблонов коллекций)
