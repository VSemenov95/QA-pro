# Права ролей: подраздел «Расписания»

> Права на вкладку, каталог и карточку расписаний с ограничениями по доступным ИС/БС, а также поиск и выбор расписаний в шаблонах, экземплярах коллекций и правилах реагирования.

## 200-Описание ролевой модели ЗСМ.pdf

### Поля и элементы
- 94 Вкладка «Администрирование» с подразделом «Расписания»: Просмотр read +.
- 95 Каталог расписаний: Просмотр read +. Видимость: 1) системные расписания, для которых выбрано ВСЕ ИС; 2) системные и пользовательские расписания, для которых выбраны ИС пользователя (PPPM-3397). Для роли БС: 1) системные расписания, для которых выбрано ВСЕ БС; 2) системные и пользовательские расписания, для которых выбраны БС пользователя (PPPM-3397). Для другой роли: 1) системные расписания, для которых выбрано ВСЕ БС и для пользователя выбрана хотя бы одна БС; 2) системные расписания, для которых выбрано ВСЕ ИС и для пользователя выбрана хотя бы одна ИС; 3) системные и пользовательские расписания, для которых выбраны ИС/БС пользователя (PPPM-3397).
- 96 Карточка расписания:
  - Просмотр read + — видит только те расписания, которые доступны в каталоге.
  - Добавление create + — добавлять может только пользовательские, при добавлении видит только свои ИС (для БС — только свои БС).
  - Редактирование update + — только пользовательские и «свои» ИС (полное совпадение: в расписании указано N ИС, все N ИС доступны пользователю); для БС аналогично со «своими» БС (PPPM-3397).
  - Удаление delete + — только пользовательские и «свои» ИС (полное совпадение: в расписании указано N ИС, все N ИС доступны пользователю); для БС аналогично.
  - Включение/Отключение switch_on/switch_off + — только пользовательские и «свои» ИС (полное совпадение); для БС аналогично.
  - Для одной из ролей: «(И Пользовательские И, системные)» PPPM-3397.
- Поиск и выбор системных и пользовательских расписаний в шаблоне коллекции — убрано из ролевки; частный случай поведения атрибутов в шаблоне описан в статьях. Для одной роли: «все расписания с признаком только для сбора коллекций».
- Поиск и выбор системных и пользовательских расписаний в экземпляре коллекции — убрано из ролевки; частный случай поведения атрибутов в экземпляре описан в статье «Правила обработки атрибутов разных типов в экземпляре коллекции». Для одной роли: «все расписания с признаком только для сбора коллекций».
- Поиск и выбор системных и пользовательских расписаний в любом (локальное/глобальное) правиле реагирования — частный случай настройки правил реагирования см. [US] «Создание нового правила реагирования». Просмотр read +: 1) системные расписания с признаком для оповещений, для которых выбрано ВСЕ ИС; 2) системные и пользовательские расписания с признаком для оповещений, для которых выбраны ИС пользователя. Для одной роли: «все расписания с признаком оповещений».

### Роли и права
- В заголовках колонок встречаются роли: Ответственный ИС, Инженер ЗОНТ, Инженер СЦ, Дежурный смены, Аудитор ИБ, Аудитор ДВА, Администратор Портала, Технолог БС, Просмотр Сервисов, Пользователь.
- Знаки «+/-» по ролям разорваны, соответствие ролям не восстановимо.
