# Алгоритм обновления коллекции из шаблона (source → target)

> Алгоритм точечного обновления коллекции из шаблона (source → target): обновление текущей коллекции до последней актуальной версии шаблона с учётом пользовательских изменений.

### Описание
- Текущая коллекция — состояние на мониторинге при статусе «На мониторинге»; при статусе «Добавлено» параметры считаются совпадающими с текущей версией (source). Текущая версия (source) — версия, для которой создана коллекция. Версия для обновления (target) — всегда последняя актуальная версия шаблона (допустим случай совпадения source и target). (59-1826. Реализация точечного обновления коллекции из шаблона)
- Схема 5.2 показывает сохранение исходного значения элемента по типу/изменениям; логики ДОБАВЛЯЕМЫХ элементов на ней нет. Пример 5.3 — последовательное обновление с версии на версию. (59-1826. Реализация точечного обновления коллекции из шаблона)
- В рамках 26-1824_1825 вносится правка в шаг 3, п. 3.2 алгоритма (п. 5.1 задачи 1826). (26-1824_1825. Сохранение черновика без валидации_валидация при отправке)

### Бизнес-правила и ограничения
- Шаг 1 (сценарий 4.0). Статус «На мониторинге/Сбор данных остановлен», черновика нет: новая заявка с новым ID в статусе «Черновик», заполняется значениями из текущей коллекции, передаётся в шаг 2.2. Черновик есть, заявка не отправлена: та же заявка и ID, статус «Черновик», все текущие параметры удаляются и заполняются значениями по умолчанию из коллекции, как при ручном создании заявки изменения коллекции; передаётся в шаг 2.2. Для статуса «Добавлено» (черновика нет — редкий случай, когда заявка добавления отклонена; либо черновик есть, но заявка не отправлена) см. conflicts. После заполнения черновика валидация не требуется: черновик ещё может быть изменён на шагах 2.2–2.3, тогда выполнится исходная валидация. Если заявка уже отправлена — алгоритм не начнётся по сочетанию условий. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Шаг 2.1. Атрибуты (сравнение здесь и далее по техническому названию): добавляются системные и пользовательские атрибуты, которые есть в target, но отсутствуют в source, со значениями из target; удаляются атрибуты, которых нет в target; остальные: если включён учёт пользовательских изменений и значение в текущей коллекции отличается от source — сохраняется текущее значение, а тип, признаки обязательности, редактируемости, скрытости наследуются из target; иначе подставляются значение, тип, признаки обязательности, редактируемости, скрытости из target. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Автоматическая подстановка значений (из любой версии шаблона или коллекции) игнорирует точечные разрешения на изменение по атрибутам (ограничения задаются в 1823 Настройка «Политики разрешений» в шаблоне коллекций). (59-1826. Реализация точечного обновления коллекции из шаблона)
- Шаг 2.2. Метрики: добавленные пользователем вручную остаются без изменений (вероятно, потребуется миграция, чтобы сопоставить добавленные и не добавленные метрики у текущих коллекций); добавляются метрики, отсутствующие в текущей коллекции и присутствующие в target (в т.ч. скриптовые); удаляются метрики, которые есть в текущей коллекции, отсутствуют в target и не добавлены вручную. (59-1826. Реализация точечного обновления коллекции из шаблона)
- ДОППРОВЕРКА ПО УДАЛЕНИЮ: алгоритм завершается ошибкой, если удаляемая метрика имеет связи с ИАС (подключена к ИАС, выбрана для создания ТМ БС, есть дочернее активное правило) либо является переменной комплексной метрики из другой коллекции. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Метрики, присутствующие и в черновике, и в target: если включён учёт пользовательских изменений и значение любого параметра отличается от того же параметра в source — метрика не изменяется; иначе перезаписывается целиком значениями из target. Дочерние параметры: настройки параметров метрики по типу (уникальные для скриптовой, комплексной, метрики-контейнера); настройки порогов; настройки подключения к ИАС (не реализуем, пока не сделано PPMON-1864 Добавить управление настройками подключения ИАС для метрик на уровне шаблона, с наследованием настроек в дочерние коллекции); настройки правил отбора рядов с дочерними настройками подключения к ИАС; любые другие дочерние сущности карточки метрики, настраиваемые сейчас или в будущем. Автоматическая подстановка игнорирует точечные разрешения на изменение по атрибутам (1823). (59-1826. Реализация точечного обновления коллекции из шаблона)
- Шаг 2.3. Признак автопостановки в коллекции изменяется согласно значению из шаблона target. Шаг 2.4. Набор разрешений применяется согласно настройке разрешений из target-version (1823 Настройка «Политики разрешений» в шаблоне коллекций). (59-1826. Реализация точечного обновления коллекции из шаблона)
- Шаг 2.5. Метки (отдельный алгоритм, независимо от признака учёта пользовательских изменений): 1) на вкладку «Атрибуты объекта» черновика добавляются все метки из target, которых нет в текущей коллекции; 2) с вкладки убираются метки коллекции, которых нет в target, кроме меток типа «Пользовательская»; 3) на метрики коллекции добавляются все метки, которые есть на коллекции, но нет на метриках. (59-1826. Реализация точечного обновления коллекции из шаблона)
- По всем пунктам шага 2 при учёте изменений: если в source значение не задано, а в коллекции задано — считается, что изменение пользователя есть. Для меток учёт пользовательских изменений пока не реализуется. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Шаг 3. Валидация черновика: проверка каждого атрибута по правилам из «Правила обработки атрибутов разных типов в экземпляре коллекции»; если все проверки пройдены — атрибуты валидны. Уникальные проверки метрик: для комплексных — все метрики из списка переменных присутствуют в черновике заявки; наличие хотя бы одной включённой метрики, не являющейся статусом коллекции. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Шаг 4. Валидация пройдена, автопостановка не включена — заявка переходит в статус СОЗДАНО и требует ручной обработки; автопостановка включена — заявка передаётся в автообработку. При успешной обработке заявки версия коллекции меняется на версию шаблона, из которой выполнено обновление. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Обработка скрипта: если пользователь изменил скрипт в коллекции относительно шаблона, то при обновлении с сохранением изменений скрипт считается сохранённым с пользовательским изменением и не изменяется; аргументы и подстановки скрипта не изменяются; метрики скрипта считаются добавленными пользователем и не изменяются. (59-1826. Реализация точечного обновления коллекции из шаблона)

### Сообщения и ошибки
- Невозможность удалить метрику (связи с ИАС, ТМ БС, дочернее активное правило, использование как переменной комплексной метрики в другой коллекции) — алгоритм завершается ошибкой. (59-1826. Реализация точечного обновления коллекции из шаблона)
- Валидация не пройдена — обновление завершается ошибкой, черновик не создается, операция откатывается. (59-1826. Реализация точечного обновления коллекции из шаблона)
