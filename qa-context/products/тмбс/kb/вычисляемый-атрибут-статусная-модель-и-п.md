# Вычисляемый атрибут: статусная модель и переходы между статусами

> Статусная модель вычисляемого атрибута (ВА) в карточке мониторинга (КМ): перечень статусов, бизнес-правила и переходы между статусами с указанием, кто их выполняет (пользователь или система).

### Описание
- Документ описывает статусную модель вычисляемого атрибута (ВА) в карточке мониторинга (КМ) и переходы между статусами с комментариями. (18-Вычисляемый атрибут)
- Перечень статусов (код — название): DRAFT — «Черновик»; IN_WORK — «В работе»; CONNECTED — «Подключено»; MONITORING — «На мониторинге»; DISCONNECTED — «Отключено»; DISCONNECTED_MANUAL — «Отключено вручную». (18-Вычисляемый атрибут)
- Статус «В работе» скрыт и не используется. (18-Вычисляемый атрибут)

### Бизнес-правила и ограничения
- Статус «Черновик» является инициирующим: пользователь создаёт ВА в КМ, все ВА первоначально создаются только в статусе «Черновик». (18-Вычисляемый атрибут)
- В статусе «Черновик» пользователь не может поставить ВА на мониторинг. (18-Вычисляемый атрибут)
- «Черновик» — единственный статус для внесения изменений в ВА. (18-Вычисляемый атрибут)
- Изменение статуса согласно статусной модели возможно только при создании и редактировании новой версии КМ. (18-Вычисляемый атрибут)

### Сценарии
- Переходы (текущий статус → целевой статус: кто переводит и комментарий):
- Черновик → Подключено: пользователь переводит при готовности ВА к постановке на мониторинг. (18-Вычисляемый атрибут)
- Черновик → Отключено вручную: выполняет пользователь (комментарий в документе не приведён). (18-Вычисляемый атрибут)
- Подключено → Черновик: пользователь при внесении изменений в атрибуты переводит ВА в статус «Черновик»; перевод возможен как при редактировании версии КМ, так и при просмотре КМ. (18-Вычисляемый атрибут)
- Подключено → Отключено вручную: пользователь переводит при неготовности ВА к постановке на мониторинг или при желании выключить сбор вычисляемого атрибута. (18-Вычисляемый атрибут)
- Подключено → На мониторинге: система автоматически переводит ВА в «На мониторинге» при постановке пользователем КМ на мониторинг. (18-Вычисляемый атрибут)
- Отключено вручную: пользователь переводит ВА в этот статус при желании отключить сбор данных по ВА. (18-Вычисляемый атрибут)
- Отключено вручную → Черновик: пользователь переводит для внесения изменений в ранее отключённый ВА. (18-Вычисляемый атрибут)
- Отключено вручную → Подключено: пользователь переводит для постановки ВА на мониторинг. (18-Вычисляемый атрибут)
- Отключено: система автоматически переводит ВА в этот статус при снятии КМ с мониторинга. (18-Вычисляемый атрибут)
- Отключено → На мониторинге: система автоматически переводит статус ВА в «На мониторинге» при постановке пользователем КМ на мониторинг. (18-Вычисляемый атрибут)
- На мониторинге: система автоматически переводит ВА в этот статус при обновлении КМ или постановке КМ на мониторинг. (18-Вычисляемый атрибут)
- На мониторинге → Отключено: система автоматически переводит при снятии пользователем КМ с мониторинга. (18-Вычисляемый атрибут)
- На мониторинге → Отключено вручную: пользователь переводит при желании выключить сбор вычисляемого атрибута. (18-Вычисляемый атрибут)
- На мониторинге → Подключено: система переводит при создании новой версии КМ (редактировании КМ). (18-Вычисляемый атрибут)
- Также указано: «Подключено» — система переводит ВА в этот статус при создании новой версии КМ. (18-Вычисляемый атрибут)

### Открытые вопросы
- Пометка в документе: «НУЖНО ПРИВЕСТИ ДИАГРАММУ СТАТУСНОЙ МОДЕЛИ В АКТУАЛЬНОЕ СОСТОЯНИЕ». (18-Вычисляемый атрибут)
- Для перехода «Черновик → Отключено вручную» комментарий не заполнен (указано только «Пользователь»). (18-Вычисляемый атрибут)
- В исходном тексте часть ячеек таблицы (текущий/целевой статус) пропущена, поэтому для некоторых строк (Отключено вручную, Отключено, На мониторинге) направление перехода восстановлено по комментарию. (18-Вычисляемый атрибут)
