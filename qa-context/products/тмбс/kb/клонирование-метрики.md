# Клонирование метрики

> Клонирование метрики — функция кнопки «Клонировать» в окне просмотра метрики, которая через диалог выбора полей создаёт копию метрики в статусе «Черновик» для ускорения создания метрик.

### Описание
- Пользовательская история: «Я как Пользователь системы. Хочу Клонировать метрику. Для того, чтобы Облегчить и ускорить процесс создания метрик». (Клонирование метрики -4)
- Контекст: клонирование метрик необходимо для ускорения процесса создания метрик, предзаполняя их нужной информацией заранее. (Клонирование метрики -4)
- История изменений: версия 1, 17.06.25, автор Лазарев Никита, «Создание». (Клонирование метрики -4)

### Экраны и навигация
- Клонирование происходит по нажатию на кнопку в окне просмотра. (Клонирование метрики -4)
- При нажатии на кнопку «Клонировать» появляется диалоговое окно с выбором полей для клонирования. (Клонирование метрики -4)
- После выбора полей и нажатия «Клонировать» открывается окно создания метрики в статусе «Черновик» с скопированными выбранными полями; доступны кнопки «Сохранить» и «Отмена». (Клонирование метрики -4)
- Формы UI: 5.3.1 Клонирование метрики (Кнопка) — расположение кнопки (показано на макете); 5.3.2 Клонирование метрики (Диалоговое окно). (Клонирование метрики -4)

### Поля и элементы
- Кнопка «Клонировать» (5.3.1): формат — кнопка; обязательность — нет; редактируемое поле — «-»; валидация: доступна для нажатия в любом статусе метрики в любом статусе карточки мониторинга (кроме «Постановка»); сообщения об ошибке — «-». (Клонирование метрики -4)
- Диалоговое окно (5.3.2), поле «Название»: поле для ввода; обязательное — да; редактируемое — да; правила валидации — «-» (валидируется только в момент сохранения метрики); сообщения об ошибке — «-». (Клонирование метрики -4)
- Поле «Поля для клонирования»: множественный выбор; обязательное — да; редактируемое — да; правила валидации — «-»; сообщения об ошибке — «-». (Клонирование метрики -4)
- Кнопки «Клонировать» и «Отмена»: кнопка; обязательность — да; редактируемое — «-»; правила валидации — «-»; сообщения об ошибке — «-». (Клонирование метрики -4)
- В окне доступны для нажатия: чекбокс напротив каждого элемента (выбор полей для копирования), кнопка «Клонировать», кнопка «Отмена». (Клонирование метрики -4)
- Доступные для клонирования поля: Все; Описание; Методика расчета; Единицы измерения; Периодичность расчета; Параметры критичности; Код метрики; Код события метрики. При нажатии на «Все» выделяются все доступные варианты. (Клонирование метрики -4)

### Бизнес-правила и ограничения
- Клонируется только сохранённая информация метрик. Если пользователь ввёл информацию и, не нажав «Сохранить», нажал «Клонирования», несохранённая информация не склонируется. (Клонирование метрики -4)
- Клонировать метрику можно в любом статусе карточки (как в режиме просмотра, так и в режиме редактирования) и самой метрики, кроме статусов, не подразумевающих взаимодействия с карточкой (на данный момент только «Постановка»). (Клонирование метрики -4)
- Можно выбрать, какие поля необходимо клонировать. (Клонирование метрики -4)
- Склонированная метрика создаётся в статусе «Черновик». (Клонирование метрики -4)
- При клонировании наименование также клонируется с припиской «КОПИЯ». (Клонирование метрики -4)
- Можно клонировать только 1 метрику за раз. (Клонирование метрики -4)

### Роли и права
- Дополнительных разрешений для функционала не вводится; необходимо разрешение на создание метрики. (Клонирование метрики -4)

### Сценарии
- Критерий 1: ЕСЛИ пользователь находится в режиме просмотра карточки ИЛИ в режиме редактирования карточки, И находится на странице метрик, И имеет разрешение на создание метрик; КОГДА нажимает на метрику И нажимает на кнопку «Клонировать»; ТОГДА видит всплывающее окно с множественным выбором полей для копирования. Доступные кнопки: чекбокс напротив каждого элемента, «Клонировать», «Отмена». (Клонирование метрики -4)
- Критерий 2: ЕСЛИ критерий 1 выполнен; КОГДА выбирает один, несколько или «все» поля И нажимает «Клонировать»; ТОГДА открывается окно создания метрики в статусе «Черновик», все выбранные поля скопированы, доступны кнопки «Сохранить» и «Отмена». (Клонирование метрики -4)
- Критерий 3: ЕСЛИ критерий 2 выполнен; КОГДА пользователь нажимает «Сохранить»; ТОГДА метрика сохранена в статусе «Черновик». (Клонирование метрики -4)
- Критерий 4: ЕСЛИ критерий 2 выполнен; КОГДА пользователь нажимает «Отменить»; ТОГДА окно создания метрики закрыто, создание «клона» не произошло. (Клонирование метрики -4)
