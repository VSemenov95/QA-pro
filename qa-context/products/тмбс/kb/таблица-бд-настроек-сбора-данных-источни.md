# Таблица БД настроек сбора данных источников данных (data_source_data_collecting_info)

> Таблица БД data_source_data_collecting_info хранит настройки сбора данных для источников данных.

### Описание
- Назначение таблицы: хранит информацию о настройках сбора данных для источников данных. (2-data_source_data_collecting_info)
- Название таблицы в тексте фрагмента не указано; оно взято только из имени файла «2-data_source_data_collecting_info.pdf». (2-data_source_data_collecting_info)

### Поля и элементы
- data_source_id — тип INT4, «Идентификатор источника данных», ограничение: PK. (2-data_source_data_collecting_info)
- is_data_collecting — тип BOOLEAN, «Признак активности сбора данных», NULLABLE. (2-data_source_data_collecting_info)
- is_tech_attributes_only — тип BOOLEAN, «Признак сбора технических атрибутов», NULLABLE. (2-data_source_data_collecting_info)
- data_source_version — тип INT4, «Версия источника данных», NULLABLE. (2-data_source_data_collecting_info)
- ttl — тип VARCHAR(32), «Время жизни данных», NULLABLE. (2-data_source_data_collecting_info)
- connector_type — тип VARCHAR(32), «Тип коннектора», NULLABLE. (2-data_source_data_collecting_info)
- change_status — тип VARCHAR (длина не указана), описание: «??», ограничение: CHECK — может быть только PROCESSING или FAILED. (2-data_source_data_collecting_info)
- error_text — тип TEXT, «Текст ошибки», NULLABLE. (2-data_source_data_collecting_info)

### Бизнес-правила и ограничения
- Поле change_status может принимать только значения PROCESSING или FAILED (CHECK-ограничение). (2-data_source_data_collecting_info)
- Первичный ключ: data_source_id. (2-data_source_data_collecting_info)
- Остальные поля, кроме data_source_id и change_status, допускают NULL (NULLABLE). Для change_status признак NULLABLE в документе не указан. (2-data_source_data_collecting_info)

### Открытые вопросы
- Описание поля change_status в документе помечено как «??» (не заполнено). (2-data_source_data_collecting_info)
- Длина типа VARCHAR у поля change_status не указана. (2-data_source_data_collecting_info)
