# Отключение вычисляемого атрибута карточки мониторинга (статус «Отключено вручную»)

> Функциональность ручного отключения вычисляемого атрибута (ВА) карточки мониторинга через статус «Отключено вручную», при котором расчёт метрик и запись данных по ВА прекращаются, а остальные ВА продолжают работать.

### Описание
- Пользовательская история: «Я как Пользователь системы. Хочу Отключить вычисляемый атрибут. Для того, чтобы Данные источника не попадали в события БС так как на текущий момент не актуальны». (Отключение вычисляемого атрибута карточки мониторинга-10)
- Пользователю периодически нужно отключать ВА в карточке мониторинга (КМ): 1) неактуальность мониторинга ВА; 2) ошибка в срабатывании или методике расчёта, нужны время и уточнения; затем пользователь должен включить ВА. Включение/выключение нужно для остановки расчёта показателей по транзакциям. (Отключение вычисляемого атрибута карточки мониторинга-10)
- История изменений: v1, 2024-12-13, Klimov A. N., PPBP-285, PPBP-284, PPBP-283 (Выполнено), «Создание документа»; v1.1, 2025-01-16, Климов А.Н., PPBP-276 [Analytics] 271 «Обновить инструкцию пользователя отключением КТ» (В работе), «Исправлены ошибки в документе». (Отключение вычисляемого атрибута карточки мониторинга-10)

### Экраны и навигация
- Формы пользовательского интерфейса не изменяются. Статус «Отключено вручную» появляется на UI после добавления со стороны BE. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Статус ВА меняется в режиме просмотра КМ и в режиме редактирования (создания) КМ. Кнопки/действия: «Поставить на мониторинг», «Снять с мониторинга», «Обновить карточку». (Отключение вычисляемого атрибута карточки мониторинга-10)

### Поля и элементы
- Статусы ВА: «Черновик» — начальный, редактирование атрибутов; переход в «Подключено», «Отключено вручную». «Подключено» — готов к постановке на мониторинг, изменения атрибутов невозможны; переход в «На мониторинге» (автоматически при постановке КМ), «Отключено вручную», «Черновик». «Отключено» — ставится автоматически при «Снять с мониторинга»; пользователь может получить его только снятием КМ; переход в «На мониторинге» автоматически. «Отключено вручную» — расчёт метрик не идёт, данные не собираются и не пишутся в таблицы бизнес-сервиса; переход в «Черновик», «Подключено». «На мониторинге» — данные собираются и пишутся; ставится автоматически; переход в «Подключено» (пользователь и система), «Отключено» (система), «Отключено вручную» (пользователь), «Черновик» (пользователь). (Отключение вычисляемого атрибута карточки мониторинга-10)
- «Отключено» выставляется только системой при отключении КМ; «Отключено вручную» — только пользователем, переводы из него тоже только пользователем, система их менять не может. (Отключение вычисляемого атрибута карточки мониторинга-10)

### Бизнес-правила и ограничения
- Бизнес-требования: 1) отключить ВА, ранее поставленный на мониторинг; 2) включить отключённый ВА; 3) отредактировать отключённый ВА, провести по статусной модели; 4) отключить ВА, созданный, но не поставленный на мониторинг; 5) включить ВА без редактирования КМ; 6) выключить ВА без редактирования КМ. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Ограничения: вводится статус «Отключено вручную»; данные по транзакциям могут поступать, если находятся в темах Kafka, до полной вычитки, после чего новые не поступают; при отключении/включении КМ ВА в «Отключено вручную» статус не меняет (не становится «Отключено» и не «На мониторинге»). (Отключение вычисляемого атрибута карточки мониторинга-10)
- Требования к системе: при отключении не писать в таблицы мониторинга БС (таблица вычисляемых атрибутов), т.е. в таблицы ClickHouse БС; ранее сохранённые данные не теряются; при смене статуса для постановки на мониторинг ВА ставится на мониторинг и данные поступают в таблицы БС. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Отключение (просмотр КМ): ВА → «Отключено вручную», данные не считаются и не пишутся в ClickHouse; в config_service.configuration нет записей по ВА; остальные ВА «На мониторинге» работают штатно; при обновлении КМ и смене версии статус сохраняется. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Включение (просмотр КМ): ВА → «Подключено» (без изменений) или «Черновик» (если нужны изменения, затем «Подключено»); пользователь обновляет КМ и ставит на мониторинг; статус → «На мониторинге», начинается сбор и расчёт, запись в ClickHouse, в config_service.configuration появляются записи. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Отключение (редактирование КМ): при постановке КМ на мониторинг ВА в «Отключено вручную» не меняет статус, данные не собираются и не пишутся, записей конфигурации нет, остальные ВА штатно. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Включение (редактирование КМ): новая версия КМ → статус ВА «Черновик» или «Подключено» (без изменений «Отключено вручную» → «Подключено»; иначе → «Черновик», изменения, «Подключено») → постановка КМ на мониторинг; «Подключено» автоматически → «На мониторинге»; метрики поступают в таблицы БС; записи конфигурации есть. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Доработка алгоритма: в «Отключено вручную» только из «Черновик», «Подключено», «На мониторинге»; из него только в «Черновик», «Подключено»; в «Отключено» только при отключении КМ; из «Отключено» только при включении КМ; у метрики («метрика»/«М») со статусом «Отключено вручную» статус при отключении/включении КМ не меняется. (Отключение вычисляемого атрибута карточки мониторинга-10)

### Сценарии
- Критерии приёмки (только положительный сценарий). С редактированием КМ: 1.1 из «Черновик»/«Подключено» в «Отключено вручную» (новая версия КМ или черновик, сохранение); 2.1 из «Отключено вручную» в «Черновик»/«Подключено» (черновик КМ, сохранение); 3.1 «Поставить на мониторинг» — ВА остаётся «Отключено вручную»; 4.1 «Снять с мониторинга» — ВА «Отключено вручную». (Отключение вычисляемого атрибута карточки мониторинга-10)
- Без редактирования КМ: 5.1 КМ «На мониторинге», ВА «На мониторинге»/«Черновик»/«Подключено» → «Отключено вручную»; 6 «Отключено вручную» → «Черновик»/«Подключено»; 7 «Обновить карточку» в разделе списка ВА — статус «Отключено вручную» сохраняется. (Отключение вычисляемого атрибута карточки мониторинга-10)
- Отключение в просмотре: открыть КМ и ВА → статус «Отключено вручную» (из «Черновик», «Подключено», «На мониторинге») → обновить КМ. В редактировании: открыть КМ и ВА → новая версия КМ → «Отключено вручную» (из «Черновик», «Подключено»; в источнике текст обрывается). (Отключение вычисляемого атрибута карточки мониторинга-10)
