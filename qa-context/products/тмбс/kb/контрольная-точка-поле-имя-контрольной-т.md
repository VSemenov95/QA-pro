# Контрольная точка: поле «Имя контрольной точки» (правила и валидация)

> Поле «Имя контрольной точки» в карточке мониторинга — обязательное редактируемое поле ввода с именем по умолчанию «Новая контрольная точка» и проверкой уникальности имени в рамках карточки мониторинга.

### Описание
- Фрагмент описывает поле «Имя контрольной точки» (КТ) в виде таблицы со столбцами: «Наименование поля / элемента», «Формат / тип элемента», «Обязательное поле», «Редактируемое поле», «Правила отображения, валидации», «Сообщения об ошибке». (4-ТМ.06.03.Контрольная точка)

### Поля и элементы
- Наименование поля / элемента: «Имя контрольной точки». (4-ТМ.06.03.Контрольная точка)
- Формат / тип элемента: «Поле ввода». (4-ТМ.06.03.Контрольная точка)
- Обязательное поле: «Да». (4-ТМ.06.03.Контрольная точка)
- Редактируемое поле: «Да». (4-ТМ.06.03.Контрольная точка)

### Бизнес-правила и ограничения
- При создании КТ имя устанавливается по умолчанию как "Новая контрольная точка". После чего пользователь может изменить имя КТ. (4-ТМ.06.03.Контрольная точка)
- Имя КТ не может повторять существующие имена КТ в карточке мониторинга. (4-ТМ.06.03.Контрольная точка)
- Имя КТ должно быть уникальным в рамках карточки мониторинга. (4-ТМ.06.03.Контрольная точка)

### Сообщения и ошибки
- «Контрольная точка с таким именем уже существует в карточке мониторинга» (4-ТМ.06.03.Контрольная точка)
