# Таблица БД связи источников данных и информационных систем (data_source_inf_system)

> Таблица БД data_source_inf_system хранит связи между источниками данных и информационными системами.

### Описание
- Назначение таблицы: устанавливает связь между источниками данных и информационными системами. (data_source_inf_system-2)

### Поля и элементы
- Структура таблицы (поле, тип, описание, ограничения): (data_source_inf_system-2)
  - `id` — SERIAL (INT4) — уникальный идентификатор записи — PK. (data_source_inf_system-2)
  - `data_source_row_id` — INT4 — связь с источником данных — NULLABLE (FK). (data_source_inf_system-2)
  - `inf_system_id` — INT4 — связь с информационной системой — NULLABLE (FK). (data_source_inf_system-2)

### Бизнес-правила и ограничения
- Primary Key (в документе написано «Primery Key»): id. (data_source_inf_system-2)
- Foreign Key: data_source_row_id -> data_source.row_id. (data_source_inf_system-2)

### Расхождения между документами
- Внешний ключ на информационную систему: в разделе «Ключи и индексы» указано поле inf_syste_id -> information_system.id, а в структуре таблицы поле названо inf_system_id. (data_source_inf_system-2)
