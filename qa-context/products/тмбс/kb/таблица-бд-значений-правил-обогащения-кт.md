# Таблица БД значений правил обогащения КТ (enrichment_rule_value)

> Таблица БД enrichment_rule_value хранит значения правил обогащения контрольных точек (КТ) с типом оператора сравнения и связью с правилом обогащения.

### Описание
- Назначение таблицы: «Таблица для хранения правил обогащения в КТ». (enrichment_rule_value-2)
- Документ — описание структуры таблицы БД (файл «enrichment_rule_value-2.pdf», одна страница). Название таблицы в тексте фрагмента явно не указано, оно взято из имени файла. (enrichment_rule_value-2)

### Поля и элементы
- `id` — тип SERIAL(INT4); «Уникальный идентификатор записи»; PK. (enrichment_rule_value-2)
- `enrichment_rule_id` — тип INT4; «Связь с правилом обогащения»; NOT NULL (FK). (enrichment_rule_value-2)
- `value` — тип TEXT; «Значение, используемое в правиле»; NULLABLE. (enrichment_rule_value-2)
- `operator_type` — тип VARCHAR; «Тип оператора для сравнения»; NOT NULL, DEFAULT: EQUALS. (enrichment_rule_value-2)

### Бизнес-правила и ограничения
- Primary Key: `id`. (enrichment_rule_value-2)
- Foreign Key: `enrichment_rule_id` -> `enrichment_rule.id`. (enrichment_rule_value-2)
- `enrichment_rule_id` обязателен (NOT NULL) и ссылается на таблицу `enrichment_rule`. (enrichment_rule_value-2)
- `value` может быть пустым (NULLABLE). (enrichment_rule_value-2)
- `operator_type` обязателен (NOT NULL), значение по умолчанию — EQUALS. (enrichment_rule_value-2)
