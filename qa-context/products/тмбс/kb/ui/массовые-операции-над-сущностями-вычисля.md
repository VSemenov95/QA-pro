# Массовые операции над сущностями (вычисляемыми атрибутами и метриками), созданными из шаблона

> Массовые операции позволяют администратору ТМБС одновременно изменять статус, удалять или обновлять по шаблону вычисляемые атрибуты и метрики, созданные из активного шаблона, для нескольких бизнес-сервисов.

### Описание
- Массовые операции позволяют администратору ТМБС применять изменения к группе вычисляемых атрибутов или метрик, созданных на основе одного шаблона, одновременно для нескольких бизнес-сервисов (карточек мониторинга). (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- Операции выполняются над сущностями, отмеченными галочками на вкладке «Бизнес-сервисы» в карточке шаблона. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- Три типа операций: 1) Изменение статуса – перевод всех выбранных сущностей в указанный статус (если переход соответствует статусной модели); 2) Удаление – удаление выбранных сущностей; 3) Обновление по шаблону – синхронизация сущностей с текущей версией шаблона с заполнением/подтверждением параметров, с флагом «Синхронизировать пороги критичности». (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)

[СА] Сформировать шаблон в ТМБС для стандартных метрик по сущностям ЕМД». (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)

### Экраны и навигация
- Вкладка «Бизнес-сервисы» в карточке шаблона: на ней галочками отмечаются сущности, над которыми выполняется массовая операция. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)

### Бизнес-правила и ограничения
- Операции доступны только для шаблона в статусе «Активный». (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- Изменение статуса выполняется, только если переход соответствует статусной модели. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- Обновление по шаблону требует заполнения/подтверждения параметров и учитывает флаг «Синхронизировать пороги критичности». (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- При успешном выполнении операций (удаление, изменение статуса, обновление) для каждой затронутой карточки в статусе MONITORING необходимо запустить асинхронное обновление; оно выполняется один раз для каждой уникальной карточки, а не для каждой сущности. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- Если для какой-либо сущности операция не удалась (например, статус недопустим, удаление невозможно), она пропускается. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)

### API и интеграции
- Все контракты имеют статус «Новый». (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- ComputedAttributeTemplateController (вычисляемые атрибуты): GET /api/template/{templateId}/linked-computed-attributes – список всех вычисляемых атрибутов, созданных из шаблона, с информацией о бизнес-сервисе и карточке мониторинга, в которых они используются; POST /api/template/{templateId}/computed-attribute/delete – удаляет выч. атрибуты, созданные из шаблона, для указанных бизнес-сервисов (только для шаблона в статусе «Активный»); POST .../computed-attribute/change-status – изменяет статус указанных выч. атрибутов, если это соответствует статусной модели, с учётом возможности применения к черновикам; POST .../computed-attribute/update – обновляет выч. атрибуты по текущей активной версии шаблона, требует заполнения новых параметров (если появились), учитывает флаг «Синхронизировать пороги критичности»; POST .../computed-attribute/get-params – список параметров шаблона и сохранённые значения для указанных выч. атрибутов. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- MetricTemplateController (метрики): GET /api/template/{templateId}/linked-metrics – список всех метрик, созданных из шаблона, с информацией о бизнес-сервисе и карточке мониторинга; POST /api/template/{templateId}/metric/delete – удаляет метрики для указанных бизнес-сервисов (только для шаблона в статусе «Активный»); POST .../metric/change-status – изменяет статус указанных метрик, если это соответствует статусной модели, с учётом возможности применения к черновикам; POST .../metric/update – обновляет метрики по текущей активной версии шаблона, требует заполнения новых параметров, учитывает флаг «Синхронизировать пороги критичности»; POST .../metric/get-params – список параметров шаблона и сохранённые значения для указанных метрик. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)

### Роли и права
- Операции доступны администратору ТМБС. (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
- Для вызова всех перечисленных ручек требуются разрешения на чтение бизнес-сервисов (Бизнес-сервис), удаление/обновление вычисляемых атрибутов (Вычисляемые атрибуты) и метрик (Метрика). (ТМ. [СА] Массовые операции над сущностями, созданными из шаблона-10)
