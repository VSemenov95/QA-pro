# Таблица БД атрибутов вычисляемых атрибутов бизнес-сервиса (bs_{$bs}_attribute_old_distributed)

> Таблица ClickHouse (Distributed) с результатами расчёта вычисляемых атрибутов бизнес-сервисов, настраиваемых пользователем, хранящая вычисления до реализации фичи PPMON-1382.

### Описание
- В таблице представлены результаты расчёта вычисляемых атрибутов бизнес-сервисов, которые пользователь может настроить в интерфейсе. (6-bs_{$bs}_attribute_old_distributed)
- В таблице хранятся вычисления атрибутов до реализации фичи PPMON-1382 ПП. ТМБС. Передача метрик из ТМБС в ЗСМ в привязке к сервисам с агрегирующим расчетом на стороне ТМБС. (6-bs_{$bs}_attribute_old_distributed)
- Оглавление документа: Описание, Колонки, DDL, Примечание. Раздел «Примечание» пустой. (6-bs_{$bs}_attribute_old_distributed)

### Поля и элементы
Колонки (имя · тип · описание):
- transaction_type · String · ID БС (6-bs_{$bs}_attribute_old_distributed)
- transaction_time · DateTime64(3, 'Europe/Moscow') · Время транзакции (6-bs_{$bs}_attribute_old_distributed)
- transaction_uuid · UUID · uuid транзакции (6-bs_{$bs}_attribute_old_distributed)
- transaction_attribute_value · Int32 · Вычисляемое значение атрибута (6-bs_{$bs}_attribute_old_distributed)
- attribute_id · UInt32 · ID атрибута (6-bs_{$bs}_attribute_old_distributed)
- attribute_name · String · Наименование атрибута (6-bs_{$bs}_attribute_old_distributed)
- attribute_status · String · Статус атрибута (6-bs_{$bs}_attribute_old_distributed)
- attribute_threshold_type · String · Значение threshold согласно настроенным интервалам (6-bs_{$bs}_attribute_old_distributed)
- unit · String · Единица измерения значения (6-bs_{$bs}_attribute_old_distributed)
- transaction_events_count · UInt16 · Количество событий транзакции, на которых расчитан атрибут (6-bs_{$bs}_attribute_old_distributed)
- valid · Bool · Признак валидности записи (6-bs_{$bs}_attribute_old_distributed)
- replacing_version · UInt16 · описание в документе не указано (6-bs_{$bs}_attribute_old_distributed)
- partial · Bool · true, если часть ключей событий транзакции невалидны, т.е. не участвовали в склейке (6-bs_{$bs}_attribute_old_distributed)
- user_transaction_time · Nullable(DateTime64(3, 'Europe/Moscow')) · время транзакции, вычисление которого настраивается пользователем (6-bs_{$bs}_attribute_old_distributed)
- insert_timestamp · DateTime64(3, 'Europe/Moscow') · Время записи вычисления в ClickHouse (6-bs_{$bs}_attribute_old_distributed)
- <tech_attr> · Array · Дополнительный тех. атрибут, выбранный пользователем для переноса данных событий в таблицу атрибутов (6-bs_{$bs}_attribute_old_distributed)

### Бизнес-правила и ограничения
- Значения по умолчанию из DDL: valid DEFAULT toUInt8(1); partial DEFAULT toUInt8(0); user_transaction_time DEFAULT NULL; replacing_version DEFAULT if(toUInt8(valid), transaction_events_count, toUInt16(65535)). (6-bs_{$bs}_attribute_old_distributed)
- event_stage, action, event_id_group_1, current_time_fl, event_time, not_existing_fl: Array(String) DEFAULT []. В примере DDL они соответствуют дополнительным тех. атрибутам <tech_attr>. (6-bs_{$bs}_attribute_old_distributed)

### API и интеграции
- DDL (пример для БС 6606): `default`.bs_6606_attribute_distributed; CREATE TABLE default.bs_6606_attribute_distributed со всеми перечисленными колонками (типы и DEFAULT как выше; массивные колонки event_stage, action, event_id_group_1, current_time_fl, event_time, not_existing_fl — Array(String) DEFAULT []). (6-bs_{$bs}_attribute_old_distributed)
- Движок: Distributed('cl1', 'default', 'bs_6606_attribute', reinterpretAsUInt64(transaction_uuid)) — кластер 'cl1', БД 'default', базовая таблица 'bs_6606_attribute', ключ шардирования reinterpretAsUInt64(transaction_uuid). (6-bs_{$bs}_attribute_old_distributed)

### Открытые вопросы
- В DDL пример приведён под именем bs_6606_attribute_distributed, а не bs_{$bs}_attribute_old_distributed. (6-bs_{$bs}_attribute_old_distributed)
- Описание колонки replacing_version в документе не указано. (6-bs_{$bs}_attribute_old_distributed)
- Раздел «Примечание» не содержит текста. (6-bs_{$bs}_attribute_old_distributed)
