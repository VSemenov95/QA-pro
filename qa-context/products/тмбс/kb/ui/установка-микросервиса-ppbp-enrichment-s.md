# Установка микросервиса ppbp-enrichment-service

> Установка микросервиса ppbp-enrichment-service: требования к SSL-хранилищам Kafka и таблица его переменных окружения (№ 1–29) с умолчаниями, примерами и обязательностью.

### Описание
- В контейнер необходимо добавить keystore и truststore с ключами для доступа к Kafka, если она работает через SSL. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Необходимо учесть переменные среды из Таблицы 4.2.7-1 «Данные переменных окружения ppbp-enrichment-service» (раздел 4.2.7). В одном из фрагментов таблица доведена до п. 26, строки 27–29 приведены отдельно. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- TM_ENRICHMENT_UNDEFINED_TOPIC_ENABLE = true: сообщение передается в undefined topic как единое целое. Принадлежность сообщения к Бизнес-сервису реализуется на merging-service по правилам селективности. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_ENRICHMENT_UNDEFINED_TOPIC_ENABLE = false: сообщение тиражируется для каждого Бизнес-сервиса и передается независимо. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
