# Карточка мониторинга: статусная модель и переходы между статусами

> Статусная модель карточки мониторинга ТМБС: шесть статусов и допустимые переходы между ними в разрезе одной версии карточки и в разрезе всей карточки.

### Описание
- Документ описывает статусную модель карточки мониторинга и переходы между статусами. (4-Карточка мониторинга 04.08.2026)
- Детализация приведена в двух разрезах: в рамках одной версии карточки мониторинга и в рамках всей карточки мониторинга. (4-Карточка мониторинга 04.08.2026)
- Различие разрезов: в разрезе всей карточки добавлены переходы в статус «Черновик» из статусов «На мониторинге», «Ошибка постановки» и «Отключено» с комментарием «Новая версия карточки в черновике». (4-Карточка мониторинга 04.08.2026)

### Поля и элементы
- Статусы карточки (код — название): DRAFT — «Черновик»; MONITORING — «На мониторинге»; DISCONNECTED — «Отключено»; ARCHIVE — «В архиве»; STAGING — «Постановка»; STAGING_ERROR — «Ошибка постановки». (4-Карточка мониторинга 04.08.2026)

### Бизнес-правила и ограничения
- Переходы в рамках одной версии карточки (текущий статус → целевой: комментарий): (4-Карточка мониторинга 04.08.2026)
  - (начальный, «-») → Черновик: Пользователь создает карточку мониторинга
  - Черновик → Постановка: Пользователь ставит карточку на мониторинг
  - Постановка → На мониторинге: Карточка успешно прошла постановку на мониторинг
  - Постановка → Ошибка постановки: Произошла ошибка при постановке карточки на мониторинг. Карточка частично находится на мониторинге
  - На мониторинге → Отключено: Пользователь снял карточку с мониторинга
  - На мониторинге → В архиве: Текущая версия карточки перестала быть актуальной
  - На мониторинге → Постановка: Пользователь обновил карточку и ставит её на мониторинг
  - Ошибка постановки → Постановка: Пользователь ставит карточку на мониторинг
  - Ошибка постановки → Отключено: Пользователь снял карточку с мониторинга
  - Ошибка постановки → В архиве: Текущая версия карточки перестала быть актуальной
  - Отключено → Постановка: Пользователь ставит карточку на мониторинг
  - Отключено → В архиве: Текущая версия карточки перестала быть актуальной
  - В архиве → (переходов нет, «-»): Неактуальная версия карточки
- Переходы в рамках всей карточки: все переходы разреза одной версии, плюс: (4-Карточка мониторинга 04.08.2026)
  - На мониторинге → Черновик: Новая версия карточки в черновике
  - Ошибка постановки → Черновик: Новая версия карточки в черновике
  - Отключено → Черновик: Новая версия карточки в черновике

### Сценарии
- Создание и постановка: создание (Черновик) → Постановка → На мониторинге или Ошибка постановки. (4-Карточка мониторинга 04.08.2026)
- Снятие с мониторинга пользователем: На мониторинге / Ошибка постановки → Отключено. (4-Карточка мониторинга 04.08.2026)
- Обновление: из «На мониторинге» пользователь обновляет карточку и ставит её на мониторинг (→ Постановка); в разрезе всей карточки при этом появляется новая версия в статусе «Черновик». (4-Карточка мониторинга 04.08.2026)
- Устаревание версии: «На мониторинге», «Ошибка постановки», «Отключено» → «В архиве», когда текущая версия карточки перестала быть актуальной. (4-Карточка мониторинга 04.08.2026)
