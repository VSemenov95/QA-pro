# Таблица БД Сервисов (название таблицы в документе не указано; файл service-6)

> Таблица БД для хранения списка Сервисов: структура полей, типы данных, ограничения, значения по умолчанию и первичный ключ.

### Описание
- Назначение таблицы: «Таблица предназначена для хранения списка Сервисов». (service-6)
- Название таблицы в документе не указано (файл service-6.pdf). (service-6)

### Поля и элементы
Структура: поле — тип; описание; значение по умолчанию; ограничения.
- id — SERIAL (INT4); уникальный идентификатор записи; ограничение: PK. (service-6)
- external_id — TEXT; внешний идентификатор сервиса (например, код из внешней системы); NOT NULL. (service-6)
- name — TEXT; название сервиса; NOT NULL. (service-6)
- code — TEXT; уникальный код сервиса; NOT NULL. (service-6)
- type — TEXT; тип сервиса; по умолчанию SERVICE; NOT NULL. (service-6)
- status — ENUM; статус сервиса; NOT NULL; доступные для обработки значения: IN_WORK, ARCHIVE. (service-6)
- criticality — TEXT; критичность сервиса; NULLABLE. (service-6)
- stream — TEXT; стрим-владелец Сервиса; NULLABLE. (service-6)
- description — TEXT; описание Сервиса; NULLABLE. (service-6)
- create_date — TIMESTAMPTZ; дата и время создания Сервиса; NULLABLE. (service-6)
- modify_date — TIMESTAMPTZ; дата и время последнего изменения; NULLABLE. (service-6)
- version — INT4; версия записи (для контроля изменений); по умолчанию 1; NOT NULL. (service-6)
- version_string — TEXT; семантическая версия сервиса; по умолчанию 1.0; NOT NULL. (service-6)

### Бизнес-правила и ограничения
- Допустимые значения status для обработки: IN_WORK, ARCHIVE. (service-6)
- Значения по умолчанию: type — SERVICE; version — 1; version_string — 1.0. (service-6)
- Поля criticality, stream, description, create_date, modify_date допускают NULL. (service-6)
- Поля external_id, name, code, type, status, version, version_string — NOT NULL. (service-6)
- Primary Key: id (автоинкремент). (service-6)
