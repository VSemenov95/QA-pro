# Добавление всех технических атрибутов источника в контрольную точку

> Кнопка в контрольной точке карточки мониторинга, по которой одним действием добавляются все технические атрибуты из подключённого источника данных, при этом бизнес-наименование копируется из технического атрибута.

### Описание
- Задача PPBP-892 «Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных»; версия 1 документа от 02.04.2025, автор Лазарев Никита. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Пользовательская история: «Я как Пользователь системы» хочу «Иметь возможность разом добавлять технические атрибуты, заведенные в источнике, в контррольную точку», для того чтобы «Не заводить все по одному». (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Контекст: количество атрибутов для добавления в контрольную точку может быть достаточно большим, поэтому нужна кнопка, по нажатию на которую все заведённые в источнике данных атрибуты добавляются в атрибуты контрольной точки. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Бизнес-требования: 1) по нажатию на кнопку разом добавить в КТ все технические атрибуты, заведённые в источнике (в КТ должен быть подключён источник данных); 2) ТА добавляются из подключённой на данный момент версии источника; 3) при добавлении ТА через кнопку «Добавить все атрибуты источника» значение бизнес-атрибута должно копировать наименование технического атрибута. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)

### Поля и элементы
- «Добавить» — раскрывающийся список. Активно в режиме редактирования, в режиме просмотра задизейблено. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- «Добавить -> Атрибут» — кликабельный вариант, строка. Доступно в режиме редактирования. По нажатию добавляется пустая строка для заполнения. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- «Добавить -> Все атрибуты из источника» — кликабельный вариант, строка. Доступно в режиме редактирования. По нажатию появляется модальное окно с предупреждением о добавлении всех атрибутов источника; в случае подтверждения все атрибуты источника данных добавляются в КТ. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- «Удалить» — кнопка. Доступна в режиме редактирования, если отмечен хотя бы один технический атрибут. По нажатию появляется модальное окно с предупреждением об удалении атрибутов; в случае подтверждения удаляет атрибут(ы). (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Чекбокс — доступно для выделения в режиме редактирования; выделяет атрибут для последующего удаления. Чекбокс в «шапке» выделяет все добавленные атрибуты. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- «Описание» — поле для ввода (свободное). Обязательное: Нет. Редактируемое: Да. Доступно для ввода в режиме редактирования. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)

### Бизнес-правила и ограничения
- Источник данных должен быть подключён в КТ. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Атрибуты добавляются из подключённой на данный момент версии источника. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Если в КТ уже были заведены тех. атрибуты и их бизнес-наименование: добавляются все атрибуты источника, отсутствующие в КТ; бизнес-наименование добавленных соответствует значению «Технического атрибута»; ранее добавленные остаются с бизнес-наименованием, введённым пользователем. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Критерии приёмки описывают только положительный сценарий. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)

### Роли и права
- Новые разрешения не требуются. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)

### Сценарии
- Критерий 1. ЕСЛИ пользователь создаёт/редактирует карточку мониторинга и находится внутри КТ, КОГДА нажимает «Добавить» -> «Все атрибуты источника», ТОГДА появляется модальное окно (Форма 2.1) с вариантами «Добавить» и «Отменить». (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Критерий 2. ЕСЛИ выполнен критерий 1, КОГДА нажимает «Отменить», ТОГДА возвращается в КТ в режиме редактирования, изменений не происходит. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
- Критерий 3. ЕСЛИ выполнен критерий 1, КОГДА нажимает «Добавить», ТОГДА добавляются все атрибуты источника, отсутствующие в КТ; бизнес-наименование добавленных соответствует значению «Технического атрибута»; ранее добавленные остаются с бизнес-наименованием, введённым пользователем. (Заведение бизнес-атрибутов в контрольной точке по техническим атрибутам из источника данных-8)
