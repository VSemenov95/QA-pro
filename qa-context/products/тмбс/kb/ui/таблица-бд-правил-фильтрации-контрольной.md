# Таблица БД правил фильтрации контрольной точки (group_rule)

> Таблица БД group_rule хранит правила фильтрации сообщений для контрольной точки, которые применяются при обработке на enrichment'е.

### Описание
- Таблица с правилами обработки на enrichment`e. (3-(R) group_rule)
- Правила фильтрации (принадлежит) сообщений для контрольной точки. Сами правила. (3-(R) group_rule)
- Название таблицы в тексте фрагмента не указано; название документа: «3-(R) group_rule.pdf». (3-(R) group_rule)

### Поля и элементы
Структура таблицы (поле — тип — описание — ограничения):
- checkpoint_group_id — int(4) — Идентификатор группы правил. Значение по умолчанию и ограничения не указаны. (3-(R) group_rule)
- id — serial4 — Идентификатор правила. Ограничения: PK, NOT_NULL. (3-(R) group_rule)
- order_value — int(4) — Порядок отображения в интерфейсе. Ограничения: NOT_NULL. (3-(R) group_rule)
- technical_attribute_id — int(4) — Идентификатор тех атрибута к которому определяется правило. Ограничения: NOT_NULL. (3-(R) group_rule)
- operator_code — varchar(255) — Оператор/предикат. Ограничения: NOT_NULL. (3-(R) group_rule)
- parameters — text — Парметры правила/предиката. Ограничения: NOT_NULL. (3-(R) group_rule)
- Значения по умолчанию для полей не указаны. (3-(R) group_rule)

### Бизнес-правила и ограничения
- Primery Key: id (автоинкремент). (3-(R) group_rule)
- Foreign Key: checkpoint_group_id -> checkpoint_group.id. (3-(R) group_rule)
- Foreign Key: technical_attribute_id -> technical_attribute.id. (3-(R) group_rule)
