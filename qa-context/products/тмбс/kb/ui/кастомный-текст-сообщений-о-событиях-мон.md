# Кастомный текст сообщений о событиях мониторинга

> Пользовательская история (черновик, версия 1) о возможности для Администратора задавать кастомный текст автоматических сообщений о событиях мониторинга с подстановкой названия бизнес-сервиса, метрики и полей транзакции.

### Описание
- Пользовательская история: «Я как Администратор. Хочу Задать кастомный текст сообщения о событии мониторинга. Для того, чтобы Получить сообщение о событии мониторинга, учитывающее особенности конкретного бизнес-сервиса». ([US] Кастомный текст в событиях мониторинга-7)
- Контекст: в продукте реализован функционал отправки автоматических сообщений о событиях мониторинга, которые не предполагают возможность настройки или кастомизации текста сообщения. ([US] Кастомный текст в событиях мониторинга-7)
- Получатели уведомлений видят сообщение, которое не всегда содержит всю необходимую информацию о транзакции. Получателями являются в том числе пользователи, которые не имеют доступ к дашбордам мониторинга бизнес-сервиса. ([US] Кастомный текст в событиях мониторинга-7)
- Необходимо разработать новый функционал, позволяющий пользователям настраивать текст сообщения о событиях мониторинга в соответствии с бизнес-потребностями. ([US] Кастомный текст в событиях мониторинга-7)

### Бизнес-правила и ограничения
- БТ 1: пользователь должен иметь возможность добавить в текст сообщения произвольный текст. ([US] Кастомный текст в событиях мониторинга-7)
- БТ 2: пользователь должен иметь возможность добавить в текст сообщения название бизнес-сервиса и название метрики; они должны подставляться автоматически. ([US] Кастомный текст в событиях мониторинга-7)
- БТ 3: пользователь должен иметь возможность добавить в текст необходимые поля транзакции, значения которых будут отображаться в сообщении. Состав полей транзакции уникален для каждого бизнес-сервиса; текст сообщения с деталями транзакции необходим в том числе пользователям, не имеющим доступ к дашбордам мониторинга бизнес-сервиса. ([US] Кастомный текст в событиях мониторинга-7)
- БТ 4: получатель сообщения должен увидеть детали транзакции в виде, доступном для бизнес-пользователя; в тексте должны использоваться бизнес-термины. Комментарий: «Задать alias для названия поля». ([US] Кастомный текст в событиях мониторинга-7)
- БТ 5: пользовательские сообщения должны сохраняться в системе и быть доступны для просмотра и редактирования после их создания. ([US] Кастомный текст в событиях мониторинга-7)
