# Таблица БД интервалов вычисляемых атрибутов (general_computed_attribute_interval)

> Таблица БД general_computed_attribute_interval хранит интервалы значений (с типом критичности) для вычисляемых атрибутов и связана с таблицей computed_attribute.

### Описание
- Назначение таблицы: «Хранит интервалы значений для вычисляемых атрибутов». (4-general_computed_attribute_interval)

### Поля и элементы
Структура таблицы (поле — тип данных — описание — ограничения):
- `id` — SERIAL (INT4) — Уникальный идентификатор записи — PK. (4-general_computed_attribute_interval)
- `type` — ENUM — Тип (критичность) — NOT NULL. Допустимые значения: NORMAL, WARNING, CRITICAL. (4-general_computed_attribute_interval)
- `active` — BOOLEAN — Признак активности — NULLABLE. (4-general_computed_attribute_interval)
- `min_value` — INT8 — Минимальное значение интервала — NULLABLE. (4-general_computed_attribute_interval)
- `max_value` — INT8 — Максимальное значение интервала — NULLABLE. (4-general_computed_attribute_interval)
- `computed_attribute_id` — INT4 — Связь с выч.атрибутом — NOT NULL (FK). (4-general_computed_attribute_interval)
- `send_deviation` — BOOLEAN — Признак отправки отклонений по порогу критичности — NULLABLE. (4-general_computed_attribute_interval)

### Бизнес-правила и ограничения
- Ключи и индексы: Primery Key: id; Foreign Key: computed_attribute_id -> computed_attribute.id. (4-general_computed_attribute_interval)
- Поля `type` и `computed_attribute_id` обязательны (NOT NULL). (4-general_computed_attribute_interval)
- Поля `active`, `min_value`, `max_value`, `send_deviation` допускают NULL. (4-general_computed_attribute_interval)
