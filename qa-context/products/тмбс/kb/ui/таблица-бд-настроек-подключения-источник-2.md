# Таблица БД настроек подключения источников к коннектору Астром (data_source_connector_kafka)

> Таблица БД data_source_connector_kafka хранит настройки подключения источников данных к коннектору Астром (адрес брокера, топик, group_id и параметры опроса Kafka).

### Описание
- Назначение таблицы: «Хранит настройки подключения источников к коннектору Астром». (2-data_source_connector_kafka)
- Название таблицы в тексте фрагмента явно не указано; имя файла документа: 2-data_source_connector_kafka.pdf. (2-data_source_connector_kafka)

### Поля и элементы
Структура (поле · тип · описание · ограничения):
- id · SERIAL (INT4) · Уникальный идентификатор записи · PK (2-data_source_connector_kafka)
- data_source_row_id · INT4 · Связь с источником данных · NOT NULL (FK) (2-data_source_connector_kafka)
- bootstrap_adress · TEXT · Адрес брокера · NULLABLE (2-data_source_connector_kafka)
- input_topic · TEXT · Название выходного топика kafka · NULLABLE (2-data_source_connector_kafka)
- max_poll_records · INT4 · Максимальное количество записей для хранения · NULLABLE, DEFAULT: 500 (2-data_source_connector_kafka)
- description · TEXT · Описание подключения · NULLABLE (2-data_source_connector_kafka)
- group_id · VARCHAR · описание в документе: «??» · NULLABLE, DEFAULT: trmonbs (2-data_source_connector_kafka)

### Бизнес-правила и ограничения
- Primary Key: id. (2-data_source_connector_kafka)
- Foreign Key: data_source_row_id -> data_source.row_id. (2-data_source_connector_kafka)
- data_source_row_id обязателен (NOT NULL). (2-data_source_connector_kafka)
- Значение по умолчанию max_poll_records: 500. (2-data_source_connector_kafka)
- Значение по умолчанию group_id: trmonbs. (2-data_source_connector_kafka)
