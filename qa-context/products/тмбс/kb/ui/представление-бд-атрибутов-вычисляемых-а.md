# Представление БД атрибутов вычисляемых атрибутов бизнес-сервиса (bs_{$bs}_attribute_distributed, view)

> Виртуальное представление ClickHouse bs_{$bs}_attribute_distributed, которое собирает результаты расчёта вычисляемых атрибутов бизнес-сервиса из таблиц bs_{$bs}_attribute_old_distributed и bs_{$bs}_attribute_table_distributed.

### Описание
- Виртуальное представление (view), которое собирает результаты расчёта вычисляемых атрибутов бизнес-сервисов из таблиц bs_{$bs}_attribute_old_distributed и bs_{$bs}_attribute_table_distributed. (bs_{$bs}_attribute_distributed (view)-2)
- Разделы документа: Описание, Колонки, DDL, Примечание. Разделы «DDL» и «Примечание» в представленном фрагменте не содержат текста (в «Примечание» указана только цифра «1»). (bs_{$bs}_attribute_distributed (view)-2)

### Поля и элементы
Колонки представления (имя · тип · описание):
- transaction_type · String · ID БС (bs_{$bs}_attribute_distributed (view)-2)
- transaction_time · DateTime64(3, 'Europe/Moscow') · Время транзакции (bs_{$bs}_attribute_distributed (view)-2)
- transaction_uuid · UUID · uuid транзакции (bs_{$bs}_attribute_distributed (view)-2)
- transaction_attribute_value · Int32 · Вычисляемое значение атрибута (bs_{$bs}_attribute_distributed (view)-2)
- attribute_id · UInt32 · ID атрибута (bs_{$bs}_attribute_distributed (view)-2)
- attribute_name · String · Наименование атрибута (bs_{$bs}_attribute_distributed (view)-2)
- attribute_status · String · Статус атрибута (bs_{$bs}_attribute_distributed (view)-2)
- attribute_threshold_type · String · Значение threshold согласно настроенным интервалам (bs_{$bs}_attribute_distributed (view)-2)
- unit · String · Единица измерения значения (bs_{$bs}_attribute_distributed (view)-2)
- transaction_events_count · UInt16 · Количество событий транзакции, на которых расчитан атрибут (bs_{$bs}_attribute_distributed (view)-2)
- valid · Bool · Признак валидности записи (bs_{$bs}_attribute_distributed (view)-2)
- replacing_version · UInt16 · описание не указано (bs_{$bs}_attribute_distributed (view)-2)
- partial · Bool · true, если часть ключей событий транзакции невалидны, т.е. не участвовали в склейке (bs_{$bs}_attribute_distributed (view)-2)
- user_transaction_time · Nullable(DateTime64(3, 'Europe/Moscow')) · время транзакции, вычисление которого настраивается пользователем (bs_{$bs}_attribute_distributed (view)-2)
- insert_timestamp · DateTime64(3, 'Europe/Moscow') · Время записи вычисления в ClickHouse (bs_{$bs}_attribute_distributed (view)-2)
- service_id · int4 · Идентификатор Сервиса (bs_{$bs}_attribute_distributed (view)-2)
- <tech_attr> · Array · Дополнительный тех. атрибут, выбранный пользователем для переноса данных событий в таблицу атрибутов (bs_{$bs}_attribute_distributed (view)-2)

### Бизнес-правила и ограничения
- Колонка <tech_attr> соответствует дополнительному техническому атрибуту, который пользователь выбрал для переноса данных событий в таблицу атрибутов. (bs_{$bs}_attribute_distributed (view)-2)
- Колонка user_transaction_time допускает значение NULL (Nullable). (bs_{$bs}_attribute_distributed (view)-2)

### Открытые вопросы
- Описание колонки replacing_version в документе не указано. (bs_{$bs}_attribute_distributed (view)-2)
- Содержимое раздела «DDL» в документе отсутствует. (bs_{$bs}_attribute_distributed (view)-2)
- Раздел «Примечание» содержит только значение «1», пояснений нет. (bs_{$bs}_attribute_distributed (view)-2)
