# Установка микросервиса ppbp-metrics-threshold-service

> Описание установки микросервиса ppbp-metrics-threshold-service (расчёт пороговых метрик): требования к keystore/truststore для Kafka по SSL и таблица переменных окружения 4.2.12-1.

### Описание
- Если Kafka работает через SSL, в контейнер нужно добавить keystore и truststore с ключами для доступа к Kafka. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- При установке учитываются переменные среды из таблицы 4.2.12-1 «Данные переменных окружения ppbp-metrics-threshold-service». Формат: № ИМЯ — описание; по умолчанию; пример; обязательность. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Keystore и truststore нужны, если Kafka работает через SSL. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Обязательные (Да): KAFKA_BOOTSTRAP_SERVERS, KEYSTORE_LOCATION, KEYSTORE_PASSWORD, TRUSTSTORE_LOCATION, TRUSTSTORE_PASSWORD, LOGGING_HOST, APPLICATION_NAME, DATASOURCE_SCHEMA, RDBMS_DATASOURCE_URL, RDBMS_DATASOURCE_USERNAME, RDBMS_DATASOURCE_PASSWORD, TM_CLICKHOUSE_NODEADDRESSES, TM_METRICS_ESM_TOPIC_NAME, TM_TABLE_NAME_TEMPLATE_WITH_LAST_UPDATE_TIMESTAMP. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Открытые вопросы
- В таблице примеры для RDBMS_DATASOURCE_URL/USERNAME/PASSWORD сдвинуты («так в документе»): у URL указан pg_pass, у USERNAME — jdbc:postgresql://localhost:5432/mydb, у PASSWORD — pg_user. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Имя TM_TASKS_STARTER_ENABLED повторяется в строках 33 и 42 с разным описанием. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Для TM_REDIS_PASSWORD в документе указан секретоподобный пароль по умолчанию; для TM_CRON_TIMEZONE описание названо «частотой запуска», хотя это часовой пояс; для TM_CLICKHOUSE_MAXCONNECTIONS обязательность не указана. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
