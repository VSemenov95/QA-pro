# Ссылка на дашборд из карточки мониторинга

> Возможность добавить в карточке мониторинга (КМ) необязательную ссылку на дашборд Grafana и переходить по ней из режима просмотра КМ и из списка карточек мониторинга.

### Бизнес-правила и ограничения
- Поле опциональное; если ссылка не указана, в режиме просмотра и в списке элемент отсутствует. (15-[US] Ссылка на дашборд из карточки мониторинга)
- Если в предыдущей версии ссылки не было, а добавлена в новую версию в статусе «Черновик», в режиме просмотра она отображается только после постановки новой версии на мониторинг (существующий паттерн). (15-[US] Ссылка на дашборд из карточки мониторинга)
- Ссылку видят только пользователи с разрешением на просмотр карточки соответствующего бизнес-сервиса. (15-[US] Ссылка на дашборд из карточки мониторинга)
- В списке ссылка выводится для каждой карточки с указанной ссылкой в поставленной на мониторинг версии. В режиме просмотра ссылка не редактируется: «Редактировать» и иконка удаления отсутствуют. (15-[US] Ссылка на дашборд из карточки мониторинга)
- Критерии приёмки описывают только положительный сценарий. (15-[US] Ссылка на дашборд из карточки мониторинга)
