# Обработка и связка транзакций событий бизнес-сервисов

> Группа функций продукта «ТМБС», которая относит события к бизнес-сервисам, выявляет идентификаторы и цепочки событий, присваивает им сквозной идентификатор транзакции и уведомляет пользователя о событиях, которые связать нельзя.

### Описание
- Группа функций «Обработка и связка транзакций событий бизнес-сервисов». (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- Продукт может присваивать сквозной идентификатор группе событий, образующих транзакцию. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- 3.1 Обработка событий продукта, входящих в БС, для отнесения событий к конкретным БС для дальнейшей обработки согласно заданной пользователем конфигурации. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- 3.2 Выявление идентификаторов событий, согласно заданной пользователем конфигурации. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- 3.3 Выявление цепочки событий исходя из выявленных идентификаторов событий. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- 3.4 Связка событий в цепочку и присвоение событиям сквозной идентификатор транзакции. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- 3.5 Обнаружение несвязанных событий, событий, которым невозможно присвоить сквозной идентификатор. Обнаружение элементов несвязанной цепочки событий. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- 3.6 Уведомление пользователя о событиях, которые невозможно связать в цепочку, присвоить сквозной идентификатор. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
