# Установка микросервиса ppbp-event-collector-kafka

> Установка микросервиса ppbp-event-collector-kafka: требования к SSL-хранилищам Kafka в контейнере и перечень переменных окружения (Таблица 4.2.5-1) для подключения к Kafka, логирования и тонкой настройки consumer/producer.

### Описание
- В контейнер необходимо добавить keystore и truststore с ключами для доступа к Kafka, если она работает через SSL. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Необходимо учесть переменные среды из Таблицы 4.2.5-1 «Данные переменных окружения ppbp-event-collector-kafka» (колонки: №, Переменная окружения, Описание, Значение по умолчанию, Пример, Обязательность). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Поля и элементы
Формат: «№ ИМЯ — описание; по умолчанию; пример; обязательность».
- 1 JAVA_OPTS — параметры запуска JVM, включая настройки SSL-хранилищ; Xmx1024m; -Djavax.net.ssl.trustStorePassword=$(TRUSTSTORE_PASSWORD) -Djavax.net.ssl.trustStore=/opt/keystores/truststore.p12; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 2 KAFKA_BOOTSTRAP_SERVERS — адрес сервера Kafka; localhost:9092; (10.***.64.21:30195,10.***.64.26:30195,10.***.64.27:30195); Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 3 KEYSTORE_LOCATION — путь к файлу хранилища ключей keystore; null; /opt/keystores/keystore.p12; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 4 KEYSTORE_PASSWORD — пароль к файлу keystore; null; secret(certificate-pkcs12-password)[password] visibility; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 5 TRUSTSTORE_LOCATION — путь к файлу хранилища ключей truststore; null; /opt/keystores/truststore.p12; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 6 TRUSTSTORE_PASSWORD — пароль к файлу truststore; null; secret(certificate-pkcs12-password)[password]; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 7 LOGGING_CONFIG — путь к файлу с конфигурацией логирования; classpath:log4j2-kubernetes.xml; classpath:log4j2-local.xml; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 8 LOGGING_LEVEL_ROOT — уровень логирования; info; debug; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 9 LOGGING_HOST — адрес fluent-bit (агент для сбора и маршрутизации логов), на который отправляются логи, в случае использования встроенного log4j2-kubernetes.xml; null; 127.0.0.1; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 10 SERVER_PORT — HTTP-порт приложения; 8000; 8080; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 11 SPRING_CLOUD_STREAM_KAFKA_BINDER_CONFIGURATION_SECURITY_PROTOCOL — протокол безопасности для Kafka биндера; SSL; PLAINTEXT; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 12 TM_KAFKA_SSL_ENABLED — флаг включения SSL для Kafka; true; false; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 13 TM_KAFKA_FETCHMINBYTES — минимальный объём данных, который сервер должен вернуть в запросе fetch; если данных недостаточно, запрос ждёт накопления указанного количества; увеличение значения может повысить пропускную способность сервера за счёт небольшого увеличения задержки; в kafka-client "fetch.min.bytes"; null; 256000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 14 TM_KAFKA_MAXPOLLRECORDS — максимальное количество записей, возвращаемых за один вызов poll(); не влияет на внутреннее поведение получения данных — консьюмер кэширует записи из каждого fetch-запроса и отдаёт их порциями; в kafka-client "max.poll.records"; null; 5000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 15 TM_KAFKA_MAXPOLLINTERVALMS — максимальный интервал между вызовами poll() при управлении группой потребителей; при превышении консьюмер считается неработоспособным и исключается из группы; в kafka-client "max.poll.interval.ms"; null; 20000000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 16 TM_KAFKA_BATCHSIZE — размер пакета (в байтах) для отправки сообщений в Kafka; null; 256000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 17 TM_KAFKA_FETCHMAXWAITMS — максимальное время ожидания сервера перед ответом на fetch, если данных недостаточно для `fetch.min.bytes`; только для локальных fetch-запросов, для удалённых используйте `remote.fetch.max.wait.ms` на брокере; в kafka-client "fetch.max.wait.ms"; null; 20000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 18 TM_KAFKA_FETCHMAXBYTES — максимальный объём данных в одном fetch; если первый пакет в первой непустой партиции превышает лимит, он всё равно возвращается; не абсолютный максимум — размер пакета определяется брокером через `message.max.bytes` или топиком через `max.message.bytes`; в kafka-client "fetch.max.bytes"; null; 52428800; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 19 TM_KAFKA_MAXPARTITIONFETCHBYTES — максимальный размер данных из одной партиции за запрос (в байтах); записи извлекаются пакетами; если первый пакет в первой непустой партиции превышает лимит, он всё равно возвращается; максимальный размер пакета определяется брокером через `message.max.bytes` или `max.message.bytes`; null; 20000000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 20 TM_KAFKA_LINGERMS — время ожидания перед отправкой пакета для накопления сообщений (мс); null; 15000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 21 TM_KAFKA_LISTENER_FORMAT — формат сериализации данных для слушателя (consumer); JSON; AVRO; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 22 TM_KAFKA_TOMSSENDER_FORMAT — формат сериализации данных для отправителя (producer); JSON; AVRO; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 23 TM_KAFKA_PRODUCER_COMPRESSIONTYPE — тип сжатия данных для отправителя (producer); null; lz5; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 24 TM_KAFKA_GROUPID — идентификатор kafka consumer группы; trmonbs-collector-service; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Открытые вопросы
- В строке 24 (TM_KAFKA_GROUPID) в выдержке указано только одно значение (trmonbs-collector-service) без явного разделения на «по умолчанию» и «пример». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
