# Таблица БД связи конфигураций с Сфера.Конфигурации (название таблицы в документе не указано)

> Описание структуры двух таблиц БД интеграции со Сфера.Конфигурации: таблицы связи конфигураций (документ 3) и таблицы конфигураций (документ 4), названия обеих таблиц в документах не указаны.

### Описание
- Назначение таблицы связи: «Таблица связи конфигураций с Сфера.Конфигурации». Название самой таблицы в документе не указано. (3-configuration_integration_link)
- Назначение таблицы конфигураций: «Таблица конфигураций со Сфера.Конфигурации». Название самой таблицы в документе не указано. (4-configuration_integration_is)

### Поля и элементы
Таблица связи конфигураций (3-configuration_integration_link):
- id — serial4 — «Идентификатор записи» — PK, NOT_NULL. (3-configuration_integration_link)
- number — text — «Идентификатор отображения на UI». (3-configuration_integration_link)
- name — text — «Наименование конфигурации связи». (3-configuration_integration_link)
- ci1 — text — «Связь с сервисом 1». (3-configuration_integration_link)
- ci2 — text — «Связь с сервисом 2». (3-configuration_integration_link)
- external_id — text — «Идентификатор цепочки сервисов». (3-configuration_integration_link)
- create_date — timestamptz — «Дата создания связи». (3-configuration_integration_link)
- modify_date — timestamptz — «Дата изменения связи». (3-configuration_integration_link)
- details — text — «Вся информация о связях». (3-configuration_integration_link)

Таблица конфигураций (4-configuration_integration_is):
- id — serial4 — «Идентификатор записи» — PK, NOT_NULL. (4-configuration_integration_is)
- external_id — text — «Внешний идентификатор сервиса (Например, код из внешней системы)». (4-configuration_integration_is)
- code — text — «Код ЦС». (4-configuration_integration_is)
- name — text — «Наименование конфигурации». (4-configuration_integration_is)
- description — text — «Тип ЦС». (4-configuration_integration_is)
- create_date — timestamptz — «Дата создания конфигурации». (4-configuration_integration_is)
- modify_date — timestamptz — «Дата изменения конфигурации». (4-configuration_integration_is)
- details — text — «Объект со всей информацией об ИС». (4-configuration_integration_is)

Значения по умолчанию не указаны ни для одного поля в обеих таблицах. (3-configuration_integration_link; 4-configuration_integration_is)

### Бизнес-правила и ограничения
- Ключи и индексы: Primary Key (в документе 4 написано «Primery Key»): id (автоинкремент). (3-configuration_integration_link; 4-configuration_integration_is)
- Ограничения PK и NOT_NULL указаны только для поля id. (4-configuration_integration_is)

### Открытые вопросы
- Названия таблиц в документах не указаны. (3-configuration_integration_link; 4-configuration_integration_is)
- Документы описывают две разные таблицы (связей и конфигураций/ИС) с частично совпадающими именами полей (external_id, create_date, modify_date, details) и разными описаниями; это не считалось расхождением. (3-configuration_integration_link; 4-configuration_integration_is)
