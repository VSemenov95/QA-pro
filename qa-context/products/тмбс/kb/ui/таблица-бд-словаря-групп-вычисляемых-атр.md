# Таблица БД словаря групп вычисляемых атрибутов (dictionary_attribute_group)

> Таблица БД dictionary_attribute_group — словарь групп вычисляемых атрибутов с идентификатором записи и обязательным наименованием группы.

### Описание
- Назначение таблицы: «Словарь групп выч.атрибутов». (2-dictionary_attribute_group)
- Название таблицы в тексте фрагмента не указано; имя файла документа: 2-dictionary_attribute_group.pdf. (2-dictionary_attribute_group)

### Поля и элементы
- Структура таблицы (колонки: Название поля, Тип данных, Описание, Ограничения): (2-dictionary_attribute_group)
- `id` — тип данных SERIAL(INT4); описание: «Уникальный идентификатор записи»; ограничения: PK. (2-dictionary_attribute_group)
- `value` — тип данных TEXT; описание: «Наименование группы»; ограничения: NOT NULL. (2-dictionary_attribute_group)

### Бизнес-правила и ограничения
- Primary Key: id (в документе написано «Primery Key: id;»). (2-dictionary_attribute_group)
- Поле value обязательно для заполнения (NOT NULL). (2-dictionary_attribute_group)
- Других ключей и индексов во фрагменте нет. (2-dictionary_attribute_group)
