# Выгрузка нескольких вычисляемых атрибутов одной строкой (online-service)

> Архитектурный механизм выгрузки нескольких вычисляемых атрибутов из Kafka в ClickHouse одной строкой с преобразованием через Materialized View в формат «1 вычисляемый атрибут = 1 строка» для снижения нагрузки на Kafka и ClickHouse.

### Описание
- Пользовательская история: «Я как Администратор. Хочу Получать вычисляемые атрибуты из кафка в виде одной строки. Для того, чтобы Снизить нагрузку на Clickhouse и Kafka». ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Архитектурное решение «Выгрузка нескольких вычисляемых атрибутов одной строкой сервисом "online-service"». ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Команде необходимо уменьшить нагрузку на kafka и CH при работе с вычисляемыми атрибутами. Механизм: записи из сырых топиков Kafka выгружаются в CH одной строкой, где посредством MatView преобразовываются в текущий формат хранения данных в таблицах _attribute. ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Разделы «История изменений» (колонки: Версия, Дата, Автор, Задача, Описание изменений) и «Открытые вопросы» («<Заполняет автор документа>») не заполнены; подраздел 4.3 «Допущения и ограничения» без содержимого. ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)

### API и интеграции
- Kafka: топик *clickhouse_attributes (в тест-кейсе: -bs_*id*_clickhouse_attribute); запись о выч. атрибуте хранится в формате одной строки (до преобразования). ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- ClickHouse: таблица bs_id_attribute_queue читает данные из *clickhouse_attributes топика Kafka. ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Materialized View bs_id_attribute_mv (в тест-кейсе: -bs_*id*_attribute_mv) преобразует данные из Kafka в формат хранения (1 вычисляемый атрибут = 1 строка). ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Результаты записываются в таблицу bs_id_attribute_distributed (в тест-кейсе: -bs_*id*_attribute_distributed). ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Процесс преобразования: 1) чтение данных из Kafka; 2) преобразование с помощью Materialized View; 3) запись результатов в целевую таблицу bs_id_attribute_distributed. ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Пример создания таблицы: CREATE TABLE default.bs_id_attribute_queue ON CLUSTER cl1 ( transaction_type String, transaction_time String, transaction_uuid UUID, transaction_attribute_1_value Int32, attribute_1_name String, attribute_1_status String, attribute_1_threshold_type String, ... ) ENGINE = Kafka('kafka-kafka-bootstrap.shared:9092', 'bs_id_attribute', 'clickhouse', 'JSONEachRow'); ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
- Пример создания Materialized View: CREATE MATERIALIZED VIEW default.bs_id_attribute_mv ON CLUSTER cl1 TO default.bs_id_attribute_distributed AS SELECT transaction_type, parseDateTime64BestEffort(transaction_time, 3, 'Europe/Moscow') AS transaction_time, transaction_uuid, arrayFirstOrNull(x -> x IS NOT NULL AND x != 0, [transaction_attribute_1_value, transaction_attribute_2_value, ...]) AS transaction_attribute_value, arrayFirstOrNull(x -> x IS NOT NULL, [if(NOT empty(attribute_1_name), 1, NULL), if(NOT empty(attribute_2_name), 2, NULL), ...]) AS attribute_id, ... FROM default.bs_id_attribute_queue; ([US]Выгрузка нескольких вычисляемых атрибутов одной строкой -5)
