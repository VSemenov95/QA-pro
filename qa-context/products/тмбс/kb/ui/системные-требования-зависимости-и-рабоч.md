# Системные требования: зависимости и рабочие станции пользователей

> Раздел описывает обязательные зависимости «Транзакционного мониторинга бизнес-сервисов» от других продуктов Сферы и рекомендуемые требования к рабочим станциям пользователей.

### Описание
- Раздел 3.2 содержит таблицу зависимостей от других продуктов Сферы; раздел 3.2.4 «Требования к настройкам рабочих станций пользователей». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Зависимости (все с признаком «Обязательно»):
  - «Сфера: Аутентификация» — PPAU-26.1.0 - PPAU-26.1.4 — Обязательно.
  - «Сфера: Конфигурации» — PPCM-26.1.0 - PPCM-26.2.0-01.3 — Обязательно.
  - «Сфера: Зонтичная система мониторинга» — PPPM-26.1.0 - PPPM-26.3.0-1.1 — Обязательно. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Для одного рабочего места пользователя рекомендуется персональный компьютер с минимальными характеристиками:
  - Процессор Intel Core 2-ядерный с тактовой частотой 3 ГГц или аналогичный.
  - Оперативная память не менее 4 Гб. Точный объём зависит от среды разработки автоматизированных тестов.
  - Цветной монитор с разрешением не менее 1920 x 1080 пикселей, на котором можно использовать всю рабочую область экрана для отображения веб-приложения.
  - Устройства ввода (клавиатура, «мышь»).
  - Пропускная способность канала связи между рабочей станцией и веб-сервером — 2 Мбит/с. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Информация: для корректного отображения элементов веб-приложения «Сфера: Транзакционный мониторинг бизнес-сервисов» рекомендуется установить 100-процентный масштаб дисплея в настройках операционной системы ПК. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
