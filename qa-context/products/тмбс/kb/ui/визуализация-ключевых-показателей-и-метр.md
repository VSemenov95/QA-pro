# Визуализация ключевых показателей и метрик прохождения транзакции бизнес-сервиса

> Группа функций с набором дашбордов (общая информация по БС, список транзакций, детализация транзакции, события мониторинга), показывающих качественные показатели бизнес-сервиса и метрики прохождения его транзакций.

### Описание
- Группа функций «Визуализация ключевых показателей и метрик прохождения транзакции бизнес-сервиса»: пользователь видит набор дашбордов с качественными показателями БС и транзакции. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- Для запуска продукта «Сфера: Транзакционный мониторинг бизнес-сервисов» нужно открыть пользовательский интерфейс в окне браузера. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Функции: 7.1 Просмотр показателей качества работы БС; 7.2 Просмотр списка транзакций БС и показателей качества прохождения транзакции; 7.3 Поиск и просмотр транзакций, просмотр ключевых качественных характеристик выбранной транзакции; 7.4 Просмотр детализации транзакции, её атрибутов, метрик, качественных характеристик. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)

### Экраны и навигация
- Главный интерфейс: ссылка на дашборд со списком событий мониторинга продукта; список бизнес-сервисов на мониторинге со ссылками на дашборды по каждому БС: с общей информацией; со списком транзакций; с детальной информацией по транзакции; с событиями мониторинга. Для просмотра нужно перейти на нужный дашборд. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- 5.3.1.1 Интерфейс с общей информацией по бизнес-сервису: область навигации фильтрует показатели БС по времени совершения транзакций, доступны предустановленные временные периоды. Графики: «Общее количество транзакций» (суммарное количество транзакций по БС за период) и «Суммарное количество ошибочных транзакций» за период. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- 5.3.1.2 «Дашборд со списком транзакций бизнес-сервиса»: область навигации фильтрует список по типу порога (рис. 5.3.1.2-1) и по времени совершения (предустановленные периоды; показываются ошибочные транзакции за период). При нажатии на транзакцию в дополнительном окне открывается «Дашборд с детальной информацией по бизнес-сервису» (рис. 5.3.1.2-2). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- 5.3.1.3 «Дашборд с детальной информацией по бизнес-сервису»: слева область навигации, где выбирается идентификатор интересующей транзакции. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- 5.3.1.4 «Дашборд события мониторинга». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Поля и элементы
- Общая информация по БС: Количество ошибочных транзакций; Среднее время прохождения транзакции; Количество ошибочных транзакций групп «Аномальность», «Полнота», «Завершенность», «Своевременность»; Общее количество транзакций; Количество транзакций с порогом Normal, Warning, Critical. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Список транзакций (после выбора порога и периода): количество транзакций по группам вычисляемых атрибутов; список транзакций БС с ошибками согласно порогу и периоду. Если количество ошибочных транзакций по группе (Аномальность, Полнота, Своевременность, Завершенность) больше нуля, элемент визуализации меняет цвет. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Строка списка: Идентификатор бизнес-сервиса (transaction_bs_id); Тип транзакции (transaction_type); Идентификатор транзакции (transaction_uuid); число вычисляемых атрибутов с ошибкой по группам Аномальность, Полнота, Своевременность, Завершенность (в документе написано «Антомальность»). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Детальная информация по транзакции: Идентификатор транзакции; Время прохождения транзакции; Счёт отправителя и получателя; Этапы прохождения; Группы вычисляемых атрибутов с индикацией ошибок по группе; Детали прохождения; Вычисляемые атрибуты с индикацией ошибок по расчётному атрибуту; Список вычисляемых атрибутов с детализацией расчёта. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Этапы (порядок прохождения): Время события транзакции (event_time); Идентификатор события транзакции (uuid); Этап транзакции (event_stage). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Группы вычисляемых атрибутов: наличие ошибок в группе; при ошибках элемент группы меняет цвет. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Детали транзакции: Идентификатор события (uuid); Идентификатор транзакции (transaction_uuid); Идентификатор источника события (event_source_id); Идентификатор ключа события (event_id_1, event_id_2, event_id_3). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Вычисляемые атрибуты транзакции: наименование и идентификатор атрибута, статус расчёта; при ошибках элемент меняет цвет. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Список вычисляемых атрибутов: Время совершения транзакции (transaction_time); Тип транзакции (transaction_type); Этап транзакции, для которого рассчитан атрибут (transaction_stage); Значение вычисляемого атрибута (attribute_id); Имя (attribute_name); Тип достигнутого порога (attribute_threshold_type); Порог (attribute_threshold_value); Группа (attribute_group). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Дашборд события мониторинга: количество событий и атрибуты: Идентификатор события (id); Краткая информация (title); Приложение, сформировавшее событие (application); Категория (category); Текст события (alert_text); Критичность (severity); перечень в источнике обрывается. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Время отображения дашбордов не должно превышать 60 секунд. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)
- Время отклика продукта в 90% случаев (кроме дашбордов) не должно превышать 5 секунд. (Сфера.ТМБС_Описание_продукта_PPBP-26.3.0-4)

### Открытые вопросы
- Полный перечень атрибутов события мониторинга после severity в выдержке не приведён. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
