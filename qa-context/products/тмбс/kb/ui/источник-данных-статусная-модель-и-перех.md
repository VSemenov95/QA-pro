# Источник данных: статусная модель и переходы между статусами

> Статусная модель источника данных ТМБС: шесть статусов (DataSourceStatus), допустимые переходы между ними и разрешения (Permission) на смену статуса.

### Описание
- Документ описывает статусную модель источника данных и разрешения на смену статусов. (Источник данных-10)
- Статусы (enum DataSourceStatus): DRAFT("DRAFT", "Черновик"), IN_ANALYSIS("IN_ANALYSIS", "В анализе"), IN_WORK("IN_WORK", "В работе"), CONNECTED("CONNECTED", "Подключен"), DISCONNECTED("DISCONNECTED", "Отключен"), INCIDENT("INCIDENT", "Авария"). (Источник данных-10)
- В разделе «Детализация статусной модели» дана таблица с колонками «Текущий статус», «Целевой статус», «Комментарий»; комментарии в таблице не заполнены. (Источник данных-10)

### Бизнес-правила и ограничения
Допустимые переходы (текущий статус → целевой статус):
- Черновик → Подключен (Источник данных-10)
- Черновик → В анализе (Источник данных-10)
- В анализе → Черновик (Источник данных-10)
- В анализе → В работе (Источник данных-10)
- В работе → В анализе (Источник данных-10)
- В работе → Подключен (Источник данных-10)
- Подключен → Авария (Источник данных-10)
- Подключен → Отключен (Источник данных-10)
- Подключен → Черновик (Источник данных-10)
- Отключен (в таблице обозначен как «Отключено вручную») → Черновик (Источник данных-10)
- Отключено вручную → Подключен (Источник данных-10)
- Авария → Подключен (Источник данных-10)
- Авария → Отключен (Источник данных-10)

### Роли и права
Разрешения на переходы (Permission):
- DRAFT → IN_ANALYSIS: PPBP_DATASOURCE_STATUS_CHANGE_FROM_DRAFT_TO_INANALYSIS (Источник данных-10)
- DRAFT → CONNECTED: PPBP_DATASOURCE_STATUS_CHANGE_FROM_DRAFT_TO_INANALYSIS (то же разрешение, что и для DRAFT → IN_ANALYSIS) (Источник данных-10)
- IN_ANALYSIS → DRAFT: PPBP_DATASOURCE_STATUS_CHANGE_FROM_INANALYSIS_TO_DRAFT (Источник данных-10)
- IN_ANALYSIS → IN_WORK: PPBP_DATASOURCE_STATUS_CHANGE_FROM_INANALYSIS_TO_INWORK (Источник данных-10)
- IN_WORK → IN_ANALYSIS: PPBP_DATASOURCE_STATUS_CHANGE_FROM_INWORK_TO_INANALYSIS (Источник данных-10)
- IN_WORK → CONNECTED: PPBP_DATASOURCE_STATUS_CHANGE_FROM_INWORK_TO_CONNECTED (Источник данных-10)
- CONNECTED → INCIDENT: PPBP_DATASOURCE_STATUS_CHANGE_FROM_CONNECTED_TO_INCIDENT (Источник данных-10)
- INCIDENT → CONNECTED: PPBP_DATASOURCE_STATUS_INCIDENT_TO_CONNECTED (Источник данных-10)
- INCIDENT → DISCONNECTED: PPBP_DATASOURCE_STATUS_INCIDENT_TO_DISCONNECTED (Источник данных-10)
- DISCONNECTED → CONNECTED: PPBP_DATASOURCE_STATUS_CHANGE_FROM_DISCONNECTED_TO_CONNECTED (Источник данных-10)
- DISCONNECTED → DRAFT: PPBP_DATASOURCE_STATUS_CHANGE_FROM_DISCONNECTED_TO_DRAFT (Источник данных-10)
- CONNECTED → DRAFT: PPBP_DATASOURCE_STATUS_CHANGE_FROM_CONNECTED_TO_DRAFT (Источник данных-10)
- CONNECTED → DISCONNECTED: PPBP_DATASOURCE_STATUS_CHANGE_FROM_CONNECTED_TO_DISCONNECTED (Источник данных-10)

### Открытые вопросы
- «НУЖНО ДОБАВИТЬ ОПИСАНИЯ ПЕРЕХОДОВ НА ДИАГРАММУ СТАТУСНОЙ МОДЕЛИ». (Источник данных-10)
- Колонка «Комментарий» в таблице детализации не заполнена. (Источник данных-10)
- В таблице детализации используется название статуса «Отключено вручную», тогда как в перечне статусов указан «Отключен» (DISCONNECTED); соответствие в документе не пояснено. (Источник данных-10)
- Для перехода DRAFT → CONNECTED указано то же разрешение, что и для DRAFT → IN_ANALYSIS (PPBP_DATASOURCE_STATUS_CHANGE_FROM_DRAFT_TO_INANALYSIS); не уточнено, намеренно ли. (Источник данных-10)
