# Таблица БД бизнес-сервисов (название таблицы в документе не указано; файл 5-business_service)

> Таблица БД бизнес-сервисов хранит информацию о бизнес-сервисах (ТМБС), включая их атрибуты и статусы.

### Описание
- Назначение таблицы: «Хранит информацию о бизнес-сервисах, включая их атрибуты и статусы.» (5-business_service)
- Название таблицы в документе не указано (файл 5-business_service.pdf). (5-business_service)

### Поля и элементы
Структура таблицы (поле · тип · описание · ограничения):
- id · SERIAL (INT4) · Уникальный идентификатор записи · PK (5-business_service)
- external_id · TEXT · Внешний идентификатор сервиса (Например, код из внешней системы) · NOT NULL (5-business_service)
- name · TEXT · Название бизнес-сервиса · NOT NULL (5-business_service)
- code · TEXT · Уникальный код сервиса · NOT NULL (5-business_service)
- type · TEXT · Тип сервиса · NOT NULL (5-business_service)
- status · ENUM · Статус сервиса · NOT NULL. Доступные для обработки значения: IN_WORK, ARCHIVE (5-business_service)
- criticality · TEXT · Критичность сервиса · NULLABLE (5-business_service)
- stream · TEXT · Стрим-владелец БС · NULLABLE (5-business_service)
- description · TEXT · Описание БС · NULLABLE (5-business_service)
- create_date · TIMESTAMPTZ · Дата и время создания БС · NOT NULL (5-business_service)
- modify_date · TIMESTAMPTZ · Дата и время последнего изменения · NOT NULL (5-business_service)
- version · INT4 · Версия записи (для контроля изменений) · NOT NULL, DEFAULT 1 (5-business_service)
- primary_information_system · TEXT · Связь с основной информационной системой · NULLABLE (5-business_service)
- version_string · TEXT · Семантическая версия сервиса · NOT NULL, DEFAULT 1.0 (5-business_service)

### Бизнес-правила и ограничения
- Поле status принимает значения IN_WORK и ARCHIVE. (5-business_service)
- Поля criticality, stream, description и primary_information_system допускают NULL. (5-business_service)
- Значения по умолчанию: version = 1, version_string = 1.0. (5-business_service)

### API и интеграции
- Ключи и индексы: Primery Key: id (автоинкремент). Других ключей и индексов в документе не указано. (5-business_service)
