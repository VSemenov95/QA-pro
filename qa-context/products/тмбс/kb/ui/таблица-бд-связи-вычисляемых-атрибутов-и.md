# Таблица БД связи вычисляемых атрибутов и групп (computed_attribute_group)

> Таблица БД computed_attribute_group устанавливает связь между вычисляемыми атрибутами и их группами.

### Описание
- Назначение таблицы: устанавливает связь между вычисляемыми атрибутами и их группами. (3-computed_attribute_group_reference)
- Название таблицы в тексте фрагмента не указано; имя файла документа: «3-computed_attribute_group_reference.pdf». (3-computed_attribute_group_reference)

### Поля и элементы
| Название поля | Тип данных | Описание | Ограничения |
|---|---|---|---|
| computed_attribute_id | INT4 | Связь с вычисляемым атрибутом | NOT NULL (FK) |
| name | TEXT | Связь с группой (типом) атрибутов | NOT NULL (FK) |
(3-computed_attribute_group_reference)

### Бизнес-правила и ограничения
- Primery Key (написание как в документе): составной ключ (group_id, computed_attribute_id). (3-computed_attribute_group_reference)
- Foreign Key: computed_attribute_id -> computed_attribute.id. (3-computed_attribute_group_reference)
- Foreign Key: group_id -> dictionary_attribute_group.id. (3-computed_attribute_group_reference)

### Открытые вопросы
- В таблице структуры поле группы названо «name» (тип TEXT, «Связь с группой (типом) атрибутов», NOT NULL (FK)), а в разделе «Ключи и индексы» используется поле group_id. Поле group_id в таблице структуры отсутствует; расхождение в документе не разъяснено. (3-computed_attribute_group_reference)
- Тип данных TEXT для поля внешнего ключа не соответствует типу ссылочного поля, указанного в документе (dictionary_attribute_group.id); в документе это не поясняется. (3-computed_attribute_group_reference)
