# Шаблоны метрик

> Раздел «Шаблоны метрик» (Администрирование) позволяет создавать, редактировать и удалять шаблоны метрик, управлять их группами и массово менять статус, синхронизировать и удалять метрики, созданные по шаблону.

### Описание
- Управление шаблонами метрик осуществляется из раздела «Администрирование» – «Шаблоны метрик». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Разделы 5.3.5 «Шаблоны метрик», 5.3.5.1 «Создание шаблона», 5.3.5.2 «Редактирование шаблона», 5.3.5.3 «Удаление шаблона», 5.3.5.4 «Вкладка «Группы»» добавлены в версии 3.0 (25.07.2026); 5.3.5.5 «Управление связанными метриками» добавлен в версии 3.2 (26.08.2026). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Экраны и навигация
- Страница «Шаблоны метрик» содержит две вкладки: «Шаблоны» — список шаблонов метрик в виде таблицы; «Группы» — список групп шаблонов метрик (подробнее см. раздел 5.3.3.2 «Вкладка «Группы»»). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Создание: кнопка «Создать Шаблон» открывает окно параметров шаблона. После заполнения всех полей нажать «Создать». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Редактирование: на вкладке «Шаблон» навести курсор на строку шаблона и нажать ЛКМ, в окне заполнить параметры и нажать «Сохранить»; аналогично созданию (раздел 5.3.5.1). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Удаление: на вкладке «Шаблоны» навести курсор на строку нужного шаблона — в правой части строки отобразится кнопка удаления. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Если на основе шаблона созданы метрики, в карточке шаблона доступна вкладка «Связанные метрики» (рисунок 5.3.5.2-1; Рисунок 5.3.5.5-1 - Вкладка «Связанные метрики»): список метрик, созданных на основе шаблона, с указанием принадлежности к карточке мониторинга и бизнес-сервису. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Массовые действия: отметить элементы списка чекбоксами (Рисунок 5.3.5.5-2 - Чекбоксы на вкладке), затем выбрать действие на панели инструментов (Рисунок 5.3.5.5-3 - Массовые действия). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Поля и элементы
- Название Шаблона — верхняя строка, по умолчанию «Новый шаблон»; иконки: карандаш — редактирование, галочка — сохранить, крестик — отмена. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Статус атрибута — вторая строка, раскрывающийся список; доступное значение — «Черновик». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Вкладка «Общие настройки»: «Описание» (вручную, текст); «Методика расчета» (вручную, текст); Единицы измерения; Периодичность расчета; чекбокс «Выгружать в ЗСМ» — выгрузка метрики в зонтичную cистему мониторинга; Группа шаблонов — выбор группы; Метки — одна или несколько из справочника; Уровни критичности — см. раздел 5.2.15 «Создание вычисляемого атрибута». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Вкладка «Код метрики»: «Код метрики» — редактор кода, определяющего алгоритм вычисления; панель инструментов редактора — сброс до первоначального значения, отмена и повтор изменений, удаление всех значений; «Переменные» — кнопка «Добавить переменную» и кнопка «Добавить все переменные» (добавляет в таблицу все коды переменных из SQL‑скрипта в формате ${var}, которых ещё нет в таблице). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Типы переменных: Строка; Массив строк; Число; Массив чисел; Тег вычисляемого атрибута; Теги вычисляемых атрибутов. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Кнопки вкладки «Связанные метрики»: «Изменить статус», «Синхронизировать», «Удалить». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- «Изменить статус»: выпадающий список со всеми возможными статусами метрик; модальное окно с кнопками «Изменить», «Отменить». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Модальное окно синхронизации (Рисунок 5.3.5.5-4 - Синхронизация с шаблоном): список всех метрик, созданных по шаблону и привязанных к отмеченным бизнес-сервисам; для каждой — набор параметров (переменных) шаблона для заполнения; чекбокс «Синхронизировать пороги критичности» (по умолчанию выключен, включается вручную); кнопки «Синхронизировать», «Отмена». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Модальное окно удаления: список названий и идентификаторов выбранных метрик; кнопки «Удалить», «Отмена». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Редактирование параметров шаблона доступно в статусе «Черновик». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Для переменных допустимы только буквы латинского алфавита, цифры и нижние подчёркивания. Все переменные записываются как ${var_code} без кавычек; для строковых типов («Строка», «Массив строк», «Тег вычисляемого атрибута», «Теги вычисляемых атрибутов») кавычки добавляются автоматически при создании метрики на основе шаблона. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Если на основе шаблона созданы метрики, удалить шаблон нельзя. Удаление шаблона: подтверждающее окно, в котором нужно нажать «Удалить». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Доступность действий на вкладке «Связанные метрики» по статусу шаблона: «Черновик» — выбор метрик чекбоксами, доступны «Изменить статус» и «Удалить» («Синхронизировать» недоступна); «Активный» — список с принадлежностью к карточке мониторинга и бизнес-сервису, после выбора доступны «Изменить статус», «Синхронизировать», «Удалить»; «Архивный» — список с принадлежностью, доступны «Изменить статус» и «Удалить» («Синхронизировать» недоступна). (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Изменить статус: после выбора статуса открывается окно с сообщением; «Отменить» — окно закрывается, статусы не меняются, возврат на вкладку; «Изменить» — для всех выбранных бизнес-сервисов (карточек мониторинга) меняется статус всех метрик, связанных с шаблоном, если новый статус допустим для атрибута согласно статусной модели; атрибуты, для которых статус недоступен, пропускаются. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Синхронизировать: заполнить все необходимые поля и нажать «Синхронизировать»; если обязательные поля не заполнены, синхронизация не запускается, незаполненные параметры подсвечиваются как ошибка. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Чекбокс «Синхронизировать пороги критичности» включён: для каждой метрики обновляется template_parameters_applied (сохраняются актуальные значения), значения параметров сохраняются, обновляются все поля, пороги критичности перезаписываются из шаблона. Выключен: то же, но пороги не обновляются, если изменены вручную (manual_interval_override = true). «Отмена» — окно закрывается, изменения не применяются. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Удалить: «Отмена» — метрики не удаляются; «Удалить» — удаляются все выбранные метрики шаблона, не подлежащие удалению пропускаются. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Сообщения и ошибки
- Изменение статуса, окно: «Статус всех выбранных метрик будет изменен на «{выбранный статус}»». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- По завершении: «Статус успешно изменен для метрик: {идентификаторы атрибутов через запятую}» и/или «Не удалось изменить статус для метрик: {идентификаторы атрибутов через запятую}». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Синхронизация, по завершении: «Успешно обновлены метрики: {идентификаторы метрик через запятую}» и/или «Не удалось обновить метрики: {идентификаторы метрик через запятую}». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- «Карточка мониторинга {id/имя карточки} обновлена»; «Не удалось обновить карточку {id/имя карточки}». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Удаление, окно: «Вы действительно хотите удалить метрики:» + список названий и идентификаторов. По завершении: «Успешно удалены Метрики: {идентификаторы метрик через запятую}» и/или «Не удалось удалить метрики: {идентификаторы метрик через запятую}». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Открытые вопросы
- В тексте сказано, что массовые действия выполняются для шаблонов в статусе «Активный», но таблица доступности допускает «Изменить статус» и «Удалить» также для «Черновик» и «Архивный». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Содержимое раздела 5.3.5.3 в выдержке приведено частично; вкладка названа и «Шаблоны», и «Шаблон». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
