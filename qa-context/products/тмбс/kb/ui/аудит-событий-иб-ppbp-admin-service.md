# Аудит событий ИБ (ppbp-admin-service)

> Сбор событий аудита ИБ сервисом ppbp-admin-service с отправкой сообщений во внешний сервис аудита и перечнем кодов событий аудита, формируемых вызовами API продукта ТМБС.

### Описание
- Продукт поддерживает сбор событий аудита ИБ. Сбор событий осуществляется на сервисе: ppbp-admin-service. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Сбор событий аудита реализован с помощью отправки сообщений во внешний сервис для их дальнейшей обработки. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Для корректной отправки сообщений в ресурсах аудируемых сервисов должен находиться файл sfera-audit-events-metadata.yaml, описывающий события аудита. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Информация об архитектуре, форматах сообщений аудита и файла sfera-audit-events-metadata.yaml представлена в руководстве администратора продукта «Сфера: Аудит». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
