# Таблица БД связи бизнес-сервисов и информационных систем (название таблицы в документе не указано; файл 3-bs_system_inf_

> Таблица БД, связывающая бизнес-сервисы с информационными системами (связь «многие ко многим» через ссылки на bs_system и inf_system).

### Описание
- Назначение таблицы: «Связывает бизнес-сервисы с информационными системами». (3-bs_system_inf_system)
- Название таблицы в документе явно не указано (источник — файл 3-bs_system_inf_system.pdf). (3-bs_system_inf_system)

### Поля и элементы
Структура таблицы (Название поля / Тип данных / Описание / Ограничения):
- id — SERIAL (INT4) — «Уникальный идентификатор записи» — PK. (3-bs_system_inf_system)
- bs_id — INT4 — «Идентификатор бизнес-сервиса» — NOT NULL. (3-bs_system_inf_system)
- inf_system_id — INT4 — «Идентификатор информационной системы» — NOT NULL. (3-bs_system_inf_system)

### Бизнес-правила и ограничения
- Primary Key: id (автоинкремент). (3-bs_system_inf_system)
- Foreign Key: bs_id -> bs_system.id. (3-bs_system_inf_system)
- Foreign Key: inf_system_id -> inf_system.id. (3-bs_system_inf_system)
- Поля bs_id и inf_system_id — NOT NULL. (3-bs_system_inf_system)
