# Мониторинг микросервисов: метрики самомониторинга (actuator/prometheus)

> Раздел 5.5 руководства администратора описывает метрики самомониторинга микросервисов ТМБС (actuator/prometheus) и указывает, какие из них нужно включать для каждого сервиса.

### Описание
- Раздел 5.5 содержит таблицы метрик самомониторинга для каждого микросервиса (5.5.1–5.5.10); метрики доступны через actuator/prometheus. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Колонки таблиц: «№», «Наименование в actuator», «Наименование в prometheus», «Описание», «Нужно включать». Имя в actuator задаётся через точку, в prometheus через подчёркивание. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- В колонке «Нужно включать» значение «#Н/Д» означает, что метрику включать не нужно; если указано имя prometheus-метрики, её нужно включать. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Категории строк: Приложение, CPU, Диск, Executor, HTTP, HikariCP, БД (JDBC), JVM, Kafka (app info), Kafka (consumer), Kafka (producer), Кэш (XA), Логирование, Процесс, Resilience4j, Spring, Spring Cloud Stream, Kafka template, Tomcat (сессии), Кастомные метрики. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 5.6. Трассировка: «Трассировка продукта отсутствует.» (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 5.7. Масштабирование и производительность: масштабирование сервисов описано в Архитектуре продукта «Сфера: Транзакционный мониторинг бизнес-сервисов». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 5.5.11 «Отключение метрик мониторинга» указан в заголовке выдержки, содержимое не приведено. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Поля и элементы
- Таблицы по сервисам: 5.5.2-1 ppbp-configuration-service; 5.5.3-1 ppbp-ecm-integration-service; 5.5.4-1 ppbp-event-collector-kafka; 5.5.5-1 ppbp-metrics-calculator; 5.5.6-1 ppbp-metrics-treshold; 5.5.7-1 ppbp-online-metrics; 5.5.8-1 ppbp-preprocessor; 5.5.9-1 ppbp-enrichment; 5.5.10-1 ppbp-merging-transaction. Также упомянут ppbp-event-admin-service (в его описаниях пометка «(добавлено)», кроме строк 273–275 spring.kafka.listener). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Приложение: application.ready.time → application_ready_time_seconds («Время перехода в состояние READY»); application.started.time → application_started_time_seconds («Время перехода в состояние STARTED»). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- CPU: system.cpu.count → system_cpu_count («Общее количество доступных CPU-ядер»); system.cpu.usage → system_cpu_usage. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Процесс: process.files.max → process_files_max_files («Максимальное количество файловых дескрипторов, которое может открыть процесс (лимит ОС)»); process.files.open → process_files_open_files («Текущее количество открытых файловых дескрипторов»); process.start.time → process_start_time_seconds («Время старта процесса (Unix timestamp в секундах)»). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- HikariCP: hikaricp.connections.acquire/active/creation/idle/max/min/pending/timeout/usage → hikaricp_connections_*; JDBC: jdbc.connections.max → jdbc_connections_max, jdbc.connections.min → jdbc_connections_min (#Н/Д). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- JVM: jvm.buffer.*, jvm.classes.*, jvm.gc.*, jvm.memory.* и др. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Kafka (consumer/producer): kafka.consumer.* / kafka.producer.* (coordinator, fetch.manager, io, network, node.*, request/response, authentication, reauthentication, record.*, buffer и др.), по умолчанию «#Н/Д», кроме перечисленных в правилах. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Kafka template: spring_kafka_template_seconds_count («Количество отправленных сообщений в kafka»), _max («Максимальное время отправки сообщения в kafka (сек)»), _sum («Суммарное время отправки сообщений в kafka (сек)»); все «#Н/Д». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Tomcat (сессии): tomcat.sessions.active.current, active.max, alive.max, created, expired, rejected → tomcat_sessions_active_current_sessions, tomcat_sessions_active_max_sessions, tomcat_sessions_alive_max_seconds, tomcat_sessions_created_sessions_total, tomcat_sessions_expired_sessions_total, tomcat_sessions_rejected_sessions_total; все «#Н/Д». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Кастомные: ppbp.attributes (ppbp_attributes_seconds_count/_max/_sum), ppbp.latency.between.services (ppbp_latency_between_services_seconds_count/_max/_sum), ppbp.processing → ppbp_processing_seconds_sum («Суммарное время обработки (сек)»), ppbp.sent.to.merger → ppbp_sent_to_merger_total («Общее количество событий, отправленных в merger»); все «#Н/Д». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Включать для сервисов (где указано): process.cpu.usage → process_cpu_usage («Загрузка CPU процессом с учетом всех ядер (диапазон [0.0–1.0], где 1.0 = 100%)»); process.uptime → process_uptime_seconds («Время безотказной работы процесса (в секундах)»); http.server.requests → http_server_requests_seconds_count («Общее количество обработанных серверных запросов»); jvm.memory.max → jvm_memory_max_bytes; jvm.memory.used → jvm_memory_used_bytes. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- ppbp-metrics-calculator (5.5.5-1) дополнительно: hikaricp_connections_active, hikaricp_connections_idle, hikaricp_connections_min, hikaricp_connections_pending, hikaricp_connections_timeout_total. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- ppbp-merging-transaction (5.5.10-1) дополнительно: kafka_producer_buffer_total_bytes. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Для сервисов с Kafka producer-метриками включать: kafka_producer_record_error_total («Общее количество ошибок записей»), kafka_producer_record_send_total («Общее количество отправленных записей»), kafka_producer_request_latency_avg («Средняя задержка запросов producer'а»). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Опечатки в исходных данных: system.load.average.1m указано как system_load_average_m (корректно system_load_average_1m); kkafka_consumer_node_request_size_max (корректно kafka_consumer_node_request_size_max); logj_events_total (корректно log4j2_events_total). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Открытые вопросы
- Таблицы приведены фрагментами; номера строк одних и тех же метрик Kafka producer различаются между фрагментами, так как относятся к разным сервисам. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
