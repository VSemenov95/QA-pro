# Таблица БД связи Сервисов и Бизнес-сервисов (название таблицы в документе не указано; файл s_system_bs_system-2)

> Таблица БД, хранящая связь между Сервисами и Бизнес-сервисами (многие-ко-многим) через внешние ключи на service и business_service.

### Описание
- Назначение таблицы: «Связь между Сервисами и Бизнес-сервисами». (s_system_bs_system-2)
- Название таблицы в документе не указано (известно только имя файла: s_system_bs_system-2). (s_system_bs_system-2)

### Поля и элементы
Структура таблицы (поле — тип данных — описание — значение по умолчанию — ограничения):
- id — SERIAL (INT4) — «Уникальный идентификатор записи» — значение по умолчанию не указано — PK. (s_system_bs_system-2)
- service_id — INT4 — «Идентификатор сервиса» — значение по умолчанию не указано — NOT NULL. (s_system_bs_system-2)
- bs_id — INT4 — «Идентификатор бизнес-сервиса» — значение по умолчанию не указано — NOT NULL. (s_system_bs_system-2)

### Бизнес-правила и ограничения
- Primary Key: id (автоинкремент). (s_system_bs_system-2)
- Foreign Key: service_id -> service.id. (s_system_bs_system-2)
- Foreign Key: bs_id -> business_service.id. (s_system_bs_system-2)
- Поля service_id и bs_id обязательны (NOT NULL). (s_system_bs_system-2)
- Индексы в документе, кроме первичного ключа, не указаны. (s_system_bs_system-2)
