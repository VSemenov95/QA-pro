- Документ «30-ТМ.Онбординг.pdf» (3 страницы) — страница онбординга для новых участников команды ТМБС. Оглавление: Блок-схема системы; Видео онбординга; Ссылка на FAQ; Полезные ссылки; Список стендов; Получение доступов в пространство inno.local. (30-ТМ.Онбординг)
- Разделы «Блок-схема системы» и FAQ в тексте представлены только заголовками (содержимое — вложения/ссылки). (30-ТМ.Онбординг)

### Сценарии
- Получение доступов в пространство inno.local: (1) завести заявку согласно статье https://sfera-t1.ru/knowledge/pages?id=124510 на учётку типа *_tk@inno.local (секция «Доступ в МММ (sfera.inno.local)»); (2) заводить заявку здесь: https://jira.inno.tech/servicedesk/customer/portal/1/create/384, текст брать из статьи; (3) попросить коллег добавить в нужное пространство PPBP в https://sfera.inno.local (права сейчас есть у Кадышева Сергея). (30-ТМ.Онбординг)
