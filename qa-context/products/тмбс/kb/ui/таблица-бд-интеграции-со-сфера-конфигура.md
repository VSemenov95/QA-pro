# Таблица БД интеграции со Сфера.Конфигурации (configuration_integration_chain)

> Таблица БД configuration_integration_chain служит для интеграции со Сфера.Конфигурации и хранит данные о конфигурациях (внешний идентификатор, название, код, тип, статус, критичность, поток, описание, даты, версия, детали).

### Описание
- Назначение таблицы: «Таблица для интеграции со сфера.конфигурации». (2-(R) configuration_integration_chain)
- Название таблицы в тексте фрагмента явно не указано; имя файла документа: «2-(R) configuration_integration_chain.pdf». (2-(R) configuration_integration_chain)

### Поля и элементы
Структура таблицы (колонки: Название поля, Тип данных, Описание, Значение по умолчанию, Ограничения):
- id — serial4; ограничения: PK, NOT_NULL (2-(R) configuration_integration_chain)
- external_id — text (2-(R) configuration_integration_chain)
- name — text (2-(R) configuration_integration_chain)
- code — text (2-(R) configuration_integration_chain)
- type — text (2-(R) configuration_integration_chain)
- status — text (2-(R) configuration_integration_chain)
- criticality — text (2-(R) configuration_integration_chain)
- stream — text (2-(R) configuration_integration_chain)
- description — text; описание: «Описание» (2-(R) configuration_integration_chain)
- create_date — timestamptz (2-(R) configuration_integration_chain)
- modify_date — timestamptz (2-(R) configuration_integration_chain)
- version — text (2-(R) configuration_integration_chain)
- details — text (2-(R) configuration_integration_chain)

### Бизнес-правила и ограничения
- Ключи и индексы: Primery Key: id (автоинкремент). (2-(R) configuration_integration_chain)
- Значения по умолчанию для полей не указаны. (2-(R) configuration_integration_chain)
- Ограничение NOT_NULL указано только для поля id. (2-(R) configuration_integration_chain)
