# Клонирование вычисляемого атрибута

> Функциональность клонирования вычисляемого атрибута в ТМБС: по кнопке «Клонировать» пользователь выбирает поля сохранённого атрибута и получает его копию в статусе «Черновик» для ускорения создания новых атрибутов.

### Описание
- Пользовательская история: «Я как Пользователь системы. Хочу Клонировать вычисляемый атрибут. Для того, чтобы Облегчить и ускорить процесс создания вычисляемых атрибутов». (6-Клонирование вычисляемого атрибута)
- Контекст: клонирование необходимо для ускорения создания вычисляемых атрибутов, предзаполняя их нужной информацией заранее. (6-Клонирование вычисляемого атрибута)
- История изменений: версия 1, 17.06.25, автор Лазарев Никита, задача «Создание». Раздел «Открытые вопросы» в документе пуст. (6-Клонирование вычисляемого атрибута)

### Экраны и навигация
- Клонирование выч.атрибута происходит по нажатию на кнопку в окне просмотра. (6-Клонирование вычисляемого атрибута)
- Предусловие: пользователь находится в режиме просмотра карточки ИЛИ в режиме редактирования карточки, И находится на странице вычисляемых атрибутов, И имеет разрешение на создание вычисляемых атрибутов. (6-Клонирование вычисляемого атрибута)
- Действие: нажимает на вычисляемый атрибут И нажимает на кнопку «Клонировать». (6-Клонирование вычисляемого атрибута)
- При нажатии на «Клонировать» появляется диалоговое окно с выбором полей для клонирования. После выбора полей и нажатия «Клонировать» открывается окно создания вычисляемого атрибута в статусе «Черновик». (6-Клонирование вычисляемого атрибута)
- Макеты: 5.3.1 «Клонирование выч.атрибута (Кнопка)» (расположение кнопки) и 5.3.2 «Клонирование выч.атрибута (Диалоговое окно)». (6-Клонирование вычисляемого атрибута)

### Поля и элементы
- 5.3.1 Кнопка: наименование «Клонироваь» (так в документе); тип: Кнопка; обязательность: Нет; редактируемое: «-»; валидация: доступна для нажатия в любом статусе выч.атрибута в любом статусе карточки мониторинга (кроме «Постановка»); сообщения об ошибке: «-». (6-Клонирование вычисляемого атрибута)
- 5.3.2 «Название»: поле для ввода; обязательность: Да; редактируемое: Да; валидация: «-» (валидируется только в момент сохранения выч.атрибута); сообщения об ошибке: «-». (6-Клонирование вычисляемого атрибута)
- 5.3.2 «Поля для клонирования»: множественный выбор; обязательность: Да; редактируемое: Да; валидация: «-»; сообщения об ошибке: «-». (6-Клонирование вычисляемого атрибута)
- 5.3.2 Кнопки «Клонировать» и «Отмена»: кнопка; обязательность: Да; редактируемое: «-»; валидация: «-»; сообщения об ошибке: «-». (6-Клонирование вычисляемого атрибута)
- В диалоговом окне доступны для нажатия: чекбокс напротив каждого элемента (выбор полей для копирования), кнопка «Клонировать», кнопка «Отмена». (6-Клонирование вычисляемого атрибута)
- Доступные для клонирования поля: Все; Тип атрибута; Класс; Единицы измерения; Группы; Описания; Методика расчета; Параметры критичности; Правила вычисления. При нажатии на «Все» выделяются все доступные варианты. (6-Клонирование вычисляемого атрибута)
- В окне создания клона доступны для нажатия кнопки «Сохранить» и «Отмена». (6-Клонирование вычисляемого атрибута)

### Бизнес-правила и ограничения
- Клонируется только сохранённая информация выч.атрибута: если пользователь ввёл информацию и, не нажав «Сохранить», нажал «Клонирования», несохранённая информация не склонируется. (6-Клонирование вычисляемого атрибута)
- Клонировать можно в любом статусе карточки (в режиме просмотра и редактирования) и самого выч.атрибута, кроме статусов, не подразумевающих взаимодействия с карточкой (на данный момент только «Постановка»). (6-Клонирование вычисляемого атрибута)
- Можно выбрать, какие поля клонировать. (6-Клонирование вычисляемого атрибута)
- Склонированный выч.атрибут создаётся в статусе «Черновик». (6-Клонирование вычисляемого атрибута)
- При клонировании наименование также клонируется с припиской «КОПИЯ». (6-Клонирование вычисляемого атрибута)
- Можно клонировать только 1 вычисляемый атрибут за раз. (6-Клонирование вычисляемого атрибута)
- Название в диалоговом окне валидируется только в момент сохранения выч.атрибута. (6-Клонирование вычисляемого атрибута)

### Роли и права
- Требуется разрешение на создание вычисляемых атрибутов; дополнительных разрешений не вводится. (6-Клонирование вычисляемого атрибута)

### Сценарии
- Критерий 1: пользователь (в режиме просмотра или редактирования карточки, на странице вычисляемых атрибутов, с разрешением на создание) нажимает на вычисляемый атрибут и кнопку «Клонировать» → видит всплывающее окно с множественным выбором полей; доступны чекбокс напротив каждого элемента, кнопки «Клонировать» и «Отмена». (6-Клонирование вычисляемого атрибута)
- Критерий 2 (при выполнении критерия 1): пользователь выбирает одно, несколько или «все» поля и нажимает «Клонировать» → открывается окно создания вычисляемого атрибута в статусе «Черновик», выбранные поля скопированы, доступны «Сохранить» и «Отмена». (6-Клонирование вычисляемого атрибута)
- Критерий 3 (при выполнении критерия 2): нажатие «Сохранить» → вычисляемый атрибут сохранён в статусе «Черновик». (6-Клонирование вычисляемого атрибута)
- Критерий 4 (при выполнении критерия 2): нажатие «Отменить» → окно создания закрыто, создание «клона» не произошло. (6-Клонирование вычисляемого атрибута)
