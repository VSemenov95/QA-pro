# Метрика Сервиса: статусная модель и переходы между статусами

> Статусная модель метрики Сервиса (МС) в продукте ТМБС: четыре статуса (Черновик, Подключено, На мониторинге, Отключено вручную) и правила переходов между ними, выполняемых пользователем или автоматически системой.

### Описание
- Документ «5-Метрика Сервиса» описывает статусную модель метрики Сервиса (МС) и детализацию переходов между статусами. (5-Метрика Сервиса)
- МС создаётся пользователем в рамках конкретного Сервиса. (5-Метрика Сервиса)
- Оглавление документа: «Метрика Сервиса», «Детализация статусной модели». (5-Метрика Сервиса)

### Поля и элементы
- Статусы (код, значение): DRAFT("DRAFT", "Черновик"); CONNECTED("CONNECTED", "Подключено"); MONITORING("MONITORING", "На мониторинге"); DISCONNECTED_MANUAL("DISCONNECTED_MANUAL", "Отключено вручную"). (5-Метрика Сервиса)
- Раздел «Статус»: «В работе скрыт и не используются.» (формулировка неполная, к какому статусу/объекту относится, не указано). (5-Метрика Сервиса)
- Кнопка «Обновить карточку» (в карточке Сервиса) — используется для автоматического перевода МС из «Подключено» в «На мониторинге». (5-Метрика Сервиса)

### Бизнес-правила и ограничения
- Статус «Черновик» является инициирующим: все МС первоначально создаются только в статусе «Черновик». (5-Метрика Сервиса)
- В статусе «Черновик» пользователь не может поставить МС на мониторинг. (5-Метрика Сервиса)
- «Черновик» — единственный статус для внесения изменений в МС. (5-Метрика Сервиса)
- Перевод из «Подключено» в «На мониторинге» выполняет система автоматически, когда пользователь нажимает кнопку «Обновить карточку» для карточки Сервиса и обновляются конфигурации для метрик Сервиса. (5-Метрика Сервиса)
- Таблица переходов (текущий статус → целевой: комментарий; тест-кейс): (5-Метрика Сервиса)
  - «-» (нет статуса) → «Черновик»: пользователь создаёт МС в рамках конкретного Сервиса; PPBP-1785.
  - «Черновик» (без смены статуса): пользователь не может поставить МС на мониторинг; «Черновик» единственный статус для внесения изменений в МС; PPBP-1795.
  - «Черновик» → «Подключено»: пользователь переводит для постановки МС на мониторинг; PPBP-1786.
  - «Черновик» → «Отключено вручную»: пользователь переводит при неготовности МС к постановке на мониторинг; PPBP-1787.
  - «Подключено» (как целевой статус из исходного состояния): пользователь переводит МС в данный статус при готовности МС к постановке на мониторинг.
  - «Подключено» → «Черновик»: пользователь при внесении изменений в атрибуты переводит МС в «Черновик»; PPBP-1788.
  - «Подключено» → «Отключено вручную»: пользователь переводит при неготовности МС к постановке на мониторинг, или при желании выключить сбор МС; PPBP-1789.
  - «Подключено» → «На мониторинге»: система при нажатии пользователем кнопки «Обновить карточку» для карточки Севриса и обновлении конфигураций для метрик Сервиса автоматически переводит статус МС в «На мониторинге»; PPBP-1790.
  - «Отключено вручную» (как целевой статус): пользователь переводит МС в данный статус при желании отключить сбор данных по МС; PPBP-1797.
  - «Отключено вручную» → «Черновик»: пользователь для внесения изменений в ранее отключенную МС переводит в «Черновик»; PPBP-1794.
  - «Отключено вручную» → «Подключено»: пользователь переводит для постановки МС на мониторинг; PPBP-1793.
  - «На мониторинге» (как целевой статус): пользователь переводит МС в данный статус при желании поставить МС на мониторинг; PPBP-1796.
  - «На мониторинге» → «Отключено вручную»: пользователь переводит при желании выключить сбор МС; PPBP-1791.
  - «На мониторинге» → «Черновик»: пользователь переводит при желании редактирования МС; PPBP-1792.
- Тест-кейсы — ссылки вида https://sfera-t1.ru/testing/project/PPBP/test-issue/PPBP-NNNN. (5-Метрика Сервиса)

### Роли и права
- Переходы выполняет «Пользователь»; исключение — переход «Подключено» → «На мониторинге», выполняемый системой автоматически. (5-Метрика Сервиса)

### Сценарии
- Создание МС: пользователь создаёт МС в рамках конкретного Сервиса → «Черновик». (5-Метрика Сервиса)
- Постановка на мониторинг: «Черновик» → «Подключено» (пользователь) → «На мониторинге» (система по кнопке «Обновить карточку» в карточке Сервиса с обновлением конфигураций метрик Сервиса). (5-Метрика Сервиса)
- Редактирование: из «Подключено», «Отключено вручную» или «На мониторинге» пользователь переводит МС в «Черновик» и вносит изменения. (5-Метрика Сервиса)
- Отключение сбора: из «Черновик», «Подключено» или «На мониторинге» пользователь переводит МС в «Отключено вручную». (5-Метрика Сервиса)
- Включение отключённой МС: «Отключено вручную» → «Подключено» для постановки на мониторинг. (5-Метрика Сервиса)

### Открытые вопросы
- Фраза «В работе скрыт и не используются.» в разделе «Статус» не содержит подлежащего. (5-Метрика Сервиса)
- У части строк таблицы переходов (целевые «Подключено», «Отключено вручную», «На мониторинге») не указан исходный статус; из документа он однозначно не определяется. (5-Метрика Сервиса)
