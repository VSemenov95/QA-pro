# Метрика: поле «Имя метрики» (правила и валидация)

> Поле «Имя метрики» в карточке мониторинга — обязательное редактируемое поле ввода с именем по умолчанию «Новая метрика» и требованием уникальности в рамках карточки мониторинга.

### Поля и элементы
- Поле «Имя метрики»: формат/тип элемента — Поле ввода; обязательное поле — Да; редактируемое поле — Да. (4-ТМ.06.06.Метрика)

### Бизнес-правила и ограничения
- При создании метрики имя устанавливается по умолчанию как "Новая метрика". (4-ТМ.06.06.Метрика)
- Пользователь может изменить имя метрики. (4-ТМ.06.06.Метрика)
- Имя метрики не может повторять существующие имена метрик в карточке мониторинга; имя должно быть уникальным в рамках карточки мониторинга. (4-ТМ.06.06.Метрика)

### Сообщения и ошибки
- Метрика с таким именем уже существует в карточке мониторинга (4-ТМ.06.06.Метрика)
