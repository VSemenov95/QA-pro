# Установка микросервиса ppbp-preprocessor-service

> Установка микросервиса ppbp-preprocessor-service: настройка SSL-хранилищ для Kafka и переменные окружения (Kafka, ScyllaDB, логирование, потоки обработки, форматы сериализации).

### Описание
- В контейнер необходимо добавить keystore и truststore с ключами для доступа к Kafka, если она работает через SSL. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Необходимо учесть переменные среды из Таблицы 4.2.6-1 «Данные переменных окружения ppbp-preprocessor-service». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Поля и элементы
Формат: ИМЯ — описание; по умолчанию; пример; обязательность. Источник всех пунктов: Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4
- JAVA_OPTS — параметры запуска JVM, включая настройки SSL-хранилищ; Xmx1G; -Djavax.net.ssl.trustStorePassword=$(TRUSTSTORE_PASSWORD) -Djavax.net.ssl.trustStore=/opt/keystores/truststore.p12; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- KAFKA_BOOTSTRAP_SERVERS — адрес сервера Kafka; localhost:9092; (10.***.64.21:30195,10.***.64.26:30195,10.***.64.27:30195); Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- KEYSTORE_LOCATION — путь к файлу keystore; null; /opt/keystores/keystore.p12; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- KEYSTORE_PASSWORD — пароль к файлу keystore; null; secret(certificate-pkcs12-password)[password] visibility; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TRUSTSTORE_LOCATION — путь к файлу truststore; null; /opt/keystores/truststore.p12; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TRUSTSTORE_PASSWORD — пароль к файлу truststore; null; secret(certificate-pkcs12-password)[password]; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- LOGGING_CONFIG — путь к файлу с конфигурацией логирования; classpath:log4j2-kubernetes.xml; classpath:log4j2-local.xml; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- LOGGING_LEVEL_ROOT — уровень логирования; info; debug; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- SERVER_PORT — HTTP-порт приложения; 8000; 8080; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- LOGGING_HOST — адрес fluent-bit (агент для сбора и маршрутизации логов), на который отправляются логи, в случае использования встроенного log4j2-kubernetes.xml; null; 127.0.0.1; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- SPRING_CLOUD_STREAM_KAFKA_BINDER_CONFIGURATION_SECURITY_PROTOCOL — протокол безопасности для Kafka биндера; SSL; PLAINTEXT; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_SSL_ENABLED — флаг включения SSL для Kafka; true; false; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_CONTACTPOINTS — точки контакта для подключения к ScyllaDB; scylla-client.shared; 10.0.0.5:9042; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_KEYSPACE — имя ключевого пространства в ScyllaDB; trmonbs_merge; my_keyspace; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_LOCALDC — локальный центр данных в ScyllaDB; dc1; dc1; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_PASSWORD — пароль для аутентификации в ScyllaDB; пример secret(scylla-creds)[password] visibility; Нет; в документе указано значение по умолчанию (секрет, здесь не приводится). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_PORT — порт для подключения к ScyllaDB; 9042; 9042; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_SSL_ENABLED — флаг включения SSL для ScyllaDB; false; true; Да. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_SCYLLA_USERNAME — имя пользователя для аутентификации в ScyllaDB; trmonbs_admin; scylla_user; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_PREPROCESSOR_CORE_INCOMECONCURRENCY — размер общего пула потоков по обработке всех входящих сообщений; 32; 16; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_PREPROCESSOR_CORE_SPLITTEDMESPROCCONCURRENCY — размер общего пула потоков по обработке всех сообщений, полученных после разбивки входящего сообщения на несколько исходящих; 1000; 500; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_PREPROCESSOR_CORE_TOPICSLISTENINGCONCURRENCY — количество групп слушателей на все топики. Например: есть 3 входящих топика; если значение = 2, то одна группа слушателей будет создана на топики 1 и 2, а другая на топик 3; таким образом параллельно будет слушаться 2 групп топиков; 32; 4; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_PREPROCESSOR_CORE_TOPICSPARTITIONSCONCURRENCY — количество групп слушателей на один топик. Например: если топик содержит 5 партиций, а слушателей 2, то первый слушатель будет поочерёдно читать партиции 1, 2 и 3, а второй слушатель — партиции 4, 5; 1; 2; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_PREPROCESSOR_DYNAMICLISTENERS_ENABLED — переключатель механизма чтения входящих сообщений из Kafka. True — включается механизм, позволяющий создавать заданное количество consumers, которые параллельно читают входящие данные; это увеличивает пропускную способность сервиса и утилизацию ресурсов, снижает частоту чтения из недозагруженных топиков kafka, но создаёт бОльшее количество consumer-ов, что может сказаться на нагрузке Kafka. False — создаётся 1 consumer, который по кругу вычитывает сообщения из топиков; значение в документе: true; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_FETCHMINBYTES — минимальное количество байт данных для получения от брокера Kafka; null; 256000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_MAXPOLLRECORDS — максимальное количество записей, возвращаемых за один вызов poll(); null; 5000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_BATCHSIZE — размер пакета (в байтах) для отправки сообщений в Kafka; null; 256000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_FETCHMAXWAITMS — максимальное время ожидания данных от брокера при запросе (в миллисекундах); null; 20000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_MAXPARTITIONFETCHBYTES — максимальный размер данных для извлечения из одной партиции за один запрос (в байтах); null; 20000000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_LINGERMS — время ожидания перед отправкой пакета, чтобы накопить больше сообщений (в миллисекундах); null; 15000; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_LISTENER_FORMAT — формат сериализации данных для слушателя (consumer); JSON; AVRO; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_TOMSSENDER_FORMAT — формат сериализации данных для отправителя (producer); JSON; AVRO; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- TM_KAFKA_PRODUCER_COMPRESSIONTYPE — тип сжатия данных для отправителя (producer); null; lz5; Нет. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
