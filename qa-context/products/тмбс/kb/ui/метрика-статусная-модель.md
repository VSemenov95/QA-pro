# Метрика: статусная модель

> Статусная модель метрики (М) в карточке мониторинга (КМ): статусы метрики, правила и переходы между ними, выполняемые пользователем или системой.

### Описание
- Документ описывает статусную модель метрики (М) в карточке мониторинга (КМ). (Метрика-10)
- Статусы (код, название): DRAFT «Черновик»; IN_WORK «В работе»; CONNECTED «Подключено»; MONITORING «На мониторинге»; DISCONNECTED «Отключено»; DISCONNECTED_MANUAL «Отключено вручную». (Метрика-10)
- Статус «В работе» скрыт и не используется. (Метрика-10)

### Бизнес-правила и ограничения
- Пользователь создаёт метрику (М) в карточке мониторинга (КМ). (Метрика-10)
- Статус «Черновик» является инициирующим: все М первоначально создаются только в статусе «Черновик». (Метрика-10)
- В статусе «Черновик» пользователь не может поставить М на мониторинг. (Метрика-10)
- «Черновик» — единственный статус для внесения изменений в М. (Метрика-10)
- Изменение статуса согласно статусной модели возможно только при создании и редактировании новой версии КМ. (Метрика-10)

### Сценарии
Переходы статусов (текущий → целевой: кто и когда переводит):
- Черновик → Подключено: пользователь, при готовности М к постановке на мониторинг. (Метрика-10)
- Черновик → Отключено вручную: пользователь. (Метрика-10)
- Подключено (вход в статус): пользователь переводит М при готовности к постановке на мониторинг; система переводит М в этот статус при создании новой версии КМ. (Метрика-10)
- Подключено → Черновик: пользователь при внесении изменений в атрибуты. Возможно как при редактировании версии карточки мониторинга, так и при просмотре карточки мониторинга. (Метрика-10)
- Подключено → Отключено вручную: пользователь при неготовности М к постановке на мониторинг или при желании выключить сбор М. (Метрика-10)
- Подключено → На мониторинге: система автоматически, при постановке пользователем КМ на мониторинг. (Метрика-10)
- Отключено вручную (вход в статус): пользователь, при желании отключить сбор данных по М. (Метрика-10)
- Отключено вручную → Черновик: пользователь, для внесения изменений в ранее отключённую М. (Метрика-10)
- Отключено вручную → Подключено: пользователь, для постановки М на мониторинг. (Метрика-10)
- Отключено (вход в статус): система автоматически, при снятии КМ с мониторинга. (Метрика-10)
- Отключено → На мониторинге: система автоматически, при постановке пользователем КМ на мониторинг. (Метрика-10)
- На мониторинге (вход в статус): система автоматически, при обновлении КМ или постановке КМ на мониторинг. (Метрика-10)
- На мониторинге → Отключено: система автоматически, при снятии пользователем КМ с мониторинга. (Метрика-10)
- На мониторинге → Отключено вручную: пользователь, при желании выключить сбор М. (Метрика-10)
- На мониторинге → Подключено: система, при создании новой версии КМ (редактировании КМ). (Метрика-10)
- На мониторинге → Черновик: пользователь, при желании редактирования М. (Метрика-10)
