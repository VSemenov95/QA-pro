# Таблица БД элементов данных блока (структура таблицы, связь с datablock)

> Таблица БД элементов данных блока хранит элементы данных (название, порядковый номер, значение), связанные с блоком данных datablock через внешний ключ datablock_id.

### Описание
- Назначение таблицы в документе указано как «??? Хранит записи о сотрудниках» (текст содержит маркер «???», формулировка не уточнена). (datablock_data-2)
- Название таблицы во фрагменте не указано. (datablock_data-2)
- По описаниям полей таблица хранит элементы данных (название, порядковый номер, значение), связанные с блоком данных (datablock). (datablock_data-2)

### Поля и элементы
Структура таблицы (Название поля / Тип данных / Описание / Ограничения):
- id — SERIAL(INT4) — Уникальный идентификатор записи — PK (datablock_data-2)
- name — TEXT — Название элемента данных — NOT NULL (datablock_data-2)
- order — INT4 — Порядковый номер — NOT NULL (FK) (datablock_data-2)
- value — TEXT — Значение элемента данных — NULLABLE (datablock_data-2)
- datablock_id — INT4 — Связь с блоком данных — NOT NULL (FK) (datablock_data-2)

### Бизнес-правила и ограничения
- Primery Key (так в документе): id. (datablock_data-2)
- Foreign Key: datablock_id -> datablock.id. (datablock_data-2)
- Для поля order в ограничениях указано «NOT NULL (FK)», но в разделе «Ключи и индексы» внешний ключ для order не описан. (datablock_data-2)

### Открытые вопросы
- Назначение таблицы указано как «??? Хранит записи о сотрудниках», что не соответствует описаниям полей (элементы данных, блок данных); требуется уточнение. (datablock_data-2)
- Название таблицы не указано. (datablock_data-2)
- Для поля order указан FK, но целевая таблица и поле в разделе «Ключи и индексы» не приведены. (datablock_data-2)
