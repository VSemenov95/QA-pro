# Таблица БД связи роли и бизнес-сервиса (название таблицы в документе не указано)

> Таблица БД, хранящая связь роли и бизнес-сервиса (БС): тип роли, порядковый номер и ссылка на бизнес-сервис.

### Описание
- Назначение таблицы: «??? Хранит связь роли и бс» (формулировка в документе с вопросительными знаками, назначение не уточнено). (2-datablock)
- Название таблицы в документе не указано; файл называется «2-datablock.pdf». (2-datablock)

### Поля и элементы
- `id` — тип SERIAL (INT4); описание: «Уникальный идентификатор записи»; ограничения: PK. (2-datablock)
- `type` — тип ENUM; описание: «Тип данных»; ограничения: NOT NULL. Допустимые значения: BS_OWNER, BS_TECHNOLOGIST, BS_RESPONSIBLE, BS_MANAGERS, BS_CONFIG_DATA, OTHER. (2-datablock)
- `order` — тип данных указан как NULL; описание: «Порядковый номер»; ограничения: NULLABLE. (2-datablock)
- `bs_id` — тип INT4; описание: «Связь с БС»; ограничения: NULLABLE (FK). (2-datablock)

### Бизнес-правила и ограничения
- Primary Key (в документе написано «Primery Key»): id. (2-datablock)
- Foreign Key: bs_id -> business_service.id. (2-datablock)
- Поле `type` обязательно (NOT NULL), `order` и `bs_id` допускают пустые значения (NULLABLE). (2-datablock)
