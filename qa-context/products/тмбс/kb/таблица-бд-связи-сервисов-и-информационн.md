# Таблица БД связи Сервисов и Информационных систем (файл 2-s_system_inf_system; название таблицы в документе не указано)

> Таблица БД, хранящая связь «многие ко многим» между Сервисами и Информационными системами (название таблицы в документе не указано).

### Описание
- Назначение таблицы: «Связь между Сервисами и Информационными системами». (2-s_system_inf_system)
- Название таблицы в документе не указано (файл 2-s_system_inf_system.pdf). (2-s_system_inf_system)

### Поля и элементы
| Название поля | Тип данных | Описание | Значение по умолчанию | Ограничения |
|---|---|---|---|---|
| id | SERIAL (INT4) | Уникальный идентификатор записи | не указано | PK |
| service_id | INT4 | Идентификатор сервиса | не указано | NOT NULL |
| inf_system_id | INT4 | Идентификатор информационной системы | не указано | NOT NULL |
(2-s_system_inf_system)

### Бизнес-правила и ограничения
- Primary Key: id (автоинкремент). (2-s_system_inf_system)
- Foreign Key: service_id -> service.id. (2-s_system_inf_system)
- Foreign Key: inf_system_id -> information_system.id. (2-s_system_inf_system)
- Поля service_id и inf_system_id обязательны (NOT NULL). (2-s_system_inf_system)
