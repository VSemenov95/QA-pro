# Таблица БД кодов отклонений (code_deviation)

> Справочная таблица БД code_deviation, хранящая значения кодов отклонений для ручных событий мониторинга.

### Описание
- Назначение таблицы: хранит справочные значения кодов отклонений для ручных событий мониторинга. (5-code_deviation)
- Название таблицы в документе явно не указано; документ называется «5-code_deviation.pdf». (5-code_deviation)

### Поля и элементы
Структура таблицы (поле / тип / описание / значение по умолчанию / ограничения):
- `id` — тип `uuid`; описание: «Идентификатор кода отклонения»; по умолчанию: «автоинкремент»; ограничения: PK, NOT_NULL. (5-code_deviation)
- `code_deviation` — тип `var(255)` (так указано в документе); описание: «Код отклонения»; по умолчанию: «-» (не задано); ограничения: NOT_NULL, UNIQUE. (5-code_deviation)

### Бизнес-правила и ограничения
- Ключи и индексы: Primery Key (так в документе): `id` (автоинкремент). (5-code_deviation)
- `id`: PK, NOT_NULL. (5-code_deviation)
- `code_deviation`: NOT_NULL, UNIQUE, то есть значения кодов отклонений в таблице не повторяются. (5-code_deviation)

### Открытые вопросы
- Название таблицы в тексте документа не указано. (5-code_deviation)
- Для поля `id` указан тип `uuid` и одновременно значение по умолчанию «автоинкремент». (5-code_deviation)
- Для `code_deviation` указан тип `var(255)`; полное наименование типа (например, varchar) в документе не приведено. (5-code_deviation)
