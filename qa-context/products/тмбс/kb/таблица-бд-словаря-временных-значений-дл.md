# Таблица БД словаря временных значений для вычисляемых атрибутов (dictionary_attribute_unit)

> Таблица БД dictionary_attribute_unit — словарь временных значений (единиц) для вычисляемых атрибутов с полями id и value.

### Описание
- Назначение таблицы: «Словарь временных значений для выч.атрибутов». (2-dictionary_attribute_unit)
- Имя таблицы в тексте фрагмента не указано; название документа: «2-dictionary_attribute_unit.pdf». (2-dictionary_attribute_unit)

### Поля и элементы
- id — тип SERIAL(INT4); описание: «Уникальный идентификатор записи»; ограничение: PK. (2-dictionary_attribute_unit)
- value — тип TEXT; описание: «Наименование единицы»; ограничение: NOT NULL. (2-dictionary_attribute_unit)

### Бизнес-правила и ограничения
- id — первичный ключ (PK). (2-dictionary_attribute_unit)
- value — обязательное поле (NOT NULL). (2-dictionary_attribute_unit)
- Ключи и индексы: Primery Key: id; (2-dictionary_attribute_unit)
