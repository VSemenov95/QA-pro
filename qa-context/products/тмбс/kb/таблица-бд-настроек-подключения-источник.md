# Таблица БД настроек подключения источников к коннектору Астром (data_source_connector_astrom_key)

> Таблица БД data_source_connector_astrom_key хранит настройки подключения источников данных к коннектору Астром и связана с таблицей data_source.

### Описание
- Назначение таблицы: «Хранит настройки подключения источников к коннектору Астром». (2-data_source_connector_astrom_key)
- Название таблицы в тексте фрагмента явно не указано; по имени файла документа — 2-data_source_connector_astrom_key. (2-data_source_connector_astrom_key)

### Поля и элементы
Структура таблицы (поле — тип — описание — ограничения):
- id — SERIAL (INT4) — Уникальный идентификатор записи — PK. (2-data_source_connector_astrom_key)
- data_source_row_id — INT4 — Связь с источником данных — NOT NULL (FK). (2-data_source_connector_astrom_key)
- env_uuid — TEXT — Идентификатор окружения (?) — NULLABLE. (2-data_source_connector_astrom_key)
- host_name — TEXT — Адрес хоста — NULLABLE. (2-data_source_connector_astrom_key)
- offset — INT8 — Смещение для чтения данных? — NULLABLE. (2-data_source_connector_astrom_key)
- step — INT8 — Шаг для обработки данных? — NULLABLE. (2-data_source_connector_astrom_key)
- no_details — BOOLEAN — Признак отсутствия детализации? — NOT NULL, DEFAULT: false. (2-data_source_connector_astrom_key)
- description — TEXT — Описание назначения ключа — NULLABLE. (2-data_source_connector_astrom_key)
- service_name — TEXT — Название — NULLABLE. (2-data_source_connector_astrom_key)
- service_id — TEXT — Идентификатор сервиса — NULLABLE. (2-data_source_connector_astrom_key)
- servie_alias — TEXT — ??? — NULLABLE (в документе написано именно «servie_alias»). (2-data_source_connector_astrom_key)

### Бизнес-правила и ограничения
- Primary Key (в документе написано «Primery Key»): id. (2-data_source_connector_astrom_key)
- Foreign Key: data_source_row_id -> data_source.row_id. (2-data_source_connector_astrom_key)
- Поле data_source_row_id обязательно (NOT NULL). (2-data_source_connector_astrom_key)
- Поле no_details обязательно (NOT NULL), значение по умолчанию false. (2-data_source_connector_astrom_key)
- Остальные поля (env_uuid, host_name, offset, step, description, service_name, service_id, servie_alias) допускают NULL. (2-data_source_connector_astrom_key)
