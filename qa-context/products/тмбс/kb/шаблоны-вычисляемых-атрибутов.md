# Шаблоны вычисляемых атрибутов

> Раздел администрирования «Шаблоны вычисляемых атрибутов» позволяет создавать и вести шаблоны и их группы с переменными и правилами вычисления, а также массово менять статус, удалять и синхронизировать (обновлять) вычисляемые атрибуты, созданные из шаблона, с последующим обновлением карточек монитори

### Описание
- Авторизованный пользователь создаёт, редактирует, удаляет шаблоны вычисляемых атрибутов, задаёт параметры (переменные) и управляет статусами, чтобы многократно использовать типовые расчёты в карточках мониторинга. История: статус «В работе», версия 1 от 08 апр. 2026, автор @Kalinina D.А. (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов)
- Задачи: PPBP-1666, PPBP-1913, PPBP-1915; прототипы Pixso; тест-кейсы PPBP-1922, 1924–1932, 1935–1946, 3191–3196, 3210–3213, 1802, 2175, 3213, 3215, 3216, 3214, 3198 (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов)

### Бизнес-правила и ограничения
- Переменные записываются как ${var_code} без кавычек; для строковых типов (Строка, Массив строк, Тег контрольной точки, Теги контрольных точек) кавычки добавляются автоматически при создании атрибута. Коды уникальны; дубли подсвечиваются (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Шаблон сохраняется при заполненных обязательных полях; список переменных должен совпадать с переменными в правилах вычисления (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов)
- Шаблон удалить нельзя, если есть созданные из него выч.атрибуты. Группу нельзя удалить, если в ней есть шаблоны; название группы уникально (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- «Черновик»: поля редактируются (кроме «Тип атрибута», «Класс»), правила вычисления редактируются, выбор связанных атрибутов недоступен. «Активный»/«Архивный»: недоступно всё, кроме «Статус» (на обеих вкладках); выбор связанных атрибутов доступен. Массовые действия — для «Активный» (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Смена статуса: выпадающий список всех возможных статусов; применяется, если допустим по статусной модели, иначе атрибут пропускается; отмена — окно закрывается, статусы не меняются, возврат на вкладку связанных атрибутов (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Массовое удаление: удаляются выбранные атрибуты шаблона, неудаляемые пропускаются (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Синхронизация: сохранённые значения предзаполнены; новые параметры пусты (или default); удалённые не отображаются; при незаполненных параметрах сохранение блокируется и поля подсвечиваются ошибкой (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- 5.10 (пороги = true; критерий 5.8, все параметры заполнены): обновляются все поля, пороги перезаписываются из шаблона, значения параметров сохраняются, обновляется template_parameters_applied. 5.11 (= false): обновляются все поля, кроме порогов, изменённых вручную при manual_interval_override = true; остальное так же (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- 5.12: «Отменить» — шторка закрывается, изменения не применяются (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов)
- 5.13: при 5.3, 5.6, 5.10 или 5.11 и наличии successIds определяются уникальные monitoringCardRowId карточек в статусе «MONITORING»; для каждого запрос обновления конфигурации без блокировки UI (24-ТМ. Заведение шаблонов _ групп шаблонов вычисляемых атрибутов)
