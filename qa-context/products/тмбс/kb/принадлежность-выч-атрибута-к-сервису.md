# Принадлежность выч. атрибута к Сервису

> Возможность создавать, редактировать, сбрасывать и просматривать принадлежность вычисляемого атрибута к Сервису через селект «Сервис» в карточке выч. атрибута, а также клонировать атрибут вместе с привязкой.

### Описание
- Пользовательская история: «Я как Авторизованный Пользователь. Хочу Иметь возможность создавать, редактировать и просматривать принадлежность Выч. атрибута к Сервису. Для того, чтобы Вычислять атрибуты на основании принадлежности выч. атрибута к конкретному Сервису». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Работы в рамках спецификации: 1) создание принадлежности при создании выч. атрибута (КП 1.0–1.4; PPBP-1799 [US] Реализовать интерфейс со списком сервисов в отдельной вкладке (с поиском по наименованию/коды сервисов и фильтрацией по найденным по доп. атрибутам)); 2) создание при редактировании (КП 2.0–2.4); 3) удаление принадлежности (КП 3.0–3.2); 4) подсказка селекта «Сервис» (КП 4.0); 5) клонирование выч. атрибута с привязкой к сервису (КП 5.0–5.2); 6) поиск в селекте «Сервис» (КП 6.0–6.1; PPBP-2530 [US] Доработка 4-го варианта). (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Работы вне спецификации, допущения и ограничения, бизнес-правила и примечания для Dev/QA, техническое решение (SA): не заполнены. Грумминг (дата «0.03.2026») — ссылка на видео dion.vc. (18-ТМ. Принадлежность выч. атрибута к Сервису)
- История: v1 08 мар. 2026 (PPBP-1742) — первая версия; v2 11 мар. 2026 (PPBP-1863) — макеты, таблица атрибутов п.13.1, сценарий 4.0; v3 01 апр. 2026 (PPBP-1863) — пермиссия на добавление привязки в п. 9, изменены КП 1.3, 1.4, 2.3, 2.4, 3.1, 3.2 (тексты тостов, макеты), в КП 1.4, 2.4, 3.2 удалена подсветка поля «Сервис» на фронте, в п. 13.2 добавлена обработка 403 для GET /api/service/header; v4 26 авг. 2026 (PPBP-2528, артефакты для 4 варианта реализации) — новая таблица атрибутов (код сервиса вместо идентификатора), вывод кода сервиса в селекте, пункт «Поиск в селекте «Сервис»», новый плейсхолдер, новые макеты, новый КП 5 «Клонирование выч атрибута с привязкой к сервису». (18-ТМ. Принадлежность выч. атрибута к Сервису)

### Экраны и навигация
- Создание (5.1): «Карточка мониторинга» (создание/редактирование) → «Вычисляемые атрибуты» → «Создать вычисляемый атрибут» → форма «Создание вычисляемого атрибута», блок «Общие настройки», поле «Сервис» → выбор Сервиса → «Сохранить». При успешной валидации (в т.ч. при наличии разрешения на привязку Сервиса) создаётся выч. атрибут с привязкой; возврат в «Вычисляемые атрибуты», в колонке «Связанный сервис» выбранный Сервис. (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Редактирование (5.2): предусловие — карточка выч. атрибута в статусе «Черновик». «Карточка мониторинга» → «Вычисляемые атрибуты» → выч. атрибут в списке → форма «Редактирование выч. атрибута», «Общие настройки», поле «Сервис» → выбор → «Сохранить»; автоматический возврат в раздел, колонка «Связанный сервис» обновлена. (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Диалог «Клонирование атрибута» (КП 5.0); форма «Карточка создания выч. атрибута» (после клонирования). (18-ТМ. Принадлежность выч. атрибута к Сервису)

### Поля и элементы
- Селект «Сервис» («Общие настройки»): плейсхолдер «Выбрать из списка». Список: Сервисы в рамках цепочки сервисов, для каждого «Наименование Сервиса» и «Код сервиса». После выбора дропдаун закрывается, селект показывает «Наименование Сервиса» и «галку вниз». «Крестик» — сброс значения. (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Колонка «Связанный сервис» в таблице выч. атрибутов: «Наименование Сервиса» и «Код сервиса». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Подсказка у селекта: «Принадлежность вычисляемого атрибута к Сервису». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Диалог «Клонирование атрибута»: текстовое поле «Название»; чек-боксы «Все», «Тип атрибута», «Класс», «Единицы измерения», «Группы», «Описание», «Методика расчета», «Параметры критичности», «метки», «Правила вычисления», «Сервис» (по умолчанию все true); кнопка «Клонировать». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Таблица атрибутов 13.1: селект — name, «Наименование сервиса», string, select, макс. длина «В рамках ширины селекта», обязательность «Нет», default «-», валидация «-»; список селекта — name «Наименование сервиса» и code «Код сервиса» (string, select, «В рамках ширины списка селекта», обязательность «Нет»). Поиск и фильтрация (13.3): «-». (18-ТМ. Принадлежность выч. атрибута к Сервису)

### Бизнес-правила и ограничения
- Редактирование принадлежности — только если карточка в статусе «Черновик». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Права на объект «Сервис» проверяются на бэке; DTO валидируется. (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Пустой список (13.2): при отсутствии Разрешения 1 GET /api/service/header возвращает 403; на FE пустой список селекта «Сервис», ошибка-тост при раскрытии не предусмотрена. (18-ТМ. Принадлежность выч. атрибута к Сервису)
- Поиск в селекте выполняется на FE по «Код сервиса» и «Наименование сервиса». Подсветка поля «Сервис» на фронте в КП 1.4, 2.4, 3.2 удалена. (18-ТМ. Принадлежность выч. атрибута к Сервису)

### API и интеграции
- GET /api/service/header — источник списка Сервисов; без Разрешения 1 — 403. (18-ТМ. Принадлежность выч. атрибута к Сервису)

### Сообщения и ошибки
- КП 1.3: тост «Успешно» / «Вычисляемый атрибут {$"name"} создан». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- КП 1.4: тост «Ошибка» / «Не удалось сохранить вычисляемый атрибут: {$"errorMessage"}». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- КП 2.3 и 3.1: «Успешно» / «Вычисляемый атрибут {$"name"} обновлен». (18-ТМ. Принадлежность выч. атрибута к Сервису)
- КП 2.4 и 3.2: «Ошибка» / «Не удалось обновить вычисляемый атрибут: {$"errorMessage"}». Причина неудачи: нехватка прав (403, нет Разрешения 1). (18-ТМ. Принадлежность выч. атрибута к Сервису)

### Роли и права
- Роль 1: Администратор; ролевая модель применяется для UI и API. Разрешение 1: PPBP_SERVICE_CHANGE_LINK (ID «-»), добавлено в v3. (18-ТМ. Принадлежность выч. атрибута к Сервису)

### Сценарии
- 1.0: Роль 1, SFERA, страница карточки мониторинга, «Вычисляемые атрибуты»; «Создать вычисляемый атрибут» → форма с селектом «Сервис» (плейсхолдер «Выбрать из списка»). Макет PPBP-1690.

- 1.4: нет Разрешения 1 (403) → атрибут не создаётся, тост ошибки. PPBP-1699.

- 2.1: при статусе «Черновик» нажатие на селект → список. PPBP-1691.
- 2.2: выбор Сервиса. PPBP-1692.
- 2.3: «Сохранить» → сохранение, закрытие формы, тост успеха, обновлена колонка. PPBP-1695, PPBP-1698.
- 2.4: 403 → не обновляется, тост ошибки. PPBP-1700.
- 3.0: после КП 1.3 или 2.3 в форме редактирования «крестик» сбрасывает значение, пустой селект с плейсхолдером. PPBP-1693.

- 4.0: наведение на подсказку у селекта «Сервис» → «Принадлежность вычисляемого атрибута к Сервису». PPBP-1697.
- 5.0: на форме «Карточка выч. атрибута» кнопка клонирования → диалог «Клонирование атрибута». Критерии 5.1–5.2, 6.0–6.1 в выдержке не приведены. (18-ТМ. Принадлежность выч. атрибута к Сервису)
