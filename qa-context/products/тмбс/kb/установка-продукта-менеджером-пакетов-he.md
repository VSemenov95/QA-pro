# Установка продукта менеджером пакетов Helm

> Установка продукта «ТМБС» в Kubernetes менеджером пакетов Helm: подготовка инфраструктуры, подключение к репозиторию, переопределение переменных, установка meta-chart и проверка результата.

### Описание
- Установку продукта можно произвести при помощи менеджера пакетов Helm для Kubernetes. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Для установки необходимо подготовить инфраструктуру в соответствии с описанными выше требованиями: развернуть Kafka; развернуть Scylla; развернуть Postgresql; развернуть Redis. После этого можно устанавливать компоненты продукта. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 4.2.15. Интеграция с канальным приложением: реализовать интеграцию согласно инструкции, изложенной в документе «Процесс внесения изменений на контурах КП». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 4.2.16. Пример файла конфигурации и рекомендуемые значения параметров: примеры файла конфигурации соответствуют переменным среды, описанным в предыдущем разделе. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 4.2.17. Проверка корректности установки: правильность установки проверяется вручную через анализ работы микросервисов. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Перед установкой убедиться, что Helm установлен и настроен на нужный кластер Kubernetes. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Если в продукте нет контурозависимых переменных, пункт переопределения переменных (шаг 3) не выполняется. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### API и интеграции
- Репозиторий Helm: https://dist.sfera-t1.ru/app/ppdl-new/api/repo/helm/PPBP-helm-int (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Требуется развёрнутая инфраструктура: Kafka, Scylla, Postgresql, Redis. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Доступ к https://dist.sfera-t1.ru осуществляется по учётной записи (login, password). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Сообщения и ошибки
- Вывод при добавлении репозитория: `PPPM has been added to your repositories`. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Вывод при установке: `Release "name" does not exist. Installing it now.` / `NAME: PPBP` / `LAST DEPLOYED: date` / `NAMESPACE: PPBP` / `STATUS: deployed`. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Сценарии
- 1. Вход в репозиторий продукта Сферы «Сфера: Транзакционный мониторинг бизнес-сервисов» командой: `helm repo add PPPM https://dist.sfera-t1.ru/app/ppdl-new/api/repo/helm/PPBP-helm-int--username login --password 'password'`, где login — имя учётной записи для доступа к https://dist.sfera-t1.ru; password — пароль от учётной записи. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 2. Проверка подключения к репозиторию: `helm search repo PPBP --devel` (при успехе выводится последняя версия опубликованного чарта). Для вывода всех доступных чартов добавить параметр «-l»: `helm search repo PPBP--devel -l`. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 3. Переопределение переменных, зависящих от контура: скачать архив с чартами `https://dist.sfera-t1.ru/app/ppdl-new/api/repo/helm/ PPBP-helm-int/version.tar.gz`, где version — версия продукта; извлечь файл values.yaml из корня архива, открыть и отредактировать, выставив нужные параметры переменным, требующим замены (например, строку подключения к базе данных); полный список переменных и их описание — в разделе 4.2.3; переименовать файл в extra-values.yaml. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 4. Установка продукта с использованием meta-chart: `helm -n namespace upgrade -i PPBP -f extra-values.yaml chart_name --devel --version version`, где namespace — имя namespace в Kubernetes для установки; chart_name — имя чарта (колонка «NAME» вывода команды search, п. 2); version — версия чарта (колонка «CHART VERSION» вывода команды search, п. 2). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- 5. Сохранить файл extra-values.yaml для упрощения дальнейших обновлений продукта. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Проверка корректности установки выполняется вручную (см. 4.2.17). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
