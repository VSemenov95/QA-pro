# Таблица БД вычисляемых атрибутов типа «Полнота» (completeness_computed_attribute)

> Таблица БД completeness_computed_attribute хранит информацию о вычисляемых атрибутах типа «Полнота»: связи с единицей измерений и начальной контрольной точкой, SQL-скрипты расчёта и время ожидания значения.

### Описание
- Назначение таблицы: «Хранит информацию о вычисляемых атрибутах типа "Полнота"». (2-completeness_computed_attribute)
- Название таблицы в тексте фрагмента не указано; имя файла документа — «2-completeness_computed_attribute.pdf». (2-completeness_computed_attribute)

### Поля и элементы
| Название поля | Тип данных | Описание | Ограничения |
|---|---|---|---|
| id | INT4 | Уникальный идентификатор записи | PK |
| unit_id | INT4 | Связь с единицей измерений | NULLABLE (FK) |
| start_point_checkpoint_id | INT4 | Связь с первой (начальной) контрольной точкой | NULLABLE (FK) |
| start_point_script | TEXT | SQL-код для расчета начальной контрольной точки | NULLABLE |
| value_script | TEXT | SQL-код для вычисления значения атрибута | NULLABLE |
| normal_value_timeout | INT4 | Время ожидания значения (в секундах) | NULLABLE |
(2-completeness_computed_attribute)

### Бизнес-правила и ограничения
- Primery Key (так в документе): id. (2-completeness_computed_attribute)
- Foreign Key: unit_id -> dictionary_attribute_unit.id. (2-completeness_computed_attribute)
- Foreign Key: start_point_checkpoint_id -> checkpoint.id. (2-completeness_computed_attribute)
- Все поля, кроме id, допускают NULL (NULLABLE). (2-completeness_computed_attribute)
