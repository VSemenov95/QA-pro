# Таблица БД словаря единиц измерения метрик (dictionary_metric_unit)

> Таблица БД dictionary_metric_unit — словарь единиц измерения (временных значений) для метрик с полями id и value.

### Описание
- Назначение таблицы: Словарь временных значений для метрик. (2-dictionary_metric_unit)

### Поля и элементы
- Структура таблицы (поля: название, тип данных, описание, ограничения): (2-dictionary_metric_unit)
  - `id` — тип SERIAL(INT4); описание: «Уникальный идентификатор записи»; ограничения: PK. (2-dictionary_metric_unit)
  - `value` — тип TEXT; описание: «Наименование единицы»; ограничения: NOT NULL. (2-dictionary_metric_unit)

### Бизнес-правила и ограничения
- Ключи и индексы: Primary Key: id (в документе написано «Primery Key: id;»). (2-dictionary_metric_unit)
- Поле `value` обязательно для заполнения (NOT NULL). (2-dictionary_metric_unit)
