# Таблица БД распределённых вычисляемых значений метрик Сервиса (файл 2-s_{$s}_metric_distributed)

> Таблица БД для хранения распределённых вычисляемых значений метрик Сервиса с обязательными колонками метрики, объекта, времени вставки и uuid-ами транзакций.

### Описание
- Таблица для хранения вычисляемых значений метрик Сервиса. (2-s_{$s}_metric_distributed)
- Название таблицы в тексте фрагмента не указано; оно присутствует только в имени файла «2-s_{$s}_metric_distributed.pdf». (2-s_{$s}_metric_distributed)
- Структура документа (оглавление): «Описание», «Обязательные колонки», «DDL», «Примечание». (2-s_{$s}_metric_distributed)

### Поля и элементы
- Обязательные колонки; в таблице документа есть столбцы «Имя», «Тип», «Описание», значения столбца «Тип» не приведены. (2-s_{$s}_metric_distributed)
- metric_uuid — описание не указано. (2-s_{$s}_metric_distributed)
- metric_id — ID метрики сервиса. (2-s_{$s}_metric_distributed)
- metric_time — время метрики сервиса. (2-s_{$s}_metric_distributed)
- metric_name — имя метрики сервиса. (2-s_{$s}_metric_distributed)
- metric_value — значение метрики сервиса. (2-s_{$s}_metric_distributed)
- metric_period — период расчета метрики сервиса. (2-s_{$s}_metric_distributed)
- metric_object — объект, выбранный запросом метрики для пользовательских нужд. (2-s_{$s}_metric_distributed)
- metric_object_count — количество объектов, выбранных запросом пользователя. (2-s_{$s}_metric_distributed)
- insert_timestamp — время вставки записи в клик. (2-s_{$s}_metric_distributed)
- <tech_attr> — доп. атрибут всех БС, для которых КТ и выч. атрибуты промаркированы как принадлежащие к Сервису. (2-s_{$s}_metric_distributed)
- transaction_uuids — uuid-ы транзакций выч.атрибутов на основании которых посчиталась метрика Сервиса. (2-s_{$s}_metric_distributed)

### Открытые вопросы
- Раздел «DDL» во фрагменте пуст: DDL-скрипт не приведён. (2-s_{$s}_metric_distributed)
- Раздел «Примечание» во фрагменте пуст. (2-s_{$s}_metric_distributed)
- Типы колонок и описание колонки metric_uuid не указаны. (2-s_{$s}_metric_distributed)
- Название таблицы в документе не указано. (2-s_{$s}_metric_distributed)
