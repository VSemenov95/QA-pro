# Представление БД атрибутов вычисляемых атрибутов Сервиса (s_{$s}_attribute_distributed, view)

> Виртуальное представление s_{$s}_attribute_distributed (view), собирающее результаты расчётов вычисляемых атрибутов бизнес-сервисов из вью bs_{$bs}_attribute_distributed с совпадением по service_id.

### Описание
- Виртуальное представление (view), которое собирает результаты расчётов вычисляемых атрибутов бизнес-сервисов из других вью бизнес-сервисов bs_{$bs}_attribute_distributed (view), в рамках которых есть совпадения по service_id. (2-s_{$s}_attribute_distributed (view))
- Название документа: «2-s_{$s}_attribute_distributed (view).pdf». Оглавление: Описание, Колонки, DDL, Примечание. (2-s_{$s}_attribute_distributed (view))

- transaction_type — String — ID БС (2-s_{$s}_attribute_distributed (view))
- transaction_time — DateTime64(3, 'Europe/Moscow') — Время транзакции (2-s_{$s}_attribute_distributed (view))
- transaction_uuid — UUID — uuid транзакции (2-s_{$s}_attribute_distributed (view))
- transaction_attribute_value — Int32 — Вычисляемое значение атрибута (2-s_{$s}_attribute_distributed (view))
- attribute_id — UInt32 — ID атрибута (2-s_{$s}_attribute_distributed (view))
- attribute_name — String — Наименование атрибута (2-s_{$s}_attribute_distributed (view))
- attribute_status — String — Статус атрибута (2-s_{$s}_attribute_distributed (view))
- attribute_threshold_type — String — Значение threshold согласно настроенным интервалам (2-s_{$s}_attribute_distributed (view))
- unit — String — Единица измерения значения (2-s_{$s}_attribute_distributed (view))
- transaction_events_count — UInt16 — Количество событий транзакции, на которых расчитан атрибут (2-s_{$s}_attribute_distributed (view))

- <tech_attr> — Array — Дополнительный тех. атрибут, выбранный пользователем для переноса данных событий в таблицу атрибутов (2-s_{$s}_attribute_distributed (view))
