# Переключение формата общения между микросервисами и формата записи в ClickHouse

> Процедура переключения формата общения микросервисов ТМБС (JSON/AVRO) и формата записи данных в ClickHouse с перечнем переменных окружения, сжатия и затрагиваемых таблиц.

### Описание
- Для перевода из бинарного формата общения сервисов в json и наоборот нужно выполнить шаги сценария ниже. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Бизнес-правила и ограничения
- Переключение формата записи в ClickHouse: для применения/смены параметра необходимо также сменить соответствующий параметр в админ-сервисе с пересозданием kafka-engine в clickhouse для realms: ATTRIBUTE, TIMEOUT_ATTRIBUTE. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Realm — это набор сущностей в clickhouse (ATTRIBUTE: bs__attribute, bs__attribute_queue, bs__attribute_mv, bs__attribute_distributed). (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Перед переключением формата необходимо пересоздать таблицы CH. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### API и интеграции
- Таблица 4.2.20-1 «Микросервисы и переменные для переключения бинарного формата общения» (столбцы: переменная для переключения входящего потока; переменная для переключения исходящего потока; переменная для установки сжатия). Для всех микросервисов переменная сжатия: TM_KAFKA_PRODUCER_COMPRESSIONTYPE: [none|gzip|snappy|lz4|zstd], default: none - без сжатия. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
  - ppbp-event-collector-kafka: входящий — «-»; исходящий — TM_KAFKA_TOMSSENDER_FORMAT: [JSON|AVRO].
  - ppbp-preprocessor-service: входящий — TM_KAFKA_LISTENER_FORMAT: [JSON|AVRO]; исходящий — TM_KAFKA_TOMSSENDER_FORMAT: [JSON|AVRO].
  - ppbp-enrichment-service: входящий — TM_KAFKA_LISTENER_FORMAT: [JSON|AVRO]; исходящий — TM_KAFKA_TOMSSENDER_FORMAT: [JSON|AVRO].
  - ppbp-merging-transactions-service: входящий — TM_KAFKA_LISTENER_FORMAT: [JSON|AVRO]; исходящий — TM_KAFKA_TOMSSENDER_FORMAT: [JSON|AVRO].
  - ppbp-online-metrics-service: входящий — TM_KAFKA_LISTENER_FORMAT: [JSON|AVRO]; исходящий — «-».
- Таблица 4.2.20-2 «Микросервисы и переменные» (запись в ClickHouse). Переменная сжатия у обоих: TM_KAFKA_PRODUCER_COMPRESSIONTYPE: [none|gzip|snappy|lz4|zstd], default: none - без сжатия. Переменная переключения формата данных у обоих: TM_KAFKA_TOCLICKSENDER_FORMAT: {JSON|AVRO]. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
  - ppbp-online-metrics-service: топик bs_*_clickhouse_attributes; таблицы bs_*_attribute, bs_*_attribute_distributed, bs_*_attribute_mv.
  - ppbp-timeout-attribute-service: топик bs_*_clickhouse_timeout_attributes; таблицы bs_*_timeout_attribute, bs_*_timeout_attribute_distributed, bs_*_timeout_attribute_mv.

### Сценарии
- Переключение формата общения сервисов: 1) Поменять переменную для переключения входящего потока (если есть). 2) Рестартнуть сервис. 3) Поменять переменную для переключения исходящего потока. 4) Рестартнуть сервис. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
- Переключение формата записи в ClickHouse: пересоздать таблицы CH, сменить соответствующий параметр в админ-сервисе с пересозданием kafka-engine для realms ATTRIBUTE, TIMEOUT_ATTRIBUTE. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
