# Строковый вычисляемый атрибут

> Строковый вычисляемый атрибут — тип вычисляемого атрибута карточки мониторинга, который возвращает текстовое значение по SQL-коду и поддерживает создание, редактирование, удаление, клонирование, отладку, просмотр в сводке и привязку к ручному событию мониторинга.

### Описание
- Пользовательская история: «Я как Авторизованный Пользователь Хочу Иметь возможность создавать, редактировать и просматривать вычисляемый атрибут типа "Строковый" Для того, чтобы Возвращать текстовые значения при расчете». (5-ТМ. Строковый вычисляемый атрибут)
- История изменений: №1, 05 мая 2026, @Kalinina D.А., задача PPBP-2025 [BA] «Аналитика по функионалу "выч. атрибут, возвращающий строковое значение"»: «Создана первая версия документа». Связанный документ: Техническое решение (SA) — «Готово» (ссылки нет). (5-ТМ. Строковый вычисляемый атрибут)
- Задача PPBP-2020 «Реализовать выч. атрибут, возвращающий строковое значение»; работы: 1 Создание (1.0–1.3); 2 Редактирование (2.0–2.2); 3 Удаление (3.0); 4 Клонирование (4.0–4.1); 5 Отладка (5.0–5.3); 6 Просмотр в сводке (6.0); 7 Связь события мониторинга с выч. атрибутом по полю «Рассчитывать по» (7.0–7.1). Разделы «Контекст», «Пользовательский путь», «Работы вне спецификации», «Допущения и ограничения», «Бизнес-правила», «Примечания для Dev/QA» пусты. (5-ТМ. Строковый вычисляемый атрибут)

### Бизнес-правила и ограничения
- 1.1: форма перестраивается при выборе типа «Строковый». (5-ТМ. Строковый вычисляемый атрибут)
- 1.2: при успешном создании форма закрывается, в таблице появляется запись, в колонке «Тип» — «Строковый», отображается тост об успехе. (5-ТМ. Строковый вычисляемый атрибут)
- 2.1: при сохранении валидируются данные DTO. (5-ТМ. Строковый вычисляемый атрибут)
- 3.0: удаление и 4.1: клонирование — как для выч. атрибутов других типов. (5-ТМ. Строковый вычисляемый атрибут)
- 4.0: форма выбора полей для клонирования: Все; Тип атрибута; Описание; Группы; Класс; Методика расчета; Правила вычисления. (5-ТМ. Строковый вычисляемый атрибут)
- Отладка 5.1–5.3: SQL возвращает строку; максимум задаётся параметром STRING_ATTRIBUTE_MAX_VALUE_LENGHT (в названии 5.1: «длина вычисленного значения ≤ 256»). Длина ≤ лимита — отображается вычисленная строка (stringValue); больше — сообщение об ошибке; синтаксически неверный SQL — стандартное сообщение об ошибке выполнения запроса. (5-ТМ. Строковый вычисляемый атрибут)
- 6.0: в «Сводке» отображаются выч. атрибуты типов «Строковый», «Общий», «Полнота», «С ожиданием по времени». (5-ТМ. Строковый вычисляемый атрибут)
- 7.0: список «Рассчитывать по» показывает все объекты карточки (метрики, выч. атрибуты), включая строковые. 7.1: после выбора и «Сохранить» событие сохраняется, в колонке «Рассчитывать по» списка событий — название строкового выч. атрибута. (5-ТМ. Строковый вычисляемый атрибут)

### API и интеграции
