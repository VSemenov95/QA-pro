# Таблица БД атрибутов фильтрации контрольной точки (filtering_attribute)

> Таблица БД filtering_attribute хранит атрибуты, задействованные в фильтрации внутри контрольной точки, и связана с карточкой мониторинга через mc_row_id.

### Описание
- Назначение таблицы: хранит атрибуты, задействованные в фильтрации внутри контрольной точки. (2-filtering_attribute)
- Название таблицы в тексте фрагмента не указано; имя документа: «2-filtering_attribute.pdf». (2-filtering_attribute)

### Поля и элементы
Структура таблицы (название поля, тип данных, описание, ограничения):
- id — SERIAL(INT4) — Уникальный идентификатор записи — PK. (2-filtering_attribute)
- entity_id — INT4 — Идентификатор сущности — NULLABLE. (2-filtering_attribute)
- name — VARCHAR(255) — Название атрибута — NULLABLE. (2-filtering_attribute)
- is_filtering — BOOLEAN — Используется ли атрибут для фильтрации — NOT NULL, DEFAULT: false. (2-filtering_attribute)
- attribute_type — VARCHAR(255) — Тип атрибута — NULLABLE. (2-filtering_attribute)
- mc_row_id — INT8 — Связь с карточкой мониторинга — NOT NULL. (2-filtering_attribute)
- is_reuired — BOOLEAN — Обязательность — NULLABLE (название поля приведено в документе дословно, с написанием «is_reuired»). (2-filtering_attribute)

### Бизнес-правила и ограничения
- id: первичный ключ. (2-filtering_attribute)
- is_filtering: NOT NULL, значение по умолчанию false. (2-filtering_attribute)
- mc_row_id: NOT NULL. (2-filtering_attribute)
- entity_id, name, attribute_type, is_reuired: NULLABLE. (2-filtering_attribute)
- Ключи и индексы: Primery Key: id (написание «Primery» дословно из документа). Других ключей и индексов во фрагменте не указано. (2-filtering_attribute)
