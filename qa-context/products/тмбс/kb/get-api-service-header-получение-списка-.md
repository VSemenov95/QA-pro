# GET /api/service/header — получение списка Сервисов

> Метод GET /api/service/header возвращает список Сервисов ТМБС с привязанными к ним Бизнес-сервисами; необязательный параметр mcId передаётся в заголовке.

### Описание
- URL: /api/service/header; метод HTTP: GET; наименование метода: «Получение списка Сервисов»; ссылка на swagger: - (GET _api_service_header-6)
- История изменений: 1.0, @Perekin D.С., 26 февр. 2026, «Создание странциы», задача PPBP-1742 [Аналитика] ТМБС. Сервисы. Передача метрик из ТМБС в ЗСМ в привязке к сервисам с агрегирующим расчетом на строне ТМБС; 1.1, 10 мар. 2026, «Изменение ручки: Исправлен DTO ответа; Добавлен необязательный атрибут запроса в хедере {mcId}», PPBP-1742; 1.2, 11 мар. 2026, «добавлен атрибут "code" в DTO ответа», PPBP-1863 [Аналитика] ТМБС. Сервисы. Передача метрик из ТМБС в ЗСМ в привязке к сервисам с агрегирующим расчетом на строне ТМБС ч2; 1.3, 10 апр. 2026, «Добавлен раздел "Разрешения"», PPBP-1905 [SA] ТМБС. Конфигурирование метрики сервиса (GET _api_service_header-6)

### Поля и элементы
- Входные параметры: authorization — string, JWT (token) пользователя, расположение: header, обязательный: + (GET _api_service_header-6)
- Входные параметры: mcId — int64, Идентификатор Карточки мониторинга, расположение: header, обязательный: -, значение по умолчанию: -, пример: 1851 (GET _api_service_header-6)
- Выходные параметры: content — object, обязательный: - (GET _api_service_header-6)
- id — int32, Идентификатор Сервиса, обязательный: +, пример: 4206 (GET _api_service_header-6)
- extServiceId — string, Внешний идентификатор Сервиса, обязательный: +, пример: CI3008588 (GET _api_service_header-6)
- code — string, Код Сервиса, обязательный: +, пример: SRV-88 (GET _api_service_header-6)
- name — string, Наименование сервиса, обязательный: +, пример: Сервис (GET _api_service_header-6)
- businessService — object, Массив связанных Бизнес-сервисов, обязательный: + (GET _api_service_header-6)
  - BSId — int32, Внутренний идентификатор БС, обязательный: +, пример: 3950 (GET _api_service_header-6)
  - name — string, Наименование БС, обязательный: +, пример: Бизнес-сервис (GET _api_service_header-6)
  - extBSId — string, Внешний идентификатор БС, обязательный: +, пример: CI0652123 (GET _api_service_header-6)

### Бизнес-правила и ограничения
- Логика работы, если {mcId} не передаётся: 1) в таблице config_service.service в колонке "id" получить идентификатор сервиса; 2) если для данного объекта сервиса в таблице config_service.s_system_bs_system есть связка с бизнес-сервисом, объект должен попадать в DTO ответа по ручке; 3) иначе, если совпадений в config_service.s_system_bs_system нет, объект в итоговую выборку DTO не попадает (GET _api_service_header-6)
- Логика работы, если {mcId} передаётся: в документе указан только заголовок «Передаем {mcId}», описание шагов отсутствует (GET _api_service_header-6)

### API и интеграции
- Способ авторизации: JWT (token) пользователя (GET _api_service_header-6)
- http-статус коды в ответе: 200 (GET _api_service_header-6)
- Пример запроса: 'https://trmonbs-admin-service.ppmon.dev.sfera-t1.ru/api/service/header/{mcId}' (GET _api_service_header-6)
- Пример ответа: массив [{"id":4206,"extServiceId":"CI3008588","сode":"SRV-88","name":"Наименование Сервиса","businessService":[{"BSId":3950,"name":"Наименование Бизнес-сервиса 1","extBSId":"CI0652123"},{"BSId":3951,"name":"Наименование Бизнес-сервиса 2","extBSId":"CI0652123"}]}] (GET _api_service_header-6)

### Сообщения и ошибки
- Обработка ошибок: 400, 403, 409, 423, 500 (GET _api_service_header-6)

### Роли и права
- Роли: Администратор (GET _api_service_header-6)
- Разрешение: PPBP_SERVICE_READ (ссылка: Сервис) (GET _api_service_header-6)

### Открытые вопросы
- Не описана логика при переданном {mcId}; в примере запроса mcId указан в пути URL, а во входных параметрах — в header; в примере ответа ключ «сode» (возможно кириллическая «с»), в таблице — «code»; в описании выходных параметров content — object, а в примере ответ — массив без обёртки content (GET _api_service_header-6)
