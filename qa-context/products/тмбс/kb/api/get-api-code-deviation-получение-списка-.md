# GET /api/code-deviation/ — получение списка справочных значений кодов отклонений для ручных событий мониторинга

> Метод GET /api/code-deviation/ возвращает администратору список справочных значений кодов отклонений (id и code) для ручных событий мониторинга.

### Описание
- Метод: «Получение списка справочных значений кодов отклонений для ручных событий мониторинга». URL*: /api/code-deviation/. Метод HTTP*: GET. Способ авторизации*: JWT (token) пользователя. (4-GET _api_code-deviation_)
- Ссылка на swagger: https://trmonbs-admin-service.ppmon.test.sfera-t1.ru/swagger-ui/index.html#/MonitoringEventController (4-GET _api_code-deviation_)
- Оглавление страницы: Описание метода, История изменений, Входные параметры, Пример запроса, Выходные параметры, Пример ответа, Логика работы. Раздел «Логика работы» указан в оглавлении и как заголовок, но текста в нём нет. (4-GET _api_code-deviation_)

### Поля и элементы
**Входные параметры**
- authorization: тип string; описание «JWT (token) пользователя»; расположение header; обязательный: «+»; значение по умолчанию: «-»; пример: «-». (4-GET _api_code-deviation_)

**Выходные параметры** (обязательность и значение по умолчанию для обоих — «-»)
- id: тип uuid; «Идентификатор кода отклонения»; пример в таблице: 1. (4-GET _api_code-deviation_)
- code: тип string; «Код отклонения события мониторинга»; пример: ШВ-1234. (4-GET _api_code-deviation_)

### API и интеграции
- Пример запроса: GET https://trmonbs-admin-service.ppmon.dev.sfera-t1.ru/api/code-deviation/ (4-GET _api_code-deviation_)
- Ответ — массив объектов с полями id и code. Пример ответа: [{"id": "c86cb707-b4cc-4d54-8d1d-e984648828ee","code": "ШВ-1234"},{"id": "c86cb707-b4cc-4d54-8d1d-e984648828ff","code": "ГП-1234"}] (4-GET _api_code-deviation_)

### Сообщения и ошибки
- Обрабатываемые ошибки*: 400, 403, 409, 423, 500. (4-GET _api_code-deviation_)
- http-статус коды в ответе: 200. (4-GET _api_code-deviation_)

### Роли и права
- Роли*: Администратор. Авторизация: JWT (token) пользователя. (4-GET _api_code-deviation_)
