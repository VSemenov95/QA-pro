- Предусловия: SFERA_AUDIT_ENABLED = true, SFERA_AUDIT_TRANSPORT_MODE=KAFKA, SFERA_AUDIT_KAFKA_TOPIC=audit-event; существует карточка мониторинга с известным mcId, например, 211296.

- Отправить POST {{baseURL}}/api/checkpoints/attributes/{mcId}; ожидается «Статус Код 200 ОК».
- Проверить в Kafka сообщения PPBP_CHECKPOINT_UPDATE_MONITORING_CARD_ATTRIBUTES со status=START и SUCCESS; ожидается их присутствие в топике audit-event.
- Тест имеет статус «Успешен», дата 24.09.2026 21:04:03; у шагов указано «Нет результата».
