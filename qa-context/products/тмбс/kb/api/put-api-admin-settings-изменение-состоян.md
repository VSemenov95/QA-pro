# PUT /api/admin-settings/ — изменение состояний для глобальных интеграционных настроек

> Метод PUT /api/admin-settings/ позволяет администратору изменять глобальные признаки отправки отклонений, событий мониторинга и метрик БС во внешние системы.

### Описание
- Наименование метода: «Изменение состояний для глобальных интеграционных настроек». Метод изменяет глобальные признаки отправки отклонений, событий мониторинга и метрик БС во внешние системы. (3-PUT _api_admin-settings_)
- Оглавление документа: Описание метода, История изменений, Входные параметры, Пример запроса, Выходные параметры, Пример ответа, Логика работы. (3-PUT _api_admin-settings_)
- Раздел «Логика работы» в предоставленном фрагменте не содержит текста (приведён только заголовок и пример ответа). (3-PUT _api_admin-settings_)
- История изменений: версия 1.0, автор @Perekin D.С., дата 04 мая 2026, описание изменений «Создание страницы», номер задачи не указан. (3-PUT _api_admin-settings_)

### Поля и элементы
- Входные параметры:
  - authorization — string, JWT (token) пользователя, расположение: header, обязательный: +, значение по умолчанию: не указано.
  - sendDeviation — boolean, глобальный признак отправки отклонений во внешние системы, расположение: body, обязательный: +, значение по умолчанию: false.
  - sendMonitoringEvents — boolean, глобальный признак отправки событий мониторинга во внешние системы, расположение: body, обязательный: +, значение по умолчанию: false.
  - sendMetric — boolean, глобальный признак отправки метрик БС во внешние системы, расположение: body, обязательный: +, значение по умолчанию: false. (3-PUT _api_admin-settings_)
- Выходные параметры (все обязательные: +, по умолчанию false):
  - sendDeviation — boolean, глобальный признак отправки отклонений во внешние системы.
  - sendMonitoringEvents — boolean, глобальный признак отправки событий мониторинга во внешние системы.
  - sendMetric — boolean, глобальный признак отправки метрик БС во внешние системы. (3-PUT _api_admin-settings_)
