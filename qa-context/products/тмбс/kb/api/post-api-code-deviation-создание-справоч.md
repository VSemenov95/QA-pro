# POST /api/code-deviation/ — создание справочных значений кодов отклонений для ручных событий мониторинга

> Метод POST /api/code-deviation/ создаёт справочные значения кодов отклонений для ручных событий мониторинга; доступен только роли Администратор, авторизация по JWT.

### Описание
- URL: /api/code-deviation/; метод HTTP: POST; наименование: Создание справочных значений кодов отклонений для ручных событий мониторинга. (6-POST _api_code-deviation_)
- Способ авторизации: JWT (token) пользователя. (6-POST _api_code-deviation_)
- Ссылка на swagger: https://trmonbs-admin-service.ppmon.test.sfera-t1.ru/swagger-ui/index.html#/MonitoringEventController (6-POST _api_code-deviation_)
- Оглавление страницы: Описание метода, История изменений, Входные параметры, Пример запроса, Выходные параметры, Пример ответа, Логика работы. (6-POST _api_code-deviation_)
- История изменений: версия 1.0, автор @Perekin D.С., 08 июл. 2026, «Создание страницы», задача PPBP-2280 [Аналитика] ТМБС. Отправка отклонений в сторонние системы по требованиям второй поставки; версия 1.1, автор @Perekin D.S., 27 июл. 2026, «Изменен тип данных для ИД кода отклонения, изменен нейминг атрибута 'codeDeviation' на 'code'». (6-POST _api_code-deviation_)

### Поля и элементы
- Входной параметр authorization: string; «JWT (token) пользователя»; header; обязательный: +; значение по умолчанию: -; пример: -. (6-POST _api_code-deviation_)
- Входной параметр code: array<string>; «Код отклонения события мониторинга»; body; обязательный: +; значение по умолчанию: -; пример: ШВ-1234. (6-POST _api_code-deviation_)
- Выходной параметр id: string; «Идентификатор кода отклонения»; обязательность и значение по умолчанию: -; пример: c86cb707-b4cc-4d54-8d1d-e984648828ee. (6-POST _api_code-deviation_)
- Выходной параметр code: string; «Код отклонения события мониторинга»; обязательность и значение по умолчанию: -; пример: ШВ-1234. (6-POST _api_code-deviation_)

### Бизнес-правила и ограничения
- Метод доступен только роли Администратор. (6-POST _api_code-deviation_)
- Авторизация по JWT (token) пользователя, передаётся в заголовке authorization. (6-POST _api_code-deviation_)
- Параметр code (массив строк) передаётся в теле запроса и обязателен. (6-POST _api_code-deviation_)

### API и интеграции
- POST /api/code-deviation/ — сервис trmonbs-admin-service, контроллер MonitoringEventController. (6-POST _api_code-deviation_)
- Пример ответа из раздела «Пример ответа» (без id): [{"code":"ШВ-1234"},{"code":"ГП-1234"}] (6-POST _api_code-deviation_)
- Пример из раздела «Логика работы» (с id): [{"id":"c86cb707-b4cc-4d54-8d1d-e984648828ee","code":"ШВ-1234"},{"id":"c86cb707-b4cc-4d54-8d1d-e984648828ff","code":"ГП-1234"}] (6-POST _api_code-deviation_)

### Сообщения и ошибки
- Обрабатываемые коды ошибок: 400, 403, 409, 423, 500. (6-POST _api_code-deviation_)
- Успешный ответ: http-статус 200. (6-POST _api_code-deviation_)
- Тексты сообщений об ошибках в документе не приведены. (6-POST _api_code-deviation_)

### Роли и права
- Администратор. (6-POST _api_code-deviation_)

### Открытые вопросы
- Раздел «Пример запроса» пуст. (6-POST _api_code-deviation_)
- В разделе «Логика работы» приведён только JSON-пример ответа, текстового описания логики нет. (6-POST _api_code-deviation_)

### Расхождения между документами
- Пример ответа в разделе «Пример ответа» не содержит поле id, хотя в выходных параметрах id описан; в разделе «Логика работы» пример содержит id. (6-POST _api_code-deviation_)
