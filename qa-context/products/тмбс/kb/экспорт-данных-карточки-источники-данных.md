# Экспорт данных карточки (источники данных, вычисляемые атрибуты, метрики, БС, карточки мониторинга)

> Экспорт в формате JSON источников данных, вычисляемых атрибутов, метрик, бизнес-сервисов и карточек мониторинга для переноса объектов между средами (например, из «песочницы» на прод) при наличии специального разрешения.

### Описание
- Пользовательская история: «Я как Пользователь системы хочу иметь возможность экспортировать Источники данных, Вычисляемые атрибуты, Метрики, БС и Карточки мониторинга для того, чтобы переносить объекты из одной среды в другую для дальнейшей работы с ними». (9-Экспорт данных карточки )
- Контекст: пользователи часто редактируют объекты в некой «песочнице» и впоследствии переносят результаты своей работы на прод-среду вручную. Чтобы упростить процесс, реализуется механизм импорта и экспорта данных посредством их выгрузки и загрузки из одной среды в другую. (9-Экспорт данных карточки )
- Выгрузка объектов происходит в формате JSON. (9-Экспорт данных карточки )
- Экспортировать возможно: Карточки мониторинга, Источники данных, Метрики, Вычисляемые атрибуты, Бизнес-сервисы. (9-Экспорт данных карточки )

### Экраны и навигация
- Выгрузка выполняется со страниц источников данных / вычисляемых атрибутов / метрик / БС. (9-Экспорт данных карточки )
- Таблица выгруженных файлов находится в пункте «Администрирование - Загрузки». (9-Экспорт данных карточки )

### Поля и элементы
- Чекбоксы для выбора нужных объектов для выгрузки. (9-Экспорт данных карточки )
- Кнопка «Экспорт». (9-Экспорт данных карточки )

### Бизнес-правила и ограничения
- Экспорт возможен только при наличии специального разрешения; если разрешения нет, выгрузка данных невозможна. (9-Экспорт данных карточки )
- Все объекты, кроме «карточки мониторинга», поддерживают множественную выгрузку. (9-Экспорт данных карточки )
- Для export_item=monitoring_card допускается только один object_id; для остальных export_item поддерживается массив object_id. (9-Экспорт данных карточки )
- Поля с NULL значениями включаются в ответ как null. (9-Экспорт данных карточки )
- Данные выгружаются «как есть» (без изменений). (9-Экспорт данных карточки )
- Все таблицы возвращаются на одном уровне вложенности с полными названиями. (9-Экспорт данных карточки )
- Если для таблицы нет данных, возвращается пустой массив []. (9-Экспорт данных карточки )
- Все экспортируемые файлы логгируются и записываются в таблицу в пункте «Администрирование - Загрузки». (9-Экспорт данных карточки )

### API и интеграции
- GET api/export (в разделе 4 «Подробное описание таблиц, параметров и логики выгрузки» указан только этот метод). (9-Экспорт данных карточки )
- Параметры запроса: export_item (например, monitoring_card) и object_id (один идентификатор для monitoring_card, массив для остальных export_item). (9-Экспорт данных карточки )

### Роли и права
- Для выгрузки требуется специальное разрешение; без него выгрузка невозможна. (9-Экспорт данных карточки )

### Сценарии
- Критерий приёмки 1: ЕСЛИ пользователь находится на странице источников данных/вычисляемых атрибутов/метрик/бс И имеет разрешение на выгрузку, КОГДА выбирает нужные объекты чекбоксами И нажимает «Экспорт», ТОГДА выгружается информация по выбранным вычисляемым атрибутам в формате JSON. (9-Экспорт данных карточки )

### Открытые вопросы
- Раздел 4 содержит только заголовок «GET api/export»; описание таблиц, параметров и логики выгрузки отсутствует. (9-Экспорт данных карточки )
- Название специального разрешения на выгрузку не указано. (9-Экспорт данных карточки )
- Критерий приёмки описан только для вычисляемых атрибутов, хотя условие перечисляет также источники данных, метрики и БС; для карточек мониторинга критерии не приведены. (9-Экспорт данных карточки )
