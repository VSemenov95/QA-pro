# Контрольная точка: статусная модель и переходы между статусами

> Статусная модель контрольной точки (КТ) в карточке мониторинга: семь статусов, автоматические и ручные переходы между ними и разрешения на ручные переходы.

### Описание
- Документ описывает статусную модель контрольной точки (КТ) в карточке мониторинга (КМ): список статусов, переходы между ними с комментариями и разрешения на переходы. (25-Контрольная точка)
- Статусы КТ: DRAFT("DRAFT", "Черновик"), IN_ANALYSIS("IN_ANALYSIS", "В анализе"), IN_WORK("IN_WORK", "В работе"), CONNECTED("CONNECTED", "Подключено"), MONITORING("MONITORING", "На мониторинге"), DISCONNECTED("DISCONNECTED", "Отключено"), DISCONNECTED_MANUAL("DISCONNECTED_MANUAL", "Отключено вручную"). (25-Контрольная точка)
- В документе указано: «Статусы и на текущий момент не используются». В тексте пропущены названия статусов (на схеме подписаны «В работе» и «В анализе»); по-видимому, речь о статусах «В анализе» и «В работе». (25-Контрольная точка)

### Бизнес-правила и ограничения
- Статус «Черновик»: пользователь создаёт КТ в КМ. Статус является инициирующим. Все КТ первоначально создаются только в статусе «Черновик». (25-Контрольная точка)
- В статусе «Черновик» пользователь не может поставить КТ на мониторинг. «Черновик» — единственный статус для внесения изменений в КТ. (25-Контрольная точка)
- Черновик → Подключено: когда пользователь считает, что КТ готова к мониторингу, он переводит её из «Черновик» в «Подключено». (25-Контрольная точка)
- Черновик → Отключено вручную: если пользователь понимает, что созданная им КТ не готова к постановке на мониторинг, он может перевести КТ в «Отключено вручную». (25-Контрольная точка)
- Черновик → В анализе; В анализе → Черновик; В анализе → В работе; В работе → В анализе; В работе → Подключено: переходы указаны в таблице без комментариев (статусы, по документу, не используются). (25-Контрольная точка)
- Статус «Подключено»: в нём пользователь может поставить КТ на мониторинг. (25-Контрольная точка)
- Подключено → Отключено вручную: при создании или редактировании КМ пользователь может отключить выбранную КТ. (25-Контрольная точка)
- Подключено → На мониторинге: при постановке КМ на мониторинг целевой статус присваивается КТ автоматически, совместно с постановкой КМ на мониторинг. (25-Контрольная точка)
- Подключено → Черновик: при создании или редактировании КМ пользователь может изменить состояние КТ, чтобы внести необходимые коррективы; для этого переводит КТ из «Подключено» в «Черновик». (25-Контрольная точка)
- Статус «Отключено вручную» необходим для отключения КТ. Он не меняется для КТ при постановке КМ на мониторинг; статус остаётся неизменным. (25-Контрольная точка)
- Отключено вручную → Черновик: при создании или редактировании КМ пользователь может принять решение о необходимости внесения изменений в КТ и переводит её в статус (в документе указано «Отключено вручную» — вероятно, опечатка, целевой статус по таблице «Черновик»). (25-Контрольная точка)
- Отключено вручную → Подключено: при создании или редактировании КМ пользователь может принять решение о включении ранее отключённой КТ и переводит её в «Подключено». (25-Контрольная точка)
- Статус «На мониторинге» отображается автоматически при постановке КМ на мониторинг функцией «Поставить на мониторинг». (25-Контрольная точка)
- На мониторинге → Подключено: при переводе КМ в статус черновика все КТ автоматически переводятся в «Подключено». Этот статус используется, чтобы подготовить КТ к постановке на мониторинг. (25-Контрольная точка)
- На мониторинге → Черновик: комментарий в документе не указан. (25-Контрольная точка)
- На мониторинге → Отключено: при отключении КМ функцией «Снять с мониторинга» все КТ данной КМ приобретают статус «Отключено». (25-Контрольная точка)
- Статус «Отключено» отображается автоматически при отключении КМ функцией «Снять с мониторинга». (25-Контрольная точка)
- Отключено → На мониторинге: при постановке ранее отключённой КМ функцией «Поставить на мониторинг» все КТ КМ переходят в «На мониторинге». (25-Контрольная точка)
- Отключено → Подключено; Отключено → Черновик: комментарии в документе не указаны. (25-Контрольная точка)

### API и интеграции
- Разрешения на переходы, заданные соответствием StatusChanging(из статуса, в статус) → Permission: (25-Контрольная точка)
  - DRAFT → IN_ANALYSIS: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DRAFT_TO_INANALYSIS
  - DRAFT → CONNECTED: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DRAFT_TO_CONNECTED
  - IN_ANALYSIS → DRAFT: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_INANALYSIS_TO_DRAFT
  - IN_ANALYSIS → IN_WORK: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_INANALYSIS_TO_INWORK
  - IN_WORK → IN_ANALYSIS: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_INWORK_TO_INANALYSIS
  - IN_WORK → CONNECTED: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_INWORK_TO_CONNECTED
  - CONNECTED → DRAFT: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_CONNECTED_TO_DRAFT
  - MONITORING → DRAFT: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_MONITORING_TO_DRAFT
  - MONITORING → DISCONNECTED: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_MONITORING_TO_DISCONNECTED
  - DISCONNECTED → CONNECTED: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DISCONNECTED_TO_CONNECTED
  - DISCONNECTED → DRAFT: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DISCONNECTED_TO_DRAFT
  - DRAFT → DISCONNECTED_MANUAL: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DRAFT_TO_DISCONNECTEDMANUAL
  - CONNECTED → DISCONNECTED_MANUAL: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_CONNECTED_TO_DISCONNECTEDMANUAL
  - DISCONNECTED_MANUAL → DRAFT: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DISCONNECTEDMANUAL_TO_DRAFT
  - DISCONNECTED_MANUAL → CONNECTED: PPBP_CHECKPOINT_STATUS_CHANGE_FROM_DISCONNECTEDMANUAL_TO_CONNECTED
- В списке разрешений нет переходов CONNECTED → MONITORING, DISCONNECTED → MONITORING, MONITORING → CONNECTED (в таблице они описаны как автоматические при действиях над КМ). (25-Контрольная точка)

### Роли и права
- Каждый ручной переход между статусами КТ требует разрешения вида PPBP_CHECKPOINT_STATUS_CHANGE_FROM_<ИЗ>_TO_<В>. (25-Контрольная точка)

### Сценарии
- Создание КТ: создаётся в КМ в «Черновик» → пользователь переводит в «Подключено» → при постановке КМ на мониторинг КТ автоматически получает «На мониторинге». (25-Контрольная точка)
- «Снять с мониторинга»: все КТ КМ переходят в «Отключено»; при повторной «Поставить на мониторинг» — в «На мониторинге». (25-Контрольная точка)
- Перевод КМ в черновик: все КТ автоматически переходят в «Подключено». (25-Контрольная точка)
- Ручное отключение КТ: из «Черновик» или «Подключено» → «Отключено вручную»; возврат — в «Подключено» (или «Черновик»). (25-Контрольная точка)

### Открытые вопросы
- Статусы «В анализе» и «В работе» не используются, хотя переходы и разрешения для них описаны. (25-Контрольная точка)
- Для части переходов (На мониторинге → Черновик, Отключено → Подключено, Отключено → Черновик и др.) комментарий не указан. (25-Контрольная точка)
- В описании перехода «Отключено вручную → Черновик» целевой статус назван «Отключено вручную» (вероятная опечатка). (25-Контрольная точка)
