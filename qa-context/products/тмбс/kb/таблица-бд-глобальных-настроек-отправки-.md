# Таблица БД глобальных настроек отправки во внешние системы (название таблицы в документе не указано; файл 5-admin_settin

> Таблица БД с глобальными настройками отправки отклонений, событий мониторинга и метрик во внешние системы (название таблицы в документе не указано).

### Описание
- Назначение таблицы: хранит глобальные настройки для отправки отклонений, событий мониторинга, метрик во внешние системы. (5-admin_settings)
- Название таблицы в документе не указано (файл 5-admin_settings.pdf). (5-admin_settings)

### Поля и элементы
Структура таблицы (поле · тип · описание · значение по умолчанию · ограничения):
- `id` · int4 · Идентификатор глобальных настроек отправки сущностей во внешние системы · значение по умолчанию не указано · PK. (5-admin_settings)
- `send_deviation` · boolean · Признак отправки отклонений и событий во внешние системы · true · NOT_NULL. (5-admin_settings)
- `send_monitoring_events` · boolean · Признак отправки событий мониторинга · true · NOT_NULL. (5-admin_settings)
- `send_metric` · boolean · Признак отправки метрик во внешние системы · true · NOT_NULL. (5-admin_settings)

### Бизнес-правила и ограничения
- Первичный ключ: `id`. (5-admin_settings)
- Поля `send_deviation`, `send_monitoring_events`, `send_metric` обязательны (NOT_NULL), значение по умолчанию у каждого — true. (5-admin_settings)
