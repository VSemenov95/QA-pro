# Применение шаблонов метрик в карточке мониторинга

> Создание метрик в карточке мониторинга из готовых шаблонов и управление ими: редактирование порогов, дублирование, отвязка от шаблона и синхронизация с обновлённой версией шаблона.

### Описание
- Пользовательская история (статус «В работе»): «Я как Авторизованный Пользователь хочу создавать метрики на основе готовых шаблонов, управлять ими (редактировать пороги, дублировать, отвязывать от шаблона, синхронизировать с обновлённой версией шаблона) для того, чтобы быстро настраивать типовые расчёты, избегая ручного копирования кода, и при этом иметь возможность кастомизировать критические пороги, а также обновлять атрибуты при изменении шаблона без потери ручных правок». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- История изменений: версия 1 от 08 апр. 2026, автор @Kalinina D.А., «Создана первая версия документа». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Разделы «Контекст», «Пользовательский путь», «Работы вне спецификации», «Допущения и ограничения», «Бизнес-правила», «Атрибуты полей форм», «Правила валидации», «Поиск и фильтрация», «Примечания для Dev/QA» не заполнены; в «Работы в рамках спецификации» только заглушки «Критерии 1.0/2.0/3.0». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)

- Вкладки метрики: «Общие настройки», «Код метрики», «Код автоматического события». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)

### Поля и элементы
- Окно выбора шаблонов: отображаются активные шаблоны метрик; поиск по названию шаблона; выбор группы шаблонов; кнопка «Далее». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Форма параметров: раздел «Общие параметры»; поля по типам переменных; название метрики можно изменить; кнопка «Создать». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Типы параметров и поля: Число -> числовое поле; Строка -> текстовое поле; Метка вычисляемого атрибута -> селект выч.атрибутовметки; Массив чисел -> поле ввода нескольких числовых значений; Массив строк -> поле ввода нескольких строковых значений; Метки вычисляемых атрибутов -> мультиселект выч.меток атрибутов. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Форма редактирования метрики из шаблона: поле «Шаблон» вверху с названием шаблона и ссылкой на него; индикатор «Синхронизировано с шаблоном» (synced_with_template = true) или «Шаблон не синхронизирован» (synced_with_template = false, т.е. шаблон изменён после создания/последней синхронизации); кнопки «Синхронизировать», «Отвязать от шаблона», клонирования метрики, «Сохранить». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Редактируемые поля: «Название», «Статус», «Пороги критичности». Все остальные (единицы измерения, методика расчёта, класс, группы, метки, SQL-скрипт и т.д.) заблокированы (disabled). Вкладка «Код метрики»: все поля disabled. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Индикатор ручного изменения порогов критичности (появляется после изменения порогов). (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Форма клонирования: изменение названия и выбор клонируемых полей: Все, Описание, Методика расчета, Единицы измерения, Периодичность расчета, Параметры критичности, Код метрики, Метки. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Форма параметров при синхронизации: чекбокс «Синхронизировать пороги критичности» (по умолчанию false); кнопка «Сохранить»; кнопки «Продолжить», «Отмена» в окнах подтверждения. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Технические поля: template_id, synced_with_template, manual_intrvals_override, template_parameters_applied, template_parameter. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)

### Бизнес-правила и ограничения
- 1.0: пользователь авторизован в SFERA, имеет Роль 1, открыл карточку мониторинга (вкладка «Метрики»), нажимает «Создать из шаблона» -> окно выбора шаблонов с активными шаблонами метрик. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.1: при выборе группы шаблонов все шаблоны группы автоматически добавляются в выбор. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.2: при вводе текста в поиск по названию список обновляется, отображаются только подходящие шаблоны. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.3: при выбранных нескольких шаблонах (условие ссылается на «Критерий 4.0») и «Далее» открывается форма заполнения значений переменных; названия метрик соответствуют названиям шаблонов, название можно изменить. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.4: параметры разных шаблонов с одинаковым кодом, названием и типом выносятся в «Общие параметры» и заполняются один раз; значения можно заполнить только там, в списке переменных по шаблонам они disabled со значением из общих. Если дефолтные значения отличаются, подставляется первое попавшееся. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.6: если у переменной задано дефолтное значение, поле предзаполнено им. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.7: если не все значения введены, при «Создать» сохранение блокируется, поле подсвечивается ошибкой. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.8: если на форме есть метрики с повторяющимися названиями ИЛИ имя новой метрики совпадает с существующей, при «Создать» — сообщение об ошибке валидации уникальности и возврат к форме параметров. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.9: при успехе для каждого шаблона создаётся метрика в статусе «Подключено». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 1.10: если выбран шаблон, ранее уже применённый в этой карточке, система возвращает ошибку 400. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 2.0: в карточке метрики с template_id != NULL стандартная форма редактирования; редактируются только «Название», «Статус», «Пороги критичности». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 2.2: если напротив порогов критичности включён хотя бы один параметр автогенерации события мониторинга, на вкладке «Код автоматического события» — см. «Настройка автоматического события в карточке метрики». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 2.3: при изменении названия/статуса и «Сохранить» они обновляются, связь с шаблоном сохраняется. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 2.4: при изменении порогов и «Сохранить» пороги сохраняются; устанавливается manual_intrvals_override = true (если пороги отличаются от шаблонных), появляется индикатор ручного изменения; индикатор синхронизации остаётся «Синхронизировано» (если шаблон не изменялся). (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 3.1: при подтверждении клонирования открывается форма создания новой метрики со скопированными выбранными полями; «Название» дополняется префиксом "КОПИЯ"; template_id не заполняется; все поля редактируемы; после сохранения создаётся независимая метрика. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 4.1: после «Продолжить» отвязка: template_id = NULL; synced_with_template = false; template_parameters_applied очищается; форма как у метрики без привязки, все поля редактируемы. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 4.2: при «Отмена» форма возвращается в исходное состояние, связь с шаблоном сохраняется. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.0: при synced_with_template = true индикатор «Синхронизировано с шаблоном», кнопка «Синхронизировать» неактивна. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.1: при synced_with_template = false индикатор «Шаблон не синхронизирован», кнопка «Синхронизировать» активна. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.3: после «Продолжить» система запрашивает у BE список параметров шаблона и сохранённые значения; BE возвращает все параметры шаблона (из template_parameter) и для каждого сохранённое значение (из template_parameters_applied), если есть. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.4: отображаются все параметры обновлённого шаблона; существующие предзаполнены сохранёнными значениями (можно изменить); новые параметры пустые, если нет defaultValue, иначе предзаполнены им; чекбокс «Синхронизировать пороги критичности» (по умолчанию false). (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.5: если не все значения введены, при «Сохранить» сохранение блокируется, поле подсвечивается ошибкой. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.6: при «Сохранить» все поля обновляются по шаблону; пороги: чекбокс false — без изменений, true — перезаписываются из шаблона; SQL-скрипт обновляется с подстановкой новых значений параметров; новые значения сохраняются в template_parameters_applied. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.7: после синхронизации индикатор «Синхронизировано с шаблоном», кнопка «Синхронизировать» неактивна, поля обновлены. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- 5.8: при «Отмена» форма закрывается, сущность не изменяется, статус остаётся «Шаблон не синхронизирован». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)

### Сценарии
- Создание: «Создать из шаблона» -> выбор шаблонов/группы, поиск -> «Далее» -> заполнение параметров -> «Создать» -> метрики в статусе «Подключено» и уведомление. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Редактирование: изменение названия, статуса, порогов -> «Сохранить». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Дублирование: кнопка клонирования -> выбор полей и названия -> подтверждение -> форма новой метрики с префиксом «КОПИЯ» без привязки к шаблону. (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Отвязка: «Отвязать от шаблона» -> модальное окно -> «Продолжить» или «Отмена». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
- Синхронизация: «Синхронизировать» -> предупреждение -> «Продолжить» -> форма параметров с чекбоксом -> «Сохранить» или «Отмена». (11-ТМ. Применение шаблонов метрик в карточке мониторинга)
