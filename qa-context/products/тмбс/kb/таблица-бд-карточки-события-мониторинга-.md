# Таблица БД карточки события мониторинга (название таблицы в документе не указано; файл 11-monitoring_event)

> Таблица БД карточки события мониторинга (файл 11-monitoring_event; название таблицы в документе не указано) хранит события мониторинга со связями с метриками, вычисляемыми атрибутами, кодами отклонений и сервисами.

### Описание
- Назначение таблицы: «Таблица карточки события мониторинга». Название таблицы в документе не указано (файл 11-monitoring_event). (11-monitoring_event)

### Поля и элементы
Структура таблицы (поле · тип · описание):
- id · serial4 · Идентификатор записи события мониторинга (11-monitoring_event)
- monitoring_event_id · int4 · Идентификатор события мониторинга (11-monitoring_event)
- monitoring_card_row_id · int4 · идентификатор карточки мониторинга (11-monitoring_event)
- name · text · Наименование события мониторинга (11-monitoring_event)
- description · text · Описание события мониторинга (11-monitoring_event)
- type · monitoring_event_type · Тип события мониторинга (11-monitoring_event)
- status · metric_status · Статус события мониторинга (11-monitoring_event)
- upload_to_zsm · bool · Признак отправки события мониторинга в ЗСМ (11-monitoring_event)
- script · text · Код события мониторинга (11-monitoring_event)
- alerted_object_url_template · text · Шаблон ссылки на дашборд (11-monitoring_event)
- calculation_period_in_minutes · int4 · Частота запроса (11-monitoring_event)
- create_user_id · int4 · Идентификатор пользователя создавшего события мониторинга (11-monitoring_event)
- create_date · timestamp · Дата создания события мониторинга (11-monitoring_event)
- modify_user_id · int4 · Идентификатор пользователя обновившего события мониторинга (11-monitoring_event)
- modify_date · timestamp · Дата обновления события мониторинга (11-monitoring_event)
- linked_metric_id · int4 · Идентификатор связанной метрики (11-monitoring_event)
- linked_computed_attribute_id · int4 · Идентифкатор связанного выч. атрибута (11-monitoring_event)
- send_interval_value · int4 · описание не указано (11-monitoring_event)
- send_interval_unit · monitoring_event_send_interval_unit · описание не указано (11-monitoring_event)
- notification_group_name · text · Наименование группы оповещений (11-monitoring_event)
- code_deviation_id · uuid · Идентификатор кода отклонения (11-monitoring_event)
- service_id · int4 · Идентификатор сервиса (11-monitoring_event)
- Значения по умолчанию в документе не указаны (в колонке значений по умолчанию для service_id стоит «-»). (11-monitoring_event)

### Бизнес-правила и ограничения
- У поля id указаны PK и NOT_NULL. (11-monitoring_event)
- Поля code_deviation_id и service_id помечены NULLABLE. (11-monitoring_event)
- Комментарий к code_deviation_id: «Идет во 2-ую поставку по ОСУС PPMON-1784 ТМБС. Отправка отклонений в сторонние системы ч2». (11-monitoring_event)
- Комментарий к service_id: «PPBP-2530 [US] Доработка 4-го варианта реализации». (11-monitoring_event)
- Соответствие остальных ограничений и комментариев конкретным полям из текста документа однозначно не определяется. (11-monitoring_event)

### API и интеграции
- upload_to_zsm — признак отправки события мониторинга в ЗСМ. (11-monitoring_event)
- code_deviation_id связано с отправкой отклонений в сторонние системы (ОСУС). (11-monitoring_event)
- Primary Key: id (автоинкремент). (11-monitoring_event)
- Foreign Key: code_deviation_id -> code_deviation.id; service_id -> service.id. (11-monitoring_event)
