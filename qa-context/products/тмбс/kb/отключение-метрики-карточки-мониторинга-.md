# Отключение метрики карточки мониторинга (статус «Отключено вручную»)

> Пользователь может вручную отключить метрику в карточке мониторинга (новый статус «Отключено вручную»), чтобы остановить её расчёт и запись данных, и затем включить её обратно по статусной модели.

### Описание
- Пользовательская история: «Я как Пользователь системы. Хочу Отключить метрику. Для того, чтобы Метрики по БС не рассчитывались так как на текущий момент не актуальны». Пользователю периодически нужно отключать метрики (М) в карточке мониторинга (КМ). (Отключение метрики карточки мониторинга-18)
- Отключение нужно, когда: 1) мониторинг текущей М неактуален; 2) есть ошибка в срабатывании или методике расчёта М, и для обновления методики нужно время и уточнения. Позже пользователь должен включить М. Включение и выключение М останавливает и запускает расчёт показателей по транзакциям. (Отключение метрики карточки мониторинга-18)
- История изменений: версия 1 от 2024-12-13 (@Klimov A. N.) — «Создание документа»; версия 1.1 от 2025-01-16 (Климов А.Н.), задача PPBP-276 [Analytics] 271 «Обновить инструкцию пользователя отключением КТ В работе» — «Исправлены ошибки в документе». (Отключение метрики карточки мониторинга-18)

### Экраны и навигация
- Формы пользовательского интерфейса не изменяются. Статус «Отключено вручную» появляется на UI после добавления со стороны BE. (Отключение метрики карточки мониторинга-18)
- Статус М меняется двумя способами по статусной модели: в режиме просмотра КМ и в режиме редактирования (создания) КМ. Кнопки и действия: «Поставить на мониторинг», «Снять с мониторинга», «Обновить карточку»; раздел списка М в КМ. (Отключение метрики карточки мониторинга-18)

### Поля и элементы
- Таблицы Clickhouse, в которые при отключении М данные не записываются: bs_{%}_metric; bs_{%}_metric_distributed; bs_{%}_metric_last_insert_time_mv; bs_{%}_metric_mv; bs_{%}_metric_queue, где {%} — идентификатор БС, для которого создана М. (Отключение метрики карточки мониторинга-18)
- PostgreSQL: в config_service.metric отключённая М имеет статус DISCONNECTED_MANUAL; в config_service.configuration для application = trmonbs-metrics-calculator-service и key = tm.bsmetrics.{%} в поле value нет записей по отключённой М ({%} — идентификатор БС). (Отключение метрики карточки мониторинга-18)

### Бизнес-правила и ограничения
- Критерии приёмки: 1) отключить М, ранее поставленную на мониторинг; 2) включить ранее отключённую М; 3) отредактировать ранее отключённую М, провести по статусной модели; 4) отключить М, созданную, но не поставленную на мониторинг; 5) включить М без редактирования КМ; 6) выключить М без редактирования КМ. (Отключение метрики карточки мониторинга-18)
- Два статуса выключения: «Отключено» — М отключается вместе с КМ, проставляется автоматически; «Отключено вручную» — отключение пользователем. Оба приводят к отключению М. (Отключение метрики карточки мониторинга-18)
- «Отключено» выставляется только системой при отключении КМ, переводы из него система делает автоматически. «Отключено вручную» выставляется только пользователем; переводы из него делает только пользователь, система изменить не может. (Отключение метрики карточки мониторинга-18)
- Требования к системе: 1) при отключении М данные не пишутся в таблицы мониторинга БС (таблица метрик), т.е. не поступают в таблицы Clickhouse БС; 2) ранее сохранённые данные по М не теряются; 3) при смене статуса для постановки на мониторинг по статусной модели М ставится на мониторинг и данные поступают в таблицы БС; 4) после отключения данные могут поступать, если в темах Kafka не все данные прочитаны; после полной вычитки новые данные не поступают (поступление и обработка в БД идут до полной вычитки). (Отключение метрики карточки мониторинга-18)
- Предупреждение: при отключении и при включении КМ М в «Отключено вручную» статус не меняет (не становится «Отключено» и не становится «На мониторинге»), остаётся «Отключено вручную». Данные по остальным М в «На мониторинге» собираются штатно. (Отключение метрики карточки мониторинга-18)
- Статусная модель (статус — переводы): «Черновик» — начальный статус при создании М, редактирование атрибутов; в «Подключено», «Отключено вручную». «Подключено» — готовность к постановке на мониторинг, атрибуты менять нельзя; в «На мониторинге» (автоматически при постановке КМ на мониторинг), «Отключено вручную», «Черновик». «Отключено» — проставляется автоматически при «Снять с мониторинга», пользователь не может установить его без снятия КМ с мониторинга; в «На мониторинге» (автоматически при постановке КМ). «Отключено вручную» — расчёт не идёт, данные не собираются и не пишутся в таблицы бизнес-сервиса; в «Черновик», «Подключено». «На мониторинге» — данные собираются и пишутся, статус ставится автоматически при постановке КМ; в «Подключено» (пользователем и системой), «Отключено» (системой), «Отключено вручную» (пользователем), «Черновик» (пользователем). (Отключение метрики карточки мониторинга-18)
- Проверка статуса: в «Отключено вручную» только из «Черновик», «Подключено», «На мониторинге»; из него только в «Черновик», «Подключено»; в «Отключено» только при отключении КМ; из «Отключено» только при включении КМ. (Отключение метрики карточки мониторинга-18)
- Логика, режим просмотра КМ. Отключение: 1) открыть КМ с М; 2) сменить статус на «Отключено вручную»; 3) обновить КМ. Итог: данные не считаются и не пишутся в Clickhouse; в config_service.configuration нет записей конфигурации по М; при повторном обновлении КМ и смене версии КМ статус не меняется. Включение: 1) открыть КМ; 2) сменить статус на «Подключено» или «Черновик» (без изменений — «Отключено вручную» → «Подключено»; при изменениях — → «Черновик», изменения, → «Подключено»); 3) обновить КМ, поставить М на мониторинг: статус «На мониторинге», данные собираются, пишутся в Clickhouse, записи в config_service.configuration присутствуют. (Отключение метрики карточки мониторинга-18)
- Логика, режим редактирования КМ. Отключение: 1) открыть КМ и М; 2) создать новую версию КМ; 3) сменить статус на «Отключено вручную»; 4) «Поставить на мониторинг»: статус не меняется, данные не собираются и не пишутся в Clickhouse, записей в config_service.configuration нет. Включение: 1) открыть КМ и М; 2) создать новую версию КМ; 3) сменить статус на «Черновик» или «Подключено» (как выше); 4) поставить КМ на мониторинг: «Подключено» → «На мониторинге», рассчитанные метрики поступают в таблицы БС, записи в config_service.configuration присутствуют. (Отключение метрики карточки мониторинга-18)

### Сценарии
- Только положительные. С редактированием КМ: 1.1 новая версия КМ или черновик, статус М «Черновик» или «Подключено» → сменить на «Отключено вручную», сохранить → «Отключено вручную»; 2.1 черновик КМ, М «Отключено вручную» → сменить на «Черновик» или «Подключено», сохранить → этот статус; 3.1 КМ в «Черновик» или новая версия, «Поставить на мониторинг» → М «Отключено вручную»; 4.1 открыть КМ, «Снять с мониторинга» → М «Отключено вручную». (Отключение метрики карточки мониторинга-18)
- Без редактирования КМ: 5.1 КМ «На мониторинге», М в «На мониторинге», «Черновик» или «Подключено» → сменить на «Отключено вручную», сохранить → «Отключено вручную»; 6 КМ «На мониторинге», М «Отключено вручную» → сменить на «Черновик» или «Подключено», сохранить → этот статус; 7 КМ «На мониторинге», раздел списка М, «Обновить карточку» → М «Отключено вручную». (Отключение метрики карточки мониторинга-18)
