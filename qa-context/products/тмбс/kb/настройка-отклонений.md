# Настройка отклонений

> Раздел администрирования «Настройка отклонений» позволяет управлять отправкой отклонений, событий мониторинга и метрик БС в ЗСМ/ОСУС глобально и по карточкам мониторинга.

### Описание
- Пользователь настраивает через UI отправку отклонений для метрик и событий мониторинга в сторонние системы (ОСУС, ЗСМ). (17-ТМ. Настройка отклонений; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Вторая поставка. Глобальный режим обслуживания включает/выключает отправку событий мониторинга, отклонений и метрик БС для ВСЕХ бизнес-сервисов. Локальный режим делает то же для выбранных БС через Карточки мониторинга. (ТМ. [СА] Настройка отклонений актуальная-29)
- Работы спецификации: страница (КП 1.0–1.4, PPBP-2115); общие настройки (2.0–2.3); КМ в режиме редактирования (3.0–3.3) и просмотра (4.0–4.1); фильтр по статусу (5.0–5.1); поиск (6.0–6.1). Связанные документы: «ТМ. [СА] Настройка отклонеий», «Разрешения для настройки отклонений». (17-ТМ. Настройка отклонений)

### Экраны и навигация
- Меню «Администрирование»: «Контрольные точки», «Источники данных», «События источников данных», «Настройка отклонений». (17-ТМ. Настройка отклонений; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- Страница: блок «Общие настройки» (кнопка «Редактировать», чек-боксы, по умолчанию недоступны) и блок «Карточки мониторинга» (поле «Поиск», фильтр по статусу КМ, таблица, навигация и пагинация). (17-ТМ. Настройка отклонений; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- КП 1.2 (только Разрешение 1): кнопки «Редактировать» нет, чек-боксы задизейблены. (17-ТМ. Настройка отклонений)
- КП 2.0 (режим редактирования): чек-боксы, «Сохранить», «Отменить». КП 2.1 — модалка «Сохранить изменения»: «Изменение данных настроек может повлиять на работоспособность системы. Вы уверены что хотите сохранить изменения?», кнопки «Отменить» и «Сохранить». (17-ТМ. Настройка отклонений)
- Строка таблицы КМ подсвечивается при наведении (КП 3.0, 4.0). Клик открывает форму КМ: ID Карточки; Название карточки; Статус; три чек-бокса; «Частота проверки наличия отклонений» (в режиме редактирования доступны); «Сохранить», «Отменить». (17-ТМ. Настройка отклонений)
- Ошибка 500 (КП 1.4): иконка «500 ошибка», заголовок «Внутренняя ошибка сервера», описание «Пожалуйста, обновите страницу или обратитесь к администратору», кнопка «Обновить». (17-ТМ. Настройка отклонений)

### Поля и элементы
- Чек-боксы общих настроек: «Отправлять отклонения событий мониторинга в ЗСМ»; «Отправлять события мониторинга в ЗСМ»; «Отправлять метрики в ЗСМ». После «Редактировать» становятся доступны. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4; 17-ТМ. Настройка отклонений)
- Столбцы таблицы КМ: ID; Название; Статус; Отпр. отклонений; Отпр. событий; Отпр. метрик. Поиск по «ID» и «Название», сброс крестиком; фильтр статусов списком с чек-боксами. (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)
- DTO отклонения для ЗСМ: title, category, externalId, severity, metricValue — из SQL события мониторинга, обязательны (trmonbs-metrics-threshold-service); application — env TM_MONITORING…APPLICATIONNAME (текст обрезан), обязателен (ecm-integration-service); alertText; ciName — название ЦС из Каталога сервисов (= ChainName ОСУС); ciType — Сервис или Цепочка сервисов, сейчас NULL, необязателен; metricName (= MetricName ОСУС); timeCreated (= DetectionTime ОСУС, из timeAlertCreated); metricKey — SHA256 от полей TM_MONITORINGEVENT_KEYGENERATION_SOURCECOLUMNS (ecm-integration-service); additionalAttributes — NULL. (ТМ. [СА] Настройка отклонений актуальная-29)
- alertId (NULL) и originalData (рекомендовано к удалению) — «Исключен из контракта от 20.03.2026». (ТМ. [СА] Настройка отклонений актуальная-29)
- customAttributes: ppbpNotificationGroup (из поля «Группа оповещений» на FE, если не указана — пустая строка; = NotificationGroup ОСУС); ppbpChainCode («СМБ-БЦ-2185»), ppbpCiIdChain («CI123456»), ppbpCiIdService, ppbpCiIdItSystem — из tm.bsmetrics.<bsId>, обязателен хотя бы один из трёх CiId; ppbpMetricId («1234», Atribute_Id, из tm.bsmetrics.<bsId>, обязателен); ppbpMetricCode («АН.ФИ1», из MetricCode); ppbpInstanceId («PPBP-01», из env CONFIG_MON…, текст обрезан). (ТМ. [СА] Настройка отклонений актуальная-29)
- metricProps (пример для ключей 1157 и 1099): sendingEnabled true, incomeObjectsSeparator «,», alertedObjectUrlTemplate «», alertedObjectUrlSeparator «\n». (ТМ. [СА] Настройка отклонений актуальная-29)

### Бизнес-правила и ограничения
- БД: новая таблица admin_settings; в monitoring_card добавлены send_deviation, send_monitoring_events, send_metric, check_interval_minutes; дефолт новых колонок «false». (ТМ. [СА] Настройка отклонений актуальная-29)
- Метрики (tm.bsmetrics.<bsId>; ppbp-metrics-calculator-service, ppbp-metrics-threshold-service): для БС «На мониторинге» при admin_settings.send_metric=false — exportToKafka=false у всех metrics; при true — по карточкам «На мониторинге»: send_metric карточки false → exportToKafka=false, true → значения из config_service.metric не меняются. (ТМ. [СА] Настройка отклонений актуальная-29)
- События и отклонения (tm.monitoringevent.ecm.bs.<bsId>; ppbp-ecm-integration-service): config_service.monitoring_event: code_deviation_id != null — отклонение, = null — событие. Глобальные send_monitoring_events / send_deviation = false → sendingEnabled=false для metricProps.<monitoringEventId> всех БС; при true смотрится флаг карточки: false → sendingEnabled=false, true → остаются значения upload_to_zsm. (ТМ. [СА] Настройка отклонений актуальная-29)
- Частота: атрибут deviationCalculationIntervalInMinutes в tm.bsmetrics.<bsId> заполняется из monitoring_card.check_interval_minutes для каждого события; trmonbs-metrics-threshold-service применяет его при поиске отклонений в ClickHouse. Чанкование — на стороне ppbp-ecm-integration (текст обрезан). (ТМ. [СА] Настройка отклонений актуальная-29)
- POST /api/authorities/: при objectId=null и отсутствии ALL_OBJECT в ответе исключаются PPBP_ADMIN_SETTINGS_READ и PPBP_ADMIN_SETTINGS_UPDATE. (ТМ. [СА] Настройка отклонений актуальная-29)
- Без Разрешений 1 и 2 — пустые ответы и пустая таблица КМ (КП 1.3). (17-ТМ. Настройка отклонений; Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### API и интеграции
- GET /api/admin-settings/ «Получение списка глобальных интеграционных настроек»: header authorization (JWT, обязателен); ответ boolean (обязательные, по умолчанию false) sendDeviation, sendMonitoringEvents, sendMetric; пример {"sendDeviation":true,"sendMonitoringEvents":false,"sendMetric":true}; 200; ошибки 400, 403, 409, 423, 500; роль Администратор; v1.0, 04 мая 2026. (3-GET  _api_admin-settings_)
- PATCH /api/admin-settings/monitoring-card/{monitoringCardRowId} «Изменение настроек для карточки мониторинга»: JWT; path monitoringCardRowId (int8, обязателен, пример 777); body sendDeviation, sendMonitoringEvents, sendMetric (boolean, необязательны, false), checkIntervalMinutes (int4, обязателен, 1). Ответ — массив: id, cardId, name, status{status,value}, sendDeviation, sendMonitoringEvents, sendMetric, checkIntervalMinutes (обязательны, кроме id, cardId, name); пример status DRAFT «Черновик»; 200; ошибки 400, 403, 409, 423, 500; роль Администратор; v1.0, 04 мая 2026. (6-PATCH _api_admin-settings_monitoring-card_{monitoringCardRowId})

### Сообщения и ошибки
- Успех сохранения — уведомление в правом нижнем углу; иначе уведомление «Ошибка». (Сфера.ТМБС_Руководство_пользователя_PPBP-26.3.0-4)

### Роли и права
- Разрешение 1 (BE) — отображение страницы; Разрешение 2 (FE) — кнопка «Редактировать». Меню требует Роль №1. (17-ТМ. Настройка отклонений)

### Сценарии
- Включение отправки метрик в ЗСМ: export_to_kafka=true в таблице метрик по ID из CSV (temp_migration_ids), затем INSERT в config_service.table_create_records; ожидание 5–30 минут, успех — processed=true, failed=false. (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)

### Открытые вопросы
- В GET и PATCH раздел «Логика работы» пуст; swagger не указан; monitoringCardRowId указан как «header path». (3-GET  _api_admin-settings_; 6-PATCH _api_admin-settings_monitoring-card_{monitoringCardRowId})
- В SA для события указано «!= null» (по смыслу = null); сервисы названы то ppbp-, то trmonbs-. (ТМ. [СА] Настройка отклонений актуальная-29)
- В админ-руководстве SQL использует test_metric и «drop tabletemp_migration_ids». (Сфера.ТМБС_Руководство_администратора_PPBP-26.3.0-4)
