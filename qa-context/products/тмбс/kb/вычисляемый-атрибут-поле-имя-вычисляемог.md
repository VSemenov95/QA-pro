# Вычисляемый атрибут: поле «Имя вычисляемого атрибута» (правила и валидация)

> Поле «Имя вычисляемого атрибута» — обязательное редактируемое поле ввода в карточке мониторинга с именем по умолчанию и проверкой уникальности в рамках карточки.

### Поля и элементы
- Поле «Имя вычисляемого атрибута»: формат/тип элемента — «Поле ввода»; обязательное поле — «Да»; редактируемое поле — «Да». (4-ТМ.06.05.Вычисляемый атрибут)

### Бизнес-правила и ограничения
- При создании вычисляемого атрибута имя устанавливается по умолчанию как "Новый вычисляемый атрибут". (4-ТМ.06.05.Вычисляемый атрибут)
- Пользователь может изменить имя вычисляемого атрибута. (4-ТМ.06.05.Вычисляемый атрибут)
- Имя вычисляемого атрибута не может повторять существующие имена вычисляемого атрибута в карточке мониторинга; имя должно быть уникальным в рамках карточки мониторинга. (4-ТМ.06.05.Вычисляемый атрибут)

### Сообщения и ошибки
- Сообщение об ошибке при нарушении уникальности имени: «Вычисляемый атрибут с таким именем уже существует в карточке мониторинга». (4-ТМ.06.05.Вычисляемый атрибут)
