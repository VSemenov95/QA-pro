# Память агента

Правила из замечаний команды. Агент соблюдает их при генерации и ревью. Строка: «- [генерация|ревью|оба] правило».

- [оба] При возникновении конфликта между требованиями и Правилами для агента — следуй Правилам для агента
- [генерация] Оформляй тела запросов, запросы в БД и примеры сообщений в Kafka в блоках кода с синтаксисом языка запроса
- [генерация] Группируй все связанные предусловия (условия окружения, состояния БД, сообщения из внешних источников) в единое precondition, не разбивая логически связанные элементы на несколько пунктов
