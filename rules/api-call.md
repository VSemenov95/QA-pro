Шаг вызова API описывай только так: «Вызвать МЕТОД ЭНДПОИНТ с телом:», затем пустая строка и блок кода с телом запроса (три обратные кавычки, language json). Метод и эндпоинт пиши прямо в этом шаге: отдельного блока request в кейсе нет. Другие формулировки в этом шаге («отправить запрос», «выполнить», «сделать POST») не используй. Если у запроса нет тела, пиши «Вызвать МЕТОД ЭНДПОИНТ» без двоеточия и блока кода.
