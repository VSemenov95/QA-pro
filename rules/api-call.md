Шаг вызова API описывай только так: «Вызвать МЕТОД {baseURL}/ЭНДПОИНТ с телом:», затем пустая строка и блок кода с телом запроса (три обратные кавычки, language json). Метод и адрес пиши прямо в этом шаге: отдельного блока request в кейсе нет. Другие формулировки в этом шаге («отправить запрос», «выполнить», «сделать POST») не используй. Если у запроса нет тела, пиши «Вызвать МЕТОД {baseURL}/ЭНДПОИНТ» без двоеточия и блока кода.
Адрес вызова API везде — в названии, предусловиях, шагах, ожидаемых результатах и блоках кода — пиши одинаково: {baseURL}/ЭНДПОИНТ, например POST {baseURL}/api/v1/orders. {baseURL} — адрес тестового стенда: пиши его именно так, буквально, без подстановки реального адреса из документации, без http:// и домена и без других вариантов записи ({{baseUrl}}, {base_url}, ${host}). Путь начинается с косой черты.
