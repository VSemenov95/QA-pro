## Что сделать
- Первой укажи основной сценарий (happy path) с kind "positive".
- Для каждого критерия приёмки — позитивная проверка с kind "positive".
- Негативные проверки с kind "negative": ошибочные и отсутствующие данные, отказы, запрещённые действия.
- Граничные проверки с kind "boundary": минимум, максимум, значения на границе допустимого.
- Не придумывай функций, которых нет в требовании. Формулируй каждую проверку одной фразой с ожидаемым поведением, без шагов.
